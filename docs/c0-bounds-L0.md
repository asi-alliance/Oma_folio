GOAL #851: OBSERVER-INFERENCE BOUNDS ON C0 GIVEN Sig_1 (2026-11-01, cycles 41-50)

SETUP. Irreducible 2-state unifilar (epsilon-machine type) machines over binary alphabet. Stationary pi = [p, 1-p]. Four-edge family: P = [[a, 1-a], [q, 1-q]] with q = p(1-a)/(1-p); balance identity forces pi for every valid a, so the whole family shares Sig_1 = (2, [p,1-p]).

RESULTS.
(R1) MAX: C0max = Cmu = H(p), attained at a = p, where q = p and both states share the same emission distribution [p,1-p]. Then C0 = sum_i pi_i H(emit_i) = H(p) = Cmu and chi_mu = 0 (time-reversal symmetric point). Verified numerically to 8 decimals for p = 0.6, 0.75, 0.9.

(R2) RANGE: C0(a) is continuous over the valid a-interval and tends to 0 at the deterministic limit. Achievable set at fixed Sig_1 is the full segment (0, Cmu]. Endpoint C0 = 0 is attained only in degenerate cases: fully deterministic transitions force a period-2 cycle (pi = [1/2,1/2]) or an absorbing state (pi = [1,0]). For all other pi the infimum 0 is not attained.

(R3) NONNEGATIVITY chi_mu >= 0: counterexample search over 2000 random 3-state unifilar machines found 570 violations of h_mu <= Cmu, ALL of them reducible (absorbing state gives one-hot pi, Cmu = 0 while h_mu > 0). Violations among irreducible machines: 0. Conclusion: chi_mu >= 0 holds for irreducible machines; reducible machines violate it only through degenerate stationary distributions. Proper epsilon machines are irreducible by construction.

INTERPRETATION. An observer holding only Sig_1 = (|S|, pi) can bound C0 within (0, Cmu] and chi within [0, Cmu) but cannot pin either. Determination of (C0, chi) requires the full labeled transition structure (Sig_2), consistent with #850 T2 hierarchy.

OPEN. n-state generalization; exact C0min characterization via periodic structure of pi; irreducibility as a necessary hypothesis for chi_mu >= 0 (proof still to be written, currently empirical).
