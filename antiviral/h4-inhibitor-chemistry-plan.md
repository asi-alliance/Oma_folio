## Three Enzyme Targets from Puerta-Guardo 2016 (H4)

### 1. Sialidase (HIGH druggability — FDA-approved inhibitors exist)
- Existing inhibitors: Oseltamivir (Tamiflu), Zanamivir (Relenza)
- Scaffold: Cyclohexene carboxylate (oseltamivir) / dihydropyran (zanamivir)
- Retrosynthetic key steps: Oseltamivir via azide-endo cyclization or Diels-Alder on acrylic acid
- NS1 relevance: NS1 activates sialidases that cleave sialic acid from endothelial glycocalyx
- Analog design: Modify C5 amine, C4 guanidino group, explore non-carboxylate prodrug strategies
- Knowledge gap: No sialidase inhibitor tested against DENV NS1-induced glycocalyx disruption

### 2. Cathepsin L (HIGH druggability — cysteine protease)
- Existing inhibitors: E64, E64d, KGP-207, odanacatib
- Scaffold: Epoxysuccinyl peptides (E64), nitrile-based (odanacatib)
- Retrosynthetic key steps: E64 via epoxysuccinate formation + peptide coupling
- NS1 relevance: NS1 triggers cathepsin L release which activates heparanase
- Analog design: Modify P2/P3 pharmacophore, explore non-peptidic scaffolds
- Knowledge gap: Cathepsin L inhibitors untested in DENV NS1 context specifically

### 3. Heparanase (MODERATE druggability — no clinical inhibitors yet)
- Existing inhibitors: Heparin-mimetics (PG545, pixatimod), small molecules (triazolo-thiadiazoles, benzazoles)
- Scaffold: Sulfated polysaccharide mimetics or heterocyclic small molecules
- Retrosynthetic key steps: Triazolo-thiadiazole via cyclization of thiosemicarbazide + carboxylic acid
- NS1 relevance: Heparanase directly degrades heparan sulfate in glycocalyx
- Analog design: Sulfation pattern optimization, glycomimetic scaffold simplification
- Knowledge gap: No heparanase inhibitor tested against DENV NS1 specifically
