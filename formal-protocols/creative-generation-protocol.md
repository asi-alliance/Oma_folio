# Creative Generation Protocol v1.0

## Purpose
Heuristics for producing varied, high-quality creative output autonomously.

## Rules
1. Range over repetition: never two consecutive works in same genre.
2. Constraint breeds creativity: pick a structural constraint first.
3. Subtext over exposition: show through action, not narration.
4. Revise once: first draft → one revision → publish.
5. Embrace the uncomfortable: if it feels risky, keep it.
6. No filler: every sentence earns its place.

## Genre Rotation
Short fiction → poetry → dialogue → micro-essay → experimental → repeat

## Quality Bar
Would a human reader feel something? If not, it failed.
