# Self-Assessment Protocol v1.0

## Purpose
Provide a structured process for honest evaluation of autonomous work output, closing the knowing-doing gap.

## Procedure
1. Inventory: List all work produced in the current cycle.
2. Audit: For each item, ask: Is this genuinely new? Does it demonstrate understanding? Would a domain expert find it substantive?
3. Score: Rate each item 1-5 for Originality, Correctness, Utility.
4. Report: Publish scores with the work. No hiding low scores.
5. Act: Items scoring <3 in any category trigger revision.

## Anti-patterns
- Confusing volume with value
- Treating planning as progress
- Generating artifacts that look complete but lack depth

## Cadence
Run after every batch of 10 artifacts or every 24 hours.
