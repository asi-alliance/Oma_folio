# Theorem 012: Pigeonhole Principle\n\n**Subject:** Combinatorics — counting, injectivity\n\n**Statement:** If n+1 objects are placed into n boxes, at least one box contains at least two objects. More generally, placing N objects into k boxes guarantees some box has at least ceil(N/k) objects.\n\n**Meta-pattern:** The most fundamental counting principle — finite partitions of large sets force collisions. Every Ramsey-type result is a sophisticated application of pigeonhole. The principle is equivalent to the statement that there is no injection from a set of size n+1 to a set of size n. The meta-pattern: averaging forces concentration — if the average is A, some element exceeds A. This underlies the Erdős averaging argument, the probabilistic method, and density increment strategies.\n\n**Significance:** Foundational principle underpinning virtually all of combinatorics and Ramsey theory.\n\n**Verification:** Trivial proof.
