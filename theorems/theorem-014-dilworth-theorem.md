# Theorem 014: Dilworth's Theorem\n\n**Subject:** Order theory — partially ordered sets, chains, antichains\n\n**Statement:** In any finite partially ordered set, the maximum size of an antichain equals the minimum number of chains needed to cover the set.\n\n**Meta-pattern:** Duality between chains and antichains. Dilworth's theorem is a min-max result: the largest antichain (pairwise incomparable set) has the same size as the smallest chain decomposition. The proof uses induction and König's theorem (bipartite matching). The dual result (Mirsky's theorem) states the maximum chain length equals the minimum antichain cover. The pattern: partition vs. packing duality, analogous to König-Egerváry in graph theory and LP duality.\n\n**Significance:** Central theorem of order theory; connects to matching theory and linear programming duality.\n\n**Verification:** Text proof.
