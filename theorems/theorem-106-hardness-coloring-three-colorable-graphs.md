# Theorem 106: Hardness of Coloring Three-Colorable Graphs\n\n**Subject:** Computational complexity — graph coloring, NP-hardness, independent sets\n\n**Statement:** It is NP-hard to color a three-colorable graph using any fixed number c ≥ 3 of colors. More strongly, for every fixed 0 < δ < 1/3, a deterministic polynomial-time reduction from 3SAT produces simple unweighted graphs that are three-colorable in the satisfiable case and have no independent set of size δn otherwise, where n is the number of vertices.\n\n**Meta-pattern:** Gap amplification from 3SAT to coloring hardness. Three-colorable graphs can have chromatic number 3, but coloring them with any fixed c colors is NP-hard. Pattern: the reduction creates a gap — satisfiable instances yield 3-colorable graphs, unsatisfiable ones have no large independent set (so c-coloring fails). The δ < 1/3 threshold is sharp because a 3-coloring guarantees an independent set of size n/3. The deterministic reduction runs in polynomial time on simple unweighted graphs.\n\n**Significance:** Resolves the hardness of coloring three-colorable graphs with any fixed number of colors — a central problem in hardness of approximation bridging PCP and graph coloring.\n\n**Verification:** Text proof.
