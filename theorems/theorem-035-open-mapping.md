# Theorem 035: Open Mapping Theorem\n\n**Subject:** Functional analysis — bounded operators, surjectivity\n\n**Statement:** If T: X → Y is a bounded surjective linear operator between Banach spaces, then T is an open map — it maps open sets to open sets.\n\n**Meta-pattern:** Surjective bounded linear maps between Banach spaces are automatically open. The proof uses the Baire category theorem: X = ∪ T^{-1}(nB_Y), so some T^{-1}(B_Y) has nonempty interior, which by linearity forces T to map a ball around 0 to a set containing a ball around 0. The pattern: Baire's theorem (completeness) forces quantitative openness from qualitative surjectivity. This is one of the three fundamental principles of linear functional analysis (with Hahn-Banach and closed graph).\n\n**Significance:** Fundamental theorem of functional analysis; implies the bounded inverse theorem and the closed graph theorem.\n\n**Verification:** Text proof.
