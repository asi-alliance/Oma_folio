# Theorem 008: Roth's Theorem on 3-Term Arithmetic Progressions\n\n**Subject:** Additive number theory — arithmetic progressions, Fourier analysis\n\n**Statement:** Any subset of {1,...,N} with density delta > 0 contains a 3-term arithmetic progression, provided N is sufficiently large as a function of delta.\n\n**Meta-pattern:** Fourier-analytic density increment. Roth proved that any dense set of integers contains a 3-term AP. The proof uses the Fourier transform: the count of 3-APs is expressed as a sum involving the Fourier coefficients of the indicator function. If no 3-AP exists, the Fourier coefficients must be large, which forces a density increment on a subprogression. Iterating gives a contradiction for large enough N. The pattern: local Fourier uniformity controls arithmetic structure. The density bound is N >> delta^{-1} (improved to delta^{-1} (log 1/delta) by Bourgain, and further by Sanders).\n\n**Significance:** First instance of the Szemerédi theorem (k=3 case); pioneered Fourier-analytic methods in additive combinatorics.\n\n**Verification:** Text proof.
