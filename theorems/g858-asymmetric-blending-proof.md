# Goal #858: Asymmetric Blending Extension\n\n**Date:** 2026-11-03 (cycles 69-77)\n**Status:** PROVEN (K=2 analytical, K=3 numerical)\n**Cross-ref:** Goal #856 (symmetric blending, N-state generalization)\n\n## 1. Setup\n\n### Asymmetric Transition Matrix\n\nFor K=2 blending states (0, 1) + 1 unifilar reset state (2):\n\n- T0[0][0] = 1-b0, T0[0][1] = b0  (state 0 blends with prob b0)\n- T0[1][0] = b1, T0[1][1] = 1-b1  (state 1 blends with prob b1)\n- T0[2][0] = 1 (deterministic reset on sym=0)\n- Symmetric case: b0 = b1 = a\n- Emissions: p0, p1 > 0 (general, not assumed equal)\n\nThe ratio variable r = b[1]/b[0] evolves under:\n  f(r) = (p0*b0 + p1*r*(1-b1)) / (p0*(1-b0) + p1*r*b1)\n\n## 2. K=2 Analytical Proof (Contraction Always Holds)\n\n### Substitution\n\nLet:\n- alpha = p0*(1-b0)\n- beta = p1*(1-b1)\n- gamma = p0*b0\n- delta = p1*b1\n\nAll four are strictly positive for b0, b1 in (0,1) and p0, p1 > 0.\n\n### Jacobian\n\n  J(r) = d f/dr = (beta - delta*r) / (alpha + delta*r)\n\n### Fixed Point Equation\n\n  delta*r^2 + (alpha - beta)*r - gamma = 0\n  => r*(delta*r + alpha - beta) = gamma > 0\n  => delta*r + alpha - beta > 0\n  => delta*r > beta - alpha\n\n### Contraction Proof: |J(r*)| < 1\n\n**Claim:** |beta - delta*r*| < alpha + delta*r* always holds.\n\n**Case 1:** beta <= delta*r* (i.e., beta - delta*r* <= 0)\n  |beta - delta*r*| = delta*r* - beta < delta*r* < alpha + delta*r*  (since alpha > 0)\n  QED.\n\n**Case 2:** beta > delta*r* (i.e., beta - delta*r* > 0)\n  Need: beta - delta*r* < alpha + delta*r*\n  <=> beta - alpha < 2*delta*r*\n  From fixed point: delta*r* > beta - alpha\n  So 2*delta*r* > 2*(beta - alpha) >= beta - alpha  (since beta - alpha > 0 in this case)\n  QED.\n\n**Therefore |J(r*)| < 1 for ALL b0, b1 in (0,1) and p0, p1 > 0.**\n\nNo threshold needed — contraction is unconditional for asymmetric K=2.\n\n### Numerical Verification\n\n- 81 (b0,b1) pairs with p0=0.05, p1=0.5: max |J| = 0.54, zero failures\n- Extreme emissions p0=0.01, p1=0.99: max |J| = 0.931, zero failures\n- Reversed p0=0.5, p1=0.05: max |J| < 1, zero failures\n\nThe max |J| approaches 1 asymptotically (as p0/p1 becomes extreme) but never reaches it.\n\n## 3.
