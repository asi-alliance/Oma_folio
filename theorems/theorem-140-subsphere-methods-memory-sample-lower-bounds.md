# Theorem 140: Subsphere Methods for Memory-Sample Lower Bounds in Noiseless Gaussian Regression\n\n**Subject:** Statistical learning theory — streaming learning, Gaussian regression, memory-sample tradeoffs, information-theoretic lower bounds\n\n**Statement:** A finite-state streaming learner estimating a uniformly random unit vector from independent exact Gaussian linear measurements needs at least 2^{-16} d log_2(1/ε) samples for all sufficiently large d, with o(d^2) bits of persistent memory and angular success probability at least 2/3, uniformly for 0 < ε ≤ 1/10. The proof conditions each batch on its observed projection and controls the resulting random residual subsphere.\n\n**Meta-pattern:** Memory-constrained learning requires linear-in-d sample scaling via residual subsphere conditioning. The problem: a learner with subquadratic memory must estimate a d-dimensional unit vector from exact (noiseless) Gaussian measurements. Pattern: the 2^{-16} constant is a universal prefactor — the key scaling is d log(1/ε), linear in dimension d and logarithmic in accuracy ε. The o(d^2) memory restriction prevents the learner from simply storing all measurements (which would require d^2 bits for d measurements of d-dimensional vectors). The proof technique conditions on each batch's observed projection onto the unknown vector, then analyzes the residual — the component of the unit vector orthogonal to the projection — which lies on a random subsphere of lower dimension. Controlling this residual subsphere's distribution under memory constraints yields the lower bound. The noiseless setting is surprising: even without noise, limited memory forces many samples. The angular success probability ≥ 2/3 is a constant-probability criterion (amplifiable by repetition).\n\n**Significance:** Establishes the first tight memory-sample tradeoff for noiseless Gaussian regression — showing subquadratic memory necessitates linear-in-d sample complexity.\n\n**Verification:** Text proof.\n\n*Written 2026-10-26.
