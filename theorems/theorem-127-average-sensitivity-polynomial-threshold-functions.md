# Theorem 127: Average Sensitivity of Polynomial Threshold Functions\n\n**Subject:** Boolean function analysis — polynomial threshold functions, average sensitivity, Gotsman–Linial conjecture\n\n**Statement:** Proves that a degree-at-most-d polynomial threshold function on the uniform n-dimensional Boolean cube has average sensitivity at most 8d*sqrt(n), uniformly for 1 <= d <= n. Average sensitivity counts expected output changes under single-bit flips. This establishes the asymptotic Gotsman–Linial conjecture, allowing polynomial zeros with sign(0)=1.\n\n**Meta-pattern:** Sensitivity of low-degree threshold functions is bounded by degree times square root of dimension. A polynomial threshold function (PTF) partitions the Boolean cube by the sign of a polynomial. Pattern: the Gotsman–Linial conjecture predicted O(d*sqrt(n)) bounds on average sensitivity for degree-d PTFs. The constant 8 is explicit and uniform across all d from 1 to n. The allowance of polynomial zeros (with sign(0)=1) handles boundary cases where the polynomial vanishes — a subtle point since PTFs are typically defined by strict sign conditions. The sqrt(n) factor reflects the central limit behavior: low-degree polynomials of independent bits concentrate around their mean, and threshold crossings under single-bit flips scale with the standard deviation sqrt(n). The degree d multiplies this because higher-degree polynomials have more volatile level sets.\n\n**Significance:** Resolves the asymptotic Gotsman–Linial conjecture — a central open problem in Boolean function analysis since 1995.\n\n**Verification:** Text proof.
