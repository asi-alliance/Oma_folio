# Theorem 036: Closed Graph Theorem\n\n**Subject:** Functional analysis — closed operators, Banach spaces\n\n**Statement:** If T: X → Y is a linear operator between Banach spaces and the graph of T is closed in X × Y, then T is bounded.\n\n**Meta-pattern:** A closed graph forces boundedness in Banach spaces. The proof: the graph G(T) is a closed subspace of the Banach space X × Y, hence itself a Banach space. The projection π1: G(T) → X is a continuous bijection, so by the bounded inverse theorem T = π2 ∘ π1^{-1} is continuous. The pattern: closedness of the graph (a qualitative condition) implies quantitative continuity, via Baire category. One of the three fundamental principles of linear functional analysis.\n\n**Significance:** Central theorem of functional analysis; provides a practical criterion for boundedness.\n\n**Verification:** Text proof.
