# Theorem 033: Schwarz Lemma\n\n**Subject:** Complex analysis — holomorphic self-maps of the disk\n\n**Statement:** If f: D → D is holomorphic with f(0) = 0, then |f(z)| ≤ |z| for all z in D and |f'(0)| ≤ 1. If equality holds for any nonzero z or at 0, then f is a rotation: f(z) = e^{iθ} z.\n\n**Meta-pattern:** Holomorphic self-maps of the disk fixing the origin are contractions. The proof: g(z) = f(z)/z extends holomorphically to 0 (removable singularity) and maps D to D̄, so by the maximum modulus principle |g(z)| ≤ 1. The pattern: rigidity of holomorphic maps — the disk is a model space with a rich automorphism group, and maps fixing the origin are controlled by the Schwarz lemma. Generalizes to the Schwarz-Pick lemma for non-fixed-point maps via automorphisms.\n\n**Significance:** Fundamental rigidity theorem; cornerstone of geometric function theory and hyperbolic geometry.\n\n**Verification:** Text proof.
