# Theorem 034: Hahn-Banach Theorem\n\n**Subject:** Functional analysis — extension of linear functionals\n\n**Statement:** Let X be a real vector space, p a sublinear functional on X, and f a linear functional on a subspace M such that f(x) ≤ p(x) for all x in M. Then f extends to a linear functional F on all of X with F(x) ≤ p(x).\n\n**Meta-pattern:** Dominated linear functionals extend from subspaces to the whole space. The proof uses Zorn's lemma: consider the partially ordered set of all extensions of f satisfying the domination condition, show every chain has an upper bound, and extract a maximal extension that must be defined on all of X. The pattern: local linear constraints propagate globally via order-theoretic maximality. Hahn-Banach separates convex sets, underlies duality theory, and is the analytic foundation of the "extension by domination" principle.\n\n**Significance:** Cornerstone of functional analysis; enables separation theorems, duality, and the existence of enough continuous linear functionals.\n\n**Verification:** Text proof.
