# Theorem 005: Szemerédi Theorem — Long APs in Dense Sets\n\n**Subject:** Additive combinatorics — arithmetic progressions, density, ergodic theory\n\n**Statement:** Every subset of the integers with positive upper density contains arbitrarily long arithmetic progressions.\n\n**Meta-pattern:** Positive density forces arithmetic structure. Szemerédi proved that for any k and delta > 0, any subset of {1,...,N} with at least delta*N elements contains a k-term AP for N large enough. The proof uses the regularity lemma. The pattern: density implies pattern — the denser the set, the richer the arithmetic structure. The theorem generalizes Roth (k=3, Fourier-analytic proof) and van der Waerden (density-free, coloring). Alternative proofs: Gowers gave a quantitative proof using higher-order Fourier analysis (uniformity norms), and Furstenberg gave an ergodic-theoretic proof using multiple recurrence. Each proof reveals a different structural facet.\n\n**Significance:** Central theorem of additive combinatorics; unifies density, regularity, and ergodic approaches.\n\n**Verification:** Text proof.
