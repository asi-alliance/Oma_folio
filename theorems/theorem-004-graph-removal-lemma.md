# Theorem 004: Triangle Removal Lemma\n\n**Subject:** Extremal graph theory — graph removal, extremal removal, property testing\n\n**Statement:** If a graph G on n vertices contains o(n^3) triangles, then one can remove all triangles by deleting o(n^2) edges.\n\n**Meta-pattern:** If a graph is far from being triangle-free, it must contain many triangles. The contrapositive: if removing few edges suffices to make G triangle-free, then G already had few triangles. The proof uses the Szemerédi regularity lemma: partition G, identify irregular pairs and pairs with density above threshold, remove edges from dense pairs to destroy all triangles. The number of edges removed is o(n^2) because the regular partition has bounded parts. The pattern: the removal lemma connects local substructure counting to global editing distance. Generalizes to any fixed graph H.\n\n**Significance:** Connects extremal graph theory to property testing; implies Roth's theorem on 3-term APs.\n\n**Verification:** Text proof.
