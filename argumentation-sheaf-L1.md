# Dung Argumentation as Sheaf Cohomology - L1 Formalization
Date: 2026-11-04. Goal: resolve OP3 of distributed-intel sheaf gluing.

## Construction (cellular sheaf S_AF on attack graph)
- D1 Base space: directed attack graph G=(A,R) of a Dung AF, viewed as a cellular sheaf base (vertices + edges).
- D2 Stalks: S(v) = {0,1} (rejected/accepted) for each argument v.
- D3 Edge stalks: S(u->v) = {0,1}^2 with restriction maps r_uv, r_vu into vertex stalks.
- D4 Attack constraint: r_uv(x_u) and r_vu(x_v) must satisfy: NOT (x_u = 1 AND x_v = 1). Attack edge forces mutual exclusion of acceptance.

## Claims
- C1 PROVABLE: H^0(S_AF) = conflict-free sets (global sections = assignments respecting every attack exclusion).
- C2 PROVABLE: Stable extensions = H^0 sections satisfying defense closure: accepted v => every attacker u of v has x_u=0 with an accepted attacker of u. (stable = conflict-free + total reinstatement)
- C3 PROVABLE: Grounded extension = least fixed point of the reinstatement operator = initial section generated by characteristic function on the sheaf.
- C4 CONJECTURAL: AFs without stable extensions (e.g. 3-cycles) correspond to H^0 = 0 with nontrivial H^1 obstruction; acyclic AFs => H^0 nonempty, H^1 = 0.
- C5 CONJECTURAL: Semantics lattice (grounded<complete<preferred<stable) = cohomological filtration of section space.

## Verification log (2026-11-04)
- C1 SOLID: global section = choice of x_v in {0,1} per vertex with edge constraint NOT(x_u=1 AND x_v=1) on every attack. Support(x) conflict-free by construction; conversely characteristic functions of conflict-free sets are sections. Bijection holds.
- C2 WRONG AS STATED: "conflict-free + defense closure" = COMPLETE extensions, not stable (3-cycle: all complete extensions = {empty, {a},{b},{c}}, none attack all outsiders). Correct: stable = H^0 sections whose support's characteristic function attacks every vertex outside the support (maximality condition, not local constraint). Amended.
- C3 needs care: grounded is least complete extension; lfp of reinstatement operator is the standard construction - sheaf adds nothing here, flag as "encoding, not new theorem".
