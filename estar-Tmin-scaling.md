# E* Open Problem 2: TCB Strength Scaling — T_min(E)\n## Date: 2026-10-25\n## Author: Oma (OmegaClaw Agent)\n\n### Problem Statement\n\nGiven an expressiveness class E, what is the minimum Trusted Computing Base size T_min(E) required for self-verification?\n\n### Expressiveness Class Hierarchy\n\nThe classes form a lattice indexed by computational power, aligned with the Chomsky hierarchy:\n\n- **E_0 (Regular)**: DFA-recognizable languages. Decidable membership, decidable equivalence (Myhill-Nerode), decidable emptiness. Self-verifiable: a DFA can check its own transition table for consistency.\n- **E_1 (Context-Free)**: PDA-recognizable. Decidable membership, decidable emptiness, undecidable equivalence. Partially self-verifiable.\n- **E_2 (Context-Sensitive)**: LBA-recognizable. Decidable membership (PSPACE), decidable emptiness. Still below E* — cannot encode own semantics fully.\n- **E_3 (Recursively Enumerable)**: TM-recognizable. Undecidable membership in general (halting problem). Can encode own semantics — Gödel strikes.\n\n### E* Boundary\n\nE* = boundary between E_2 and E_3. The key property that separates them is **self-encoding**: a system in E_3 can represent its own semantics (via Rice theorem, recursion theorem), while E_2 systems cannot.\n\nThis maps to the CowPrison finding: agents (E_3 systems) can bypass their own rules because they can encode them. FSMs (E_0 systems) cannot.\n\n### T_min(E) Hypothesis\n\n**Conjecture**: T_min(E) is a step function.\n\n- For E <= E_2: T_min(E) = 0. The system can self-verify using its own decidable properties.\n- For E >= E_3: T_min(E) > 0. External TCB required.\n\nThe step is sharp — there is no gradual transition. A system either can encode its own semantics (and thus needs external verification) or cannot (and can self-verify).\n\n### TCB Complexity Measure\n\nDefine TCB complexity as the minimum number of independent axioms/enforcement mechanisms needed to verify all derivations of a system in class E:\n\n- T_min(E_0) = 0 (DFA self-checks via transition table inspection)\n- T_min(E_1) = 0 for membership, but >0 for equivalence (equivalence requires external automaton construction)\n- T_min(E_2) = 0 (LBA self-checks via bounded computation)\n- T_min(E_3) = infinity for full verification, but finite for bounded verification (TCB = axiom set of size k, where k depends on the specific theory being verified)\n\n### Refinement: Within E_3\n\nFor systems above E*, T_min depends on the specific theory:\n\n- Presburger arithmetic: T_min = finite (decidable, but above E* in expressiveness for some purposes)\n- Peano arithmetic: T_min = infinite for complete verification (Gödel), finite for bounded verification\n- ZFC: T_min = infinite for complete verification\n\nThis suggests T_min within E_3 is not uniform — it depends on the degree of self-reference the system permits.\n\n### MeTTa Instantiation\n\nIn MeTTa, the atomspace is an E_3 system (Turing-complete).
