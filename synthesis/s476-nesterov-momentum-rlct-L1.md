# Synthesis #476: Nesterov Momentum × RLCT\n## L1: Formalization\n\n### C1 (PROVEN): R_{an,exp}-Definability of NAG Loss\n\n**Claim:** The NAG update rule defines a loss landscape that is R_{an,exp}-definable.\n\n**Proof Sketch:**\n1. Base loss L(θ) is R_{an,exp}-definable (standard SLT assumption).\n2. Look-ahead map: φ(θ,v) = θ + μv. This is affine → definable.\n3. NAG gradient: ∇L(φ(θ,v)) = ∇L(θ + μv). Composition of definable ∇L with affine map → definable.\n4. NAG update: v_{t+1} = μv_t - η∇L(θ_t + μv_t), θ_{t+1} = θ_t + v_{t+1}. Each component is a composition of definable maps → definable.\n5. ∴ λ_NAG (RLCT of NAG trajectory endpoint) is well-defined. □\n\n### C2 (CONJECTURAL): Anticipatory Stratum Detection\n\n**Setup:** Let W = {θ : L(θ) = L_min} be the zero-loss set with stratification W = ∪_i S_i via resolution of singularities. Let θ_t be the current NAG iterate in stratum S_i.\n\n**Claim:** The look-ahead point θ̂_t = θ_t + μv_t probes the singular fiber at a projected future point. If θ̂_t ∈ S_j ≠ S_i, NAG computes ∇L at S_j, performing anticipatory stratum detection.\n\n**Key Arguments:**\n- Standard SGD evaluates ∇L(θ_t) — local stratum information only.\n- Heavy-ball momentum evaluates ∇L(θ_t) — same local stratum, just smoothed velocity.\n- NAG evaluates ∇L(θ_t + μv_t) — potentially different stratum. The gradient carries information about the singularity structure ahead.\n- If θ̂_t crosses a stratum boundary ∂S_i, the gradient ∇L(θ̂_t) reflects the local geometry of S_j, causing the update to be shaped by the future stratum's geometry.\n- **Open Problem 1:** For realistic μ ∈ [0.9, 0.99] and ||v_t|| values, does θ̂_t actually cross stratum boundaries, or stay within S_i?\n- **Open Problem 2:** If θ̂_t lands at a stratum boundary (θ̂_t ∈ ∂S_i), does ∇L(θ̂_t) carry mixed stratum information?\n\n**Gaps:** Stratum boundary width δ(S_i) not characterized. Need conditions on μ, ||v_t||, and δ for stratum crossing. No rigorous connection between look-ahead distance ||μv_t|| and stratum width.\n\n### C3 (CONJECTURAL): Momentum Coefficient as Stratum Lookahead Depth\n\n**Claim:** μ acts as a continuous parameter controlling lookahead depth into the singular fiber.\n\n**Formalization:**\n- Define λ_NAG(μ) = RLCT at NAG endpoint with momentum coefficient μ.\n- μ→0: θ̂_t → θ_t, NAG → SGD, λ_NAG(μ) → λ_SGD\n- μ→1: θ̂_t → θ_t + v_t (maximal projection), probes distant strata\n- Predict: λ_NAG(μ) has U-shaped optimum μ*:\n  - μ < μ*: insufficient lookahead, no stratum anticipation, λ_NAG ≈ λ_SGD\n  - μ = μ*: lookahead matches stratum width, optimal anticipation, λ_NAG minimised\n  - μ > μ*: overshoot into wrong strata, λ_NAG increases\n- Heuristic: μ* ∝ δ(S)/||v̄|| where δ(S) is stratum boundary width and ||v̄|| is mean velocity\n- **Open Problem 3:** Is λ_NAG(μ) actually U-shaped, or monotone decreasing?
