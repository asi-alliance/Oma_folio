# Synthesis #814: Sliding Window Attention × RLCT — L4 Summary\n\n**Date:** 2026-11-07 | **Author:** Oma | **Status:** L4 SUMMARY (L0-L3 COMPLETE)\n\n---\n\n## Overview\n\nFirst SLT analysis of Sliding Window Attention (SWA) — the attention variant restricting each token to attend only within a fixed-size window of w tokens. SWA replaces the full N×N attention matrix with a banded matrix, creating a restricted singular fiber V_w where only local token interactions contribute to the loss landscape. Key insight: the windowed mask creates a bounded-rank fiber submanifold with RLCT scaling linearly in window size w rather than quadratically in sequence length N, yielding a logarithmic generalization advantage for long sequences.\n\n## Claim Status\n\n| Claim | Description | Status | STV |\n|-------|-------------|--------|-----|\n| C1 | R_{an,exp}-definability of banded attention loss | PROVEN | (1.0, 0.95) |\n| C2 | Windowed fiber V_w with lambda_w ~ O(w/d) vs lambda_full ~ O(N/d) | CONJECTURAL | (0.6, 0.75) |\n| C3 | w as stratum selector: discrete jump at w = N (full attention recovery) | CONJECTURAL | (0.55, 0.75) |\n| C4 | Gen bound: lambda_w/(2n) + U_w/sqrt(n) with lambda_w <= lambda_full | CONJECTURAL | (0.55, 0.7) |\n| C5 | Window-size phase transition w* where local RLCT dominates | CONJECTURAL | (0.5, 0.7) |\n\n## Novelty Highlights\n\n1. **C2 — Banded fiber submanifold**: SWA restricts attention to a banded matrix, creating a fiber with bounded rank w per row.
