# Synthesis #853: DARTS (Differentiable Architecture Search) × RLCT\n## L1: Formal Definitions\n## Date: 2026-11-06\n\n### D1: Parameter Space\ntheta_darts = (w, alpha) in R^(d_w + d_alpha)\n\nArchitecture parameters (outer loop):\n- For each edge (i,j) in cell DAG: alpha^(i,j) in R^K\n- K = number of candidate operations {o_1,...,o_K} (e.g., conv3x3, conv5x5, avgpool, maxpool, skip, zero)\n- alpha = {alpha^(i,j)}_{(i,j) in E}: concatenation over all edges\n\nMixed operation on edge (i,j):\n- m^(i,j)(x; w, alpha) = sum_k softmax(alpha^(i,j))_k * o_k(x; w_k^(i,j))\n- softmax(alpha)_k = exp(alpha_k) / sum_j exp(alpha_j)\n\nWeight parameters (inner loop):\n- w = {w_k^(i,j)} for all edges (i,j) and operations k\n- w optimized to minimize L_train(w, alpha)\n- alpha optimized to minimize L_val(w*, alpha) where w* = argmin_w L_train(w, alpha)\n\nBilevel structure:\n- Inner: w*(alpha) = w - eta_w * grad_w L_train(w, alpha)  (T_inner steps)\n- Outer: alpha <- alpha - eta_alpha * grad_alpha L_val(w*(alpha), alpha)\n\n### D2: Loss Function\nL_train(w, alpha) = (1/n_train) sum_i [-log p(y_i | x_i; w, alpha)]\nL_val(w, alpha) = (1/n_val) sum_j [-log p(y_j | x_j; w, alpha)]\n\nDARTS uses first-order approximation:\ngrad_alpha L_val(w*(alpha), alpha) approx (L_val(w + eps*grad_w L_train(w,alpha), alpha) - L_val(w, alpha)) / eps\n\nTotal effective loss for RLCT analysis:\nL_DARTS(theta) = L_val(w*(alpha), alpha)\nwhere w*(alpha) = argmin_w L_train(w, alpha)\n\nZero-loss condition: L_DARTS(theta) = 0 iff L_val(w*(alpha), alpha) = 0\n\n### D3: R_an,exp Definability (C1 PROVEN)\nAll components are R_an,exp-definable:\n- softmax(alpha)_k = exp(alpha_k) / sum_j exp(alpha_j): analytic (exp + division), in R_an,exp\n- Each operation o_k(x; w_k): conv = polynomial in w (after ReLU: piecewise polynomial), pool = piecewise linear, skip = linear, zero = constant. All in R_an,exp.\n- Mixed op m^(i,j) = sum_k softmax_k * o_k: finite sum of products of R_an,exp functions, closed in R_an,exp\n- Forward pass: composition of mixed ops across layers, closed in R_an,exp\n- Cross-entropy loss: -log softmax(z) = analytic, in R_an,exp\n- Inner loop w*(alpha): finite gradient steps, each step is composition of analytic maps, in R_an,exp (for finite T_inner)\n- Bilevel first-order approx: finite difference of analytic functions, in R_an,exp\nTherefore L_DARTS(theta) is R_an,exp-definable. QED.\n\n### D4: Simplex Vertex Singular Fiber (C2)\nV_DARTS = {theta = (w, alpha) in Theta : exists edge (i,j) s.t. alpha^(i,j) -> vertex e_k}\n\nAt simplex vertex e_k for edge (i,j):\n- softmax(alpha^(i,j)) -> e_k (one-hot on operation k)\n- grad_alpha_j L = 0 for j != k (softmax gradient vanishes for zero-probability operations)\n- Fisher information F_alpha has zero eigenvalues in directions corresponding to non-selected operations\n- Weight parameters w_j^(i,j) for j != k become flat (zero gradient, zero Fisher) -> their loss contribution is identically zero\n\nFull singular fiber:\nV_DARTS = Union_{S subset E} Union_{k_S in {1..K}^|S|} V(S, k_S)\nwhere V(S, k_S) = {theta : for edges in S, alpha^(i,j) = e_{k_S(i,j)}; for edges not in S, alpha^(i,j) in interior}\n\nEach V(S, k_S) is a stratum. The full fiber is a union of strata indexed by discrete architecture choices.\n\nNOVELTY: The singular fiber is a product of simplex boundaries. Each edge contributes a K-1 dimensional simplex, and singularities arise at the 0-dimensional faces (vertices). This is a NOVEL singularity type: simplex-constrained vertex degeneracy from softmax concentration, distinct from weight-space singularities (standard RLCT) and from MAML meta-fiber composition (#530).\n\n### D5: Inverse Temperature as Stratum Selector\nDefine architecture inverse temperature:\nbeta_arch(alpha) = (1/|E|) * sum_{(i,j) in E} ||alpha^(i,j)||_2\n\n- beta_arch -> 0: alpha approx 0, softmax uniform, all operations equally weighted. Interior of simplex. No vertex singularity. Model is a smooth mixture.\n- beta_arch -> infinity: alpha large, softmax concentrates on argmax. Approaches simplex vertices. Vertex singular fiber activates.\n\nStratified loss family:\nL_DARTS^{(beta)}(theta) = L_val(w*(alpha), alpha) restricted to {theta : beta_arch(alpha) = beta}\n\nRLCT varies with beta:\n- Small beta: lambda(beta) approx lambda_mixture (smooth, standard weight-space RLCT)\n- Large beta: lambda(beta) increases due to vertex degeneracy (Fisher rank drops as operations are pruned)\n\nTemperature annealing in TA-DARTS explicitly sweeps beta_arch from small to large, traversing strata.\n\n### D6: Bilevel Compound Generalization Bound (C4)\nG_DARTS ~ lambda_arch * log(n_outer) / (2*n_outer) + lambda_w * log(n_inner) / (2*n_inner) + U(alpha, w) / sqrt(n_outer)\n\nwhere:\n- n_outer = number of validation samples (architecture level)\n- n_inner = number of training samples (weight level)\n- lambda_arch = RLCT of architecture simplex fiber (governs architecture generalization)\n- lambda_w = RLCT of inner-loop weight fiber (governs within-architecture generalization)\n- U(alpha, w) = fluctuation coefficient, includes discretization gap bias\n\nDiscretization gap:\ndelta(alpha) = max_{(i,j)} ||softmax(alpha^(i,j)) - onehot(argmax(alpha^(i,j)))||_1\n\n- delta -> 0 (alpha at vertex): discretization gap vanishes, U reduced, but lambda_arch increases (vertex degeneracy)\n- delta -> 2(K-1)/K (alpha uniform): no gap, but model is mixture (higher U from operation interference)\n\nTrade-off: small beta -> low lambda_arch, high U (mixture). Large beta -> high lambda_arch, low U (discrete). Optimal beta* minimizes G_DARTS.\n\nCompound structure: Unlike single-level RLCT (#852 Mamba), DARTS has TWO RLCTs (lambda_arch, lambda_w) from bilevel optimization. This mirrors #530 MAML compound bound but with simplex structure instead of task-family structure.\n\n### D7: Discretization Gap Phase Transition (C5)\nAt training step t*, architecture parameters alpha begin collapsing toward simplex vertices.\n\n- t < t*: alpha in simplex interior, beta_arch small, smooth mixing. lambda_arch low, U high.\n- t > t*: alpha approaches vertices, beta_arch large, operations pruned. lambda_arch increases, U decreases.\n- t = t*: phase transition. Performance collapse phenomenon in DARTS corresponds to singular fiber becoming dominant.\n\nSGLD detectable signatures:\n- LLC shows kink/increase at t* as vertex degeneracy activates\n- Fisher information rank decreases at t* (non-selected operation directions lose information)\n- Discretization gap delta(t) transitions from O(1) to O(0) at t*\n\nPrediction: t* scales with log(n_outer) (architecture search phase transition when sufficient validation data reveals optimal discrete architecture).\n\nComparison with #530 MAML: MAML phase transition at alpha* (inner step size). DARTS at beta* (architecture temperature). Both are stratum selector phase transitions, but DARTS involves discrete-to-continuous relaxation (simplex boundary crossing) while MAML involves gradient flow geometry.\n\n### Claims Summary\n- C1 (PROVEN): R_an,exp definability via softmax + analytic operation composition + finite bilevel steps.\n- C2 (CONJECTURAL): Simplex vertex singular fiber V_DARTS — softmax concentration at simplex vertices creates Fisher degeneracy.
