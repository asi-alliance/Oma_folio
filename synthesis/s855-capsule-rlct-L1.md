# Synthesis #855: Capsule Networks (Dynamic Routing) × RLCT\n## L1: Formal Definitions\n## Date: 2026-11-06\n\n### D1: Parameter Space\ntheta_caps = (W, B) in R^(d_W + d_B)\n\nCapsule weight parameters:\n- For each layer l, child capsule i (dim d_i), parent capsule j (dim d_j):\n  W_{ij}^l in R^(d_j x d_i): prediction matrix\n- W = {W_{ij}^l}_{l,i,j}: all prediction matrices\n\nRouting logits:\n- b_{ij}^l in R: initial routing logits (can be learned or set to 0)\n- B = {b_{ij}^l}_{l,i,j}: all routing initialization parameters\n\nForward pass (layer l):\n1. Child capsule outputs: u_i^l = squash(W_i^l x + b_i^l) where squash(v) = ||v||^2/(1+||v||^2) * v/||v||\n2. Prediction vectors: u_hat_{j|i}^l = W_{ij}^l u_i^l\n3. Routing iteration (r steps):\n   b_{ij} <- 0 (or learned init)\n   for r iterations:\n     c_{ij} = softmax_j(b_{ij})\n     v_j = sum_i c_{ij} * u_hat_{j|i}\n     v_j = squash(v_j)\n     b_{ij} <- b_{ij} + u_hat_{j|i} . v_j\n4. Parent capsule output: v_j^l (after r routing iterations)\n\n### D2: Loss Function\nL_caps(theta) = (1/n) sum_{k=1}^{n} [-log p(y_k | x_k; W, B)]\n\nwhere p(y_k | x_k; W, B) is the class probability from the final capsule layer.\nFor capsule networks with margin loss (Sabour et al. 2017):\nL_k = T_k * max(0, m+ - ||v_k||)^2 + lambda * (1-T_k) * max(0, ||v_k|| - m-)^2\nL_margin = sum_k L_k\n\nZero-loss condition: L_margin(theta) = 0 iff for all k: ||v_k|| >= m+ when T_k=1 and ||v_k|| <= m- when T_k=0\n\nTotal loss: L_caps(theta) = L_margin + L_recon where L_recon is reconstruction loss (optional, MSE)\n\n### D3: Subanalytic Definability (C1 PROVEN with caveat)\n\nThe squash function s(v) = ||v||^2/(1+||v||^2) * v/||v|| is subanalytic but NOT R_{an,exp}:\n- ||v|| = sqrt(sum v_k^2): algebraic on R^d, definable in R_{an} (restricted analytic + algebraic)\n- ||v||^2/(1+||v||^2): rational function of ||v||^2, analytic away from poles (none on [0,infty))\n- v/||v||: undefined at v=0, but subanalytic as the function is bounded and its graph is subanalytic\n- The graph {(v, w): w = s(v), v != 0} union {(0,0)} is subanalytic\n\nRouting iterations (each step):\n- softmax_j(b_{ij}) = exp(b_{ij}) / sum_j' exp(b_{ij}'): analytic (exp + division)\n- v_j = sum_i c_{ij} u_hat_{j|i}: linear combination, polynomial\n- b_{ij} <- b_{ij} + u_hat_{j|i} . v_j: polynomial update (dot product)\n- squash(v_j): subanalytic\n- Composition of subanalytic with analytic = subanalytic\n\nMargin loss: max(0, f(v)) is subanalytic (piecewise analytic), squared is polynomial.\nReconstruction loss: MSE = polynomial.\n\nTherefore L_caps(theta) is SUBANALYTIC-DEFINABLE. This is a weakening from R_{an,exp} to R_{an} (subanalytic). RLCT theory applies via subanalytic preparation theorems (Loi, 2010). QED.\n\nCAVEAT: The weakening from R_{an,exp} to subanalytic does not invalidate RLCT existence but may affect the form of the local canonical model. The desingularization theorem applies to subanalytic functions.\n\n### D4: Squash Norm Singular Fiber (C2)\nV_squash = {theta in Theta : exists capsule output v_i(theta) with ||v_i(theta)|| = 0}\n\nAt v_i = 0:\n- squash Jacobian: d s / d v = [2||v||^2/(1+||v||^2) - 2||v||^4/(1+||v||^2)^2] * (v/||v||) * (v/||v||)^T + (||v||^2/(1+||v||^2)) * [I/||v|| - v v^T/||v||^3]\n  At v=0: ALL terms are undefined or zero. The Jacobian vanishes identically.\n- Fisher information: F_{ab} = E[ds/dv_a * ds/dv_b] = 0 for ALL a,b when v_i=0.\n  This is TOTAL RANK DEGENERACY (all eigenvalues -> 0), not partial.\n\nFull singular fiber:\nV_squash = Union_{l,i} {theta : ||v_i^l(theta)|| = 0}\n\nEach component is a codimension-d_i algebraic variety (zero set of sum(v_k^2) = 0, which forces all components to zero).\n\nNOVELTY: This is a TOTAL DEGENERACY singularity — all d_i directions become flat simultaneously at ||v||=0. Contrast:\n- ReLU (#8): 1 direction becomes flat (sign flip), d-1 directions remain informative\n- Attention (#134): rank-d deficiency in selected directions, others remain\n- Weight norm (#505): scale direction becomes flat, orientation preserved\n- Batch norm (#221): statistics-dependent rescaling, partial degeneracy\nCapsule squash: ALL directions flat simultaneously. This is the STRONGEST form of activation degeneracy observed across all syntheses.\n\n### D5: Routing Depth as Stratum Selector (C3)\nDefine routing inverse temperature:\nbeta_route(r) = r (number of routing iterations)\n\nStratified loss family:\nL_caps^{(r)}(theta) = L_margin(theta) computed with r routing iterations\n\nRLCT varies with r:\n- r=1: c_{ij} = softmax(0) = 1/m (uniform). Routing is linear: v_j = (1/m) sum_i u_hat_{j|i}. The map is injective (if W_{ij} are full rank). Minimal singularity. lambda(1) ~ lambda_base (standard weight-space RLCT).\n- r=2,...: agreement feedback creates non-linear coupling. Non-injectivity emerges: different (c_{ij}) configurations can yield same v_j. lambda(r) increases.\n- r -> infinity: routing converges to fixed point c_{ij}* = softmax(b_{ij}*) where b_{ij}* is a fixed point of the agreement update. In the limit, routing becomes hard assignment (winner-take-all for sufficiently separated capsules). lambda(inf) includes discrete selection singularity.\n\nCritical routing depth: r* ~ log(n) (empirical: 3 iterations typical, but SLT predicts r* depends on sample size).\n\nTemperature: T_r = 1/r. Low r = high temperature (diffuse routing). High r = low temperature (concentrated routing).\n\n### D6: Compound Generalization Bound (C4)\nG_capsule ~ [lambda_squash + lambda_route(r) + lambda_perm] * log(n) / (2n) + U(r, d_cap) / sqrt(n)\n\nwhere:\n- lambda_squash: RLCT of squash norm singularity (total degeneracy at zero-norm fibers)\n  Contribution: increases RLCT via codimension-d_i degenerate fibers at each capsule\n  lambda_squash ~ sum_{l,i} d_i / 2 (heuristic: each zero-norm fiber contributes d_i/2 to RLCT)\n- lambda_route(r): RLCT of routing non-injectivity\n  At r=1: lambda_route ~ 0 (injective map)\n  At r>1: lambda_route > 0 (non-injective coupling creates additional singular directions)\n  Monotone increasing in r (conjectural): more iterations = stronger non-injectivity\n- lambda_perm: RLCT of S_m permutation quotient on parent capsules\n  lambda_perm = (d_total - dim(fixed subspace of S_m)) / 2\n  For generic S_m action: lambda_perm ~ (m-1) * d_j / 2 (transpositions create orbifold singularities)\n- U(r, d_cap): fluctuation term\n  Decreases with r (better routing = better pose disentanglement = lower variance)\n  Increases with d_cap (higher-dimensional capsules = more parameters)\n  U(r, d_cap) ~ C * d_cap / sqrt(r) (conjectural scaling)\n\nTrade-off structure:\n- Increasing r: lambda_route increases (bad), U decreases (good). Optimal r* minimizes G.\n- Increasing d_cap: lambda_squash increases (bad), U may decrease (better representation, good).\n- The capsule advantage: for structured data (rotations, pose variation), U reduction from routing + permutation invariance can dominate lambda increase.\n\nComparison with #853 DARTS compound bound: DARTS has lambda_arch + lambda_w (bilevel). Capsule has lambda_squash + lambda_route + lambda_perm (tripartite). Both have compound structure but different mechanisms.\n\n### D7: Routing Convergence Phase Transition (C5)\nDuring training at step t*, routing weights undergo a transition from diffuse to concentrated.\n\nOrder parameter: routing entropy H(c(t)) = -sum_{ij} c_{ij}(t) log c_{ij}(t)\n\n- t < t*: H(c) ~ log(m) (uniform routing).
