# Synthesis #679: Gradient Clipping × RLCT\n## L1 Formalization — 2026-10-28\n\n### Definitions\n\n**D1 (Loss Function):** L: R^d -> R is real analytic, definable in R_an. W_0 = {w in R^d : L(w) = 0} is the zero-loss variety (true minimum set).\n\n**D2 (Gradient):** ∇L: R^d -> R^d is analytic (L analytic). The gradient norm ||∇L(θ)|| = sqrt(Σ_i (∂L/∂θ_i)^2) is definable in R_an,exp via sqrt closure.\n\n**D3 (Clipping Map):** For threshold τ > 0, define:\n  φ_τ(g) = min(1, τ/||g||) · g\n  This is piecewise: φ_τ(g) = g if ||g|| ≤ τ (interior), φ_τ(g) = (τ/||g||)·g if ||g|| > τ (exterior).\n  The min function is semi-algebraic; sqrt is definable in R_an,exp. Therefore φ_τ is definable in R_an,exp.\n\n**D4 (Clipped Update Map):** T_τ: θ -> θ - η·φ_τ(∇L(θ)). This is definable in R_an,exp as composition of definable maps. The map is piecewise smooth with switching surface S_τ = {θ : ||∇L(θ)|| = τ}.\n\n**D5 (Clipping Boundary):** S_τ = {θ ∈ R^d : ||∇L(θ)|| = τ} is a level set of the analytic function ||∇L||. By Sard's theorem, for almost all τ, S_τ is a smooth (d-1)-dimensional submanifold. At critical values τ where ∇(||∇L||) = 0 on S_τ, S_τ may develop singularities. S_τ is definable in R_an,exp.\n\n**D6 (Clipped Effective Loss):** Define L_clip(θ) implicitly via the stationary condition: ∇L_clip(θ) = φ_τ(∇L(θ)). Since φ_τ is not the gradient of any scalar function when active (non-conservative, see D7), L_clip does not exist as a standard loss. Instead, the dynamics are governed by the non-gradient vector field F_τ(θ) = -η·φ_τ(∇L(θ)).\n\n**D7 (Non-Conservative Field):** When clipping is active (||∇L|| > τ), F_τ(θ) = -η·(τ/||∇L||)·∇L(θ). The Jacobian ∂F_τ/∂θ involves derivatives of 1/||∇L|| which introduce non-symmetric terms. The curl ∇ × F_τ ≠ 0 in general, confirming F_τ is not a gradient field. This means standard RLCT (defined for loss functions) must be extended to vector field dynamics — the RLCT of the dynamical system's attractor set.\n\n### Claims\n\n**C1 (PROVEN):** The clipping map φ_τ and update map T_τ are definable in R_an,exp. The dynamics cross S_τ with a kink in the vector field (direction preserved, magnitude changes discontinuously in derivative). This kink creates a C^0-not-C^1 singularity in the flow.
