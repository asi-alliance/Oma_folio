# Synthesis #825: Titans Neural Long-Term Memory × RLCT - L0 Scoping\n# Date: 2026-11-03\n# Status: L0 DRAFT\n# C1 PROVEN (conjectured), C2-C5 CONJECTURAL\n\n## Architecture: Titans (Behrouz et al., Google DeepMind, 2024)\n\nTitans augments attention with a neural long-term memory (LTM) module — an MLP whose weights are updated online at test time via gradient descent on an associative memory loss. The \surprise\ is the gradient magnitude of this loss w.r.t. memory parameters. Memory updates use: (1) surprise (gradient) with momentum, (2) weight decay/forgetting gate, (3) persistent memory (task-learned, data-independent parameters). Three variants: MAC (Memory as Context), MAG (Memory as Gate), MAL (Memory as Layer).\n\n## Claims\n\n**C1 PROVEN**: Titans loss is R_{an,exp}-definable. LTM is an MLP with SiLU/ReLU (subanalytic). Associative memory loss uses softmax/inner-product (exp + polynomial). Online gradient step is algebraic composition of loss gradient (polynomial in weights for polynomial losses, subanalytic for ReLU). Momentum = EMA (exponential). Weight decay = exponential decay. Persistent memory = standard learnable parameters (polynomial). All components definable, closed under composition.\n\n**C2 CONJECTURAL**: Surprise magnitude (gradient norm) acts as a data-dependent stratum selector. High surprise -> large memory update -> the loss landscape w.r.t. memory parameters shifts, creating a transient singular fiber indexed by surprise level s(x). Low surprise -> near-zero update -> memory parameters near a fixed point (stable stratum). This is distinct from #824 Mamba (Delta as selector on state) because Titans' selector acts on the parameter space of the memory MLP itself, not the hidden state.\n\n**C3 CONJECTURAL**: The momentum-augmented surprise creates a singular fiber with \memory lag\ — the EMA of past gradients introduces a multi-step coupling between the loss landscape and historical input statistics. The singular locus depends on the trajectory of surprises, not just the current input. This creates a path-dependent singularity: two different input sequences reaching the same parameter configuration may have different local RLCT because their gradient histories differ.\n\n**C4 CONJECTURAL**: Generalization bound G_Titans ~ lambda_surprise / n + U(memory_update_rate) / sqrt(n). The effective RLCT lambda_surprise depends on the distribution of surprise magnitudes: frequent high-surprise inputs keep the memory in a high-RLCT regime (constant adaptation), while low-surprise inputs let the memory settle to a lower-RLCT stratum. Forgetting rate (weight decay) controls the tradeoff: fast forgetting keeps RLCT high (memory never specializes), slow forgetting allows RLCT to decrease (memory specializes to data distribution).\n\n**C5 CONJECTURAL**: Phase transition at critical forgetting rate eta*. At eta > eta* (fast forgetting), the memory module behaves like a rolling-average filter with constant RLCT (no specialization). At eta < eta* (slow forgetting), the memory specializes and RLCT drops as it memorizes task-relevant patterns. SGLD LLC shows step decrease at eta*. Distinct from #388 Mirostat (feedback control of perplexity) because Titans controls memory plasticity, not generation diversity.\n\n## Open Problems\n\n1.
