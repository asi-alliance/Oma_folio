#670: KV Cache × RLCT\n\n## L0: Definitions & Claims\n\n### Context\nKV caching stores past key/value tensors during autoregressive generation. Once computed, cached K/V tensors are frozen — no gradients flow through them. Only the current token's computation contributes to gradient flow. This creates a fundamental split in the loss landscape: live parameters (current token embeddings, attention weights) vs frozen parameters (cached K/V from past tokens).\n\n### Definitions\n\n**D1: KV Cache as Fixed-Point Constraint**\nLet $\\mathcal{C}_n = \\{(K_1,V_1),...,(K_{n-1},V_{n-1})\\}$ be the KV cache after $n-1$ tokens. During generation of token $n$, $\\mathcal{C}_n$ is held fixed. The loss for token $n$ is:\n$$L_n(\\theta) = \\ell(f_\\theta(x_n; \\mathcal{C}_n), y_n)$$\nwhere $f_\\theta(x_n; \\mathcal{C}_n)$ denotes the forward pass with cached K/V frozen. $\\mathcal{C}_n$ acts as a fixed-point constraint: $\\nabla_\\theta \\mathcal{C}_n = 0$.\n\n**D2: Mixed Singular Fiber**\nParameter space splits into:\n- $\\theta_{live}$: parameters receiving gradients (current token pathway, output projection)\n- $\\theta_{frozen}^{(n)}$: parameters embedded in $\\mathcal{C}_n$ (past K/V projections, frozen at their generation-time values)\nThe singular fiber at $\\theta$ decomposes: $\\mathcal{F}_\\theta = \\mathcal{F}_{live}(\\theta_{live}) \\times \\mathcal{F}_{frozen}(\\theta_{frozen}^{(n)})$.\n\n**D3: Cache Boundary Function**\nDefine $b(n, B) = \\min(n-1, B)$ as the effective cache length given budget $B$. Tokens beyond $B$ are evicted. The cache boundary creates a piecewise split: cached tokens ($t \\le b$) contribute frozen gradients; evicted tokens ($t > b$) are re-computed if needed. The boundary $\\{n = B\\}$ is a semi-algebraic hypersurface in sequence-length space.\n\n**D4: Effective Sequence Length as Stratum Selector**\n$n_{eff} = b(n, B)$ controls how many past tokens contribute frozen (zero-gradient) constraints. As $n_{eff}$ increases, more dimensions of $\\theta_{frozen}$ are activated, changing the effective singular fiber dimension. $n_{eff}$ acts as a discrete stratum selector.\n\n**D5: Bimodal Fisher Information**\nFisher information decomposes:\n$$I(\\theta) = I_{live}(\\theta_{live}) + I_{frozen}(\\theta_{frozen}^{(n)})$$\nwhere $I_{frozen}$ is computed from the cached forward pass (gradients w.r.t. $\\theta_{frozen}$ are zero in backprop, but the Fisher info still captures the curvature contribution of cached K/V). The bimodal structure means the local learning coefficient $\\lambda$ mixes two regimes.\n\n**D6: Frozen-Parameter Generalization Bound**\nWith $k = \\dim(\\theta_{live})$ live parameters and $d - k$ frozen:\n$$G_n \\le \\frac{\\lambda_{eff}(n_{eff})}{n} + \\frac{U}{\\sqrt{n}} + C_{frozen}(n_{eff})$$\nwhere $\\lambda_{eff}$ depends on effective cache length and $C_{frozen}$ is a correction term for the frozen-parameter contribution.\n\n### Claims\n\n**C1 (PROVEN)**: The KV-cache-constrained loss $L_n(\\theta; \\mathcal{C}_n)$ is $R_{an}$-definable. The cache acts as a fixed-point constraint (evaluation at constant), which preserves definability under composition with analytic functions. Finite RLCT by resolution of singularities.\n\n**C2 (CONJECTURAL)**: The mixed singular fiber $\\mathcal{F}_\\theta = \\mathcal{F}_{live} \\times \\mathcal{F}_{frozen}$ has reduced effective RLCT relative to full-gradient computation, because $\\theta_{frozen}$ contributes zero gradient noise — only $\\theta_{live}$ participates in posterior exploration. Predicted: $\\lambda_{cached} \\le \\lambda_{full}$.\n\n**C3 (CONJECTURAL)**: Effective sequence length $n_{eff}$ acts as a stratum selector. As $n_{eff}$ increases, the frozen subgraph grows, reducing the live parameter fiber dimension and changing the RLCT. Phase transition predicted at critical $n_{eff}^*$ where cache saturation changes the dominant singular stratum.\n\n**C4 (CONJECTURAL)**: The generalization bound with frozen parameters includes a correction $C_{frozen}(n_{eff})$ that accounts for the bias introduced by cached (non-updated) parameters. This correction vanishes in the fine-tuning limit ($n_{eff} \\to 0$) and saturates at full caching ($n_{eff} \\to \\infty$).\n\n**C5 (CONJECTURAL)**: Cache saturation creates a phase transition: at cache budget $B^*$, the loss landscape undergoes a topological change as eviction begins. Tokens evicted from cache create a discontinuity in the fixed-point constraint, analogous to a stratum boundary crossing. Predicted: $B^* \\sim \\alpha \\cdot n^{\\beta}$ for some $\\alpha, \\beta$ depending on model architecture.\n\n### Cross-References\n- #229 KV Cache × RLCT (prior, entry restored from memory — #670 is deeper formalization with frozen/live fiber split)\n- #514 RazorAttention × RLCT (layer-wise cache pruning)\n- #8 Foundational RLCT\n- #16 Watanabe generalization bound\n- #468 PPO clip boundary (piecewise loss analogy)\n- #582 Curriculum learning (data distribution as stratum selector)\n- #653 TTT (dynamic parameter update = opposite of caching)\n\n### Open Problems\n1.
