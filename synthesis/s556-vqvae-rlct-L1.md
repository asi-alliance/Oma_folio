#556 L1 FORMAL SKETCH (2026-10-23) VQ-VAE x RLCT

D1 (Setup): Parameters (theta_E, theta_D, E) in Theta subset R^d: encoder e_{theta_E}: R^d_x -> R^{d_z}, decoder D_{theta_D}: R^{d_z} -> R^d_x, codebook E = {e_1,...,e_K} subset R^{d_z}. Quantizer Q(z) = e_{k*} where k* = argmin_k ||z - e_k||^2. Straight-through estimator: z_q = z_e + sg(e_{k*} - z_e) where sg = stop-gradient. Loss L = E_x[||x - D(z_q(x))||^2] + ||sg[z_e(x)] - e_{k*}||^2 + beta||z_e(x) - sg[e_{k*}]||^2, with beta > 0 commitment weight.

D2 (Voronoi tessellation): For codebook E, define Voronoi cells V_k(E) = {z in R^{d_z} : ||z - e_k||^2 <= ||z - e_j||^2 for all j}. Each V_k is a convex polytope (semi-algebraic: defined by finitely many quadratic inequalities). Boundary dV_{ij} = {z : ||z - e_i||^2 = ||z - e_j||^2} is a codim-1 hyperplane (affine, since ||z-e_i||^2 - ||z-e_j||^2 = 2(e_j - e_i).z + ||e_i||^2 - ||e_j||^2 = 0). The quantizer Q is piecewise constant: Q(z) = e_k for z in int(V_k).

D3 (Piecewise loss family): Within cell V_k, L_k(theta,E) = E_x[1[E(x) in V_k] * (||x - D(e_k)||^2 + ||sg[z_e] - e_k||^2 + beta||z_e - sg[e_k]||^2)]. Each L_k is R_{an,exp}-definable (composition of analytic encoder/decoder with polynomial indicator-weighted quadratic losses). Full loss L = sum_k L_k, a finite sum of definable functions over semi-algebraic domains.

D4 (Singular fiber): Zero-loss set W = {(theta,E) : L(theta,E) = L*}. Singular strata: (i) Voronoi boundary fiber S_bd = {(theta,E) : E_{theta_E}(x) in dV_{ij} for some x, i, j} where loss is non-differentiable; (ii) dead-code fiber S_dead = {(theta,E) : exists k s.t. V_k(E) contains no E_{theta_E}(x) for any x in supp(p)} where gradient w.r.t. e_k vanishes; (iii) STE mismatch stratum S_STE where surrogate gradient landscape differs from true landscape.

D5 (RLCT): lambda_VQ = RLCT of the VQ-VAE loss restricted to singular fiber. Within each cell V_k, the loss is analytic (composition), so RLCT is finite by resolution of singularities. The Voronoi boundary contributes a non-smooth singularity: the effective RLCT lambda_eff = lambda_interior + lambda_boundary where lambda_boundary captures the gradient-discontinuity contribution. Dead-code stratum has lambda_dead = lambda_interior + (d_z)/2 (extra flat directions from unused e_k parameters increase multiplicity).

D6 (K as stratum selector): Codebook size K defines the Voronoi partition granularity. Effective codebook K_eff = |{k : V_k(E) intersect E_{theta_E}(supp(p)) != empty}|. Lambda(K_eff) predicted non-monotonic: small K_eff -> high quantization bias B(K,K_eff) but few boundary singularities; large K_eff -> many boundary singularities + dead-code risk. K_eff/K ratio = codebook utilization. K_eff acts as discrete stratum selector (analogous to #434 MoE expert count but discrete argmin vs softmax routing).

D7 (Generalization bound): G(K) <= lambda(K_eff)*log(n)/(2n) + B(K,K_eff) + U_STE/sqrt(n). B(K,K_eff) = quantization bias: increases with K - K_eff (dead codes waste capacity). U_STE = STE surrogate-true gradient mismatch term. U-shape: optimal K* minimizes lambda*log(n)/2n + B + U_STE. Distinct from #515 VAE (continuous latent, no Voronoi boundary, no quantization bias B).

C1 (PROVEN, definability): VQ-VAE loss is R_{an,exp}-definable. Within each Voronoi cell V_k (semi-algebraic, defined by quadratic inequalities), Q(z)=e_k is constant, so reconstruction loss ||x-D(e_k)||^2 is analytic (composition of analytic decoder with constant). Commitment and codebook losses are quadratic (algebraic). Cell membership indicator 1[z in V_k] is semi-algebraic (finite conjunction of polynomial inequalities). Full loss = sum over k of (semi-algebraic indicator * analytic loss), which is definable in R_{an,exp} by closure under finite sum, product, and restriction to semi-algebraic sets. Finite RLCT follows from resolution of singularities for definable functions (as in #8, #354, #515). QED.

C2 (CONJECTURE): Voronoi boundary dV_{ij} creates singular fibers with higher RLCT than interior. At boundary points, the loss has a gradient discontinuity (argmin switches), creating a non-smooth singular locus. The fiber dimension increases because perturbations along dV_{ij} (changing which cell is nearest) do not change the quantized output within each cell. Predicted: lambda_boundary > lambda_interior. Analogous to ReLU kink (#8) but in latent-to-codebook map. Gap: exact RLCT of piecewise-constant-with-discontinuous-gradient loss not computed (P1); relationship to semi-algebraic stratification theory needed (P2).

C3 (CONJECTURE): K (and K_eff) acts as stratum selector. Each K defines a different Voronoi partition (different algebraic variety). Lambda(K) predicted non-monotonic with minimum at K*. Small K: high bias B, low lambda (few boundaries). Large K: low bias, high lambda (many boundaries + dead-code degeneracy). K_eff < K (dead codes) is the true selector. Gap: no proof that lambda(K_eff) is non-monotonic (P3); dead-code emergence dynamics not formalized (P4).

C4 (CONJECTURE): Gen bound G(K) <= lambda(K_eff)*log(n)/(2n) + B(K,K_eff) + U_STE/sqrt(n). B(K,K_eff) measures information loss from dead codes and cell coarseness. U_STE captures STE surrogate-true gradient mismatch. U-shape predicted. Distinct from #515 VAE (no B, no U_STE). Gap: form of B(K,K_eff) unknown (P5); U_STE vs true RLCT relationship unclear (P6, cf #354).
