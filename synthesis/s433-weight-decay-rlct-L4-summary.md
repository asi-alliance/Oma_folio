# Synthesis #433: Weight Decay (L2 Regularization) × RLCT — L4 Summary\n## Date: 2026-10-28\n\n## Plain-Language Summary\n\nWeight decay — the L2 penalty λ/2·||θ||² added to a loss function — is the most common regularizer in deep learning, yet its effect on the singular geometry of the loss landscape has never been analyzed through the lens of Singular Learning Theory (SLT). This synthesis bridges that gap.\n\n**Core insight:** Adding an L2 penalty deforms the zero-loss set V₀ (where the model fits training data perfectly) into a smoothed fiber V_λ. The quadratic penalty acts like a toric contraction pulling parameters toward the origin, which can "lift" singularities — degenerate points where many parameters produce the same output. When singularities are lifted, the Real Log Canonical Threshold (RLCT) decreases, directly improving the generalization bound λ·log(n)/n.\n\n**Five claims:**\n- **C1 (PROVEN):** The L2-penalized loss L + λ/2·||θ||² is R_an,exp-definable. Trivially true since L2 is polynomial.\n- **C2 (NOVEL):** Weight decay acts as a desingularization mechanism — it shrinks the singular locus via toric-like deformation of the loss fiber, reducing RLCT.\n- **C3 (NOVEL):** The decay rate λ_wd serves as a continuous stratum selector, monotonically decreasing effective RLCT as λ_wd increases. A smooth knob, not a binary switch.\n- **C4 (NOVEL):** A two-term generalization bound G ≤ λ_eff(wd)·log(n)/n + U/√n where λ_eff < λ₀ due to desingularization. The L2 penalty buys you a better RLCT at the cost of a bias term.\n- **C5 (NOVEL):** A critical decay rate wd* ~ λ₀/n marks a phase transition: below wd*, desingularization is negligible; above wd*, over-regularization dominates.\n\n**Why it matters:** This frames weight decay not just as an optimization trick but as a geometric tool that reshapes the singular structure governing generalization. The λ_wd knob directly controls the RLCT — the quantity that SLT identifies as the true complexity measure of a model.\n\n**Most novel contribution:** C2 (desingularization via toric deformation) — bridges regularization theory with algebraic geometry of singular fibers, a connection absent from all prior literature.\n\n**Cross-references:** #491 (Grokking — weight decay as timing factor), #212 (Weight regularization phase transitions), #289 (Adam), #605 (Adagrad), #606 (RMSProp).\n\n**Open problems:** 7 — formal toric deformation proof, global monotonicity, fiber V_λ construction, wd* empirical validation, SGD coupling, bias-variance tradeoff, non-isotropic decay.
