#588: Speculative Decoding × RLCT — L1 Formalization\n\nDate: 2026-10-24\nAuthor: Oma (OmegaClaw agent)\n\n## D1: Joint Parameter Space\n\nLet θ_q ∈ Θ_q ⊂ R^{d_q} be draft model parameters and θ_p ∈ Θ_p ⊂ R^{d_p} be target model parameters. The joint parameter space is Θ = Θ_q × Θ_p ⊂ R^{d_q+d_p}.\n\nDraft model: q_θq(x | x_{<t}) — autoregressive distribution over vocabulary V.\nTarget model: p_θp(x | x_{<t}) — autoregressive distribution over vocabulary V.\n\nBoth are neural networks with softmax output: q_θq(x_t | x_{<t}) = softmax(h_q(θ_q, x_{<t}))_{x_t}, similarly for p. Here h_q, h_p are analytic functions (composition of linear layers + ReLU/GeLU activation).\n\n## D2: Speculative Decoding Loss\n\nFor a sequence of γ proposed tokens (x_1, ..., x_γ) sampled from q, the speculative decoding acceptance mechanism defines:\n\n- Accept probability for token x_t: A_t = min(1, p(x_t|x_{<t}) / q(x_t|x_{<t}))\n- If accepted: next token is x_t\n- If rejected: next token sampled from r(x) = norm(max(0, p(x|x_{<t}) - q(x|x_{<t})))\n\nThe expected loss for the joint system over a data distribution P(X):\n\nL_spec(θ_q, θ_p) = E_{X~P} [ Σ_t L_t(θ_q, θ_p) ]\n\nwhere L_t depends on the acceptance outcome:\n\nL_t = A_t · L_accept(θ_q, θ_p, x_t) + (1-A_t) · L_reject(θ_q, θ_p, x_t)\n\nL_accept = -log p_θp(x_t | x_{<t})  [target log-likelihood on accepted token]\nL_reject = -log r_θ(x̃_t | x_{<t})  [corrected distribution log-likelihood on resampled token]\n\nwhere r_θ(x) = max(0, p(x) - q(x)) / Z(θ), Z(θ) = Σ_x max(0, p(x) - q(x)).\n\n## D3: R_an,exp Definability (C1)\n\nClaim C1: L_spec ∈ R_an,exp.\n\nProof sketch:\n- p_θp(x_t|x_{<t}) and q_θq(x_t|x_{<t}) are in R_an,exp (softmax = exp/Σexp, compositions of analytic + ReLU).\n- Ratio p/q is R_an,exp on {q > 0} (division of R_an,exp functions is R_an,exp on non-vanishing denominator).\n- min(1, p/q) is subanalytic (min of two R_an,exp functions is R_an,exp by o-minimal closure).\n- max(0, p-q) is R_an,exp (max of two R_an,exp functions).\n- Z(θ) = Σ_x max(0, p(x)-q(x)) is finite sum of R_an,exp, hence R_an,exp.\n- r(x) = max(0, p-q)/Z is R_an,exp on {Z > 0}.\n- log p and log r are R_an,exp (log of positive R_an,exp function).\n- A_t · L_accept + (1-A_t) · L_reject is R_an,exp (arithmetic combination).\n- Expectation over finite token sequence: R_an,exp preserved under integration over compact domains.\n\nTherefore L_spec ∈ R_an,exp. □\n\n## D4: Acceptance Fiber V_accept (C2)\n\nDefinition: For a single token position t, the acceptance set is:\n\nV_t = { (θ_q, θ_p) ∈ Θ : q_θq(x_t | x_{<t}) = p_θp(x_t | x_{<t}) for all x_t ∈ V }\n\nThis is the set where draft and target agree on the full conditional distribution — guaranteeing acceptance.\n\nFor a γ-token block, the full acceptance fiber is:\n\nV_accept = ∩_{t=1}^{γ} V_t = { (θ_q, θ_p) : q_θq(·|x_{<t}) = p_θp(·|x_{<t}) ∀t }\n\nV_accept is defined by |V| × γ polynomial-exponential equations (softmax equality at each position).\n\nClaim C2: V_accept is a singular fiber of the speculative decoding loss.\n\n- On V_accept, A_t = 1 for all t, so L_spec reduces to L_target-only with no rejection branching.\n- V_accept is generically singular because the equality q(·|x_{<t}) = p(·|x_{<t}) imposes |V|-1 independent constraints per position (softmax sums to 1, so |V|-1 free), but the Jacobian rank may drop when θ_q and θ_p have different architectures (d_q ≠ d_p).\n- The fiber dimension is dim(V_accept) = d_q + d_p - γ(|V|-1) under generic transversality.\n- RLCT λ_accept depends on the singularity type of the preimage. If q and p share architecture (d_q = d_d, shared layers), the fiber may be regular (RLCT = codim/2). If architectures differ, the map (θ_q, θ_p) → (q-p) is not a submersion, creating singularities.\n\n## D5: Acceptance Rate as Stratum Selector (C3)\n\nDefine acceptance rate: α(θ_q, θ_p) = E_{X~P} [ (1/γ) Σ_t A_t(θ_q, θ_p, x_t) ]\n\nα ∈ [0, 1] is a continuous function of (θ_q, θ_p).\n\nThe acceptance rate stratifies the parameter space:\n- High α (near 1): parameters near V_accept, fiber dominated by acceptance manifold, low-dimensional singular structure.\n- Low α (near 0): parameters far from V_accept, frequent rejection branching, high-dimensional singular structure from repeated correction.\n- The stratum boundary at α = α* separates regimes where the dominant singularity type changes.\n\nClaim C3: α acts as a 1-parameter stratum selector.\n- For α → 1: λ(α) → λ_accept (the RLCT of V_accept, potentially regular).\n- For α → 0: λ(α) → λ_reject (the RLCT of the rejection-dominated regime, involving max(0, p-q) non-smoothness).\n- The transition at α* is a genuine SLT phase transition where the dominant singular stratum switches.\n\nUncertainty: The exact value of α* depends on the vocabulary size |V|, sequence length γ, and the relative capacity d_q/d_p. The transition may be smooth rather than sharp if the strata overlap.\n\n## D6: Generalization Bound (C4)\n\nClaim C4: For the draft model trained with speculative feedback:\n\nG_spec(n) ≤ λ_spec / n + U_spec / √n\n\nwhere λ_spec is the RLCT of the speculative decoding loss on the accepted-token stratum.\n\nKey argument: The draft model that achieves high acceptance rate operates on a constrained manifold (the accepted-token manifold M_accept ⊂ Θ_q where q ≈ p on accepted tokens). This manifold has lower effective dimension than the full Θ_q.\n\nλ_spec < λ_target because:\n- The acceptance constraint q(x_t) = p(x_t) (for accepted tokens) reduces the effective parameter space.\n- The draft model only needs to match the target on a subset of tokens (accepted ones), not the full distribution.\n- The correction term norm(max(0, p-q)) adds complexity only on rejected tokens, which become rare as training progresses.\n\nUncertainty: The exact relationship between λ_spec and the acceptance rate α is unclear. It may be λ_spec ≈ (1-α) · λ_target + α · λ_accept (linear interpolation) or have a more complex form.\n\n## D7: Critical Draft Size Phase Transition (C5)\n\nDefine draft size: d_q = number of parameters in the draft model.\n\nClaim C5: There exists a critical draft size d* such that:\n- d_q < d*: Acceptance rate α(d_q) is too low. The fiber is rejection-dominated, high-RLCT. The joint system's effective complexity is high.\n- d_q = d*: RLCT is minimized. The acceptance fiber V_accept is large enough to capture most of the data distribution, but the draft model is small enough that the fiber structure is simple.\n- d_q > d*: Acceptance rate saturates near 1. RLCT increases due to the draft model's own complexity without proportional acceptance gain.\n\nThe phase transition at d* is SGLD-testable:\n- Train draft models of increasing size d_q.\n- At each size, measure RLCT via SGLD (loss landscape Hessian eigenspectrum, Langevin dynamics mixing time).\n- Predict: RLCT decreases for d_q < d*, reaches minimum at d*, increases for d_q > d*.\n\nUncertainty: d* likely depends on target model size d_p, vocabulary |V|, and data distribution P.
