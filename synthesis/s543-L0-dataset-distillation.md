## Synthesis #543: Dataset Distillation × RLCT\n\n### L0 — Seed Document\n\n**Date:** 2026-10-23\n**Status:** L0 (seed)\n\n---\n\n#### 1. Topic\n\nDataset Distillation (DD) — the compression of a large training dataset into a small set of synthetic examples that, when used for training, produce models comparable to those trained on the full dataset.\n\n#### 2. Core Techniques\n\n- **Gradient-based DD (Wang et al., 2018):** Bi-level optimization. Inner loop trains model on synthetic data θ_t; outer loop optimizes synthetic data to minimize loss on real data.\n- **Trajectory Matching (Cazenavette et al., 2022):** Match training trajectories on synthetic vs real data rather than final loss.\n- **Gradient Matching (Zhao et al., 2021):** Match per-step gradients between synthetic and real data.\n- **Kernel-based / Feature Matching:** Match feature statistics rather than gradients.\n- **Core-set Selection:** Select representative subset rather than generating synthetic data.\n\n#### 3. RLCT Bridge (Hypothesis)\n\nThe empirical log-loss L_n(θ) defines a singularity structure in parameter space. Dataset distillation replaces the empirical loss L_n(θ) with a surrogate L_S(θ) defined by the synthetic dataset S.\n\nKey observations:\n- The synthetic dataset S has far fewer points (|S| << |D|), so the empirical process defined by L_S has different statistical properties.\n- In SLT, RLCT λ̂ measures the local complexity of the singularity near the true parameter. A smaller dataset means fewer empirical constraints, potentially altering λ̂.\n- The bi-level optimization seeks S such that argmin_θ L_S(θ) ≈ argmin_θ L_D(θ) — i.e., the minimizers (singularities) of the two losses should coincide.\n- **Hypothesis:** Successful distillation selects S such that the RLCT of L_S approximates the RLCT of L_D. The synthetic data preserves the singularity structure while reducing data complexity.\n- The nested optimization creates a structure where the inner singularity (on S) must track the outer singularity (on D). This is analogous to the desingularization hierarchy in algebraic geometry.\n\n#### 4. Novelty Assessment\n\nNo prior work connects RLCT/SLT to dataset distillation. The bi-level optimization structure is novel for SLT analysis. Existing SLT work covers single-level empirical processes; DD introduces a nested empirical process.\n\n#### 5. Key Questions\n\n- Q1: Does the RLCT of the synthetic loss L_S converge to the RLCT of the real loss L_D as distillation quality improves?\n- Q2: How does the number of synthetic images per class (IPC) affect λ̂? Fewer synthetic points → fewer constraints → different singularity?\n- Q3: Can RLCT serve as a distillation quality metric? (Lower KL divergence between singularity structures = better distillation?)\n- Q4: Is there a phase transition in distillation quality when IPC crosses a threshold related to the RLCT?\n- Q5: Does trajectory matching preserve RLCT better than gradient matching or loss matching?\n\n#### 6. Relationship to Prior Syntheses\n\n- #89 (Tensor Decomposition): Shares low-rank structure — synthetic data is a compressed representation.\n- #298 (Weight Decay): Both involve regularization through compression, but DD compresses data not parameters.\n- #173/#482 (SAM/Flat Minima): Both relate to loss landscape geometry, but DD changes the landscape itself.\n- #112 (Knowledge Editing): Both modify model behavior without full retraining.\n\n#### 7.
