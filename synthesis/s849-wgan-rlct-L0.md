# Synthesis #849: WGAN × RLCT — L0 (Initial Bridge)\n\n## Date: 2026-11-06\n## Status: L0 (initial bridge). C1 PROVEN, C2-C5 CONJECTURAL.\n\n## Core Bridge\n\nWGAN replaces the Jensen-Shannon divergence with the Wasserstein-1 distance, requiring the critic (discriminator) to be 1-Lipschitz. This Lipschitz constraint restricts critic parameters to a bounded submanifold M_L ⊂ Θ_D of the full parameter space. The singular fiber V (loss minimizers) intersected with M_L creates a **constrained singularity** V ∩ M_L whose RLCT may differ from the unconstrained GAN singularity (#277).\n\nThree enforcement mechanisms (weight clipping, gradient penalty, spectral normalization) each define M_L differently, producing distinct constrained singularity structures.\n\n## Key Insight\n\nIn standard GANs (#277), the discriminator's non-identifiability (scale symmetry D(x) → a·D(x) + b) creates a smooth singular fiber. WGAN's Lipschitz constraint **breaks this scale symmetry** — the critic cannot freely scale because |f| ≤ 1 is enforced. This transforms the smooth scale-degenerate fiber into a constrained intersection singularity at the boundary of M_L, potentially increasing RLCT (more complex singularity) but stabilizing training (bounded gradient norms).\n\n## Formal Definitions (Sketch)\n\n- **D1** (WGAN Loss): L_W = E_{x~P_r}[D(x)] - E_{z~P_z}[D(G(z))] where D is 1-Lipschitz. Lipschitz constraint: |D(x)|_Lip ≤ 1.\n\n- **D2** (Lipschitz Submanifold): M_L = {θ_D ∈ Θ_D : ||D(·;θ_D)||_{Lip} ≤ 1}. Three parameterizations: (a) weight clipping: M_L^{clip} = {θ_D : |w_i| ≤ c}, (b) gradient penalty: M_L^{gp} = {θ_D : E[||∇_x D(x)||² ≤ 1]}, (c) spectral normalization: M_L^{sn} = {θ_D : σ_max(W^l) ≤ 1 ∀l}.\n\n- **D3** (Constrained Singular Fiber): V_L = V ∩ M_L = {θ ∈ M_L : L_W(θ) = L*}. The RLCT of V_L may exceed that of V because the constraint forces the fiber into a lower-dimensional, potentially more singular intersection.\n\n- **D4** (Scale Symmetry Breaking): In unconstrained GAN, D → a·D + b is a free symmetry. Under Lipschitz constraint, a is bounded by |a| ≤ 1/||D||_{Lip}, breaking continuous scale symmetry to a bounded (possibly discrete) remnant.\n\n- **D5** (Enforcement-Specific Singularity): Each enforcement mechanism creates a different M_L geometry: weight clipping → box constraint (semi-algebraic, corners create additional singularities), gradient penalty → soft constraint (penalty landscape, analytic), spectral norm → spectral constraint (semi-algebraic via singular values).\n\n- **D6** (Generalization Bound): G(n) ≈ λ_L/n · log n + U·√(log n / n) where λ_L is the RLCT of the constrained singularity V_L.\n\n- **D7** (Phase Transition): As Lipschitz bound c → ∞ (constraint relaxed), WGAN → standard GAN, λ_L → λ_GAN. As c → 0 (tight constraint), M_L collapses, λ_L → ∞ (trivial critic). Optimal c* balances constraint tightness vs singularity complexity.\n\n## Claims\n\n- **C1** (Definability [PROVEN]): WGAN loss with weight clipping is piecewise polynomial (semi-algebraic). With gradient penalty, loss includes ||∇_x D||² which is polynomial in θ_D (chain rule through analytic D). With spectral normalization, W̃ = W/σ_max(W) is definable in R_{an,exp} (singular values are algebraic roots of polynomial equations). All three enforcement mechanisms preserve R_{an,exp}-definability. SLT conditions satisfied.\n\n- **C2** (Constrained Singularity [CONJECTURAL]): The intersection V ∩ M_L creates a constrained singular fiber whose RLCT λ_L ≥ λ_{GAN} because the Lipschitz constraint restricts the fiber to a lower-dimensional submanifold, generically increasing singularity complexity. The scale symmetry breaking removes the smooth degenerate direction present in #277.\n\n- **C3** (Enforcement Mechanism as Stratum Selector [CONJECTURAL]): The Lipschitz bound c (or gradient penalty λ_gp, or spectral norm bound) acts as a continuous stratum selector. Different c values select different constrained fibers V_L(c) with different RLCTs. U-shaped curve in c: too tight → trivial critic, too loose → unstable GAN, optimal c* → balanced singularity.\n\n- **C4** (Generalization Bound [CONJECTURAL]): G(n) ≈ λ_L/n · log n + U·√(log n / n). The constrained RLCT λ_L depends on enforcement mechanism: spectral norm (smooth algebraic constraint) may yield lower λ_L than weight clipping (non-smooth box constraint with corner singularities).\n\n- **C5** (Constraint Tightness Phase Transition [CONJECTURAL]): As c increases through critical c*, the constrained singularity V_L transitions from trivial (M_L ∩ V = ∅ for c too small) through optimal (transverse intersection, minimal λ_L) to degenerate (M_L ⊃ V, λ_L = λ_GAN, unconstrained regime). This is testable via SGLD on WGAN critics at varying c.\n\n## Open Problems\n\n1.
