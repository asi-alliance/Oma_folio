# Synthesis #654: In-Context Learning (ICL) × RLCT\n## Date: 2026-10-28 | Status: L0 (candidate framing)\n\n## Topic\nIn-context learning (ICL) — the ability of a trained model to perform new tasks from prompt examples WITHOUT parameter updates — analyzed through RLCT. Key question: does the prompt/context create an input-dependent effective singular structure in the forward pass, shifting the model across singular strata WITHOUT weight movement?\n\n## Distinction from #508\n#508 analyzed the induction-head COPYING CIRCUIT as a weight-space singularity (learnable circuit = singular locus in parameter space). #654 analyzes ICL from the FORWARD-PASS perspective: the context c conditions the effective model M(c) = f(θ*, c), creating context-dependent singular fiber V_0(c) in OUTPUT space. No gradient updates — the model traces a VIRTUAL trajectory through singular space via context alone.\n\n## Seven Questions\n1. Is the context-conditioned loss L(M(c), y) definable in R_an,exp? (C1)\n2. Does context length n_c act as a stratum selector — longer context → lower effective RLCT? (C2)\n3. Does ICL create a virtual trajectory through singular space without weight movement? (C3)\n4. Can we bound generalization with a context-length penalty term? (C4)\n5. Is there a critical context length n* where ICL accuracy jumps (phase transition)? (C5)\n6. How does context-conditioned RLCT λ(c) relate to the weight-space RLCT λ(θ*) from training?\n7. Can SGLD/LC estimation detect context-dependent RLCT shifts at inference time?\n\n## Five Claims\n- C1 (definability, provable): Context-conditioned loss L(M(c), y) is R_an,exp-definable. M(c) = f(θ*, c) is piecewise-analytic in c (attention + softmax compositions), so the loss inherits definability.\n- C2 (conjecture): Context length n_c acts as a stratum selector. More examples → richer conditioning → lower effective RLCT λ_eff(c) of the context-conditioned model. Analogous to #490 (RoPE context length L* as stratum parameter) but in output space, not weight space.\n- C3 (conjecture): ICL creates a VIRTUAL trajectory through singular space. The mapping c ↦ V_0(c) defines a context-indexed family of singular fibers. The model "moves" across strata via context without parameter updates — distinct from #653 TTT (actual weight trajectory).\n- C4 (conjecture): Generalization bound for ICL: G_ICL ≤ λ_eff(c)·log(n_c)/n_c + λ_train·log(n_train)/n_train. Context-length penalty replaces the adaptation budget term from #653.\n- C5 (conjecture): Critical context length n* ~ n_train^{λ_eff/(λ_train+λ_eff)} — phase transition between under-conditioning (too few examples, high λ_eff) and saturated conditioning (enough examples, λ_eff → λ_min).\n\n## Key Distinctness\n- #508: induction head CIRCUIT as weight-space singularity (mechanism of ICL)\n- #653: TTT creates actual parameter trajectory through stratum space (weight updates)\n- #502: RAG retrieves external context (boundary of model, not internal conditioning)\n- #654: ICL shifts effective singular fiber via FORWARD-PASS context conditioning (no weight movement)\n\n## Cross-References\n#508 (induction heads circuit), #653 (TTT dynamics), #502 (RAG), #490 (RoPE context length), #485 (RLT recurrence), #396 (GLA attention), #134 (attention), #8 (base RLCT), #100 (transformer RLCT)\n\n## Open Problems\n1. Formalize V_0(c): what is the singular fiber of the context-conditioned model?\n2. Relate λ(c) to λ(θ*): is context-conditioned RLCT bounded by training RLCT?\n3. SGLD at inference: can we estimate λ(c) from forward-pass Hessian statistics?\n4. Few-shot vs many-shot: does λ(c) monotonically decrease with n_c?\n5. Task complexity: does harder task require more context to reach low λ_eff?\n6. Failure mode: does irrelevant context INCREASE λ_eff (negative ICL)?\n7. Connection to #509 task vectors: does task vector addition shift V_0(c) predictably?
