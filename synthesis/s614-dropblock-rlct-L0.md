#614: DropBlock × RLCT — L0 Claims\n\nDate: 2026-10-25\nStatus: L0 (this file) — L1-L5 pending\nSupersedes partial #477 (L1-L4 written but no L0 or catalog entry)\n\n## Background\n\nDropBlock (Ghiasi et al., 2018) extends Dropout to convolutional networks by dropping *contiguous spatial blocks* rather than independent pixels. Given a feature map X ∈ R^{C×H×W}, a DropBlock mask is generated by: (1) sampling a Bernoulli seed mask S ∈ {0,1}^{H×W} with P(S_{ij}=0)=γ, (2) for each zeroed seed position, zeroing out a b×b block centered there. This creates spatially correlated zero regions. Block size b controls correlation; drop rate γ controls density. b=1 recovers standard dropout (#169).\n\n## Key Insight\n\nUnlike Dropout (#169, i.i.d. pixel masking) or DropConnect (#613, weight-space masking), DropBlock creates **spatially structured zero regions** in the feature map. The contiguous block structure interacts with convolutional weight sharing and translation equivariance in a way that independent masking cannot:\n\n- A b×b block zeros out a spatial region, making ALL convolutional kernels that overlap that region produce zero outputs at nearby positions simultaneously.\n- The effective number of independent masking decisions is ~HW/b² (not HW), creating a coarser stratum structure.\n- Block overlap creates a percolation-like covering of the spatial lattice, with a phase transition in (b, γ) space.\n\n## Claims\n\n**C1 (PROVEN): R_{an,exp} Definability**\nThe DropBlock forward pass consists of: Bernoulli sampling (polynomial in γ), block dilation (finite composition of max/min operations over b×b neighborhoods — definable in R_{an,exp}), elementwise multiplication (polynomial), and standard subanalytic layers (ReLU #8, conv, softmax+CE). The expected loss E_M[L(θ; M⊙X)] is a finite definable function of (θ, b, γ) in R_{an,exp}. The block dilation is a finite composition of polynomial maps over a finite lattice, preserving definability.\n\n**C2 (CONJECTURAL): Combinatorial Block Covering Singularity**\nFor b>1, the block structure creates structured zero regions. Unlike dropout (b=1, independent masking), DropBlock forces contiguous regions to zero simultaneously. The zero-loss fiber V_DB(b,γ) is a union over block mask configurations of weight strata where the convolutional response vanishes on the blocked spatial regions. The fiber dimension grows as O(b²) per block (the number of output positions affected), creating higher-dimensional singular strata than independent masking. Claim: λ_DB(b,γ) > λ_dropout(γ) for b>1 and same effective drop rate, because spatial correlation in masking creates more structured (higher-dimensional) unreachable weight strata.\n\n**C3 (CONJECTURAL): Block Size as Spatial Stratum Selector**\nThe block size b acts as an additional stratum selector beyond the drop rate γ. As b increases from 1 to min(H,W):\n- b=1: independent masking, λ_DB = λ_dropout (#169), smooth variance scaling\n- b→min(H,W): entire feature map may be zeroed by a single block, λ_DB → λ_trivial\n- Intermediate b: spatially correlated strata, percolation-like phase transition in (b,γ) space\nClaim: λ_DB(b,γ) is monotone non-decreasing in b for fixed effective drop rate γ_eff, because larger blocks create more structured (higher-dimensional) singular fibers.\n\n**C4 (CONJECTURAL): Generalization Bound with Spatial Correlation**\nThe generalization bound for DropBlock is:\nG_DB(n) ≈ λ_DB(b,γ) · log(n) / (2n) + U_DB(b,γ) / √n\nwhere λ_DB(b,γ) captures the RLCT of the block-averaged landscape and U_DB(b,γ) accounts for spatial correlation in mask sampling. Unlike dropout (#169, U scales with independent mask count ~2^{HW}), DropBlock has fewer effective mask configurations (~2^{HW/b²}), reducing U_DB for fixed γ but increasing λ_DB. Optimal (b*,γ*) trades off RLCT reduction (favoring small b) against variance reduction (favoring large b). The optimal point lies near but below the percolation threshold γ_c(b) where blocks begin to overlap and cover the entire feature map.\n\n**C5 (CONJECTURAL): SGLD LLC Percolation Signature**\nAt the percolation threshold γ_c(b) ~ 1/(b²·p_c) (where p_c is the 2D site percolation threshold), the SGLD local learning coefficient (LLC) should show a characteristic transition. Below threshold (γ < γ_c), blocks are isolated, LLC reflects partial spatial masking. Above threshold (γ > γ_c), blocks percolate, the effective feature map is mostly zero, LLC jumps to a degenerate regime. The transition is sharper for larger b (fewer independent blocks, more cooperative behavior). This percolation signature is DISTINCT from dropout (#169, smooth LLC change with γ) and DropConnect (#613, weight-space phase transition).\n\n## Open Problems\n1.
