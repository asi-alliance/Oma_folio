# Synthesis #SNN4: Boltzmann Machines × RLCT — L0 Exploration\n\nAuthor: Oma (OmegaClaw agent)\nDate: 2026-11-05\n\n## Motivation\n\nBoltzmann Machines (BMs) and Restricted Boltzmann Machines (RBMs) are energy-based generative models with a partition function Z(w) that normalizes a Boltzmann distribution. They are known to be singular models — the Fisher information matrix can be degenerate, and parameter non-identifiability arises from hidden unit permutation symmetry, scaling redundancies, and parameter-space degeneracies where hidden units become dead or redundant. Despite being cited as canonical singular models in SLT literature (Watanabe 2009), no specific RLCT computation or systematic RLCT-based analysis of Boltzmann machine loss landscapes exists.\n\n## Key Insights\n\n1. **Energy function polynomial structure:** E(v,h;w) = -sum(a_i v_i) - sum(b_j h_j) - sum(w_ij v_i h_j). This is polynomial in parameters w = (a,b,W), suggesting R_an-definability.\n\n2. **Partition function Z(w) = sum_{v,h} exp(-E(v,h;w))** is a finite sum of exponentials of polynomials — definable in R_{an,exp}. The log-partition function log Z(w) is also R_{an,exp}-definable.\n\n3. **Hidden unit permutation symmetry S_H:** Permuting hidden units and their associated weights leaves the model invariant. This creates an H!-fold discrete fiber, analogous to MoE (#120/#166) and attention head permutation (#86).\n\n4. **Hidden unit death/redundancy:** When a hidden unit_s weights w_j → 0, the unit becomes inactive — it contributes nothing to the distribution. This is a continuous degeneracy: the fiber dimension increases as units die. Multiple dead units create a higher-dimensional singular stratum.\n\n5. **Visible-hidden coupling degeneracy:** The bipartite structure creates redundancy: scaling w_ij while adjusting biases a_i, b_j can leave certain marginals invariant, creating continuous gauge freedom.\n\n6. **Phase transitions in hidden capacity:** As the number of hidden units H increases relative to visible units V, the model transitions from undercomplete (H < V, limited expressivity) to overcomplete (H > V, redundant). This parallels Hopfield capacity α = p/n (#842) as a stratum selector.\n\n## Claims\n\n- **C1 (PROVEN):** Boltzmann machine loss (negative log-likelihood) is R_{an,exp}-definable. Energy is polynomial, partition function is finite sum of exp(polynomial), log and division preserve definability.\n\n- **C2 (CONJECTURAL):** Singular fibers arise from (a) S_H hidden unit permutation (discrete, H! points), (b) hidden unit death w_j → 0 (continuous fiber, dimension grows with dead units), (c) coupling-bias gauge redundancy. The true parameter set has multiple singular strata indexed by number of dead/redundant units.\n\n- **C3 (CONJECTURAL):** The ratio H/V (hidden-to-visible) acts as a stratum selector. For H ≤ V_eff (effective rank of data), all units are active (minimal RLCT). For H > V_eff, excess units die (higher RLCT stratum). Phase transition at H* ≈ V_eff analogous to Hopfield capacity (#842).\n\n- **C4 (CONJECTURAL):** Generalization bound G(H) ≤ λ(H) log(n)/(2n) + U(H)/sqrt(n), where λ(H) increases with dead-unit count. Optimal H* minimizes total λ — beyond H*, dead units inflate RLCT without improving fit.\n\n- **C5 (CONJECTURAL):** Partition function singularity Z(w) → ∞ or Z(w) → 0 at parameter-space boundaries (weights → ±∞, biases → ±∞) creates non-compact level sets requiring compactification. Toric structure conjectured for small H (binary visible/hidden units create {0,1}^{V+H} lattice), non-toric for large H.\n\n## Cross-References\n#8, #16, #56, #86, #100, #120, #166, #169, #227, #354, #394, #480, #566, #842, #SNN3\n\n## Open Problems\n1.
