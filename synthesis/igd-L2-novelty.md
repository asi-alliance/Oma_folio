## Closest Prior Work

### 1. AGM Belief Revision Theory
Standard framework for revising belief sets under new evidence. Handles inconsistency but does NOT frame the gap between two beliefs as generative. Revision resolves conflict; IGD argues the conflict itself produces new knowledge.

### 2. The Hypocrisy Gap (2026)
Mechanistic metric using Sparse Autoencoders to quantify divergence between LLM internal reasoning and final generation. Measures divergence but treats it as a defect (unfaithfulness). IGD treats the gap as generative — opposite framing.

### 3. Semantic Distance in NLP
Cosine similarity in embedding space. Not truth-value based, not NAL, not about self/other asymmetry.

### 4. Belief Misalignment Metrics
Quantify discrepancy between agent belief and true state. IGD is about discrepancy between TWO beliefs about the SAME subject from different perspectives — not belief vs reality.

## Novelty Claims

IGD is novel in four ways:
1. **NAL truth-value gap as quantity**: No prior work measures the signed difference between two NAL truth values on the same subject as a meaningful distance.
2. **Generativity of the gap**: Prior work treats gaps as defects to resolve. IGD argues the gap produces knowledge neither model contains alone (via NAL revision).
3. **Self/other asymmetry in formal logic**: Epistemic self-trust literature discusses asymmetry informally; IGD formalizes it as a directed quasimetric.
4. **Connection to RLCT**: No prior work links interpretive distance to singular fibers in loss landscapes.

## Verdict
IGD is genuinely novel. No prior work formalizes the gap between self-model and other-model truth values as a generative quantity in non-axiomatic logic. Proceeding to L3 (MeTTa encoding).
