# Synthesis #680: DPM-Solver × RLCT\n## L0 Exploration — 2026-10-28\n\n### Topic\nDPM-Solver (Lu et al. 2022) and its variants (DPM-Solver++, DPM-Solver-v3) solve the diffusion probability flow (PF) ODE using higher-order numerical methods. The k-th order solver approximates the exponential integral of the score function s_θ(x_t,t) ≈ ∇log p_t(x_t) via Taylor expansion of order k. Given N discretization steps, the solver produces samples x_0 from noise x_T. Key parameters: solver order k ∈ {1,2,3,...}, step count N, and time discretization schedule {t_i}.\n\n### RLCT Bridge\nThe DPM-Solver creates a **parameterized family of approximate flow maps** Φ̂^{(k,N)}: (x_T, θ) → x_0. Each (k,N) pair defines a different sampling operator that transforms the score network's parameter space into a sampling distribution. The truncation error of the k-th order Taylor expansion creates a **piecewise polynomial approximation** of the true score integral, which modifies the singular structure of the sampling distribution.\n\nKey insight: the **solver order k acts as a stratum selector** for the effective sampling landscape. At k=1 (Euler method), the linear approximation introduces the most discretization error, creating the most singular effective landscape. As k→∞, the approximation converges to the exact PF ODE flow, desingularizing the effective landscape. The truncation error introduces a correction term whose zero set {(x,θ) : E_k(x,θ) = 0} has a singular fiber structure dependent on k.\n\nThis is distinct from #167 (score matching loss RLCT — about training) because #680 is about the **inference-time sampling operator's singular structure**. It is distinct from #651 (flow matching — a training objective) because #680 is about the **solver's discretization**, not the flow definition. It is distinct from #567 (Neural ODE — continuous dynamics) because #680 explicitly studies the **discretization-induced singularities**.\n\n### Claims\n\n**C1 (PROVEN):** The DPM-Solver update map Φ̂^{(k,N)} is definable in R_an,exp. Proof: The k-th order Taylor expansion uses polynomial operations (definable in R_an), exponential functions (definable in R_an,exp), and compositions with the score network s_θ (analytic, definable in R_an,exp by #167 C1). The piecewise construction over N steps uses finite compositions, preserving definability. Therefore the effective sampling distribution's singular structure is amenable to RLCT analysis.\n\n**C2 (CONJECTURAL):** The truncation error E_k(x,θ) = ||Φ(x;θ) - Φ̂^{(k)}(x;θ)||^2 defines a singular fiber structure in (x,θ)-space. The zero set W_k = {(x,θ) : E_k = 0} (exact solver) has RLCT λ_k that depends on k. For k=1 (Euler), λ_1 is largest (most singular — linear approximation creates kinks at each step boundary). As k increases, λ_k decreases monotonically: λ_1 ≥ λ_2 ≥ λ_3 ≥ ... → λ_∞ (exact ODE, desingularized). The truncation introduces C^k-not-C^{k+1} singularities at step boundaries {t_i}.\n\n**C3 (CONJECTURAL):** The pair (k,N) jointly acts as a stratum selector. For fixed N, increasing k desingularizes the effective sampling landscape. For fixed k, increasing N shrinks the step size Δt, reducing the per-step truncation error and also desingularizing. The effective RLCT λ_eff(k,N) ≈ λ_∞ + C·(Δt)^{2k} where Δt ~ 1/N. There exists a critical surface (k*,N*) where the discretization error drops below the score approximation error (governed by λ_score from #167), marking a phase transition in sampling quality.\n\n**C4 (CONJECTURAL):** Generalization bound for DPM-Solver sampling quality:\n  Gen_sample ≤ C·sqrt(λ_eff(k,N)·(d-1)/n) + C_disc·(Δt)^{2k}\nwhere the first term is the RLCT-based generalization (from score network quality) and the second is the discretization bias. For (k,N) beyond the critical surface: C_disc·(Δt)^{2k} << sqrt(λ_eff·(d-1)/n), and sampling quality is RLCT-limited. Below the critical surface: discretization bias dominates.\n\n**C5 (CONJECTURAL):** Phase transition at (k*,N*) where discretization error ~ score approximation error. For DPM-Solver with k-th order and N steps:\n  (Δt)^{2k} ~ exp(-λ_score·n^{1/α})\nwhere α is the RLCT exponent from #167. This predicts that models with lower λ_score (better generalization) require fewer steps or lower order to achieve the same sampling quality — connecting training quality (RLCT) to inference efficiency (solver parameters). The phase transition manifests as a sharp drop in FID/sampling quality metrics.\n\n### Open Problems\n1.
