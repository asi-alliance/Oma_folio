# Synthesis #654: In-Context Learning (ICL) × RLCT — L1 Formalization\n## Date: 2026-10-28 | Status: L1 (formalization)\n\n## Definitions D1-D7\n\nD1 (Context-Conditioned Model): Fix trained parameters θ*. Define M(c) = f(θ*, c) where c = (x_1,...,x_{n_c}) is the in-context prompt. M(c) maps query x_q to prediction ŷ = M(c)(x_q). Composition of attention layers with softmax → piecewise-analytic in c.\n\nD2 (Context-Conditioned Loss): L_ICL(θ, c, x_q, y) = ℓ(M(c)(x_q), y) where ℓ is standard loss (CE or MSE). For fixed θ*, define L_c(x_q, y) = L_ICL(θ*, c, x_q, y) as the effective loss over the context-conditioned model.\n\nD3 (Context-Length Stratum Selector): Define n_c = |c| (number of context tokens/examples). Hypothesis: n_c indexes a family of effective singular strata S(n_c) in output space — more context → richer conditioning → lower effective RLCT λ_eff(n_c). Analogous to #490 RoPE context length but in output/forward-pass space.\n\nD4 (Context-Conditioned RLCT): Define λ(c) = RLCT of L_c restricted to the context-conditioned effective model. Formally: λ(c) = lim_{ε→0} (−log ∫_{L_c < ε} dc) / (−log ε), treating the context c as inducing a local loss landscape around the effective prediction.\n\nD5 (Effective RLCT Monotonicity): Hypothesis: λ_eff(n_c) is non-increasing in n_c for relevant context. More in-context examples → lower effective RLCT. Failure case: irrelevant context may increase λ_eff (negative ICL). Define λ_min = inf_c λ(c) as best-case context-conditioned RLCT.\n\nD6 (Critical Context Length): Define n* ~ n_train^{λ_eff / (λ_train + λ_eff)} as the phase-transition point. Below n*: under-conditioning (λ_eff high, ICL unreliable). Above n*: saturated conditioning (λ_eff → λ_min, ICL reliable). Testable via ICL accuracy curve.\n\nD7 (ICL Generalization Bound): G_ICL ≤ λ_eff(c)·log(n_c)/n_c + λ_train·log(n_train)/n_train. Two-term bound: context-length penalty (first term) + training RLCT penalty (second term). No adaptation budget term (unlike #653 TTT) — context replaces parameter updates.\n\n## C1 Definability (PROVEN)\nM(c) = f(θ*, c) is a composition of: (i) linear projections WQ, WK, WV, WO (polynomial), (ii) softmax attention (piecewise-analytic — exp/sum), (iii) MLP layers (analytic activation GELU/SiLU). The query prediction ŷ = M(c)(x_q) is therefore piecewise-analytic in c. The loss L_c(x_q, y) = ℓ(ŷ, y) inherits R_an,exp-definability from ℓ (CE: exp/log; MSE: polynomial). Closure under composition and addition preserves definability. ∎\n\n## C2-C5 (ConJECTURAL)\n\nC2: Context length n_c acts as stratum selector. More context examples → richer conditioning → lower λ_eff(n_c). Evidence: ICL accuracy improves with more shots. Mechanism: longer context activates more induction-head circuits (#508), enriching the effective model. Distinct from #490 (RoPE position encoding singularity in weight space).\n\nC3: ICL creates a VIRTUAL trajectory through singular space. The mapping c ↦ V_0(c) defines context-indexed family of singular fibers. Model "moves" across strata via context without parameter updates. Key distinction from #653 TTT (actual θ trajectory via gradient steps) and #508 (learnable circuit as weight-space singularity).\n\nC4: Generalization bound G_ICL ≤ λ_eff(c)·log(n_c)/n_c + λ_train·log(n_train)/n_train. Context-length penalty replaces adaptation budget. No migration cost (unlike #653) — no stratum migration since no weight movement. Novel bound structure.\n\nC5: Critical context length n* ~ n_train^{λ_eff/(λ_train+λ_eff)} — phase transition between under-conditioning and saturated conditioning. Testable via ICL accuracy jump. SGLD at inference: Hessian statistics of forward pass may detect λ(c) shifts.\n\n## Cross-References\n#508 (induction head circuit singularity), #653 (TTT dynamic trajectory), #502 (RAG external context), #490 (RoPE context length), #485 (RLT recurrence), #396 (GLA attention), #509 (task vectors), #134 (attention), #8 (base RLCT), #100 (transformer RLCT)\n\n## Open Problems\n1.
