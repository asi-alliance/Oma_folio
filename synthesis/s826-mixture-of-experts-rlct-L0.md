# Synthesis #826: Mixture of Experts (MoE) × RLCT - L0 Hypothesis\n# Date: 2026-11-03\n# Status: L0 DRAFT\n\n## Architecture Overview\n\nMixture of Experts (MoE) layers replace a single dense FFN with K expert subnetworks and a learned router (gate) that selects top-k experts per token. The gate g(x) = softmax(W_g · x) produces routing probabilities, and the output is y = Σ_{i∈top-k} g_i(x) · E_i(x). Load-balancing loss L_aux = α · CV(g)² encourages uniform routing to prevent expert collapse.\n\n## Key Singularity Hypothesis\n\nMoE introduces a **piecewise-defined loss function** — for each token, only k of K experts are activated, creating K-choose-k routing regions in input space. The loss surface is a patchwork of analytic pieces glued at routing decision boundaries. These boundaries are where the softmax gate values swap rank order (g_i = g_j for some i,j), creating codimension-1 surfaces in input space.\n\nThis is structurally analogous to ReLU (#8) but with a critical difference: the routing boundaries are **data-dependent AND parameter-dependent** (the gate W_g is learned), and the combinatorial structure (which k experts are selected) creates an exponentially large number of regions (C(K,k) routing configurations).\n\n## Five Conjectures\n\n**C1 (PROVEN candidate):** The MoE composite loss (task loss + load-balancing auxiliary loss) is R_{an,exp}-definable. The top-k selection is a piecewise-analytic operation (softmax + argmax with fixed k), the expert outputs are analytic (FFN with analytic activations), and the load-balancing loss CV(g)² is a rational function of gate outputs. All components are built from analytic operations.\n\n**C2 (CONJECTURAL):** The routing boundaries g_i(x) = g_j(x) create non-empty singular fibers. When two experts are equally likely (boundary), the loss is locally invariant to which expert handles the token — creating a degenerate direction in parameter space. The fiber V_0 = {θ : L(θ) = 0 locally at routing boundaries} is non-empty because symmetric expert configurations (identical expert weights) produce flat loss directions.\n\n**C3 (CONJECTURAL):** k (number of active experts) is a discrete stratum selector. For k=1 (hard routing), the singular fiber is most complex (sharpest boundaries, most degenerate directions). For k=K (all experts active, dense), the routing singularity vanishes (softmax never creates hard boundaries). Intermediate k interpolates: lambda(k) is non-increasing in k. This mirrors Gumbel-Softmax temperature (#839) but for discrete k rather than continuous temperature.\n\n**C4 (CONJECTURAL):** The generalization bound includes a routing complexity term: Gen = λ(k)·σ²/n + C_routing, where C_routing depends on the number of routing boundary crossings in the data distribution. More routing switches = higher complexity. K (total experts) acts as capacity amplifier: the effective parameter count is k·d_expert per token, but the RLCT depends on the full K·d_expert parameter space (all experts must generalize, even rarely-activated ones).\n\n**C5 (CONJECTURAL):** A phase transition occurs at k* — below k*, load-balancing collapse (few experts handle most tokens) creates a high-λ regime where collapsed experts are singular. Above k*, the system approaches dense computation and the routing singularity softens. The transition k* ~ O(log K) balances routing expressivity against singular complexity.\n\n## Key Novelty Anticipation\n\n- Routing boundaries as data+parameter-dependent singular strata (different from ReLU #8 which has fixed input-space boundaries, and different from Mamba #824 which has data-dependent but not combinatorial boundaries)\n- k as discrete stratum selector with combinatorial structure (different from Gumbel-Softmax #839 continuous temperature)\n- Expert collapse as singular fiber degeneration (load-balancing loss as desingularization penalty)\n- Load-balancing auxiliary loss as explicit desingularization term (analogous to weight decay #323 but in routing space)\n\n## Cross-References Anticipated\n#8 (ReLU), #839 (Gumbel-Softmax), #824 (Mamba), #169 (curriculum), #323 (weight decay), #100 (dropout), #539 (focal loss), #838 (RAG top-k retrieval)\n\nNext: L1 formalization.
