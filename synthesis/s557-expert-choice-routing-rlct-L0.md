# Synthesis #557: Expert Choice Routing × RLCT L0 Exploration\n# Date: 2026-10-23\n# Status: L0 — initial exploration\n\n## Topic: Expert Choice Routing (Zhou et al. 2022) × RLCT\n\nExpert Choice (EC) routing flips the standard MoE paradigm: instead of tokens choosing experts (token-choice), experts choose tokens. Each expert computes router scores for all tokens, sorts tokens by score, and selects its top-k. This creates a *balanced assignment* — every expert gets exactly `capacity` tokens.\n\n## Key Observations\n\n1. **Token sorting = permutation operation.** The argsort that determines which tokens each expert receives is a discontinuous function of router logits. Small perturbations in logits can swap token rankings, changing the assignment non-smoothly. This is a *permutation singularity* — the stratum boundary is where two tokens have equal router score (tie).\n\n2. **Capacity constraint = hard stratum boundary.** Unlike token-choice MoE where load balancing is a soft auxiliary loss, EC routing enforces exact balance via the top-k cutoff. The cutoff at rank `capacity` creates a semi-algebraic boundary in the router logit space: `{w : score_i(w) = score_j(w), rank(i) = capacity, rank(j) = capacity+1}`.\n\n3. **Reverse information flow.** In token-choice, the stratum is determined by which experts a token selects. In EC, the stratum is determined by which tokens an expert selects. This reverses the fiber structure: the "fiber" is over expert parameters, not token representations.\n\n4. **Automatic load balancing removes auxiliary singularity.** Standard MoE (#434) has load balancing loss as an additional singularity source. EC routing achieves balance by construction — no auxiliary loss needed. This *removes* a singular stratum present in #434.\n\n## Claims\n\n**C1 (Provable):** The EC routing loss is definable in R_an,exp. The sorting operation is piecewise-definable (comparisons are definable), top-k selection is definable (rank computation via indicator functions), and the rest of the network (linear layers, softmax, etc.) is standard definable.\n\n**C2 (Conjectural):** The token-sorting permutation creates a *permutation singularity* — a discontinuous stratum selector absent in token-choice MoE. The singular locus includes all parameter configurations where token rankings tie at the capacity boundary: `{w : score_i(w) = score_j(w), i at rank k, j at rank k+1}`. This is codimension-1 in router parameter space for each expert.\n\n**C3 (Conjectural):** The capacity constraint acts as a hard stratum selector, analogous to beam width k in #435 (beam search). Optimal capacity k* scales as k* ~ n^{1/(2λ_EC+1)} where λ_EC is the RLCT of the expert-choice model. The balanced assignment reduces the effective RLCT compared to unbalanced token-choice MoE because it eliminates the load-balancing auxiliary loss singularity.\n\n**C4 (Conjectural):** Generalization bound: G_EC(n) ≤ λ_EC · log(n)/(2n) + U_EC/√n, where λ_EC = λ_local + λ_perm + λ_capacity. The permutation term λ_perm is novel — it arises from the sorting discontinuity and has no analogue in token-choice MoE (#434) or beam search (#435, which operates in token space, not router parameter space).\n\n**C5 (Conjectural):** Training dynamics phase transition: as experts specialize, the permutation strata stabilize (fewer ranking ties → fewer stratum switches). This manifests as an LLC *decrease* during training — opposite to GELU's predicted LLC bump (#555). The phase transition occurs when expert specialization score crosses a threshold, after which permutations rarely change.\n\n## Open Problems\n\n1.
