The full parameter is w = (w_r, w_g) ∈ Θ.\n\n**D2 (Retriever Embedding).** Given a passage store P = {p_1, ..., p_M} with M passages, the retriever computes embedding scores s_i(q) = <φ_{w_r}(q), φ_{w_r}(p_i)> / (||φ_{w_r}(q)|| · ||φ_{w_r}(p_i)||) for each passage p_i, where φ_{w_r}: R^{d_in} → R^{d_f} is the embedding network.\n\n**D3 (Top-k Retrieval Operator).** The top-k retrieval operator r_k(q) = TopK_k({s_i(q)}_{i=1}^M) returns the k passages with highest relevance scores. This is a semi-algebraic set-valued map: the selected set changes when s_{(k)}(q) = s_{(k+1)}(q), i.e., at rank-tie boundaries.\n\n**D4 (RAG Loss).** The RAG training loss is K_RAG(w; q, a) = -log p_{w_g}(a | q, concat(r_k(q))) = -log p_{w_g}(a | q, c_k(q)) where c_k(q) is the concatenation of query q with retrieved passages r_k(q). The empirical loss is L_n(w) = (1/n) Σ_{i=1}^n K_RAG(w; q_i, a_i).\n\n**D5 (Retrieval Boundary Singularity).** Define the retrieval boundary B_k(w_r) = {w_r ∈ Θ_r : ∃ q, ∃ permutation σ, s_{σ(k)}(q) = s_{σ(k+1)}(q)} — the set of retriever parameters where rank ties occur. This is a semi-algebraic variety (zero set of score differences) of codimension ≥ 1.\n\n**D6 (Embedding Collapse Stratum).** Define S_collapse = {w_r ∈ Θ_r : ∃ i≠j, φ_{w_r}(p_i) = φ_{w_r}(p_j)} — the set where two distinct passages have identical embeddings. This creates a degenerate fiber where retrieval cannot distinguish them.\n\n**D7 (Composite RLCT).** The RLCT λ_RAG of the RAG loss is defined as λ_RAG = lim_{t→∞} (1/(-log t)) log(∫ exp(-t·L_n(w)) φ(w) dw / ∫ exp(-t·L_n^0(w)) φ(w) dw) where L_n^0 is the non-retrieval generation loss.
