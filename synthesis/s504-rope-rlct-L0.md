# Synthesis #504: Rotary Position Embeddings (RoPE) × Real Log-Canonical Threshold (RLCT)\n## L0: Overview & Conjectures\n\n### Topic Statement\nRotary Position Embeddings (RoPE) apply a position-dependent SO(2) rotation to query/key pairs in transformer attention. This rotation action introduces a group-theoretic structure on the parameter space whose interaction with the loss landscape singularity structure has not been analyzed through the lens of Singular Learning Theory (SLT). We bridge this gap.\n\n### Definition: Rotary Position Embeddings (Su et al., 2021)\nGiven attention vectors q, k in R^{2d} (paired dimensions), RoPE applies position-m rotation:\n  q_m = R(m) * q, k_n = R(n) * k\nwhere R(m) = block_diag(R(theta_m,1), R(theta_m,2), ..., R(theta_m,d)) with R(theta) = [[cos(theta), -sin(theta)], [sin(theta), cos(theta)]] and theta_{m,i} = m * base^{-2(i-1)/d}.\nThe attention score <q_m, k_n> depends only on (m-n) due to rotation equivariance.\n\n### Definition: RLCT (Watanabe)\nThe Real Log-Canonical Threshold lambda for model p(y|x,w) and true distribution q(y|x) is the RLCT of the Kullback-Leibler loss locus K(w) = {w : KL(q||p_w) = 0} as an algebraic variety. Lower lambda = more singular = more complex.\n\n### Key Insight: SO(2) Group Action Creates Orbit-Type Stratification\nThe RoPE rotation R(m) acts on the (q,k) parameter space as an SO(2)^d group action. Group actions on algebraic varieties induce orbit-type stratifications — the parameter space decomposes into strata indexed by stabilizer conjugacy classes. Each stratum has a potentially different RLCT. The rotation angles theta_{m,i} parametrize a torus T^d = (S^1)^d acting on the paired dimensions.\n\n### Conjecture C1 (Provable): RoPE Group Action is Algebraic\nThe RoPE rotation map R: Z x Theta -> GL(2d) is definable in the o-minimal structure R_an,exp since cos/sin are restricted to compact domains and theta_{m,i} = m * base^{-2(i-1)/d} is exp-definable. Therefore the KL loss locus K(w) with RoPE is a semi-algebraic set definable in R_an,exp, and RLCT is well-defined by Watanabe's theorem.\n\n### Conjecture C2 (Conjectural): Orbit-Type Stratification Lowers Effective RLCT\nThe torus action T^d on (q,k) space creates orbit-type strata S_alpha. The minimal RLCT stratum (corresponding to generic orbits with trivial stabilizer) has strictly lower RLCT than the unrotated baseline (identity embedding). Rotation equivariance effectively "spreads" the singularity across a smooth orbit manifold, reducing the local learning coefficient at generic points.\n\n### Conjecture C3 (Conjectural): Position-Dependent RLCT\nThe RLCT of the loss locus at position offset Delta = m-n depends on the rotation angle theta_{Delta,i} = Delta * base^{-2(i-1)/d}. For Delta = 0 (same position), theta = 0 and the rotation is identity — RLCT equals the unrotated baseline. As |Delta| increases, rotations mix dimensions, potentially thickening singular fibers and lowering RLCT. This creates a position-dependent complexity profile.\n\n### Conjecture C4 (Conjectural): Base Frequency as Desingularization Parameter\nThe base frequency parameter (typically 10000) controls the rate of angular variation across positions. Large base -> slow rotation -> orbits nearly coincide -> RLCT approaches unrotated baseline. Small base -> rapid rotation -> orbits spread widely -> lower RLCT but potential information loss. There exists an optimal base* balancing singularity reduction vs expressivity, analogous to epsilon* in #224 (label smoothing) and T* in #234 (temperature scaling).\n\n### Conjecture C5 (Conjectural): Rotation-Invariant Singular Set\nThe KL loss locus K(w) is invariant under the diagonal torus action T^d (simultaneous rotation of q and k by the same angle). This invariance means the singular set has a product structure: K(w) = K_0 x T^d where K_0 is the reduced singular set on the orbit quotient. The RLCT decomposes as lambda(K) = lambda(K_0) + d/2 (the d/2 from the smooth torus factor). This makes the "effective" RLCT lambda(K_0) < lambda(K) and explains why RoPE generalizes better than absolute position embeddings.\n\n### Cross-References\n- #224 Label Smoothing × RLCT (desingularization parameter epsilon*)\n- #234 Temperature Scaling × RLCT (singularity selector T*)\n- #245 RoPE mentioned in candidate selection (this is the full treatment)\n- #264 RMSNorm (normalization as desingularization)\n- #265 SwiGLU (activation singularity structure)\n- #296 Depth as Selector (architecture parameter as RLCT selector)\n- #386 Warmup Scheduling × RLCT (schedule as phase transition control)\n\n### Open Problems\n1.
