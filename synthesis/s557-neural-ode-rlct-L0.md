# Synthesis #557: Neural ODE × RLCT\n\n## Date: 2026-10-24\n## Status: L0 DRAFT\n## Prior Work: Zero catalog hits, zero SLT/RLCT websearch hits confirmed 2026-10-23\n\n## Architecture\nNeural ODE (Chen et al. 2018): dz/dt = f_θ(z, t), solved by numerical ODE integrator (e.g., Runge-Kutta). The network depth is continuous — the state z(t) evolves along a continuous trajectory parameterized by θ. Loss computed on terminal state z(T) via adjoint method for gradients.\n\n## Claims\n\n### C1 (PROVEN): R_{an,exp}-definability of Neural ODE loss\nThe ODE dz/dt = f_θ(z,t) where f_θ is a neural network (analytic in θ for smooth activations) has a solution z(t) that is analytic in θ (Picard-Lindelöf + analytic dependence on parameters). The loss L(θ) = ℓ(z(T)) is therefore R_{an,exp}-definable. Standard ODE solvers (RK4, Euler) compose analytic steps — each step is analytic in θ, so the discretized loss is also analytic. The adjoint method computes ∂L/∂θ via backward integration of an augmented ODE — the gradient map is also analytic in θ.\n\n### C2 (CONJECTURAL): Solver discretization creates parameter-dependent singularities\nThe continuous ODE solution is analytic in θ, but numerical solvers introduce step-size h-dependent truncation. The discretized flow map Φ_h^N(θ) after N steps approximates the exact flow. For fixed h, Φ_h is analytic — but the NUMBER of solver steps N(θ) may vary adaptively (tolerance-based stepping). This creates piecewise-smooth dependence: the parameter space is partitioned into regions where N(θ) = k for each k, with discontinuities at tolerance boundaries. These boundaries are semi-algebraic sets (defined by error estimates crossing tolerance), creating singular strata. Prediction: LLC of Neural ODE with adaptive stepping > LLC with fixed stepping (adaptive introduces singular strata).\n\n### C3 (CONJECTURAL): Adjoint method creates non-injective loss-to-gradient map\nThe adjoint method computes gradients by integrating a(0) = -∂ℓ/∂z(T) backward, then ∂L/∂θ = ∫ a(t)^T ∂f/∂θ dt. This map L → ∇L is NOT injective: different loss landscapes can produce the same gradient trajectory (the adjoint ODE depends on the forward trajectory z(t), not on ℓ directly). Two functions ℓ₁, ℓ₂ yielding the same z(T) produce identical adjoint dynamics → identical gradients. This non-injectivity creates fibers in the (L, ∇L) space — a new type of singularity specific to ODE-based models not present in discrete networks. The fiber structure depends on the ODE solver and tolerance.\n\n### C4 (CONJECTURAL): Neural ODE RLCT = continuous limit of ResNet RLCT\nA ResNet with identity skip connections and depth L approximates the Euler discretization of an ODE with step h=1/L. As L→∞, the ResNet loss landscape converges to the Neural ODE loss landscape. From #199 (skip connections), ResNet RLCT < MLP RLCT because identity maps create singular fibers (redundant layers). Conjecture: lim_{L→∞} RLCT(ResNet_L) = RLCT(NeuralODE). The continuous-depth limit may have LOWER RLCT than any finite ResNet — the singular fibers of identity maps merge into a continuous flow, potentially desingularizing the landscape. Alternatively, the ODE solver reintroduces discretization singularities (#C2), so the limit may be singular. This is a phase-transition question: does continuous depth desingularize or not?\n\n### C5 (CONJECTURAL): Solver tolerance as stratum selector\nThe adaptive ODE solver tolerance ε controls the trade-off between accuracy and computation. As ε decreases, more solver steps are taken, and the discretized loss converges to the true analytic loss. For large ε, the solver coarsely approximates — effectively a low-depth ResNet with larger singular strata. For small ε, the solver approximates the true ODE — potentially regular. Conjecture: there exists a critical ε* below which the RLCT drops to the continuous-limit value. Above ε*, discretization singularities dominate. This is analogous to #213 (LR scheduling) and #424 (Fixup scaling) where hyperparameters act as stratum selectors.\n\n## Open Problems\n1.
