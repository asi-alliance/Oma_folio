TTT/TTA breaks this: the model actively traverses singular stratum space DURING inference. This creates a **dynamic stratum selector** — a test-input-dependent trajectory through the singular landscape. The singular locus accessible to the model is not a point but a PATH, parameterized by adaptation steps t and test input x_test.\n\n## Formal Setup\n- Training: θ_train* = argmin_θ R̂_train(θ), supervised loss L_sup on training distribution P_train\n- Test-time: θ_test(t) = θ_train* - η Σ_{s=1}^{t} ∇_θ L_self(θ(s); x_test), self-supervised loss L_self on test input(s)\n- Prediction: ŷ = f(x_test; θ_test(T)) for some adaptation budget T\n- Key: θ_test(t) traces a trajectory through parameter space, crossing singular stratum boundaries of the COMPOSITE loss landscape L_total = L_sup + λ·L_self\n\n## Candidate Claims\n\n### C1 (PROVEN): R_an,exp-Definability of Test-Time Adapted Loss\nThe test-time adaptation loss L_self(θ; x_test) and supervised loss L_sup(θ; x_train) are both R_an,exp-definable (standard neural network losses). The composite landscape L_total(θ) = L_sup(θ) + λ·L_self(θ) and its gradient trajectory θ_test(t) are piecewise-analytic (gradient of definable function is definable on regular strata, with piecewise transitions at stratum boundaries). PROVEN by closure properties of R_an,exp under addition, composition, and piecewise differentiation.\n\n### C2 (CONJECTURAL): Dynamic Stratum Selector — Test-Time Trajectory Through Stratum Space\nUnlike static inference (θ* fixed, single stratum accessed), TTT creates a trajectory θ_test(t) that traverses singular stratum space. The stratum accessed at step t is S(t) = {θ : L_total(θ; x_test) is locally minimal}, which depends on x_test. Different test inputs activate different trajectories through stratum space. This is a DYNAMIC stratum selector — the first such mechanism in the RLCT framework. The trajectory is piecewise-smooth, with stratum crossings at critical adaptation steps t_k where the gradient crosses a stratum boundary.\n\n### C3 (CONJECTURAL): RLCT Gap Governs Adaptation Success\nLet λ_train = RLCT of L_sup under P_train, and λ_test(x) = RLCT of L_self under the test distribution centered at x. Adaptation succeeds (improves test performance) iff the stratum gap Δλ = λ_test - λ_train is within an accessible range:\n- If Δλ ≈ 0: test stratum coincides with train stratum, adaptation unnecessary (or neutral)\n- If Δλ > 0 and moderate: adaptation descends to lower-RLCT test stratum, improving generalization on test distribution\n- If Δλ >> 0: stratum gap too large, adaptation budget T insufficient, model trapped between strata (under-adaptation)\n- If Δλ < 0: test stratum has higher complexity, adaptation may overfit to test-specific noise (over-adaptation)\nThe critical insight: RLCT gap is the fundamental quantity governing TTT success, not distribution distance (Wasserstein/KL) alone.\n\n### C4 (CONJECTURAL): Generalization Bound with Stratum Migration Term\nFor TTT with adaptation budget T on n_test test samples:\nG_TTT ≤ (λ_train · log(n_train)) / n_train + (λ_adapt(T) · log(n_test)) / n_test + C(Δλ)\nwhere λ_adapt(T) is the effective RLCT after T adaptation steps (decreasing in T toward λ_test), and C(Δλ) is a stratum migration cost proportional to the RLCT gap |Δλ|. The bound predicts:\n- TTT helps when λ_adapt(T) < λ_train (test stratum has lower complexity)\n- TTT hurts when C(Δλ) dominates (stratum gap too large for budget T)\n- Optimal T* balances stratum descent against migration cost\n\n### C5 (CONJECTURAL): Critical Adaptation Budget T* Phase Transition\nThere exists a critical adaptation budget T* ~ n_test^{1/(λ_test + 1)} such that:\n- T < T*: under-adaptation, model remains near train stratum, minimal test improvement\n- T = T*: phase transition, model crosses into test stratum, sharp performance improvement\n- T > T*: over-adaptation risk, model may descend into test-specific spurious singularities (memorizing test input structure via L_self), performance degrades\nT* is SGLD-testable: measure LLC of adapted model vs T, observe non-monotone curve with peak/transition at T*.\n\n## Predictions\n1.
