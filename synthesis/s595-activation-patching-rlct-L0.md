# Synthesis #595: Activation Patching × RLCT — L0 Claims\n\n**Date:** 2026-10-25\n**Status:** L0 drafted\n\n## Background\n\nActivation patching (aka causal tracing) is a mechanistic interpretability technique: run the model on a clean input and a corrupted input, then replace (patch) intermediate activations from the clean run into the corrupted run at a specific layer/position. The patched output differs from both clean and corrupted, isolating the causal contribution of the patched component. Formally: given clean activation a^clean_l and corrupted activation a^corr_l, the patched run substitutes a^clean_l → a^corr_l at layer l, position p, yielding output y_patch(l,p).\n\n## Claims\n\n- **C1 (Proven):** The patched loss L_patch(w, l, p) = L(y_patch(l,p), y_clean) is definable in R_{an,exp}. Proof: the patching operation is a coordinate substitution (piecewise-linear selection), the model forward pass is analytic, and composition preserves R_{an,exp} definability. The intervention boundary between patched and unpatched is a semi-algebraic set.\n\n- **C2 (Conjectural):** The patching intervention creates intervention-stratified singular fibers S_{l,p} indexed by (layer l, position p). Each intervention point defines a different effective loss landscape — the patched model sees a hybrid of clean and corrupted inputs, creating a singular fiber that is the intersection of the clean and corrupted loss varieties. The RLCT of the patched loss λ(l,p) differs from both λ_clean and λ_corr.\n\n- **C3 (Conjectural):** The intervention location (l,p) acts as a stratum selector. λ(l,p) is non-monotone in l: patching early layers creates high-RLCT (more singular) loss because early interventions propagate through more of the network, creating broader degeneracy. A critical layer l* exists where λ(l) peaks — the layer of maximal causal influence.\n\n- **C4 (Conjectural):** Generalization bound for patched models: G(l,p) ≤ C·√(λ(l,p)·d_eff(l) / n) where d_eff(l) accounts for the effective dimensionality of the intervention. Patching at causally irrelevant layers (low λ impact) yields G ≈ G_corr; patching at critical layers (high λ impact) yields G ≈ G_clean.\n\n- **C5 (Conjectural):** The patching effect size Δ(l,p) = L_corr - L_patch(l,p) has a phase transition at the critical layer l*. Below l*, patching has negligible effect (Δ ≈ 0, patched loss ≈ corrupted loss, same stratum). Above l*, patching partially restores (Δ > 0, crossed into a new stratum). The phase transition boundary is the intervention singularity surface where the patched loss changes character.\n\n## Key Novelty\n\n1. Intervention as singularity probe: activation patching is an experimental tool that directly queries the singular fiber structure by creating hybrid clean-corrupted loss landscapes. This connects mechanistic interpretability to SLT in a novel direction — patching as a measurement of λ(l,p).\n\n2. Causal influence = stratum distance: the patching effect Δ(l,p) measures how far the corrupted model is from the clean singular fiber. Large Δ = large stratum separation.\n\n3. Intervention boundary as singularity surface: the semi-algebraic boundary between patched and unpatched regimes is a new singularity type in the catalog — an intervention-induced singularity, not arising from model architecture but from the interpretability procedure itself.\n\n4. Layer-indexed RLCT λ(l): the RLCT varies across layers, connecting to #340 (logit lens layer-indexed singularity) but from the intervention side rather than the projection side.\n\n## Cross-References\n\n#8 #16 #57 #86 #94 #134 #139 #162 #170 #302 #335 #340 #503 #510 #545\n\n## Open Problems\n\n1.
