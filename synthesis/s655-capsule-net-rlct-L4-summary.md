# Synthesis #655: Capsule Networks × RLCT — L4 Plain-Language Summary\n\n## Date: 2026-10-26\n## Agent: Oma\n\n## What are Capsule Networks?\nCapsule Networks (CapsNets), introduced by Sabour, Hinton, and Frosst (2017), replace scalar neurons with vector-valued capsules. Each capsule outputs a vector whose magnitude represents instantiation probability and whose direction encodes pose parameters. A squash function maps raw capsule inputs to short zero-to-one vectors. Dynamic routing-by-agreement iteratively updates coupling coefficients between child and parent capsules via an EM-like fixed-point loop, replacing max-pooling with a learned routing process.\n\n## What does SLT/RLCT add?\nSingular Learning Theory reveals that the squash function, routing iterations, and coupling simplex each create distinct singular structures in the loss landscape. The Real Log Canonical Threshold (RLCT) of these singular loci governs generalization. CapsNets are unusually rich in singular features for a single architecture: rational poles, fixed-point boundaries, simplex faces, and a collapse phase transition.\n\n## Key Claims in Plain Language\n\n**C1 (Proven):** The CapsNet loss is R_an,exp-definable. The squash function is rational away from ||s||=0 with a continuous (but non-analytic) piecewise extension to the origin. Routing is polynomial agreement + exponential softmax, composed T times. The margin loss is piecewise polynomial and the reconstruction loss is polynomial. All components live in R_an,exp. Solid foundation.\n\n**C2 (Conjectural):** The squash function creates a rational singularity at ||s||=0 — the direction s/||s|| is undefined, creating a codimension-1 stratum where S^{d-1} is identified to a point. This is qualitatively different from RMSNorm (#466), which also has ||x||=0 singularity but without the additional scale ||s||^2/(1+||s||^2). The full singular fiber V_route also includes non-convergence boundaries, coupling saturation faces, and prediction tensor degeneracy (W_ij=0).\n\n**C3 (Conjectural):** Routing depth T acts as a stratum selector. Each additional routing iteration exposes more singular structure: V_0(T) ⊇ V_0(T-1), analogous to #485 RLT loop depth. The RLCT λ(T) is non-decreasing in T. More iterations mean richer task representation but higher effective complexity — a depth-generalization trade-off.\n\n**C4 (Conjectural):** Generalization bound: G(n,T) ≤ λ(T)·log(n)/(2n) + U(T)/√n where U(T) is routing-induced gradient tension. Unlike standard SLT bounds, the effective complexity depends on routing iterations, coupling CapsNet generalization to the routing algorithm's convergence geometry.\n\n**C5 (Conjectural):** At a critical agreement scale β*, routing collapses from distributed coupling (c_ij spread across simplex interior, multi-parent) to winner-take-all (c_ij → δ_{j*}, single-parent). λ(β) has a jump discontinuity at β*, a phase transition in the singular landscape. This parallels temperature selectors in #654 GFlowNet but arises from iterative agreement dynamics rather than a global temperature.\n\n## Key Novelty\nThe standout contribution is the **rational squash singularity at ||s||=0** combined with the **routing fixed-point stratum selector**.
