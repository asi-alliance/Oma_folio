# S812: RoPE (Rotary Position Embedding) x RLCT -- L1 Formalization\n\n## D1: Rotation Map\nFor position m and frequency spectrum theta_i = 10000^{-2i/d}, define the rotation map:\n  R_m = diag(R(theta_1 m), R(theta_2 m), ..., R(theta_{d/2} m))\nwhere R(phi) = [[cos(phi), -sin(phi)], [sin(phi), cos(phi)]] is the 2x2 rotation matrix.\nThe rotary query/key: q_m = R_m q, k_n = R_n k.\nParameter space W = {(Q, K, V, W_O)} in R^{d_model x n_layers}.\n\n## D2: Rotary Attention Loss\nThe attention logit between positions m,n:\n  S(m,n) = q^T R_m^T R_n k = q^T R_{n-m} k\ndepends only on relative position Delta = n-m. The per-token loss:\n  L(w) = (1/N) sum_{m=1}^{N} ell(sum_n softmax(S(m,n)/sqrt(d)) v_n, y_m)\nFull loss K(w) = E_{(x,y)~D}[L(w; x, y)] is R_an,exp-definable: cos/sin on compact [0, N*theta_max], softmax exponential, polynomial composition.\n\n## D3: SO(2)^{d/2} Gauge Fiber\nThe rotation group G = SO(2)^{d/2} = prod_{i=1}^{d/2} SO(2)_i acts on (q,k) by simultaneous rotation: g*(q,k) = (R_g q, R_g k). The attention logit S(m,n) = q^T R_{n-m} k is G-invariant: S(g*q, g*k, m, n) = S(q,k,m,n). This creates a gauge fiber F_g = {(q,k) : q = R_g q_0, k = R_g k_0} of dimension d/2.\n\n## D4: Singular Fiber V_0\nThe zero-loss set V_0 = {w : K(w) = 0}. The gauge sub-fiber V_g = V_0 intersect F_g is the subset of zero-loss parameters within a fixed rotation gauge. Frequency-degenerate strata V_i arise when theta_i * L_seq << 2*pi (low-freq pairs barely rotate, creating near-identity fibers with higher degeneracy).\n\n## D5: RLCT lambda_RoPE\nThe RLCT of the rotary attention loss landscape:\n  lambda_RoPE = RLCT(V_0, K)\nThe gauge fiber quotient V_0/G has potentially lower RLCT than V_0 due to the d/2-dimensional continuous symmetry:\n  lambda_RoPE <= lambda_abs - d_gauge/2\nwhere d_gauge = d/2, CONJECTURAL. Torus compactification removes tail singularities from unbounded positions.\n\n## D6: Generalization Bound\n  G_RoPE(theta, n) <= lambda_RoPE * log(n) / (2n) + U_rot / sqrt(n)\nwhere U_rot captures residual complexity after quotient. Since lambda_RoPE <= lambda_abs, the gen bound is tighter. Torus compactification bounds U_rot < U_abs.\n\n## D7: Frequency Stratum Selector\nEach frequency theta_i defines a stratum Sigma_i. Low-frequency pairs create coarse strata with winding number << 1 -- higher degeneracy, lower local RLCT. High-frequency pairs create dense winding -- lower degeneracy, higher local RLCT. The effective RLCT is U-shaped in frequency index i:\n  lambda_i ~ theta_i * L_seq (for theta_i * L_seq near 2*pi)\nTotal lambda_RoPE = sum_i lambda_i / (d/2), CONJECTURAL. Training progressively activates lower-RLCT strata.\n\n## C1 PROOF: R_an,exp Definability\nR_m uses cos(theta_i * m), sin(theta_i * m).
