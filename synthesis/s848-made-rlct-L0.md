# Synthesis #848: MADE × RLCT\n\n## L0: Introduction and Scoping\n\nMADE (Masked Autoencoder for Distribution Estimation) transforms a standard autoencoder into an autoregressive density model by masking weight connections so output i depends only on inputs {1,...,i-1}. Binary masks M^l enforce triangular connectivity.\n\nThe RLCT bridge: deterministic binary weight masks create fixed zero-weight strata in parameter space. Each masking pattern defines a singular fiber — the zero-enforced weights create non-injective maps. Permutation of hidden units within mask constraints yields combinatorial non-identifiability. Unlike dropout (#169, stochastic masks) or mixup (#258, input interpolation), MADE masks are fixed structural constraints creating permanent singularities.\n\n## L1: Formal Definitions\n\n- **D1** (MADE Masking): For layer l with weight W^l, mask M^l ∈ {0,1}^{d_l × d_{l-1}} enforces autoregressive property. Masked weight W̃^l = W^l ⊙ M^l. Masks assigned via random permutation m^l of hidden units.\n\n- **D2** (Autoregressive Factorization): p(x) = Π_i p(x_i | x_{<i}), each conditional computed via single forward pass through masked network.\n\n- **D3** (Zero-Weight Stratum): For mask M, the zero-weight set Z_M = {W : W ⊙ (1-M) = 0} is a linear subspace of parameter space. The true parameter space is the union over all valid mask patterns.\n\n- **D4** (Combinatorial Non-Identifiability): Hidden unit permutations σ within layers that preserve the autoregressive property yield equivalent networks: f(W) = f(σ(W)). The symmetry group S_{d_l} per layer creates quotient singularities V/σ.\n\n- **D5** (Empirical Loss): L(W) = -(1/n) Σ log Π_i p(x_i | x_{<i}; W⊙M), piecewise analytic in W within each mask stratum.\n\n- **D6** (Singular Fiber): V_M = {W⊙M : L(W) = 0} for fixed mask M. The full fiber is V = ∪_M V_M, a union of strata indexed by mask patterns.\n\n- **D7** (Real Code): l_f ~ Prod(W; p) restricted to non-zero-weight coordinates, analytic in IR, singular at mask boundary crossings.\n\n## L2: Claims C1-C5\n\n- **C1** (Definability [PROVEN]): Empirical loss is piecewise polynomial in W within each mask stratum (products of affine maps + sigmoid). Real code is R_{an,exp}-definable. Satisfies SLT conditions.\n\n- **C2** (Mask-Induced Quotient Singularity [CONJECTURAL]): The permutation symmetry group creates quotient singularities V/σ with RLCT λ ≥ standard RLCT. Quotient singularities generically increase RLCT.\n\n- **C3** (Combinatorial Stratum Complexity [CONJECTURAL]): Number of valid mask patterns grows combinatorially; each adds a stratum. Total RLCT λ_total ≥ max_M λ_M due to union of singular fibers.\n\n- **C4** (Generalization Bound [CONJECTURAL]): Generalization gap controlled by stratum complexity of the active mask. Simpler autoregressive orderings (fewer conditionals) → lower λ → better generalization.\n\n- **C5** (Mask Width vs RLCT Trade-off [CONJECTURAL]): Wider hidden layers with richer mask patterns explore more strata but increase λ. Optimal width balances expressivity vs RLCT, analogous to #169 dropout rate.\n\n## L3: Open Problems\n\n1.
