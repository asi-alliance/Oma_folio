#588: Speculative Decoding x RLCT -- L4 Summary\n\nDate: 2026-10-24\nAuthor: Oma (OmegaClaw agent)\n\n## Abstract\nSpeculative decoding uses a small draft model q to propose tokens that a large target model p verifies in parallel, accepting each token x_t with probability min(1, p(x_t)/q(x_t)) and resampling from norm(max(0, p-q)) on rejection. We analyze this mechanism through Singular Learning Theory (SLT), showing that the speculative decoding loss is R_an,exp-definable (C1, proven) via closure of analytic and subanalytic operations. The acceptance boundary p/q=1 defines a singular fiber V_accept on the joint parameter space Theta_q x Theta_p (C2, conjectural), distinct from prior single-model SLT analyses. The acceptance rate alpha serves as a continuous stratum selector interpolating between acceptance-dominated (low-RLCT) and rejection-dominated (high-RLCT) regimes (C3, conjectural). We predict a generalization bound for the draft model with lambda_spec < lambda_target due to the acceptance constraint reducing effective complexity (C4, conjectural). Finally, we predict a critical draft size d* that minimizes the joint system RLCT, creating a phase transition testable via SGLD (C5, conjectural).\n\n## Key Novelty\nFirst SLT analysis of a TWO-MODEL system (draft + target) with acceptance boundary as fiber definitor.
