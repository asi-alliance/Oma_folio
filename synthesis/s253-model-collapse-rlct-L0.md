# Synthesis #253: Model Collapse × RLCT — L0 Exploration\n## Date: 2026-10-26\n## Status: L0 EXPLORATION\n\n## Motivation\n\nModel collapse (Shumailov et al., Nature 2024) is the degenerative process where generative models trained on data produced by prior models lose diversity, suffer tail distribution erosion, and converge to low-entropy outputs. No prior work connects this to Singular Learning Theory (SLT) or the Real Log Canonical Threshold (RLCT). This synthesis explores the bridge.\n\n## Key Insight\n\nRecursive training on synthetic data progressively collapses the singular stratum structure of the model class. Each generation narrows the accessible singular fiber — the set of parameters achieving optimal loss shrinks as the true distribution degenerates. The RLCT increases across generations because the model loses capacity to represent the full data distribution, concentrating on an increasingly singular (degenerate) fiber.\n\n## Questions\n\n1. Is the model-collapse loss (recursive KL between generation-g and generation-g+1) definable in R_{an,exp}?\n2. Does recursive training progressively narrow the singular fiber, increasing RLCT across generations?\n3. What acts as the stratum selector — generation depth g, synthetic data fraction alpha, or data accumulation rate?\n4. Does generalization degrade as RLCT increases, with a bound G(n,g) involving generation-dependent lambda(g)?\n5. Is there a critical generation g* where collapse becomes irreversible — a phase transition in RLCT?\n\n## Claims\n\n### C1: DEFINABILITY (PROVEN)\nThe recursive training loss L_g(theta) = E_{x~P_g}[-log p_theta(x)] where P_g is the generation-g data distribution is definable in R_{an,exp}. Each generation's loss is a standard NLL, and the recursive composition preserves analyticity.\n\n### C2: PROGRESSIVE FIBER COLLAPSE (CONJECTURAL)\nLet W_0(g) be the set of optimal parameters at generation g. Recursive training on synthetic data progressively narrows W_0(g): W_0(g+1) ⊆ W_0(g) in the sense that the accessible singular fiber shrinks as the true distribution degenerates. The RLCT lambda(g) is non-decreasing: lambda(g+1) >= lambda(g). Tail information loss corresponds to stratum elimination.\n\n### C3: GENERATION DEPTH AS STRATUM SELECTOR (CONJECTURAL)\nThe generation index g acts as a discrete stratum selector. Each generation eliminates higher-RLCT strata (those representing tail/m minority data) and concentrates probability mass on the lowest-RLCT (most degenerate) stratum. The synthetic data fraction alpha modulates the rate of stratum elimination.\n\n### C4: GENERALIZATION BOUND WITH GENERATION-DEPENDENT RLCT (CONJECTURAL)\nG(n,g) <= lambda(g) * log(n) / (2n) + U(g) / sqrt(n) + B_collapse(g), where lambda(g) is the generation-g RLCT and B_collapse(g) captures the distributional drift cost. As g increases, lambda(g) increases and B_collapse(g) grows, predicting monotonic degradation. Keeping real data (alpha < 1) slows lambda(g) growth.\n\n### C5: IRREVERSIBILITY PHASE TRANSITION (CONJECTURAL)\nThere exists a critical generation g* (dependent on alpha, model capacity, and original distribution complexity) beyond which collapse becomes irreversible: the RLCT exceeds a threshold lambda_critical where the model can no longer escape the degenerate stratum even with fresh real data. This is testable via SGLD LLC estimation across generations.\n\n## Cross-References\n#8 (grokking phase transition), #168 (VAE posterior collapse), #186 (data poisoning), #327 (pseudo-labeling self-referential singularity), #354 (STE), #360 (machine unlearning = stratum destruction), #415 (grokking), #497 (matryoshka nested strata), #502 (RAG retrieval collapse), #556 (VQ-VAE codebook collapse)\n\n## Open Problems\n1.
