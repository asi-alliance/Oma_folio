# Synthesis #564: Tokenization / BPE × RLCT\n## Date: 2026-10-23\n## Status: L4 (Summary)\n\n### Plain-Language Summary\n\nTokenization — the process of splitting text into discrete tokens — is the very first step in any language model pipeline, yet its effect on the loss landscape has rarely been studied through the lens of Singular Learning Theory. This synthesis asks: what singular structure does BPE tokenization create?\n\n**Key insight**: BPE creates a hierarchical partition of input string space via its merge tree. Each merge rule draws a boundary. The resulting tokenizer map is piecewise-constant — gradients w.r.t. the input are zero within each token fiber and undefined at boundaries. This creates a fundamentally non-smooth loss landscape with singular strata at token boundaries.\n\n### Claims\n\n- **C1 (PROVEN)**: The tokenized loss is definable in R_{an,exp}. BPE merges are semi-algebraic equality tests; embedding lookup is piecewise-linear; KL divergence is analytic. Composition closure gives definability.\n- **C2 (CONJECTURAL)**: Singular fibers arise from embedding collisions (E_i = E_j, permutation symmetry) and tokenization boundary crossings (discrete jumps in prediction across token boundaries).\n- **C3 (CONJECTURAL)**: Vocabulary size V acts as a stratum selector with U-shaped RLCT: small V → coarse partition → high degeneracy → high λ; large V → fine partition → low λ but more parameters → overfitting. Optimal V* exists.\n- **C4 (CONJECTURAL)**: Generalization bound G(V) ≤ C·λ(V)/n + U(V)/√n with U-shaped λ(V). Tokenization acts as a preconditioner — directions along which T_M is constant are invisible to gradient descent.\n- **C5 (CONJECTURAL)**: BPE merge order affects λ; byte-level tokenization has λ from pure embedding collisions; product structure with positional encodings creates compound singularities.\n\n### Novel Contributions\n1.
