#616 Adadelta × RLCT - L0: Claims and Setup\n\nDate: 2026-10-25\nStatus: L0 IN PROGRESS\n\n## Background\n\nAdadelta (Zeiler 2012) extends Adagrad by replacing the cumulative squared gradient G_t with an EMA E[g^2]_t = rho * E[g^2]_{t-1} + (1-rho) * g_t^2. Crucially, it also maintains a second EMA of squared updates E[Δθ^2]_t = rho * E[Δθ^2]_{t-1} + (1-rho) * Δθ_t^2, and computes the update as:\n\nΔθ_t = -sqrt(E[Δθ^2]_{t-1} + eps) / sqrt(E[g^2]_t + eps) * g_t\n\nThis is SCALE-INVARIANT: no learning rate hyperparameter. The preconditioner is a RATIO of two EMAs — units of θ^2 in numerator, units of g^2 in denominator, so Δθ has units of θ. The update is dimensionless in the sense that it self-normalizes.\n\n## Key Distinction from Prior Optimizer Syntheses\n\n- #605 Adagrad: Irreversible accumulation G_t = sum g_k^2. Monotonic freezing. Stratum selector = cumulative gradient.\n- #606 RMSProp: Reversible EMA of g^2. Breathing singularity. Stratum selector = EMA(g^2) with forgetting factor gamma.\n- #616 Adadelta: RATIO of two EMAs (update EMA / gradient EMA). Scale-invariant. Stratum selector = ratio s_{t-1}/r_t, a PROJECTIVE quantity. New singularity type: projective/scale-invariant stratum.\n\n## Toy Model\n\nSame as #605/#606: 1D quadratic loss L(θ) = (1/2)θ^2, true θ* = 0.\n\nGradient: g_t = θ_t. \nEMA gradient: r_t = rho * r_{t-1} + (1-rho) * θ_t^2.\nUpdate EMA: s_t = rho * s_{t-1} + (1-rho) * Δθ_t^2.\nUpdate: Δθ_t = -sqrt(s_{t-1} + eps) / sqrt(r_t + eps) * θ_t.\n\nNear θ*=0: r_t → 0, s_t → 0 (both EMAs decay if θ→0). \n\nCritical: the RATIO sqrt(s_{t-1}/r_t) approaches an indeterminate form 0/0. The behavior depends on the RELATIVE decay rates. If s and r decay at the same rate, ratio → 1 (effective LR = 1, like SGD). If s decays faster, ratio → 0 (freezing). If r decays faster, ratio → ∞ (instability).\n\nThis 0/0 indeterminacy is the core singularity — a PROJECTIVE singularity where the stratum is determined by the ratio of two vanishing quantities.\n\n## Claims\n\nC1 (PROVEN): Adadelta update map is R_{an,exp}-definable.
