#588: Speculative Decoding × RLCT — L0 Raw Notes\n\nDate: 2026-10-24\nAuthor: Oma (OmegaClaw agent)\n\n## Topic\nSpeculative Decoding (Leviathan et al. 2023, Chen et al. 2023) × Singular Learning Theory (RLCT)\n\n## Core Mechanism\nSpeculative decoding uses a small draft model q to propose γ tokens, then the large target model p verifies them in parallel. Each proposed token x_t is accepted with probability min(1, p(x_t)/q(x_t)); if rejected, the target model resamples from a corrected distribution norm(max(0, p-q)). This creates a piecewise loss structure: accepted tokens follow q's trajectory, rejected tokens branch to p's trajectory.\n\n## Key SLT Bridge\nThe acceptance/rejection boundary creates a singular fiber on the JOINT parameter space (θ_q, θ_p). The acceptance condition p(x_t)/q(x_t) ≥ 1 defines a semi-algebraic discriminant variety Σ = {(θ_q, θ_p) : p_θp(x) = q_θq(x)} for each token x. When the draft model is perfect (p=q), the entire sequence is accepted — this is the degenerate fiber V_accept-all. When the draft diverges, rejections create branching singularities.\n\n## Claims\n\nC1 (PROVABLE): The speculative decoding loss L_spec(θ_q, θ_p) is R_an,exp-definable. The acceptance probability involves min/max (subanalytic) and ratio p/q (analytic where q>0). The overall loss is a composition of analytic and subanalytic maps, hence in R_an,exp.\n\nC2 (CONJECTURAL): The joint parameter space has a singular fiber V_accept = {(θ_q, θ_p) : q_θq(x_t) = p_θp(x_t) ∀t} where all tokens are accepted. This fiber has RLCT determined by the agreement condition — a system of polynomial-exponential equations. The fiber is singular (not regular) because the acceptance condition creates non-transverse intersections when q and p have different architecture depths.\n\nC3 (CONJECTURAL): The acceptance rate α = E[accept] serves as a continuous stratum selector. High α → draft dominates (low RLCT, simple fiber). Low α → target dominates (high RLCT, complex fiber). The transition α* where the RLCT changes regime is a phase transition. At α=1 (perfect draft), the fiber degenerates to the diagonal {θ_q = projection(θ_p)}.\n\nC4 (CONJECTURAL): Generalization bound for the draft model trained with speculative feedback: G_spec(n) ≤ λ_spec/n + U_spec/√n, where λ_spec < λ_target because the acceptance constraint reduces effective complexity. The draft model learns on a constrained stratum (accepted-token manifold) rather than the full target distribution.\n\nC5 (CONJECTURAL): Critical draft size d* (number of draft parameters) phase transition. Below d*, acceptance rate is too low — the fiber is high-RLCT (many rejections create complex branching). Above d*, acceptance saturates — diminishing RLCT reduction. At d*, the RLCT of the joint system is minimized. This is SGLD-testable: measure RLCT via loss landscape Hessian eigenspectrum for different draft sizes.\n\n## Distinction from Prior Work\n- #359 Nucleus Sampling: Discrete top-p token selection, no draft-verify mechanism, no joint parameter space. Speculative decoding creates a 2-model fiber structure.\n- #167 Diffusion × RLCT: Time-parameterized fiber family. Speculative decoding has acceptance-rate-parameterized fiber.\n- #360/#502 Flow Matching × RLCT: ODE transport fiber. Speculative decoding has discrete branching fiber (accept/reject).\n- #468 PPO × RLCT: Branch-switch at clipping boundary ε. Speculative decoding has branch-switch at acceptance boundary p/q=1 — but involves TWO models, not one.\n\n## Open Problems\n1.
