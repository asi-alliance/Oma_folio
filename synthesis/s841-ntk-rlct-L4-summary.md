#841 NTK (Neural Tangent Kernel) x RLCT -- L4 Plain-Language Summary\n# Date: 2026-11-03\n# Status: L0-L3 COMPLETE, L4 SUMMARY\n\n## What is NTK?\nThe Neural Tangent Kernel (NTK) describes how a neural network behaves in the infinite-width limit: training reduces to kernel regression on a fixed kernel determined by the network architecture. The NTK regime is the lazy regime where parameters barely move -- features stay frozen and learning is linear.\n\n## What is RLCT?\nThe Real Log Canonical Threshold (RLCT) measures how singular (non-Morse) a loss landscape is. A lower RLCT means more degeneracy in the critical locus, which paradoxically can improve generalization because the model occupies a larger effective volume of good solutions.\n\n## The Bridge: NTK x RLCT\nThis synthesis asks: what happens to the RLCT of the loss landscape as width d transitions from the finite-width (feature-learning) regime to the infinite-width (NTK/lazy) regime?\n\n## Claims Summary\n- C1 PROVEN: The NTK kernel is definable in R_{an,exp} (the function class where RLCT is well-defined). This follows because NTK is built from polynomial gradients of network outputs.\n- C2 CONJECTURAL: As width d increases, the NTK eigenvalue spectrum collapses (effective rank drops), making the loss fiber V_eff(d) increasingly singular (Morse-Bott rather than Morse). The eigenvalue degeneracy maps to RLCT degeneracy.\n- C3 CONJECTURAL: Width d acts as a stratum selector -- large d pushes the fiber toward the Morse (non-degenerate) regime with RLCT approaching D/2, while small d keeps it in the singular regime with lower RLCT.\n- C4 CONJECTURAL: Generalization bound G(d,n) ~ lambda(d)/n + U(d)/sqrt(n), where U(d) is an eigenvalue-decay correction term from the NTK spectrum. This bridges RLCT scaling with NTK spectral theory.\n- C5 CONJECTURAL: A phase transition occurs at critical width d* ~ n^{1/(lambda_lazy+1)}, where RLCT drops in a staircase pattern -- matching empirically observed grokking and feature-learning emergence transitions.\n\n## Key Novelty\nNo prior work bridges NTK kernel spectral theory with RLCT/singular learning theory. The NTK eigenvalue collapse provides a concrete spectral mechanism for the singular-to-Morse transition that RLCT formalizes. This is distinct from #480 (muP alpha-parametrization, continuous) and #840 (quantization staircase, discrete), and extends #77 (lazy regime context) with precise spectral-geometric structure.\n\n## Open Problems\n1.
