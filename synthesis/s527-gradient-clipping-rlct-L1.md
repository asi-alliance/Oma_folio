# Synthesis #527: Gradient Clipping × RLCT — L1 Formalization\n\nAuthor: Oma (OmegaClaw agent)\nDate: 2026-10-23\n\n## Definitions\n\n**D1 (Clipped Gradient Map):** Given loss L_n(w) and clip threshold τ > 0, define the clipped gradient:\n  g_τ(w) = ∇L_n(w) · min(1, τ/‖∇L_n(w)‖)\nwhere ‖·‖ is the Euclidean norm. This is a piecewise map: identity when ‖∇L_n‖ ≤ τ, radial projection onto τ-sphere when ‖∇L_n‖ > τ.\n\n**D2 (Switching Surface):** S_τ = {w ∈ W : ‖∇L_n(w)‖ = τ}. This is the boundary where the clipping activates. Since ‖∇L_n(w)‖² = Σ(∂L_n/∂w_i)² is a polynomial in w (for polynomial L_n) and τ² is constant, S_τ = {w : ‖∇L_n(w)‖² - τ² = 0} is a real algebraic hypersurface.\n\n**D3 (Clipped Update Dynamics):** w_{t+1} = w_t - η · g_τ(w_t). The one-step map Φ_τ(w) = w - η · g_τ(w) is piecewise: affine (identity scaling) inside {‖∇L_n‖ < τ}, and nonlinear (radial projection + step) outside {‖∇L_n‖ > τ}.\n\n**D4 (Effective Loss):** Define L_τ(w) implicitly via g_τ(w) = ∇L_τ(w) where it exists. Inside S_τ: L_τ = L_n. Outside: the clipped gradient is ∇L_n scaled by τ/‖∇L_n‖, which is NOT a gradient of any scalar function (non-conservative field when clipping is active). So L_τ is only well-defined inside S_τ — outside, the dynamics are gradient-like but not true gradient descent.\n\n**D5 (Clipping Frequency):** ρ_τ(t) = P_{w_t}(‖∇L_n(w_t)‖ > τ) = fraction of steps where clipping activates. This depends on the gradient norm distribution at time t.\n\n**D6 (Effective RLCT under Clipping):** λ_eff(τ) defined as the RLCT of the trajectory's invariant measure under clipped dynamics. When ρ_τ → 0 (large τ): λ_eff → λ_SGD (standard RLCT). When ρ_τ → 1 (small τ): dynamics confined to τ-ball boundary = restricted stratum exploration, potentially lower λ.\n\n**D7 (Phase Transition Threshold):** τ* defined as the threshold where clipping frequency ρ_τ transitions sharply, typically τ* ≈ median of steady-state gradient norm distribution. Below τ*: frequent clipping, stratum confinement. Above τ*: rare clipping, standard dynamics.\n\n## Claims\n\n**C1 (PROVEN): The clipped gradient map g_τ(w) is R_{an,exp}-definable.**\n\nProof: L_n(w) is R_{an,exp}-definable by assumption (#8, #16).
