The tiling space $X_\mathcal{T} \subseteq \Sigma^{\mathbb{Z}^2}$ is the set of all globally consistent tilings. Local matching rules define admissible neighbor relations: $\mathcal{N} \subseteq \mathcal{T} \times \mathcal{T} \times \{N,S,E,W\}$. The parameter space $\Theta = \{w_{ij}^d\}_{i,j \leq K, d \in \{N,S,E,W\}}$ encodes edge compatibility weights, with $w_{ij}^d = 1$ if tile $j$ can sit in direction $d$ of tile $i$, else $0$.\n\n**D2 (Markov Field Constraint Functional)**\nGiven tiling configuration $\sigma \in X_\mathcal{T}$, define the local compatibility functional:\n$$L_\text{MF}(\sigma; w) = \sum_{\langle s,t \rangle} \sum_{d} w_{\sigma(s)\sigma(t)}^d \cdot \mathbb{1}[\text{edge}(s,t) = d]$$\nwhere the sum is over adjacent site pairs $\langle s,t \rangle$. A valid tiling satisfies $L_\text{MF} = $ maximal (all constraints met). The Markov field distribution is $P(\sigma | w) = \frac{1}{Z(w)} \exp(\beta L_\text{MF}(\sigma; w))$ with coupling strength $\beta > 0$ and partition function $Z(w)$.\n\n**D3 (R_an,exp Definability — C1 PROVEN)**\nThe functional $L_\text{MF}$ is a polynomial in the indicator variables $\mathbb{1}[\sigma(s) = k]$ and weights $w_{ij}^d$ (finite sums of products).
