# Synthesis #877: Decision Tree × RLCT — L1 Formalization\n\n**Date:** 2026-11-09 | **Status:** L1 (formal definitions, pre-proof)\n**Distinct from:** #846 (Boosting — sequential additive ensemble; DT is single hierarchical model)\n\n---\n\n## Definitions\n\n### D1: Decision Tree Parameter Space\n\nA decision tree of depth D is parameterized by:\n- **Structure** σ = (j_1, ..., j_{2^D-1}) ∈ {1, ..., d}^{2^D-1}: feature index at each internal node\n- **Thresholds** θ = (θ_1, ..., θ_{2^D-1}) ∈ R^{2^D-1}: split threshold at each internal node\n- **Leaf predictions** c = (c_1, ..., c_{2^D}) ∈ R^{2^D}: output value at each leaf\n\nFull parameter space: W_D = {1,...,d}^{2^D-1} × R^{2^D-1} × R^{2^D}\n\nFor fixed structure σ, the continuous parameter space is Θ_σ = R^{2^D-1} × R^{2^D}, dimension d_σ = 2^{D+1} - 1.\n\n### D2: Impurity-Based Empirical Loss\n\nGiven training data {(x_i, y_i)}_{i=1}^n, x_i ∈ R^d, y_i ∈ {1,...,K}, the empirical Gini impurity loss for fixed structure σ is:\n\nL_D(θ, c | σ) = (1/n) Σ_{ℓ=1}^{2^D} n_ℓ(θ) · Gini(ℓ, θ)\n\nwhere:\n- n_ℓ(θ) = Σ_{i=1}^n 1[x_i ∈ R_ℓ(θ)] is the count of samples in leaf region R_ℓ(θ)\n- Gini(ℓ, θ) = 1 - Σ_{k=1}^K p_{ℓ,k}(θ)^2\n- p_{ℓ,k}(θ) = n_{ℓ,k}(θ) / n_ℓ(θ), with n_{ℓ,k}(θ) = Σ_{i=1}^n 1[x_i ∈ R_ℓ(θ)] · 1[y_i = k]\n- R_ℓ(θ) is the axis-aligned rectangle defined by the path from root to leaf ℓ\n\n**C1 PROVEN:** Each indicator 1[x_{i,j} ≤ θ_j] is semialgebraic (hence sub-analytic, hence in R_an). The counts n_ℓ, n_{ℓ,k} are finite sums of sub-analytic functions. The Gini impurity is a rational function of these counts (polynomial in p_{ℓ,k}). Composition and finite sums preserve R_an-definability. Thus L_D ∈ R_an for Gini. For entropy impurity, the logarithm requires R_{an,exp}, but Gini loss is purely in R_an.\n\n### D3: Kink Singular Fiber — Split-Boundary Singular Set\n\nThe singular fiber of the loss landscape for fixed σ is:\n\nV_D(σ) = {(θ, c) ∈ Θ_σ : ∇_θ L_D(θ, c | σ) is undefined or L_D achieves local minimum}\n\nThe **kink singular set** S_kink is the union of hyperplanes where a threshold crosses a data point:\n\nS_kink = ⋃_{m=1}^{2^D-1} ⋃_{i=1}^n {θ_m = x_{i, j_m}}\n\nAt each crossing, the assignment of x_i flips between leaves, causing a discontinuous jump in L_D. Between crossings, L_D is constant in θ (for fixed σ) — the loss is piecewise-constant on a cell decomposition of R^{2^D-1} defined by the n·(2^D-1) hyperplanes.\n\n**C2 CONJECTURAL:** Each crossing hypersurface θ_m = x_{i,j_m} is an A_1 (fold) singularity of L_D, analogous to Whitney cusp singularities in piecewise-smooth functions. The singular set is a hyperplane arrangement — a highly degenerate configuration with |S_kink| = O(n · 2^D) components. The RLCT contribution from each kink is conjectured to be 1/2 (fold-type), giving λ_kink ~ (n · 2^D) / 2.\n\n### D4: Depth-Stratified Loss Family\n\nDefine the depth-stratified family {L_D}_{D=1}^{D_max} where each L_D is the loss of a depth-D tree. The stratum selector is D (or equivalently, the number of leaves L = 2^D).\n\nFor each D, the parameter space dimension grows as d_D = 2^{D+1} - 1 (exponential in D). The loss landscape changes structurally with D:\n- D < D*: Sufficient samples per leaf → impurity well-defined → informative singularities\n- D > D*: Many empty/pure leaves → flat loss landscape → degenerate singularities from non-identifiability\n\n**C3 CONJECTURAL:** The effective RLCT λ(D) is non-decreasing in D with a phase transition at D* ≈ log_2(n). Below D*, λ(D) ~ λ_0 · D (linear growth from accumulating kink singularities). Above D*, λ(D) ~ λ_0 · D + c · (2^D - n) (additional degeneracy from empty-leaf non-identifiability). The transition is sharp: D* is where 2^{D*} ≈ n.\n\n### D5: Permutation Non-Identifiability Fiber\n\nAt each internal node m, swapping the left and right subtrees produces an identical partition of input space. For a depth-D tree with 2^D - 1 internal nodes, the permutation group is:\n\nG_perm = (Z/2Z)^{2^D - 1}\n\nwith |G_perm| = 2^{2^D - 1}.\n\nFor any (θ, c), the orbit under G_perm consists of 2^{2^D - 1} parameter configurations with identical loss. This creates a discrete singular fiber:\n\nV_perm = {(θ', c') : ∃ g ∈ G_perm, (θ', c') = g·(θ, c), L_D(θ', c') = L_D(θ, c)}\n\n**C5 CONJECTURAL:** The permutation fiber contributes to the RLCT via the multiplicity of the discrete group action. Unlike continuous gauge symmetries in neural networks (which contribute via Lie algebra dimension), this discrete symmetry creates isolated equivalent points. The conjecture is that the RLCT contribution is:\n\nλ_perm(D) ~ (log_2 |G_perm|) / 2 = (2^D - 1) / 2\n\nThis grows exponentially with D, dominating the total λ(D) for deep trees.\n\n### D6: Generalization Bound\n\n**C4 CONJECTURAL:** The generalization error for a depth-D decision tree satisfies:\n\nG(D, n) ≤ (λ(D) / (2n)) · log(n) + P(D, n)\n\nwhere:\n- λ(D) = λ_kink(D) + λ_perm(D) ~ (n · 2^D)/2 + (2^D - 1)/2\n- P(D, n) = C · (2^D · log(n) · d) / n is the hypothesis complexity penalty from exponentially many possible tree structures\n\nBelow D*: λ(D) ~ O(D·n), P negligible → standard SLT bound dominates\nAbove D*: λ(D) ~ O(2^D), P ~ O(2^D) → double exponential blowup in generalization error\n\nThe U-shaped generalization curve (optimal D* ≈ log_2(n)) emerges from the competition between decreasing approximation error (deeper trees fit better) and increasing λ(D) + P(D,n).\n\n### D7: Phase Transition at Critical Depth D*\n\nThe phase transition occurs at D* where 2^{D*} ≈ n:\n\nD* = ⌈log_2(n)⌉\n\n- **Below D* (D < D*):** Each leaf contains ~n/2^D >> 1 samples. Impurity is well-defined. Kink singularities are informative (thresholds that separate classes). λ(D) grows linearly.\n- **At D*:** Transition — some leaves become pure (single-class), creating the first degenerate singularities from empty-leaf non-identifiability.\n- **Above D* (D > D*):** Most leaves are empty or pure. Loss landscape becomes flat across large regions of θ-space. λ(D) grows exponentially from permutation non-identifiability of empty splits.\n\n**C5 (refined):** The phase transition D* ≈ log_2(n) is the decision tree analog of the capacity threshold in neural networks. Pruning (removing splits with low information gain) effectively reduces D below D*, recovering the pre-transition singularity structure. This connects to #491 (Grokking) phase transition methodology — both involve a critical complexity threshold where the loss landscape geometry changes qualitatively.\n\n## Claim Summary\n\n| Claim | Description | Status | Key Evidence |\n|-------|-------------|--------|-------------|\n| C1 | R_an-definability of Gini impurity loss | PROVEN | Semialgebraic indicators + polynomial Gini → R_an |\n| C2 | A_1 kink singularities at split boundaries | CONJECTURAL | Piecewise-constant loss + hyperplane arrangement |\n| C3 | Depth D as stratum selector, D* ≈ log_2(n) | CONJECTURAL | Leaf count vs sample size threshold |\n| C4 | Gen bound λ(D)·log(n)/(2n) + P(D,n) | CONJECTURAL | SLT bound + exponential complexity penalty |\n| C5 | Permutation fiber 2^(2^D-1) inflates λ | CONJECTURAL | Discrete group action on tree structure |\n\n## Open Problems (refined from L0)\n\n1.
