Forward policy PF(x|w) = softmax_f(f(x;w)) where f is a sublinear network (ReLU MLP). Backward policy PB(x|w). Reward R(x) >= 0 on compact X subset R^m.\n\nD2 (Partition Function): Z(w) = integral_X PF(x|w) dx = integral_X exp(f(x;w)) dx. This is the normalizing constant of the forward policy. Z(w) is analytic in w for fixed X compact semialgebraic.\n\nD3 (Trajectory Balance Loss): For trajectory tau = (s_0, x_1, ..., x_n) with s_F = x_n:\n  L_TB(tau|w) = [log Z(tau) - log Z(w) - sum_t log PF(x_t|s_{t-1};w) + sum_t log PB(s_{t-1}|x_t;w) - log R(x_n)]^2\nwhere Z(tau) = product_t PF_transition is the trajectory partition. The TB equation is: log Z(tau) = log Z(w) + log R(x_n) + sum_t [log PB - log PF].\n\nD4 (TB Singular Manifold): The zero set V_TB = {w in W : L_TB(tau|w) = 0 for all tau} defines the trajectory balance manifold. This is the set where the forward policy exactly samples proportional to R. V_TB is an analytic subvariety of W.\n\nD5 (Detailed Balance Fiber): For edge (s,s'), the detailed balance condition: log PF(s'|s;w) + F(s;w) = log PB(s|s';w) + F(s';w) where F is the state flow. The DB fiber V_DB(s,s') = {w : DB equation holds} is an analytic hypersurface. V_TB = intersection of all V_DB.\n\nD6 (Reward-Stratified Singular Fiber): For reward level r, define V_r = {w in V_TB : PF(x|w) proportional to R(x) on {x : R(x) = r}}. The family {V_r} gives a stratification of V_TB by reward level. Singular fibers arise where V_r has non-transversal intersection with V_TB.\n\nD7 (Temperature/Exploration Selector): Temperature epsilon > 0 scales the forward policy: PF_eps(x|w) proportional to PF(x|w)^(1/epsilon). As epsilon -> 0, the policy concentrates on max-reward states. epsilon serves as a continuous stratum selector analogous to guidance scale w in #362 CFG.\n\n## Claims\n\nC1 (PROVEN): L_TB is R_{an,exp}-definable.\nProof sketch: PF = exp(f(x;w)) with f sublinear (piecewise linear in ReLU strata) -> definable. log Z(w) = log(integral exp(f) dx) over compact semialgebraic X -> integral of definable over semialgebraic is definable (o-minimal structure).
