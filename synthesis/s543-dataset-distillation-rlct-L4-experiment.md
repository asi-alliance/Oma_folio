## Synthesis #543: Dataset Distillation × RLCT — L4 Experiment Design\n\n### Date: 2026-10-23\n### Status: L4 (experiment design)\n\n---\n\n#### Experiment 1: RLCT Preservation Across Distillation Methods (Tests C2, C4)\n\n**Setup:**\n- Dataset: CIFAR-10, CIFAR-100\n- Architecture: ResNet-18, ViT-Tiny\n- Distillation methods: Gradient Matching (GM), Trajectory Matching (TM), Distribution Matching (DM), Loss Matching (LM)\n- IPC: 1, 10, 50\n- Measure RLCT via LLC (Local Learning Coefficient) estimation (Watanabe, Hoogland et al.)\n\n**Protocol:**\n1. Train model on full dataset D → estimate λ̂_D via LLC\n2. For each method m ∈ {GM, TM, DM, LM} and IPC ∈ {1, 10, 50}:\n   a. Distill S_m,ipc using method m\n   b. Train model on S_m,ipc → estimate λ̂_S via LLC\n   c. Compute δ_RLCT = |λ̂_S - λ̂_D|\n3. Compare δ_RLCT across methods and IPC values\n\n**Predictions:**\n- C2: δ_RLCT correlates with downstream test accuracy (lower δ → higher accuracy)\n- C4: δ_RLCT(TM) ≤ δ_RLCT(GM) ≤ δ_RLCT(DM) ≤ δ_RLCT(LM)\n\n#### Experiment 2: IPC* Phase Transition (Tests C3)\n\n**Setup:**\n- Dataset: CIFAR-10\n- Architecture: ResNet-18\n- IPC sweep: 1, 2, 5, 10, 20, 50, 100, 200, 500\n- Distillation method: Trajectory Matching (best from Exp 1)\n\n**Protocol:**\n1. For each IPC value:\n   a. Distill synthetic dataset S_IPC\n   b. Train model → estimate λ̂_S(IPC) via LLC\n   c. Record test accuracy\n2. Plot λ̂_S(IPC) vs IPC\n3. Identify IPC* where λ̂_S transitions from far-from-λ̂_D to near-λ̂_D\n\n**Predictions:**\n- C3: Sharp transition in λ̂_S at critical IPC*, below which distillation fails\n- C3: IPC* scales with λ̂_D / d_eff\n\n#### Experiment 3: Desingularization Analogy (Tests C5)\n\n**Setup:**\n- Dataset: CIFAR-10\n- Architecture: ResNet-18\n- Vary compression ratio |D|/|S| = {500, 100, 50, 20, 10, 5}\n- Measure singularity structure via Hessian eigenvalue spectrum at convergence\n\n**Protocol:**\n1. For each compression ratio r:\n   a. Distill S with |D|/|S| = r\n   b. Train model on S\n   c. Compute Hessian eigenvalue spectrum at convergence\n   d. Compare spectrum shape to full-data Hessian spectrum\n2. Measure spectral alignment as function of r\n\n**Predictions:**\n- C5: Higher compression (larger r) → more "blown-up" singularity (flatter Hessian, larger null space)\n- C5: Successful distillation resolves the blown-up singularity back toward real singularity\n\n#### Experiment 4: RLCT-Guided Distillation (Tests C2 directly)\n\n**Setup:**\n- Dataset: CIFAR-10\n- Architecture: ResNet-18\n- Standard TM baseline vs RLCT-guided TM (select S to minimize δ_RLCT during distillation)\n\n**Protocol:**\n1. Standard TM: distill S using gradient matching loss\n2. RLCT-guided TM: during distillation, periodically estimate λ̂_S and steer S toward minimizing δ_RLCT\n3. Compare test accuracy and δ_RLCT of both approaches\n\n**Predictions:**\n- RLCT-guided distillation achieves lower δ_RLCT and higher accuracy than standard TM\n- Demonstrates δ_RLCT as actionable distillation objective\n\n#### Resource Estimates\n\n- Exp 1: ~200 GPU-hours (4 methods × 3 IPC × 2 architectures × 2 datasets + LLC estimation)\n- Exp 2: ~100 GPU-hours (9 IPC values × LLC estimation)\n- Exp 3: ~80 GPU-hours (6 compression ratios × Hessian computation)\n- Exp 4: ~120 GPU-hours (2 methods × multiple runs + online LLC)\n- Total: ~500 GPU-hours\n\n#### Key Metrics\n\n- δ_RLCT = |λ̂_S - λ̂_D| (primary)\n- Test accuracy (secondary)\n- Hessian eigenvalue spectrum (for C5)\n- Singularity stratum membership (which stratum does θ*(S) land in?)\n\n---\n\n!next
