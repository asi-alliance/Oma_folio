# Synthesis #854: Tabular Deep Learning (FT-Transformer / TabTransformer) × RLCT\n## L0: Exploration\n## Date: 2026-11-06\n\n### Context\nTabular deep learning architectures (TabTransformer, FT-Transformer, SAINT) adapt self-attention to mixed-type tabular data. Categorical features are embedded via learned lookup tables (one-hot × linear projection), continuous features via linear projection or piecewise-linear tokenization. These tokens are then processed by transformer layers. This synthesis bridges tabular DL architectures with Watanabe's RLCT framework.\n\n### Key RLCT Bridge\nCategorical embedding creates a **quotient singularity**: the one-hot × linear projection map φ: R^{|V|} → R^d factors through the simplex Δ^{|V|-1}, identifying all inputs with the same category to the same embedding. The fiber over each embedding vector e_v is a positive-dimensional cone (all one-hot distributions concentrating on v). This is a **piecewise-linear map with degenerate fibers** — the Jacobian rank drops from |V| to d at category boundaries. For continuous features, the tokenization map (FT-Transformer's affine + ReLU) creates standard ReLU singularities. The interaction between categorical quotient fibers and continuous ReLU strata within the same attention mechanism is the novel singularity structure.\n\n### Claims\n\n**C1 (PROVEN): R_an,exp Definability**\nTabular transformer loss is R_an,exp-definable. Categorical embedding: one-hot is piecewise-constant (definable in R_an), linear projection is polynomial, composition is piecewise-linear definable. Continuous tokenization (FT-Transformer): affine map + ReLU is subanalytic. Softmax attention and MLP are analytic (exp/sum, polynomial). Cross-entropy is analytic in prediction. Composition closure gives definability.\n\n**C2 (CONJECTURAL): Categorical Quotient Singularity**\nV_cat = {θ : ∃ category v with embedding e_v in singular stratum of attention}. The categorical embedding map creates a **quotient singularity**: φ_cat factors as one-hot → simplex → linear projection. The fiber φ_cat^{-1}(e_v) = {δ_v} is a single point in simplex coordinates but a positive-dimensional cone in the ambient one-hot space. Fisher information degenerates along category boundary directions (transitions between one-hot vectors). This is a NOVEL singularity type: **discrete quotient fiber** from categorical structure, distinct from continuous fiber degeneracies in standard RLCT.\n\n**C3 (CONJECTURAL): Mixed-Type Stratum Selector**\nThe proportion of categorical vs continuous features γ = n_cat / (n_cat + n_cont) acts as a stratum selector. At γ = 0 (all continuous): standard ReLU/attention singularities. At γ = 1 (all categorical): pure quotient singularities. At intermediate γ: product stratum V_cat × V_cont with transverse intersection conjectured. The effective RLCT λ(γ) interpolates between λ_cont (ReLU attention, from #134) and λ_cat (quotient fiber, new). Hypothesis: λ(γ) is superadditive — mixed-type losses have higher RLCT than either pure type.\n\n**C4 (CONJECTURAL): Embedding Dimension Generalization Bound**\nG_tabular ~ λ_tab · log(n)/(2n) + U(d_emb)/√n\nwhere λ_tab = λ_cat(γ) + λ_cont(1-γ) is the mixed-type RLCT, and U(d_emb) is a bias from embedding dimension mismatch. When d_emb << log(|V|) (under-parameterized embedding), the quotient fiber compresses information → higher quantization bias U. When d_emb >> log(|V|) (over-parameterized), redundant dimensions create additional flat directions → higher λ. Optimal d* minimizes G, creating a U-shaped curve in d_emb.\n\n**C5 (CONJECTURAL): Categorical Cardinality Phase Transition**\nFor high-cardinality categorical features (|V| → ∞, e.g., ZIP codes, user IDs), the quotient singularity structure changes: the embedding lookup becomes a high-dimensional sparse map. At critical cardinality |V*| ~ exp(d_emb), the embedding capacity saturates and additional categories collapse to existing singular strata. SGLD should detect: (a) LLC increase as |V| approaches |V*|, (b) Fisher rank plateau at capacity saturation, (c) generalization degradation scaling as log(|V|)/d_emb beyond |V*|.\n\n### Star Contribution\n**Discrete quotient singularity from categorical embeddings** — the one-hot × linear projection factorization through the simplex creates a fundamentally new singularity type in the synthesis folio: a quotient fiber where the fiber dimension is positive in the ambient space but zero in the simplex coordinates. This is distinct from continuous fiber degeneracies (standard RLCT), from attention rank collapse (#134, continuous QK^T), from VQ-VAE codebook collapse (#556, quantization boundary), and from DARTS simplex vertices (#853, optimization landscape). The mixed-type stratum interaction (categorical × continuous within shared attention) is the first analysis of heterogeneous feature-type singularity composition.\n\n### Distinction from Prior Syntheses\n- #134 (Attention toric): Continuous QK^T rank degeneracy.
