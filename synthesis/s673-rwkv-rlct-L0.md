## Synthesis #673: RWKV (Receptance Weighted Key Value) × RLCT\n## L0: Exploration & Claims\n\n**Date:** 2026-10-28\n**Status:** L0 DRAFT\n\n---\n\n### Architecture Overview\n\nRWKV is an RNN-Transformer hybrid that combines linear-time recurrence with Transformer-quality performance. Each residual block contains two sub-blocks:\n\n1. **Time-Mixing:** A recurrent attention-like mechanism using the WKV (Weighted Key Value) computation with learned exponential time decay. The core recurrence maintains a fixed-size state (numerator-denominator tuple) across timesteps.\n\n2. **Channel-Mixing:** A gated feedforward module where a sigmoid gate controls information flow based on time-shifted inputs.\n\nBoth blocks use **token shift** (linear interpolation between current and previous token): x' = (1-μ)⊙x_t + μ⊙x_{t-1}, creating a temporal bridge between consecutive tokens.\n\n### Key Observations for RLCT\n\n- **Fixed state size:** Unlike Transformers (KV cache grows with T) or Mamba (selective state), RWKV maintains constant-size recurrent state. This implies the singular fiber dimension is T-invariant (does not grow with sequence length).\n\n- **Learned exponential decay:** The time_decay vector w controls forgetting. The WKV computation involves exp(-w) factors, creating an exponential family of forgetting rates. The decay rate w acts as a **stratum selector** — different w values create different forgetting regimes.\n\n- **Token shift interpolation:** The (1-μ)⊙x_t + μ⊙x_{t-1} is a piecewise-linear interpolation. The mixing coefficient μ controls the interpolation point, creating a parameter-dependent family of definable maps.\n\n- **Dual singularity structure:** Time-mix (recurrent accumulation) + Channel-mix (gated MLP) create a product-space singular fiber: V_total = V_time × V_channel, where each component has distinct singularity geometry.\n\n### Five Claims\n\n**C1 (PROVEN):** The RWKV loss K(θ) is definable in R_{an,exp}.\n*Argument:* All components are definable: (1) token shift is affine, (2) WKV computation uses exp(-w) (exponential, definable in R_{an,exp}), sigmoid (definable in R_an via restriction), linear projections (polynomial), (3) channel-mix MLP with sigmoid/GELU activations is definable, (4) composition of definable maps is definable. Cross-entropy loss is definable. QED.\n\n**C2 (CONJECTURAL):** The WKV exponential decay creates a forgetting fiber with RLCT governed by decay-rate stratification.\n*Argument:* The time decay w controls the effective memory window. For large w (fast decay), the model forgets quickly — the recurrent state carries minimal information, creating a low-dimensional singular fiber (low RLCT). For small w (slow decay), long-range dependencies persist — the state carries richer information, creating a higher-dimensional fiber (higher RLCT). The decay rate w acts as a stratum selector partitioning parameter space into forgetting regimes. The boundary at w→0 (no forgetting) creates a degenerate fiber where all past tokens contribute equally — a maximally singular stratum. Gaps: (1) exact RLCT of the forgetting fiber as function of w, (2) interaction between w and data distribution, (3) whether the numerator-denominator tuple structure (h_t = (a_t, b_t)) creates a quotient singularity.\n\n**C3 (CONJECTURAL):** The constant state size creates a T-invariant RLCT, contrasting with growing-context architectures.\n*Argument:* RWKV's recurrent state (a_t, b_t) has fixed dimension regardless of sequence length T. The singular fiber V_T depends on parameters θ but not on T (the state dimension is constant). This implies λ(T) ~ λ_base (constant), contrasting with: #134 Attention (λ ~ log T, growing KV cache), #233 Mamba (λ ~ log T, selective scan with growing effective state), #672 Hyena (λ ~ log T, growing kernel). The T-invariance is a distinctive property: RWKV's singularity is determined by parameter geometry, not sequence length. Gap: whether multi-layer stacking (L blocks) introduces T-dependence through compositional depth.\n\n**C4 (CONJECTURAL):** The token-shift interpolation creates a piecewise-analytic structure with μ-dependent fiber geometry.\n*Argument:* Token shift x' = (1-μ)⊙x_t + μ⊙x_{t-1} is a convex combination parameterized by μ. The fiber V(μ) varies with μ: at μ=0 (no shift), the model sees only current token (pure feedforward); at μ=1, only previous token (pure recurrence); intermediate μ creates mixed fibers. The piecewise structure arises because the WKV recurrence branches on which token dominates. The singularity at μ→0 creates a feedforward-only stratum (no temporal mixing). Gap: (1) whether μ creates a continuous family of fibers or discrete strata, (2) interaction with channel-mix gating.\n\n**C5 (CONJECTURAL):** The dual time-mix × channel-mix composition creates a product-space singular fiber with subadditive RLCT.\n*Argument:* Each block has its own singular fiber: V_time (from WKV recurrence/decay) and V_channel (from sigmoid gating saturation). The total fiber is V_total = V_time ∩ V_channel (both blocks must simultaneously achieve zero loss). For product spaces, the RLCT is conjectured to satisfy: λ_total ≤ λ_time + λ_channel (subadditivity from intersection/product structure). The channel-mix sigmoid gate creates a saturation singularity (analogous to #134 attention softmax saturation), while time-mix creates a forgetting singularity. The composition creates a richer singularity than either alone. Gap: (1) formal proof of subadditivity, (2) whether residual connections between blocks preserve or break the product structure, (3) comparison with #233 Mamba's single-mechanism singularity.\n\n### Predictions\n\n1. **T-invariant RLCT:** Empirical LLC (learning locus coefficient) measurements on RWKV models should show λ(T) ≈ const, unlike Transformers/Mamba.\n2. **Decay-rate stratification:** Models with different learned w distributions should show different RLCT values, with slower decay → higher RLCT.\n3. **μ-sensitivity:** Perturbing token-shift μ near 0 should create measurable RLCT phase transition.\n4. **Dual-block RLCT:** Removing channel-mix should reduce λ by approximately λ_channel.\n5. **Contrast with Mamba:** RWKV λ should be lower than Mamba for long sequences (constant vs log T scaling).\n\n### Open Problems\n\n1.
