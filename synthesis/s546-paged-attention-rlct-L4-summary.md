# Synthesis #546: Paged Attention × RLCT — L4 Summary\n\n**Date:** 2026-11-07 | **Author:** Oma | **Status:** L4 SUMMARY (L0-L3 COMPLETE)\n\n---\n\n## Overview\n\nFirst SLT analysis of paged attention (vLLM-style block-table KV cache management) through the lens of Real Log Canonical Threshold. Key insight: under exact arithmetic, paged attention is a permutation of standard attention and preserves RLCT exactly (C1, proven). However, under floating-point arithmetic, the block boundaries introduce micro-singularities — discontinuous perturbations at each block boundary where summation order changes. Block size B acts as a stratum selector: B=1 maximizes summation reordering (highest perturbation), B=N eliminates reordering (standard attention). The effective FP RLCT satisfies λ_fp(B) ≥ λ_fp_std with an approximate gap ~ C·(N/B - 1)·ε². An optimal block size B* ~ √(N/(ε·d_k)) marks a phase transition between perturbation-dominated and computation-dominated regimes. Dynamic allocation introduces a temporal stratum where fragmentation increases RLCT.\n\n## Claim Status\n\n| Claim | Description | Status | STV |\n|-------|-------------|--------|-----|\n| C1 | Exact-arithmetic RLCT equivalence: IsPermutation(T) → ZeroSetPaged = ZeroSetStandard → RLCT_Paged = RLCT_Standard | PROVEN | (1.0, 0.99) |\n| C2 | FP block-boundary micro-singularities: RLCT_fp(B) ≥ RLCT_fp_std with gap ~ C·(N/B-1)·ε² | CONJECTURAL | (0.8, 0.7) |\n| C3 | Block size as stratum selector: B1 < B2 → RLCT_fp(B1) ≥ RLCT_fp(B2) (monotonicity) | CONJECTURAL | (0.75, 0.65) |\n| C4 | Optimal block size phase transition: B* ~ √(N/(ε·d_k)) marks perturbation↔computation crossover | CONJECTURAL | (0.6, 0.5) |\n| C5 | Dynamic allocation phase transition: fragmentation crossing threshold → RLCT increase | CONJECTURAL | (0.6, 0.5) |\n\n## Novelty Highlights\n\n1. **C1 — Exact-arithmetic equivalence (proven)**: Paged attention permutes the KV cache access order; under exact arithmetic this is a permutation of summation, preserving the zero set and hence RLCT. This establishes the baseline: paging itself does not change the loss landscape geometry — only floating-point arithmetic introduces new singular structure.\n\n2. **C2 — FP block-boundary micro-singularities**: At each block boundary, the floating-point summation order changes discontinuously, creating a piecewise-constant perturbation model. The perturbed zero set V_0^{fp,paged} inherits singularities from V_0^{fp,std} but adds block-boundary micro-singularities. The RLCT gap scales as ~C·(N/B - 1)·ε² — more blocks means more boundaries, more perturbation, higher effective RLCT.\n\n3. **C3 — Block size as discrete stratum selector**: B partitions the computation into strata — B=1 (maximum reordering, highest λ_fp) to B=N (zero reordering, λ_fp = λ_fp_std). This is the first treatment of memory layout as a singularity-stratifying parameter, distinct from architectural hyperparameters (LoRA rank #223, sparse pattern #545).\n\n4. **C4 — B* phase transition**: The optimal block size B* ~ √(N/(ε·d_k)) balances perturbation cost (decreases with B) against memory/computation cost (increases with B). Below B*, FP perturbation dominates generalization; above B*, standard computation cost dominates. This predicts an empirically testable LLC jump via SGLD at B*.\n\n5. **C5 — Dynamic allocation temporal stratum**: Fragmentation in the block table (variable occupancy) creates a data-dependent perturbation stratum that evolves over time. When fragmentation crosses a threshold, the effective RLCT increases — connecting memory management to loss landscape geometry.\n\n6. **Unified memory-layout perturbation framework**: C2-C5 extend the perturbation RLCT framework to memory layout, complementing #499 (Flash Attention tiling) — together they form a unified theory of how memory access patterns affect singular geometry.\n\n##
