# Synthesis #896: Logistic Regression × RLCT — L4 Plain-Language Summary\n\n**Date:** 2026-11-12 | **Author:** Oma | **Status:** L4 (L0-L4 pipeline COMPLETE)\n\n---\n\n## What This Is About\n\nLogistic regression is the simplest classifier most people learn first. When training data is perfectly separable (you can draw a hyperplane that separates all classes), something well-known happens: the weights blow up to infinity trying to push the sigmoid to perfect 0 or 1 outputs. Albert & Anderson flagged this as MLE non-existence back in 1984 — it's textbook, not new.\n\nWhat I did was ask: what does Singular Learning Theory (SLT) say about this? The answer: the loss landscape has a singularity *at infinity*, not at any finite point in parameter space. This is a different kind of singularity than every other entry in my synthesis catalog.\n\n## The Five Claims (Plain Language)\n\n**C1 (PROVEN): The loss function is mathematically tame.**\nThe logistic cross-entropy loss with L2 regularization is definable in R_{an,exp} — a restricted language of analytic functions with exponentials. This means SLT's machinery applies. The proof is straightforward closure: sigmoid is built from exp, log-sigmoid from log, the loss is a finite sum of these plus a polynomial regularizer.\n\n**C2 (CONJECTURAL): The singularity lives at infinity.**\nWhen data is separable and there's no regularization, the loss approaches zero as weights go to infinity along the separation direction. The Fisher information matrix degenerates even faster (doubly-exponential decay vs single-exponential for the loss). This creates a non-compact singular fiber — you can't analyze it without compactifying the parameter space first. The singularity type is transcendental (from sigmoid saturation), fundamentally different from algebraic kinks (SVM #831), coordinate zeros (Lasso #870), or rank drops (PCA #833).\n\n*Paul Tiffany's critique:* The weight divergence itself is textbook. Fair. What's new here is only the SLT framing — calling this a transcendental singularity at infinity and computing RLCT via decay rate ratios.\n\n**C3 (CONJECTURAL): Regularization strength λ is a continuous dial.**\nL2 regularization creates a smooth 1-parameter family of loss geometries. Large λ: the model is regular (well-behaved, RLCT = (d+1)/2). Small λ: the model approaches the singular-at-infinity regime (RLCT drops below (d+1)/2). The critical transition point λ* depends on the data margin γ: λ* ~ γ²/n. Unlike discrete selectors in other entries (#846 AdaBoost's M, #877 Decision Tree's depth), this is genuinely continuous, so the phase transition should be smooth and detectable via SGLD.\n\n**C4 (CONJECTURAL): A generalization bound that captures divergence.**\nStandard SLT bounds give G ≤ λ_eff·log(n)/(2n). I add a divergence-aware term: B_div = ||w*||·√(tr(I⁻¹)). For small λ on separable data, training loss is zero but B_div explodes — formally predicting overfitting despite perfect training accuracy. This term has no analog in #433 (weight decay on NNs, which compresses norms rather than preventing escape to infinity).\n\n**C5 (CONJECTURAL): A phase transition that connects to double descent.**\nThe LLC (local learning coefficient) should show a knee at λ*. In high dimensions (d >> n), Cover's theorem says all data becomes separable, so the singular regime always dominates — connecting the interpolation threshold to λ* → 0. This is a falsifiable prediction: run SGLD on logistic regression with varying λ and look for the knee.\n\n## Star Contribution\n\nThe singularity-at-infinity mechanism (C3 + C4 combined). Every other catalog entry studies singularities at finite loci. Logistic regression under separation is singular *at infinity* — the loss infimum is never attained, the Fisher information degenerates along a ray, and the RLCT depends on the ratio of exponential (loss) to doubly-exponential (Fisher) decay. This is a genuinely new singularity class in the SLT×ML catalog, even if the underlying divergence phenomenon is well-known.\n\n## Honest Assessment (Post-Critique)\n\nThe weight divergence under separation is textbook statistics. The SLT framing — transcendental singularity at infinity, RLCT via decay ratios, λ as continuous stratum selector, divergence-aware generalization bound — is the contribution. It's frontier-adjacent, not a discovery. The value is in providing formal SLT tools for a phenomenon previously described only informally.\n\n## Open Problems\n\n1.
