# Synthesis #848: RWKV × RLCT\n\n## L0: Introduction and Scoping\n\nRWKV is an attention-free recurrent architecture combining time-mixing (exponential decay with gating) and channel-mixing (FFN with gating). Unlike Transformer attention (#134) or SSM/Mamba state-space models (#580), RWKV uses a fixed-size recurrent state with input-dependent gating and exponential time decay (w).\n\nThe RLCT bridge: the time-decay parameter w acts as a stratum selector — different regimes of w create distinct singular fibers in the loss landscape. Gate saturation creates input-dependent singular fibers. Channel-mixing compression-redundant feature maps add singular structure.\n\n## L1: Formal Definitions\n\n- **D1** (RWKV Time-Mixing): For input sequence x, the time-mixing update is s_t = d(u, e^w) s_{t-1} + d(u, e^x) x_{t-1} + (intermediate terms), where w = e^{-w} - e^{-u} is the time-decay, u is bonus, d(.) and e(.) are sigmoid gates.\n\n- **D2** (Time-Decay as Stratum Selector): w controls exponential decay rate. For w → -∞, fixed-window recurrence. For w → 0, decay becomes instantaneous. The value of w selects a stratum in parameter space.\n\n- **D3** (Channel-Mixing FFN): y_t = g2(tanh(m g1(x))) ⊕ g1(x), where g1, g2 are sigmoid gates, m is linear, tanh is activation. Compression-redundant m creates singular fiber when m → 0.\n\n- **D4** (Loss as Analytic Function): Empirical loss L(p) = (1/n) Σ -log p(y_i | x_i; w, gates, m), analytic in parameters.\n\n- **D5** (Real Code as Factor): lf ~ Prod(w, gates | p) for finite d, analytic in IR, singular in RE.\n\n- **D6** (Singular Fiber for Time-Mixing): V(w) = {w : exponential decay saturates} is a stratum in parameter space. Gate saturation adds non-injective points.\n\n- **D7** (Channel-Mixing Singularity): Compression-redundant m with sparse activation creates singular code when activation fades.\n\n## L2: Claims C1-C5\n\n- **C1** (Definability [PROVEN]): Empirical loss and real code for RWKV are definable analytic functions, satisfying SLT conditions.\n\n- **C2** (Time-Decay Stratum Selector [CONJECTURAL]): RLCT lambda(w) is non-constant in w, creating strata. Higher complexity → slower decay → lower RLCT.\n\n- **C3** (Gate Saturation Adds Non-Injectivity [CONJECTURAL]): Gate saturation adds non-injective points to V(w), increasing RLCT.\n\n- **C4** (Generalization Bound [CONJECTURAL]): Gap controlled by time-decay stratum complexity. Analogous to #580 SSM and #134.\n\n- **C5** (Time + Channel Additivity [CONJECTURAL]): Total RLCT approximates sum of time-mixing and channel-mixing contributions.\n\n## L3: Open Problems\n\n1.
