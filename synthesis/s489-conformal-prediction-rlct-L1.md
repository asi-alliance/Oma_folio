# Synthesis #489: Conformal Prediction × RLCT\n## L1: Formalization\n\n**Date:** 2026-10-21\n\n### Formal Definitions\n\n**D1 (Nonconformity Score):** Let f_θ: X → Y be a predictor with parameters θ ∈ Θ ⊂ ℝ^d. The nonconformity score A(x,y;θ) = ℓ(f_θ(x), y) where ℓ is a loss function (e.g., absolute loss |f_θ(x) - y| for regression, or 1 - p_θ(y|x) for classification). The empirical nonconformity distribution S = {A(x_i,y_i;θ) : i=1,...,n_cal} is computed on the calibration set. The α-quantile q_α(S) = S_{(⌈(n_cal+1)(1-α)⌉)} (order statistic). The prediction set Ŷ_α(x;θ) = {y : A(x,y;θ) ≤ q_α(S)}.\n\n**D2 (Level-Set Variety):** For fixed calibration data S, define the level-set variety V_t = {θ ∈ Θ : q_α(A_cal;θ) = t}. As θ varies, q_α(S(θ)) = t defines a level set in parameter space. The true parameter set W = {θ : K(θ) = K*} contains W_CP = {θ : coverage C(α,θ) = 1-α}, the conformal-valid fiber. Under exchangeability, W_CP is non-empty and contains W. When exchangeability breaks, W_CP may become empty or lower-dimensional.\n\n**D3 (Coverage Function):** The coverage function C(α,θ) = P_{(X,Y)~P*}(Y ∈ Ŷ_α(X;θ)) = P(A(X,Y;θ) ≤ q_α(S;θ)). Under exchangeability, E[C(α,θ)] = 1-α for all θ ∈ W. Under distribution shift (P* ≠ P_cal), the coverage gap ΔC(θ) = |C(α,θ) - (1-α)| > 0. The gap function θ ↦ ΔC(θ) is piecewise smooth with a non-analytic transition at the exchangeability boundary.\n\n**D4 (Exchangeability Boundary):** Define the exchangeability functional E(P_cal, P*) = ||P_cal^{n_cal} - P*^{n_cal}||_{TV} (total variation between joint distributions of calibration samples). Exchangeability holds iff E = 0. The exchangeability boundary ∂E = {P* : E(P_cal,P*) = ε*} for some critical ε* where the coverage guarantee transitions from holding to failing. This boundary is a non-smooth manifold in distribution space.\n\n**D5 (Nonconformity Quantile Map):** The map Q: Θ → ℝ, Q(θ) = q_α(A_cal;θ) is the empirical quantile function on the calibration nonconformity scores. Q is piecewise constant (order statistic selection) with jumps when θ crosses configurations that reorder calibration scores. Each jump locus J_k = {θ : A(x_{(k)},y_{(k)};θ) = A(x_{(k+1)},y_{(k+1)};θ)} is an algebraic variety (equality of two definable functions). The union J = ∪_k J_k is the quantile-jump locus, a subvariety of Θ.\n\n**D6 (RLCT of Coverage Variety):** The RLCT of the loss K(θ) near W restricted to the conformal-valid fiber W_CP is λ_CP. Formally, λ_CP = RLCT(W_CP, K|_{W_CP}) = the RLCT of the restricted loss landscape. The standard RLCT λ satisfies λ ≥ λ_CP (restriction to a subvariety can only increase or maintain RLCT). The coverage gap satisfies ΔC ~ λ_CP · log(n_cal) / (2·n_cal) + O(1/n_cal) conjecturally.\n\n**D7 (Stratum Selector):** The calibration set size n_cal acts as a stratum selector on the quantile-jump locus J. For n_cal = 1, J is the full score-equality variety (maximally singular). As n_cal → ∞, q_α converges to the population quantile q_α*, and J concentrates to the smooth level set {θ : A_pop(θ) = q_α*}, reducing multiplicity. Thus λ_CP(n_cal) is non-increasing in n_cal, approaching the population RLCT λ_CP(∞).\n\n### Five Claims\n\n**C1 (PROVEN):** For a neural network f_θ with ReLU activations, softmax output, and any standard loss ℓ (CE, MSE, L1), the nonconformity score A(x,y;θ) = ℓ(f_θ(x), y) is definable in R_{an,exp}. The order statistic q_α is a semialgebraic selection (argmin/argmax over finite set), and the indicator 1{A ≤ q_α} is definable. Therefore the prediction set Ŷ_α and coverage function C(α,θ) are definable in R_{an,exp}.\n\n*Proof sketch:* ReLU is subanalytic (globally definable in R_an as max(0,x) = (x+|x|)/2, and |x| is definable). Softmax = exp(z_i)/Σ exp(z_j) is definable in R_{an,exp}. CE loss = -log p(y|x) = -log(softmax(z)_y) uses log∘exp = identity on positive reals, definable. The order statistic is a finite selection over n_cal elements, which is semialgebraic. The indicator 1{s ≤ t} is definable in R_an. Composition preserves definability. ∎\n\n**C2 (CONJECTURAL):** The quantile-jump locus J = ∪_k J_k is a union of algebraic varieties in Θ, each J_k being the equality locus of two nonconformity scores. The RLCT of the loss landscape near W_CP is governed by the geometry of J ∩ W_CP. The most singular component of J ∩ W_CP determines λ_CP.\n\n*Gap:* The exact algebraic structure of J_k depends on the specific loss and architecture. No general computation of λ_CP for arbitrary J is known.\n\n**C3 (CONJECTURAL):** The calibration set size n_cal is a stratum selector: λ_CP(n_cal) is non-increasing. For small n_cal, the quantile is selected from few scores, creating high-multiplicity degeneracies (many θ give the same order). As n_cal → ∞, quantile concentrates, J smooths, multiplicity decreases, λ_CP → λ_CP(∞) < λ_CP(1).\n\n*Gap:* Monotonicity is intuitive but unproven. The stratum structure of J as a function of n_cal is not formally characterized.\n\n**C4 (CONJECTURAL):** Under exchangeability, the coverage gap is E[|C(α) - (1-α)|] ≤ λ_CP · log(n_cal)/(2·n_cal) + U_CP/√(n_cal) where U_CP is a complexity term from the nonconformity score function class. Under distribution shift with exchangeability functional E = ε, an additional term ε · λ_CP appears: ΔC ≤ λ_CP · log(n_cal)/(2·n_cal) + U_CP/√(n_cal) + ε · λ_CP.\n\n*Gap:* The exact form of the distribution-shift term is speculative. The connection between exchangeability breakdown and increased λ_CP is heuristic.\n\n**C5 (CONJECTURAL):** There exists a critical shift δ* such that for E < δ*, coverage is guaranteed (C ≥ 1-α) and the loss landscape near W_CP is smooth (λ_CP small), while for E > δ*, coverage fails and the loss landscape becomes singular (λ_CP spikes). This phase transition is detectable via SGLD on the nonconformity score landscape: the SGLD localizer energy spikes at δ*.\n\n*Gap:* Existence of δ* as a sharp phase transition is conjectural. The SGLD detection mechanism is untested for this setting.\n\n### Connection to Double Descent\n\nAt the interpolation threshold (n_params ≈ n_train), the nonconformity scores on training data become degenerate (all approach 0 for overfit models).
