#560 Knowledge Distillation × RLCT — L0 Hypothesis (2026-10-23)\n\n## Topic\nKnowledge distillation (KD): training a student model f_s to match both hard labels y and soft predictions p_t = softmax(z_t/T) from a teacher model f_t, using loss L = alpha * CE(p_s, y) + (1-alpha) * T^2 * KL(p_s^T || p_t^T). Temperature T controls softness of teacher distribution. The student learns from the teacher's dark knowledge (inter-class similarities) in addition to ground truth.\n\n## Key Insight\nKnowledge distillation creates a composite loss landscape that is a weighted sum of two KL divergences: one to the true distribution (hard labels) and one to the teacher distribution (soft labels). The teacher's soft labels define a secondary singular structure — the zero-loss set of the KD loss is the intersection of (a) the hard-label zero-loss set V_hard and (b) the teacher-matching zero-loss set V_teacher = {w : f_s(x) = f_t(x)}. The RLCT of the student under KD is governed by the singularity of this intersection. When the teacher is itself a singular model at a low-RLCT stratum, V_teacher is a smooth submanifold (the teacher already resolved its singularity), and the student's KD loss has LOWER RLCT than hard-label training alone — the teacher's soft labels guide the student toward a less singular solution.\n\n## Claims\n\n**C1 (PROVEN):** The KD loss L_KD(w) = alpha * CE(f_s(x;w), y) + (1-alpha) * T^2 * KL(softmax(z_s/T) || softmax(z_t/T)) is R_an-definable. Both CE and KL of softmax functions are analytic in the parameters w (softmax is analytic, CE and KL are compositions of analytic functions). The sum of definable functions is definable. Thus K_KD(w) is in R_an,exp.\n\n**C2 (CONJECTURAL):** The zero-loss set of KD is V_KD = V_hard ∩ V_teacher, where V_hard = {w : f_s(x;w) = y} and V_teacher = {w : f_s(x;w) = f_t(x) for all x}. For a teacher that has already converged to a smooth minimum (RLCT_t = 0 or very small), V_teacher is approximately a smooth submanifold. The intersection V_hard ∩ V_teacher has codimension = codim(V_hard) + codim(V_teacher) when transverse. Since V_teacher constrains the student to match the teacher (adding constraints), the intersection has HIGHER codimension → the student's RLCT under KD is LOWER than under hard labels alone. The teacher's dark knowledge acts as a regularizer that steers the student away from highly singular strata.\n\n**C3 (CONJECTURAL):** The temperature T acts as a stratum selector. At T → ∞, the soft labels become uniform (all classes equiprobable), and V_teacher → {w : mean(z_s) = mean(z_t)} (only the mean logit must match) — a weak constraint, so V_teacher is large, RLCT_KD ≈ RLCT_hard. At T → 0, soft labels become hard (argmax of teacher), and V_teacher → {w : argmax(z_s) = argmax(z_t)} — a strong constraint matching V_hard closely. There exists an optimal temperature T* that minimizes RLCT_KD by maximizing the regularizing effect of V_teacher without collapsing it to V_hard. T* depends on the teacher's confidence calibration.\n\n**C4 (CONJECTURAL):** The generalization bound for the student under KD: G_KD <= lambda_KD * log(n) / (2n) + b_KD / sqrt(n), where lambda_KD <= lambda_hard (KD achieves lower RLCT). The improvement lambda_hard - lambda_KD is proportional to (1-alpha) * dim(V_teacher), the dimension of the teacher-matching constraint. For small students (few parameters), the constraint V_teacher is high-dimensional relative to the parameter space, so KD provides large RLCT reduction. For large students, V_teacher is low-dimensional relative to the parameter space, so KD provides minimal benefit — consistent with KD being most effective for model compression (small students).\n\n**C5 (CONJECTURAL):** Phase transition: there exists a critical student capacity d* (parameter count) below which KD helps (lambda_KD < lambda_hard, teacher guidance dominates) and above which KD hurts (the student could reach a deeper singular stratum on its own, but V_teacher constrains it to the teacher's stratum which may be shallower). This predicts that KD is most beneficial when student capacity is significantly below teacher capacity, and can hurt when student capacity approaches teacher capacity — consistent with empirical observations that self-distillation (same architecture) gives marginal benefits.\n\n## Distinction from Prior Syntheses\n- #224 Label Smoothing: Softens hard labels uniformly, not using teacher predictions. V_teacher is absent.\n- #234 Temperature Scaling: Post-hoc calibration, not training-time loss modification.\n- #169 Dropout: Stochastic masking of parameters, not soft-label regularization.\n- #99 SGD Dynamics: Trajectory behavior, not loss landscape modification via teacher.\n- #222 BatchNorm: Normalization reparameterization, not teacher-student transfer.\n- #505 Weight Norm: Scale-direction decomposition, not distillation.\n- #559 SAM: Sharpness-aware perturbation, not teacher-guided regularization.\n- #433 Weight Decay: L2 penalty, not teacher-matching constraint.\n\n## Open Problems\n1.
