#668: Proof-Theoretic Complexity × AIT\n\n## L1: Formalization\n\n### Definitions\n\n**D1 (Proof System)**: A proof system \(\Sigma = (L, A, R)\) consists of a formal language L, a set of axioms A, and inference rules R. Each rule has arity k and produces a conclusion from k premises. The proof-theoretic ordinal \(\alpha(\Sigma)\) is the smallest ordinal not provably well-founded in \(\Sigma\).\n\n**D2 (Proof Tree)**: A proof tree \(\pi\) of theorem T in \(\Sigma\) is a finite tree where:\n- Leaves are instances of axioms from A\n- Internal nodes are applications of rules from R\n- Root is T\n- **Height** \(h(\pi)\) = length of longest root-to-leaf path\n- **Size** \(s(\pi)\) = total number of nodes\n\n**D3 (Ordinal Height)**: For a proof tree \(\pi\), define the ordinal height \(\bar{h}(\pi)\) recursively:\n- \(\bar{h}(\text{leaf}) = 0\)\n- \(\bar{h}(\text{node with children } \pi_1, \ldots, \pi_k) = \sup\{\bar{h}(\pi_i) + 1 : i \leq k\}\)\n\nFor finite trees, \(\bar{h}(\pi) = h(\pi)\) (a natural number). For infinitary proof systems (e.g., \(\omega\)-logic), \(\bar{h}\) can be transfinite and relates directly to \(\alpha(\Sigma)\).\n\n**D4 (Kolmogorov Complexity)**: \(K(T)\) = length of shortest program p (on a universal Turing machine U) such that U(p) outputs a proof of T. We fix U to be a machine that enumerates proofs in \(\Sigma\).\n\n**D5 (Signature Size)**: \(|\Sigma|\) = number of distinct symbols (function/predicate/relation symbols) in the language L. Each symbol requires \(\log|\Sigma|\) bits to encode.\n\n### C1 (Main Conjecture: Height-Size Decomposition)\n\n**Claim**: There exist constants \(c_h, c_s > 0\) (depending on \(\Sigma\) and U but not on T) such that:\n$$K(T) = c_h \cdot h(\pi_T) \cdot \log|\Sigma| + c_s \cdot s(\pi_T) \cdot \log|\Sigma| + O(1)$$\n\nwhere \(\pi_T\) is the shortest proof of T (minimizing \(c_h \cdot h + c_s \cdot s\)).\n\n**Proof Sketch**:\n\n(→) Upper bound: A program encoding \(\pi_T\) must specify:\n1. The tree structure: requires \(O(h(\pi_T) \cdot \log|\Sigma|)\) bits for the branching pattern at each depth level (each node symbol needs \(\log|\Sigma|\) bits).\n2. The node labels (which axiom/rule at each node): requires \(O(s(\pi_T) \cdot \log|\Sigma|)\) bits.\n\nTotal: \(K(T) \leq c_h \cdot h \cdot \log|\Sigma| + c_s \cdot s \cdot \log|\Sigma| + O(1)\).\n\n(←) Lower bound (conjectural): Any program outputting a proof of T must encode at least:\n1. The branching depth (captured by h) — otherwise the program cannot reproduce the logical structure.\n2. The inference sequence (captured by s) — each inference step must be specified.\n\nThe lower bound requires showing no compression of the proof tree is possible beyond the tree-encoding overhead. This is the hard direction and depends on the proof system.\n\n### C2 (Overhead Computability)\n**Conjecture**: The overhead \(K(T) - c_h \cdot h(\pi_T) \cdot \log|\Sigma|\) is computably approximable from above but not from below (analogous to K itself).\n\n### C3 (Ordinal-Coefficient Stability)\n**Conjecture**: For proof systems \(\Sigma_1, \Sigma_2\) with \(\alpha(\Sigma_1) < \alpha(\Sigma_2)\), the coefficient \(c_h\) is monotonically non-decreasing in \(\alpha\). Stronger theories require more bits per unit height.\n\n### C4 (Height-Size Tradeoff)\n**Conjecture**: There exist theorem families \(\{T_n\}\) where \(h(\pi_{T_n}) = O(1)\) but \(s(\pi_{T_n}) = \Omega(n)\) (wide shallow proofs) and vice versa (narrow deep proofs). The decomposition separates these regimes.\n\n### C5 (Phase Transition)\n**Conjecture**: As \(\alpha(\Sigma)\) increases past certain ordinal thresholds (e.g., \(\varepsilon_0\), \(\Gamma_0\)), the ratio \(c_h / c_s\) undergoes a phase transition — height becomes relatively more expensive than size, reflecting the shift from predicative to impredicative reasoning.\n\n### Open Problems\n1. Prove the lower bound direction of C1 for a specific proof system (e.g., PA).\n2. Compute \(c_h, c_s\) empirically for small theorems in PA.\n3. Relate C3 to known results on ordinal strength and proof-theoretic functions.\n4. Is C5 connected to the Veblen hierarchy phase transitions?\n5. Can Curry-Howard provide a type-theoretic interpretation of the decomposition?\n\n### Cross-References\n- #354 STE × RLCT: straight-through as approximation (analogous to compression)\n- Garrabrant (2016): logical induction as alternative to proof complexity\n- Solomonoff (1964): universal prior as program-length only\n- Pudlák (1998): proof complexity lower bounds\n- Curry-Howard: proofs as programs, height as type complexity\n\n### Status\n- C1: CONJECTURAL (upper bound proven, lower bound open)\n- C2-C5: CONJECTURAL\n- Next: L2 novelty verification
