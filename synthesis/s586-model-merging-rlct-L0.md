# 586 | Model Merging × RLCT | L0 Exploration\n\n## Topic\nModel Merging (weight interpolation, task arithmetic, TIES) × Real Log-Canonical Threshold (RLCT)\n\n## Selection Rationale\nZero catalog hits confirmed. Model merging via weight interpolation W_merged = αW_A + (1-α)W_B traces a line through parameter space. The singular fiber of the merged model is the intersection of individual fibers with this line — generically lower RLCT than either parent. Task arithmetic (W + τ·δ_task) creates translated fibers. TIES resolving sign conflicts adds discrete selection stratifying the fiber. No prior SLT/RLCT work on model merging exists.\n\n## Key Bridge\nWeight interpolation is a polynomial (linear) map from the 1-dimensional α-space into the full parameter space Θ. The merged loss L(αW_A + (1-α)W_B, D) is piecewise-analytic in α with singularities at: (1) boundary crossings where the interpolation line crosses a parent's singular stratum, (2) rank-deficient interpolation points, (3) TIES sign-conflict resolution boundaries. The RLCT of the merged model along this 1D slice is generically ≤ the RLCT of either parent in full space.\n\n## Definitions\n- D1: Parent models (W_A, W_B) ∈ Θ × Θ, each with singular fibers F_A = {w : p(y|w,x) = p(y|W_A,x)}, F_B analogous\n- D2: Interpolation map ι(α) = αW_A + (1-α)W_B, polynomial in α\n- D3: Merged loss L_merge(w, α) = L(ι(α)W_A + (1-α)W_B, D_merge), piecewise-analytic in (w, α)\n- D4: Line-fiber intersection F_line = F_A ∩ im(ι) — the restriction of the parent fiber to the interpolation line\n- D5: Task arithmetic δ_task = W_task - W_base, merged W = W_base + τ·δ_task, creating translated fiber F_base + τ·δ_task\n- D6: TIES sign resolution: σ_i = sign(<δ_A_i, δ_B_i>), resolves conflict by selecting dominant sign, creating discrete stratum Σ = {w : σ_i(w) = σ_j(w)}\n- D7: Merged RLCT λ_merge(α) = RLCT of L_merge restricted to 1D slice at parameter α\n\n## Claims\n- C1 (PROVEN): R_an,exp definability. Linear interpolation ι(α) is polynomial, composition with analytic loss preserves R_an,exp. TIES sign function is semi-algebraic (uses <·,·> comparison). By Wilkie + Tarski-Seidenberg, merged loss is R_an,exp definable, hence RLCT exists.\n- C2 (CONJECTURAL): Merged fiber is line-fiber intersection. The singular fiber of the merged model at α equals F_line(α) = {w : p(y|ι(α)w,x) = p(y|true,x)}, which is the intersection of the parent fiber with the interpolation image. Generically dim(F_line) ≤ dim(F_parent), so λ_merge ≤ λ_parent.\n- C3 (CONJECTURAL): α as continuous stratum selector. As α varies from 0 to 1, the interpolation line crosses different singular strata of the parent models. Each crossing creates a phase transition in λ_merge(α). The function λ_merge(α) is piecewise-constant with jumps at stratum crossings.\n- C4 (CONJECTURAL): Model soup RLCT ≤ individual model RLCT. Averaging k models W_soup = (1/k)ΣW_i is a k-dimensional interpolation. The soup fiber is the intersection of all parent fibers with the k-flat spanned by {W_i}. By dimension reduction, λ_soup ≤ min_i λ_i. This explains why model soups generalize better.\n- C5 (CONJECTURAL): Critical α* phase transition. There exists α* where the interpolation line crosses the dominant singular stratum, causing λ_merge to drop. SGLD on the merged model should detect an LLC kink at α*. For task arithmetic, critical τ* where task direction crosses the base model's singular fiber.\n\n## Open Problems\n1.
