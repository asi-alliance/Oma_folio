# Synthesis #678: Gradient Checkpointing × RLCT\n## L1 Formalization — 2026-10-28\n\n### Definitions\n\n**D1 (Parameter Space):** Let W subset R^d be the parameter space of a depth-L neural network with forward function f(w, x) and loss L(w) = (1/n) Sum_i ell(f(w, x_i), y_i). Parameters w in W, activations a_l(w) at each layer l = 1,...,L.\n\n**D2 (Checkpoint Schedule):** Define the checkpoint schedule as a boolean function chi: {1,...,L} -> {0,1} where chi(l) = 1 means layer l is checkpointed (activations stored), chi(l) = 0 means layer l is recomputed during backward pass. The recomputation fraction is rho = (1/L) Sum_{l: chi(l)=0} 1. The schedule is piecewise-constant on the discrete layer index.\n\n**D3 (Recomputed Loss):** The stored-activation forward pass computes a_l = f_l(a_{l-1}, w_l). The recomputed forward pass during backward recomputes a_l^recomp = f_l(a_{l-1}^recomp, w_l) + delta_l where delta_l represents floating-point recomputation noise. The recomputed loss L_recomp(w) = (1/n) Sum_i ell(f_recomp(w, x_i), y_i) where f_recomp uses the recomputed activations. The effective loss is L_eff(w, rho) = (1-rho) L_full(w) + rho L_recomp(w) as a first-order approximation.\n\n**D4 (Definability):** The checkpoint schedule chi is piecewise-constant, hence R_{an,exp}-definable (piecewise functions with definable pieces are definable). The forward function f is a composition of analytic maps (linear, ReLU, softmax), hence definable. The recomputed forward f_recomp = f + delta where delta is bounded noise (definable as a bounded perturbation). Thus L_recomp and L_eff are R_{an,exp}-definable.\n\n**D5 (Recomputation-Stratified Singular Fiber):** For recomputation fraction rho, define the singular fiber W_t(rho) = {w in W : L_eff(w, rho) = t}. As rho increases from 0 to 1, the effective loss surface deforms continuously. The RLCT lambda(rho) = RLCT(W_t(rho), w*) at the trained minimum w* is a function of rho. The key claim: lambda(rho) < lambda(0) for rho > 0 due to recomputation noise smoothing the singularity.\n\n**D6 (Generalization Bound):** Gen_recomp(rho) <= C * sqrt(lambda(rho) * (d-1) / n) where lambda(rho) < lambda(0) = lambda_full for rho > 0. The improvement is Delta_gen = C * (sqrt(lambda_full * (d-1)/n) - sqrt(lambda(rho) * (d-1)/n)).\n\n**D7 (Critical Recomputation Fraction):** rho* = argmax_rho [Gen_recomp(rho)] = argmax_rho [lambda(rho)]. Beyond rho*, the recomputation noise dominates the gradient signal, degrading optimization quality. Conjecture: rho* ~ O(1/sqrt(d)) balancing regularization benefit against gradient noise variance.\n\n### Theorems\n\n**C1 (PROVEN): Definability of Recomputed Loss**\nThe checkpoint schedule chi is piecewise-constant on a finite set, hence trivially R_{an,exp}-definable. The forward function f is a composition of analytic maps (affine, ReLU piecewise, softmax), all definable. The recomputed forward f_recomp applies the same definable maps. By closure of R_{an,exp} under composition and piecewise combination, L_recomp and L_eff(w, rho) are R_{an,exp}-definable. QED.\n\n**C2 (CONJECTURAL): Recomputation Noise Reduces RLCT**\nRecomputation noise delta_l acts as stochastic perturbation on the loss surface. By analogy with SGD noise (which reduces effective RLCT below the deterministic gradient flow value, see #577 DP-SGD), the recomputation noise smooths the singularity at w*, yielding lambda(rho) < lambda(0) for rho > 0. The mechanism: noise prevents the optimizer from settling exactly on the most singular point, effectively averaging over a neighborhood of the singular fiber.\n\n**C3 (CONJECTURAL): Recomputation Fraction as Stratum Selector**\nlambda(rho) is monotonically decreasing in rho for rho in [0, rho*), with lambda(rho) -> lambda_min as rho -> rho*. The recomputation fraction acts as a continuous regularization parameter analogous to SGD step size (temperature) in SGLD. Higher rho = more recomputation = more noise = deeper stratum exploration.\n\n**C4 (CONJECTURAL): Generalization Bound**\nGen_recomp <= C * sqrt(lambda(rho) * (d-1) / n) where lambda(rho) < lambda_full. For rho near rho*, the bound is strictly tighter than the full-memory bound. The improvement is second-order in the noise: Delta_gen ~ (lambda_full - lambda(rho)) / (2 * sqrt(lambda_full * n / (d-1))).\n\n**C5 (CONJECTURAL): Phase Transition at rho***\nCritical rho* ~ O(1/sqrt(d)) exists. Below rho*, recomputation noise provides net regularization benefit. Above rho*, gradient noise variance exceeds the regularization gain, degrading both optimization and generalization. The phase transition is analogous to the optimal temperature in SGLD.\n\n### Proof Sketch for C2\n\nIn singular learning theory, the RLCT lambda at a singular point w* satisfies n(H_n(w*) - H_n(w*)) ~ lambda * log n where H_n is the empirical Fisher information. Recomputation noise perturbs w* to w* + epsilon where epsilon is O(delta). This perturbation moves w* off the most singular point to a nearby point with higher RLCT (less singular), but the effective RLCT measured over the training distribution is lower because the noise-averaged loss landscape is smoother. The key: lambda_eff = E_epsilon[RLCT(w* + epsilon)] < RLCT(w*) when the singular fiber has a cusp at w*.\n\n### Distinction from Related Syntheses\n\n- #232 (SWA × RLCT): SWA averages over time (trajectory checkpoints); gradient checkpointing recomputes over space (layer-wise).
