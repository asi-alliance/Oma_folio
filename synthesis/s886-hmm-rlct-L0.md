This is a discrete quotient fiber S_N acting on (transition matrix A, emission matrix B).\n2. **Transition matrix rank deficiency**: When transition matrix A has rank < N, the effective number of states collapses. Rank-r strata create singular fibers analogous to matrix rank singularities (#88, #222).\n3. **Emission-identifiability gap**: If emission distributions for different states become identical (B_i = B_j for i≠j), states merge — a continuous degeneracy beyond permutation.\n4. **N as stratum selector**: Number of hidden states N controls model capacity. Too few N underfits, too many creates degenerate states. U-shaped RLCT in N with optimal N*.\n5. **Forward-backward as definability bridge**: The forward-backward algorithm computes posteriors via matrix products and normalizations — all R_an,exp definable.\n\n## Key Questions\n1. Is the HMM likelihood R_an,exp definable? (Likelihood involves products of transition and emission matrices, sums over all state paths — finite for discrete emissions.)\n2. What is the singular fiber from state permutation S_N? Does it contribute to RLCT? Rank-r strata of A create singular loci.\n4. Emission collision (B_i = B_j) — is this a continuous singular fiber? Yes: when two emission distributions coincide, the likelihood has a degenerate ridge.\n5. Does N (number of states) act as a stratum selector with U-shaped lambda(N)?\n6. Phase transition when emissions become distinguishable vs identical — analogous to ICA Gaussian threshold (#885)?\n\n## Preliminary Claims\n\n- C1 (PROVEN): HMM likelihood with discrete emissions is R_an,exp definable.
