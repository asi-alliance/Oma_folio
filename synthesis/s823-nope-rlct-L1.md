## D1: NoPE Transformer Architecture Map

The NoPE transformer with L layers, hidden dim d, vocab size V, no positional encoding:

Input: X = (x_1, ..., x_n) in R^{n x d_e} (token embeddings, no PE added)

Layer l transformation:
  Q_l = H_{l-1} W_l^Q, K_l = H_{l-1} W_l^K, V_l = H_{l-1} W_l^V  (in R^{n x d})
  A_l = softmax(Q_l K_l^T / sqrt(d)) V_l  (attention, no position term)
  H_l = LN(H_{l-1} + A_l W_l^O)  (residual + layer norm)

Output: f_w(X) = softmax(H_L W^out) in R^{n x V}

Parameter space: W = {W_l^Q, W_l^K, W_l^V, W_l^O, W^out}_{l=1}^{L} in R^D
where D = L * (3*d*d + d*d) + n*V*d (no positional parameters).

The map f_w: R^{n x d_e} -> R^{n x V} is a composition of:
- Linear maps (W_l^Q, W_l^K, W_l^V, W_l^O): polynomial (degree 1)
- Bilinear product Q_l K_l^T: polynomial (degree 2)
- Scalar division by sqrt(d): constant scaling
- Softmax: exp/sum-exp, restricted analytic on bounded inputs
- LayerNorm: (x - mean)/sqrt(var + eps): rational function, definable in R_an
- Residual addition: polynomial

**S_n action:** For sigma in S_n, define P_sigma in R^{n x n} the permutation matrix.
  P_sigma X = (x_{sigma(1)}, ..., x_{sigma(n)})
  f_w(P_sigma X) = P_sigma f_w(X)  (permutation equivariance, no PE)

This holds because every component (attention, FFN, LN) is permutation-equivariant
when no position-dependent term is present.

## D2: NoPE Loss Function

Training loss over dataset D = {(X_i, Y_i)}_{i=1}^N:

L_n(w) = (1/N) sum_{i=1}^N ell(f_w(X_i), Y_i)

where ell is cross-entropy: ell(p, y) = -sum_{j=1}^V y_j log(p_j)

For permutation-invariant tasks (Y_i = P_sigma Y_i when X_i = P_sigma X_i):
  L_n(w) = L_n(sigma . w)  where sigma acts trivially on w (no PE params)
  => L_n is S_n-invariant as a function of the DATA ordering

For general tasks: L_n is NOT S_n-invariant in data, but f_w IS S_n-equivariant in architecture.

K(w) = -log L_n(w) (negative log-likelihood / loss)
K: R^D -> R is R_{an,exp}-definable (composition of definable maps, D1).

## D3: S_n Action on Parameter Space (Orbifold Structure)

S_n acts on the FIBER of f_w, not on W directly. Define:

For sigma in S_n, the permutation matrix P_sigma acts on the output:
  f_w(P_sigma X) = P_sigma f_w(X)

This means: if w achieves zero loss on data {(X_i, Y_i)}, then the same w
achieves zero loss on {(P_sigma X_i, P_sigma Y_i)}.

The zero-loss fiber: W_0 = {w in R^D : K(w) = 0}

For permutation-invariant tasks, W_0 is S_n-invariant (as a set).
The effective model class is the QUOTIENT: W_0 / S_n.

**Orbifold singularities:** At fixed points of sigma in S_n (sigma != id):
  Fix(sigma) = {w in W_0 : f_w is invariant under sigma acting on inputs}
  
For a transposition (i j): Fix((i j)) = {w : tokens i,j produce identical 
hidden representations at every layer}. This is a SINGULAR STRATUM of W_0/S_n.

The quotient W_0/S_n has orbifold singularities at Fix(sigma) for all 
sigma != id in S_n. These are locally modeled as R^d / <sigma> (quotient 
by the cyclic group generated by sigma).

## D4: Singular Fiber V_0 and Orbifold Stratification

V_0 = W_0 (the zero-loss set, when it exists) or more precisely:

V_0 = {w in R^D : K(w) = min_w K(w)}  (true minima set)

Orbifold stratification of V_0/S_n:

V_0^{(id)} = V_0 (generic stratum, smooth, codim = 0 in quotient)
V_0^{(sigma)} = {w in V_0 : w = sigma . w}  for each conjugacy class [sigma]

Strata hierarchy by cycle type of sigma:
- Identity: full dimension dim(V_0) - 0
- Transpositions (i j): dim(V_0) - d (tokens i,j identical, lose d dims)
- k-cycles: dim(V_0) - (k-1)*d (k tokens collapse to 1, lose (k-1)*d dims)
- Full permutation: dim(V_0) - (n-1)*d (all tokens identical, minimal stratum)

The deepest stratum (all tokens identical) has codimension (n-1)*d in V_0,
creating the most severe singularity in the orbifold V_0/S_n.

## D5: Orbifold RLCT lambda_NoPE

The RLCT of the orbifold W_0/S_n at a point wbar:

lambda_{NoPE}(wbar) = RLCT(K, wbar) computed on the QUOTIENT space.

For the generic stratum (wbar not fixed by any non-trivial sigma):
  lambda_{NoPE}(wbar) = lambda_0 / 2  (standard, as if no quotient)

  where lambda_0 = RLCT of K on W_0 (before quotient).

For the orbifold strata, the RLCT receives contributions from:
  (a) The singularity of K restricted to the stratum Fix(sigma)
  (b) The orbifold singularity type of R^d / <sigma> at the fixed point

**Conjecture (C2):** The effective (averaged) RLCT satisfies:
  lambda_{NoPE}^{eff} <= lambda_0 - log(|S_n|) / (2n)
  
where |S_n| = n! and the reduction comes from the volume contraction 
of the quotient map pi: W_0 -> W_0/S_n (degree |S_n| cover on generic stratum).

The orbifold singularities at Fix(sigma) ADD local RLCT contributions
but these are lower-dimensional and do not dominate the generic contribution.

## D6: Generalization Bound G_NoPE

The Bayesian generalization bound for NoPE:

G_{NoPE}(n) = lambda_{NoPE}^{eff} / n + U_{NoPE} / sqrt(n)

where:
- lambda_{NoPE}^{eff} = effective RLCT on W_0/S_n (D5)
- U_{NoPE} = fluctuation term, bounded by the complexity of the quotient

**Conjecture (C4):** For permutation-invariant tasks:
  G_{NoPE}(n) < G_{learned_PE}(n)
  
because:
  (a) lambda_{NoPE} < lambda_{learned_PE}  (no PE parameters: ambient dim reduced)
  (b) U_{NoPE} < U_{learned_PE}  (permutation equivariance constrains hypothesis class)

For permutation-sensitive tasks (order matters):
  G_{NoPE}(n) > G_{PE}(n)  (NoPE cannot represent the target, high approximation error)

The crossover defines the task-dependent regime boundary.

## D7: Context Length Phase Transition n*

The S_n orbifold structure depends on n (context length):

For small n: |S_n| = n! is small, quotient reduction is modest.
  lambda_{NoPE}(n) ~ lambda_0 - n*log(n)/(2n) = lambda_0 - log(n)/2

For large n: Two competing effects:
  (a) |S_n| = n! grows superexponentially -> larger quotient reduction
  (b) Implicit positional encoding emerges -> new singular strata appear
      (attention patterns specialize to encode position)

**Conjecture (C5):** There exists n* such that:
  - For n < n*: lambda_{NoPE}(n) decreases (quotient dominates, strata stable)
  - For n > n*: lambda_{NoPE}(n) increases (emergent positional strata dominate)

n* ~ C * d / log(d)  (depends on model capacity d and task complexity)

SGLD prediction: LLC trajectory lambda_hat(t) shows a KINK at n*:
  - Below n*: lambda_hat stable or decreasing with n
  - Above n*: lambda_hat increases with n

This is testable: train NoPE models at varying context lengths, 
measure LLC via SGLD, look for the phase transition.
