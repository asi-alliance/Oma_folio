# Synthesis #557: Neural ODE × RLCT — L1 Formalization\n\n## Date: 2026-10-24\n## Status: L1 FORMALIZATION\n## Distinct from #251: C3 adjoint non-injectivity (new fiber type), C2 adaptive solver N(theta) partitioning (new vs #251 fixed-solver analysis)\n\n## Formal Definitions\n\n### D1 (Neural ODE Architecture)\nLet z(0) = x (input). The state evolves as dz/dt = f_theta(z,t), theta in R^d, where f_theta is a neural network with analytic activations (tanh, softplus). The terminal state z(T) defines the output. Loss L(theta) = (1/n) sum_i ell(z_i(T;theta), y_i) where ell is analytic (cross-entropy via softmax, MSE). The ODE is solved by a numerical integrator with adaptive step size h_k and tolerance epsilon.\n\n### D2 (Adaptive Solver Step Partition)\nAn adaptive ODE solver (e.g., RK45) selects step count N(theta) based on local error estimates e_k(theta) crossing tolerance epsilon. Define the partition P_k = {theta : N(theta) = k}, where the solver takes exactly k steps. Each P_k is a semi-algebraic set (error estimates are polynomial in theta for fixed step composition). The full parameter space is R^d = union_k P_k (disjoint union up to boundary). Boundaries dP_k = {theta : e_k(theta) = epsilon} are algebraic hypersurfaces — the singular strata of the discretized loss.\n\n### D3 (R_{an,exp}-definability — C1 PROVEN)\nFor fixed step count N (within one partition P_k), the discretized flow Phi_h^N(theta) is a composition of N analytic maps (each RK step is rational in f_theta, which is analytic). By Wilkie's theorem, the composition of analytic functions with restricted exp/log is R_{an,exp}-definable. The loss L_k(theta) restricted to P_k is R_{an,exp}-definable. The piecewise loss L(theta) = L_k(theta) on P_k is definable in R_{an,exp} augmented with the semi-algebraic partition boundaries. QED.\n\n### D4 (Adjoint Non-Injectivity Fiber — C2 CONJECTURAL)\nThe adjoint method computes a(0) = -grad_z ell(z(T)), then integrates da/dt = -a^T grad_z f_theta(z,t) backward, and grad_theta L = integral_0^T a(t)^T grad_theta f_theta dt. Define the loss-to-gradient map Psi: L -> grad_theta L. This map factors through the forward trajectory z(t): two different loss functions ell_1, ell_2 yielding the same z(T) produce the same adjoint ODE and hence identical grad_theta L. The fiber V_c = {theta : Psi(theta) = c} captures parameters with identical gradient despite different loss values. This is a NEW fiber type: gradient-level singularity, not loss-level. The fiber dimension depends on the ODE solver and tolerance (through z(t) dependence).\n\n### D5 (Solver Tolerance Stratified Loss Family)\nFor tolerance epsilon > 0, define L_epsilon(theta) = the loss computed by the adaptive solver with tolerance epsilon. As epsilon -> 0, L_epsilon -> L_{cont} (the true continuous ODE loss, analytic in theta). For finite epsilon, L_epsilon is piecewise-analytic with partition {P_k(epsilon)}. The family {L_epsilon}_{epsilon>0} is a stratified family: decreasing epsilon refines the partition (more P_k regions, thinner strata). This is analogous to #213 (LR as stratum selector) and #424 (Fixup scaling) but with a continuous refinement parameter.\n\n### D6 (Generalization Bound)\nBy the standard RLCT generalization theory, for the piecewise loss L_epsilon on partition P_k: G(epsilon) ~ lambda_k log(n)/(2n) + b(epsilon)/sqrt(n), where lambda_k = RLCT of L_k restricted to P_k, and b(epsilon) captures the approximation bias from solver truncation (b -> 0 as epsilon -> 0). The tension: smaller epsilon reduces b (better approximation) but may increase lambda_k (more refined partition = more singular strata to navigate). Optimal epsilon* trades off bias vs singularity.\n\n### D7 (Continuous Depth Phase Transition)\nAs epsilon -> 0, the Neural ODE loss approaches the continuous-limit loss L_cont. If L_cont is regular (RLCT = d/2), then the phase transition is: for epsilon > epsilon*, discretization singularities dominate (RLCT > d/2); for epsilon < epsilon*, the loss is effectively regular (RLCT -> d/2). The critical epsilon* depends on the ODE stiffness and vector field complexity. For the ResNet limit (h = 1/L, L layers), epsilon* ~ 1/L, connecting to #199 skip connection RLCT.\n\n## Claims Summary\n- C1 PROVEN: R_{an,exp}-definability via adaptive solver composition + Wilkie closure\n- C2 CONJECTURAL: Adjoint non-injectivity creates gradient-level fibers (new type, not in #251)\n- C3 CONJECTURAL: Adaptive solver N(theta) partition creates semi-algebraic singular strata (new vs #251 fixed-solver)\n- C4 CONJECTURAL: Continuous depth as RLCT limit of ResNet, phase transition at epsilon*\n- C5 CONJECTURAL: Solver tolerance as stratum selector, epsilon* phase transition\n\n## Open Problems\n1.
