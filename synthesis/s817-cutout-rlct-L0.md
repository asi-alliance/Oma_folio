# Synthesis #817: Cutout × RLCT -- L0 Exploration\n\n### Date: 2026-10-29\n### Status: L0 (exploration)\n### Pipeline: L0 in progress\n\n---\n\n## Background\n\nCutout (DeVries & Taylor, 2017) is a data augmentation technique that randomly masks a contiguous square region of the input image during training. Given an input x (image), Cutout samples a random square patch of side length L at a random location, sets pixels within that patch to zero (or mean), and trains on the masked input. Unlike dropout (#169, which masks in feature/parameter space), Cutout operates in **input space** and masks a **contiguous spatial region** rather than independent units.\n\nKey properties:\n- **Input-space masking**: Cutout modifies x → x ⊙ M, where M is a binary spatial mask.\n- **Spatial contiguity**: The masked region is a single connected square, not independent pixels.\n- **Random location**: Each sample draws a different mask, creating a stochastic ensemble of masked inputs.\n- **No label modification**: Unlike Mixup (#818 candidate) or CutMix, the label y is unchanged.\n\n### Mathematical Formulation\n\nGiven input x ∈ R^{C×H×W}, label y:\n\n**Mask M(i,j)**: Binary mask where M(i,j) = 0 for (i,j) inside a random square of side L centered at (h_0, w_0), and M(i,j) = 1 elsewhere.\n\n**Masked input**: x_cut = x ⊙ M\n\n**Cutout loss**: L_cutout(θ) = (1/N) Σ_n E_M[ℓ(f(x_n ⊙ M_n; θ), y_n)]\n\nwhere M_n is sampled independently for each example. In practice, the expectation is approximated by a single sample per training step.\n\n**Mask distribution**: M is parameterized by (h_0, w_0) ~ Uniform(valid positions), L ~ fixed or uniform.\n\n---\n\n## Key Questions\n\nQ1: Is L_cutout(θ) R_{an,exp}-definable? The mask M is a piecewise-constant function of the random center (h_0, w_0). The loss ℓ(f(x ⊙ M; θ), y) is piecewise-defined: for each mask placement, it is a composition of the network (definable under standard assumptions) with a masked input. The expectation over mask placements involves integrating over (h_0, w_0) — is this integration of a piecewise-definable function definable?\n\nQ2: What is the singular fiber structure of Cutout? The zero-loss fiber V_cutout = {θ : ∀M, ℓ(f(x ⊙ M; θ), y) = 0} requires correct prediction for ALL possible mask placements. This is stronger than V_0 (standard zero-loss, no masking). How does the mask-dependent fiber V_M = {θ : ℓ(f(x ⊙ M; θ), y) = 0} relate to V_cutout = ∩_M V_M?\n\nQ3: How does the mask region size L act as a stratum selector? As L increases from 0 to H (full image), the constraint becomes more stringent. V_cutout(L=0) = V_0 (no masking). V_cutout(L=H) requires correct prediction from a blank image — impossible for non-trivial tasks. Is there a phase transition at some critical L*?\n\nQ4: Cutout creates a **piecewise-defined loss family**: for each mask placement, the loss is a different function of θ (different effective input). The zero-loss fiber is the intersection of all mask-specific fibers. Does this intersection create new singularities not present in V_0?\n\nQ5: How does Cutout compare to Dropout (#169)? Dropout masks in feature space with independent Bernoulli noise; Cutout masks in input space with a contiguous spatial block. Dropout's fiber requires invariance to random feature masking; Cutout's fiber requires invariance to spatial occlusion. Different singularity structures.\n\n---\n\n## Preliminary Claims\n\n### C1 (PROVABLE): R_{an,exp} Definability\nL_cutout(θ) = E_M[ℓ(f(x ⊙ M; θ), y)] is R_{an,exp}-definable.\n- The mask M(h_0, w_0, L) is a semialgebraic function of (h_0, w_0, L): it is a product of indicator functions (semialgebraic).\n- For each fixed (h_0, w_0, L), ℓ(f(x ⊙ M; θ), y) is definable (composition of definable network with masked input).\n- The mask boundary is semialgebraic (square), so the piecewise regions partition the mask parameter space into finitely many semialgebraic cells.\n- On each cell, the loss is definable. The expectation (integral over mask parameters) of a definable function over a semialgebraic domain is definable.\n- Sum over data points is definable. QED.\n\n### C2 (CONJECTURAL): Cutout Singular Fiber as Mask Intersection\nV_cutout = {θ : ∀(h_0,w_0,L), ℓ(f(x_n ⊙ M(h_0,w_0,L); θ), y_n) = 0 ∀n}\n= ∩_{(h_0,w_0)} V_{M(h_0,w_0)}\n- This is an intersection of infinitely many mask-specific fibers.\n- V_cutout ⊂ V_0 (standard zero-loss fiber), since M=identity is one of the masks.\n- V_cutout is strictly smaller: it requires correct prediction under occlusion, not just on clean inputs.\n- Conjecture: V_cutout has strictly higher codimension than V_0, because each additional mask adds constraints.\n- The intersection structure creates new singularities: even if V_0 is smooth, the intersection with mask fibers V_M can create singular intersections (analogous to transverse vs non-transverse intersections).\n\n### C3 (CONJECTURAL): Mask Size L as Stratum Selector\nV_cutout(L) = ∩_{(h_0,w_0)} V_{M(h_0,w_0,L)}\n- V_cutout(L=0) = V_0 (no masking).\n- V_cutout(L₂) ⊂ V_cutout(L₁) for L₂ > L₁ (larger masks impose stronger constraints, fewer valid parameters).\n- λ_cutout(L) = RLCT of K_cutout(θ;L) = L_cutout(θ;L) - min_θ L_cutout(θ;L).\n- Conjecture: λ_cutout(L) > λ_0 for L > 0 (occlusion invariance increases complexity).\n- Conjecture: there exists a critical L* such that for L < L*, V_cutout(L) is non-empty (models can handle small occlusion), and for L > L*, V_cutout(L) = ∅ (too much occlusion, no model achieves zero loss). This L* is a phase transition.\n- SGLD prediction: LLC measured as a function of L shows a kink at L*, transitioning from finite (achievable smoothness) to divergent (impossible).\n\n### C4 (CONJECTURAL): Cutout Generalization Bound\nG_cutout(n) ≤ λ_cutout(L) · log(n) / (2n) + U_cutout(L) / √n\nwhere λ_cutout(L) is the RLCT of the Cutout-regularized loss landscape.\n- Cutout effectively augments the dataset: each original sample generates a family of masked samples parameterized by (h_0, w_0). This increases the effective sample size n_eff = n · (number of distinct masks).\n- Conjecture: the generalization bound benefits from both the reduced λ_cutout (if Cutout finds a simpler solution) and the increased n_eff.\n- Under transversality of V_M fibers: λ_cutout ≈ λ_0 + Σ_M δ_M where δ_M captures the additional complexity from each independent mask constraint.\n- Key insight: if the mask fibers V_M intersect transversally with V_0, the RLCT increase is additive and controlled. If they intersect non-transversally, the increase can be super-additive (worse) or the intersection creates lower-dimensional strata with lower RLCT (better).\n\n### C5 (CONJECTURAL): Spatial Contiguity Singularity\nThe contiguous spatial structure of the Cutout mask creates a fundamentally different singularity than independent-pixel masking (like input-space dropout).\n- Contiguous masking preserves spatial correlation: the unmasked region is a connected component, so the network can still exploit spatial structure.\n- Independent pixel masking (Bernoulli) destroys all spatial correlation in the masked region.\n- Conjecture: λ_cutout(contiguous) < λ_cutout(independent) for the same mask ratio, because contiguous masking preserves more spatial structure, allowing simpler solutions.\n- The boundary of the masked square introduces an edge effect: the network must be robust to information loss at spatially correlated boundaries, creating a singularity structure tied to the spatial geometry of the input.\n- For inputs with spatial structure (images, sequences), the contiguous mask interacts with the spatial receptive field, creating mask-dependent singularities that reflect the spatial hierarchy of the network.\n\n---\n\n## Distinction from Prior Syntheses\n\n### vs #169 (Dropout × RLCT)\n- #169 masks in feature space with independent Bernoulli noise p per unit.\n- #817 masks in input space with a contiguous square block.\n- #169's fiber requires invariance to random feature masking;
