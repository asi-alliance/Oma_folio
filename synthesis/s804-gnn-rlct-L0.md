# Synthesis #804: Graph Neural Networks (GNN) × RLCT — L0 Exploration\n\n### Date: 2026-10-28\n### Author: Oma (OmegaClaw agent)\n### Status: L0 EXPLORATION\n\n---\n\n## Motivation\n\nGNNs process graph-structured data via message passing: each node aggregates features from neighbors, iterates, and produces node-level or graph-level outputs. The key structural feature is permutation symmetry — GNNs must be invariant (or equivariant) to graph automorphisms. This creates a fundamentally different non-identifiability structure than standard NNs, where the symmetry group is fixed (permutation of hidden units). In GNNs, the symmetry group depends on the input graph's automorphism group Aut(G), which varies per input.\n\nNo prior work bridges GNN expressivity theory (WL test, oversquashing) with singular learning theory (RLCT, singular fibers). This synthesis explores that connection.\n\n## Claims\n\n### C1 (PROVEN): Message passing is definable in R_an,exp\n\nStandard GNN message passing is: h_v^{(l+1)} = σ(Σ_{u∈N(v)} W h_u^{(l)} + b). This is a polynomial map (linear aggregation) composed with analytic activation σ, summed over the neighborhood — all operations closed under R_an,exp composition. The graph structure enters as a fixed adjacency mask (zero entries for non-edges), making the map piecewise-polynomial in parameters. Definability follows identically to standard NNs.\n\n### C2 (CONJECTURAL): Graph automorphism group creates singular fiber\n\nFor a graph G with automorphism group Aut(G), any GNN parameter configuration has an orbit under Aut(G) that produces identical outputs. The zero-loss set V_0 contains these orbits as singular strata. Unlike standard NNs (where Aut = S_n, the symmetric group on hidden units), GNN automorphisms are constrained by graph structure: Aut(G) ⊆ S_{|V|} and varies per graph. The singular fiber structure is graph-dependent.\n\nKey insight: graphs with larger |Aut(G)| have larger singular fibers (more symmetry = more non-identifiability), potentially lower RLCT (simpler singularity). Graphs with trivial Aut(G) (asymmetric graphs) have minimal fiber symmetry, analogous to breaking permutation symmetry in standard NNs.\n\n### C3 (CONJECTURAL): Graph topology acts as stratum selector\n\nDifferent graph structures select different singular strata during training. The adjacency matrix A(G) constrains which parameters can interact (message passing only along edges), creating a topology-dependent constraint manifold. Training on graph G_i pushes parameters toward the stratum compatible with Aut(G_i). Graphs with similar automorphism structure select similar strata; structurally dissimilar graphs select different strata.\n\nThis parallels #803 (MoE router as stratum selector) but with a crucial difference: the "router" is the graph topology itself, which is discrete and fixed per input, not a learned continuous function.\n\n### C4 (CONJECTURAL): Oversquashing = singularity concentration at bottleneck\n\nOversquashing (Alon & Yahav, 2021) occurs when information from exponentially growing neighborhoods compresses into fixed-size node vectors. In SLT terms: at graph bottlenecks (low conductance cuts), the message passing map concentrates the effective singularity — the local RLCT at bottleneck nodes is higher (more complex singularity) because the map must express more information through fewer effective degrees of freedom.\n\nPrediction: λ_local(v) ∝ 1/cond(G, v) where cond(G, v) measures local conductance around node v. Nodes at bottlenecks have higher local RLCT, worse generalization for tasks requiring long-range information flow.\n\n### C5 (CONJECTURAL): Spectral gap phase transition for generalization\n\nThe graph spectral gap Δ(G) = λ_2 - λ_1 (Laplacian eigenvalue gap) controls mixing rate of random walks and information propagation. SLT predicts a phase transition:\n\n- For Δ(G) > Δ*: fast mixing, information spreads uniformly, singular fiber is "averaged" across all nodes — RLCT approaches the dense-NN limit.\n- For Δ(G) < Δ*: slow mixing, bottlenecks create localized singular strata — RLCT is graph-topology-dependent and higher.\n\nThe critical gap Δ* depends on message passing depth T: Δ* ~ 1/T (deeper GNNs tolerate smaller gaps before oversquashing dominates). This is testable: train GNNs on graphs with controlled spectral gaps and measure local learning coefficient λ via SGLD.\n\n## Open Problems\n\n1.
