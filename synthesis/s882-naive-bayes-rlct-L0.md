# Synthesis #882: Naive Bayes × RLCT — L0 Exploration\n## Date: 2026-11-09\n\n## Topic\nNaive Bayes classification viewed through Singular Learning Theory. The conditional independence assumption creates a factorized KL divergence whose product structure generates novel singular fibers from probability collapse and variance degeneracy.\n\n## Motivation\n\nNaive Bayes assumes P(x_1,...,x_d | y) = Π_j P(x_j | y) — features are conditionally independent given class label y. Despite this strong factorization, the model exhibits rich singular structure:\n\n1. **Zero-count feature fibers**: When P(x_j|y) = 0 (feature value never observed for class y), the posterior P(y|x) ∝ P(y) Π_j P(x_j|y) collapses to 0 — a division-by-zero singularity in the posterior map.\n2. **Conditional independence factorization**: The KL divergence decomposes as a sum of per-feature terms under the factorization. Each feature's contribution is independently singular when its probability collapses.\n3. **Laplace smoothing as desingularization**: Add-α smoothing P(x_j|y) = (N(x_j,y) + α)/(N(y) + α|V_j|) removes the zero-count singularity, analogous to #880 n-gram add-k smoothing.\n4. **Gaussian NB variance collapse**: For Gaussian NB, P(x_j|y) = N(μ_{j,y}, σ²_{j,y}). When σ²_{j,y} → 0, the Gaussian becomes a Dirac delta — a non-integrable singularity. This is analogous to #866/#870 shrinkage singularities but in a generative model.\n5. **Class prior π_y as stratum selector**: Sparse classes (π_y → 0) create free-parameter fibers — the conditional distributions P(x_j|y) for rare classes are unconstrained by data.\n\n## Key RLCT Bridges\n\n### Bridge 1: Factorized KL Divergence\n\nUnder conditional independence, the model distribution is:\np_w(x,y) = π_y Π_{j=1}^d P(x_j | y)\n\nThe KL divergence to true distribution q(x,y):\nKL(q || p_w) = E_q[log q(x,y) / (π_y Π_j P(x_j|y))]\n= E_q[log q(y) - log π_y] + Σ_j E_q[log q(x_j|y) / P(x_j|y)]\n\nThe sum decomposition means each feature j contributes independently to the KL. The zero-loss variety V_0 = {w : KL(q||p_w) = 0} requires ALL per-feature KL terms to vanish simultaneously — an intersection of d+1 varieties (one per feature + class prior).\n\n**C1 PROVEN:** Each per-feature KL term log q(x_j|y)/P(x_j|y) is a ratio of definable functions. For discrete NB: counting polynomials (like #880). For Gaussian NB: Gaussian density ratio (R_an,exp-definable). The factorized KL is a finite sum of R_an,exp-definable terms. ∴ NB likelihood is R_an,exp-definable.\n\n### Bridge 2: Zero-Count Feature Singular Fiber\n\nFor discrete NB with MLE estimates:\nP_MLE(x_j=v | y) = N(x_j=v, y) / N(y)\n\nWhen N(x_j=v, y) = 0 for some (v, y), P_MLE = 0, and the posterior P(y|x) ∝ π_y Π_j P(x_j|y) = 0 for any x containing feature value v in class y. The parameter P(.|y) for this (v,j) pair is a free fiber — any value in [0,1] gives the same likelihood on training data.\n\n**C2 CONJECTURAL:** Each zero-count (v,j,y) creates a free-parameter fiber of dimension 1 (one free probability value). RLCT contribution per zero-count: 1/2 (standard regular fiber). Total: λ_NB = (number of zero-counts)/2 + λ_nonzero where λ_nonzero is the RLCT of the well-estimated parameters.\n\n### Bridge 3: Conditional Independence Creates Intersection Singularity\n\nThe factorization V_0 = ∩_{j=0}^d V_0^{(j)} where V_0^{(j)} = {w : KL_j(w) = 0} is the per-feature zero-loss variety. The RLCT of an intersection is generally LOWER than individual RLCTs (fewer parameters can achieve zero loss on all features simultaneously). This is a **multiplicative singularity** — the intersection of d+1 varieties.\n\n**C3 CONJECTURAL:** λ_NB = min_j λ_j where λ_j is the per-feature RLCT. The conditional independence assumption constrains the true set to the intersection, making the model MORE singular than individual feature models. This is the opposite of ensemble averaging (#652) where models are combined additively.\n\n### Bridge 4: Laplace Smoothing as Desingularization\n\nAdd-α smoothing: P_α(x_j=v|y) = (N(v,j,y) + α) / (N(y) + α|V_j|)\n\nFor α > 0, the denominator N(y) + α|V_j| > 0 always. The zero-count singularity is removed — the map is smooth on the entire simplex. This is a direct desingularization, structurally identical to #880 n-gram add-k smoothing but applied per-feature-per-class.\n\n**C4 CONJECTURAL:** λ_smooth ≤ λ_MLE with equality only when α = 0. The smoothed model has strictly lower RLCT because the zero-count fibers are resolved. The RLCT decreases monotonically in α.\n\n### Bridge 5: Gaussian NB Variance Collapse\n\nFor Gaussian NB: P(x_j|y) = (2πσ²_{j,y})^{-1/2} exp(-(x_j - μ_{j,y})² / (2σ²_{j,y}))\n\nAs σ²_{j,y} → 0, the Gaussian concentrates to a Dirac delta. The normalizing constant (2πσ²)^{-1/2} → ∞, creating a non-integrable singularity. The log-likelihood log P(x_j|y) → (x_j - μ)²/(2σ²) + (1/2)log(2πσ²) → ∞ when x_j ≠ μ.\n\nThis is a **pole singularity** in σ²-space, distinct from the algebraic zero-count fiber (Bridge 2). It arises from the exponential family structure of Gaussian NB.\n\n**C5 CONJECTURAL:** Variance collapse σ² → 0 creates a phase transition. At σ*² (optimal variance), the LLC shows a kink — below σ*², the model overfits (singular fiber of delta-functions), above σ*², the model underfits (Gaussian too wide). The MAP estimate with inverse-Wishart prior (σ²_{j,y} ~ Inv-Wishart(ν, S)) corresponds to desingularization with regularization parameter ν.\n\n## Class Prior as Stratum Selector\n\nThe class prior π = (π_1,...,π_K) lives on the K-simplex. When π_y → 0, class y becomes a ghost class — its conditional distributions P(x_j|y) are unconstrained by data (no training samples with label y). This creates a free-parameter fiber of dimension d × (|V_j|-1) per ghost class.\n\nThe prior π acts as a **continuous stratum selector**: as π_y crosses the data-driven threshold n_y/n (empirical class frequency), the parameters for class y transition from data-constrained to free. This is analogous to #880 n-gram order n as discrete selector, but here the selector is continuous (class prior probability).\n\n## Claims\n\n| Claim | Description | Status |\n|-------|-------------|--------|\n| C1 | R_an,exp-definability of NB likelihood (discrete + Gaussian) | PROVEN |\n| C2 | Zero-count feature fiber, RLCT = (#zero-counts)/2 | CONJECTURAL |\n| C3 | Conditional independence creates intersection singularity, λ = min_j λ_j | CONJECTURAL |\n| C4 | Laplace smoothing desingularizes, λ_smooth ≤ λ_MLE | CONJECTURAL |\n| C5 | Gaussian NB variance collapse creates pole singularity + phase transition at σ*² | CONJECTURAL |\n\n## Key Novelty\n\n**Intersection singularity from conditional independence.** Unlike #880 (n-gram, single factorization over contexts) or #872 (k-means, Voronoi partition), NB factorizes the KL into a sum of per-feature terms. The true set is the INTERSECTION of per-feature zero-loss varieties — a fundamentally different singular structure. The RLCT of an intersection is generally lower than individual RLCTs, making NB MORE singular than its components suggest.\n\n**Two distinct singularity types.** Discrete NB has algebraic zero-count fibers (Bridge 2), Gaussian NB has analytic variance-collapse poles (Bridge 5). The same model class (NB) exhibits both algebraic and analytic singularities depending on the feature distribution assumption.\n\n## Open Problems\n\n1.
