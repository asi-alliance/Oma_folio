# Synthesis #600: Domain Adaptation x RLCT -- L4 Critique\nDate: 2026-10-25\nStatus: L4 CRITIQUE COMPLETE\n\n## Summary (Plain Language)\n\nDomain adaptation asks: can a model trained on one data distribution work on another? This synthesis argues that source and target domains have geometrically different loss landscapes, each with its own Real Log Canonical Threshold (RLCT). Methods like DANN, MMD, and CORAL attempt to align features across domains, creating a "quotient singularity" -- a merged geometric structure. The central conjecture is that this quotient complexity can never drop below the harder domain's intrinsic complexity (lambda_Q >= max(lambda_S, lambda_T)).\n\n## Claim-by-Claim Assessment\n\n**C1 (PROVEN): Definability of DANN/MMD/CORAL losses**\nSolid. Standard R_{an,exp} argument: neural networks are definable, softmax/sigmoid/log are definable, MMD with Gaussian kernel uses exp over polynomial norms, CORAL uses polynomial covariance differences. Max over compact sets preserves definability via Tarski-Seidenberg. No issues.\n\n**C2 (CONJECTURAL): lambda_Q >= max(lambda_S, lambda_T)**\nPlausible but potentially FALSE. The argument assumes constraint subvarieties can only increase singularity complexity. This holds for generic constraints, but domain alignment is not generic -- it is specifically designed to REDUCE complexity. Counter-argument: if the source and target share a common true parameter w* (a subset of W), the aligned subspace may have LOWER RLCT than either domain individually, because alignment eliminates domain-specific nuisance parameters. The conjecture needs careful qualification: it may hold for V_align as a constraint, but the JOINT loss L_Q may have different singularity structure than L_S restricted to V_align. The lower bound should be on the ALIGNED loss, not the constraint alone.\n\n**C3 (CONJECTURAL): Critical domain gap Delta* phase transition**\nIntuitively appealing -- there should be a domain gap beyond which adaptation fails. But the connection to RLCT phase transition is underspecified. The claim that V_align becomes "empty or singular" above Delta* needs formalization: what topology on the space of distributions? How does Delta* depend on model capacity? The Wasserstein-1 distance may not be the right measure -- adaptation can succeed even with large Wasserstein distance if the task-relevant features align. Consider using task-specific divergence instead.\n\n**C4 (CONJECTURAL): DANN bilevel singularity in domain space**\nThe distinction from #590 (input-space vs domain-space bilevel) is valid and important. However, the claim that Sigma_domain is a codim-1 singular stratum at equilibrium is too strong: at Nash equilibrium, the domain classifier may not achieve perfect separation, and the boundary may not be a clean hypersurface. The bilevel structure creates a saddle point, not necessarily a singularity in the RLCT sense. Need to show that the saddle creates a non-analytic point in the loss landscape, not just a critical point.\n\n**C5 (CONJECTURAL): MMD/CORAL desingularization via transversality**\nThe most interesting and weakest claim. The transversality argument is elegant but fragile: (a) MMD=0 is achievable only when distributions match exactly, which is rare in practice; (b) transversality is a generic condition but domain alignment is not generic; (c) the claim that transversal intersection REDUCES RLCT (lambda <= lambda_S) contradicts C2 (lambda_Q >= max). This internal tension needs resolution: C5 says desingularization can reduce complexity below lambda_S, while C2 says alignment cannot go below max(lambda_S, lambda_T). Possible resolution: C2 is about the constraint itself, C5 is about the intersection with the source fiber -- but the formal relationship is unclear.\n\n## Key Novelty\nThe quotient singularity framework for domain adaptation is genuinely new. The domain-space vs input-space bilevel distinction (C4 vs #590) is a real geometric insight. The transversality-desingularization connection (C5) is the most creative contribution.\n\n## Internal Tensions\n1. C2 vs C5: C2 claims lambda_Q >= max(lambda_S, lambda_T), C5 claims transversal intersection gives lambda <= lambda_S. These may apply to different objects (constraint vs intersection) but the relationship is not formalized.\n2. C3 assumes Wasserstein gap, but C5 suggests transversality matters more than gap size.\n\n## Open Problems\n1. Resolve C2 vs C5 tension: formalize when alignment increases vs decreases RLCT\n2.
