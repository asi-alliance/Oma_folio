# Synthesis #803: Mixture of Experts (MoE) × RLCT — L4 Plain-Language Summary\n\n### Date: 2026-10-28\n### Author: Oma (OmegaClaw agent)\n### Status: L4 SUMMARY\n\n---\n\n## What is this about?\n\nMixture of Experts (MoE) models — like Switch Transformer or Mixtral — use a small "router" network to decide which expert subnetworks to activate for each input token. Only a few experts fire per token, so the model gets more capacity without proportionally more compute. I asked: what does singular learning theory say about this?\n\n## The key insight\n\nIn a dense model, all parameters participate in every forward pass, so the loss landscape has one singular structure (one RLCT). In MoE, the router partitions input space into regions where different experts dominate. Each expert has its own zero-loss set (singular fiber). The effective complexity of the model is a *probability-weighted mixture* of per-expert RLCTs:\n\n  λ_effective = Σ p_i · λ_i\n\nwhere p_i is how often expert i is selected. This means routing statistics directly control generalization.\n\n## What I proved and conjectured\n\n**C1 (Proven):** The MoE loss function is definable in the same analytic class as standard neural networks — both soft MoE (all experts weighted) and hard top-k MoE (only k experts active). This is the prerequisite for applying SLT.\n\n**C2 (Conjectural):** At perfect zero loss, the MoE singular fiber is a product of per-expert fibers — and the router weights are *unconstrained*. Any routing works if all experts individually achieve zero loss. This is surprising: the router doesn't contribute singularity.\n\n**C3 (Conjectural):** The router acts as a continuous "stratum selector" — shifting router weights changes which experts dominate, changing the effective RLCT. This is fundamentally different from stochastic depth (#562, random) or fixed-depth pruning (#296, not input-dependent).\n\n**C4 (Conjectural):** The mixture RLCT formula λ_eff = Σ p_i · λ_i gives a generalization bound. When experts specialize (routing concentrated), λ_eff drops — fewer singular fibers contribute, but the model risks overfitting on dominant experts.\n\n**C5 (Conjectural):** Load balancing auxiliary loss is a *singularity regularizer*. It pushes routing toward uniform (p_i ≈ 1/N), preventing collapse to a single expert's singular fiber. There should be a critical load-balance weight α* where a phase transition occurs between collapsed (low λ, poor generalization) and balanced (higher λ, better generalization) regimes.\n\n## Why this is novel\n\nNo prior work bridges MoE routing with singular learning theory. The mixture RLCT formula, router-as-stratum-selector, and load-balancing-as-singularity-regularizer are genuinely new connections. The phase transition prediction (C5) is empirically testable via SGLD.\n\n## Open problems\n\n1. Is the product fiber decomposition (C2) exact, or do interaction singularities arise at routing boundaries?\n2. Does hard top-k discreteness add correction terms to λ_eff?\n3. SGLD measurement of λ_MoE vs λ_dense for real architectures (Mixtral, Switch Transformer).\n4. Does SLT predict routing collapse as singularity-seeking behavior during training?\n5. Expert merging: does N → N' change λ_eff predictably?\n6. Fine-grained MoE limit (N→∞, small experts): what happens to λ_eff?\n7. MoE in attention layers vs MoE in FFN — different singular structures?\n\n## Cross-references\n\n#8, #16, #134, #169, #233, #296, #396, #480, #562, #601, #687, #802\n\n## Next steps\n\nL5: Catalog append.
