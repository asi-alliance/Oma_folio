#587: Barlow Twins × RLCT — L0 Exploration\n\nDate: 2026-10-24\n\n## Topic\nBarlow Twins (Zbontar et al., 2021): self-supervised learning via redundancy reduction. Two identical networks process distorted views, cross-correlation matrix C of embeddings driven toward identity I. Loss = sum_i (C_ii - 1)^2 + lambda * sum_{i≠j} C_ij^2.\n\n## Relationship to Prior Work\n- #541 VICReg: decomposes into separate variance (std=gamma hinge), invariance (MSE), covariance (off-diagonal) terms. Barlow Twins uses SINGLE cross-correlation matrix target — different algebraic structure.\n- #540 InfoNCE: contrastive with negatives. Barlow Twins is non-contrastive.\n- #169 Dropout: stochastic masking. Barlow Twins is deterministic forward pass.\n- #490 RoPE: positional encoding. Unrelated.\n\n## Claims\nC1 (PROVEN): R_an-definability. Cross-correlation C_ij = (1/N) sum_n z_A,n,i * z_B,n,j is polynomial in network outputs (analytic). Loss L = sum (C_ii - 1)^2 + lambda * sum_{i≠j} C_ij^2 is polynomial in C, hence R_an-definable (semi-algebraic, no exp/log/max needed).\n\nC2 (CONJECTURAL): Singular fiber = {theta : C_theta = I}. The identity cross-correlation condition imposes d(d+1)/2 constraints (d diagonal = 1, d(d-1)/2 off-diagonal = 0) on the parameter space. This defines an algebraic variety — the orthogonality fiber. Fiber dimension = dim(W) - rank(Jacobian of C-I constraints). Near-perfect redundancy reduction collapses the fiber.\n\nC3 (CONJECTURAL): Lambda coefficient as stratum selector. Lambda controls relative weight of off-diagonal (redundancy) vs diagonal (invariance) terms. At lambda=0: only invariance, fiber = {C_ii = 1}. At lambda→inf: only redundancy, fiber = {C_ij = 0 for i≠j}. Intermediate lambda selects a stratum between these extremes. Critical lambda* marks phase transition.\n\nC4 (CONJECTURAL): Generalization bound. Gen gap <= lambda_BT / n + U_BT / sqrt(n), where lambda_BT is the RLCT of the Barlow Twins loss landscape. The cross-correlation identity fiber has lower RLCT than unconstrained SSL (redundancy reduction as desingularization). The constraint variety reduces effective complexity.\n\nC5 (CONJECTURAL): Critical lambda* phase transition. At small lambda, redundancy is under-penalized (collapsed representations survive). At large lambda, over-penalization may destroy useful features. Optimal lambda* where RLCT is minimized — detectable via SGLD. Connection to #541 VICReg's separate lambda/mu/nu but in a UNIFIED cross-correlation framework.\n\n## Open Problems\n1. Fiber dimension of {C_theta = I}: is it generically transverse?
