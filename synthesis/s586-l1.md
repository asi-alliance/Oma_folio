#586: Model Merging × RLCT\n\n## L1 — Formalization\n\n### D1: Parameter Space and Parent Models\nLet W in R^d be the full parameter vector. Two parent models theta_A, theta_B in R^d are trained on datasets D_A, D_B respectively, with loss functions L_A(w) = (1/n_A) Sum l(f_w(x_i), y_i) and L_B(w) defined analogously. Both losses are R_an,exp-definable (standard neural network composition: polynomial/affine layers + subanalytic ReLU + definable output loss).\n\n### D2: Interpolation Path\nThe merged model family is:\n  W_alpha = alpha * theta_A + (1-alpha) * theta_B,  alpha in [0,1]\nFor task arithmetic: W_tau = theta_base + tau * delta_task where delta_task = theta_finetuned - theta_base, tau in R.\nBoth maps (alpha,theta_A,theta_B) to W_alpha and (tau,theta_base,delta) to W_tau are polynomial (linear), hence R_an,exp-definable.\n\n### D3: Merged Loss and R_an,exp Structure (C1 PROVEN)\nThe merged loss on a test distribution D_test:\n  L_merge(alpha) = (1/n_test) Sum l(f_{W_alpha}(x_i), y_i)\nSince f_{W_alpha} is a neural network with parameters W_alpha = alpha * theta_A + (1-alpha) * theta_B (polynomial in alpha), and l is definable (CE = softmax+log, MSE = polynomial), L_merge(alpha) is a composition of R_an,exp-definable maps. By o-minimal closure, L_merge is R_an,exp-definable. C1 PROVEN.\n\n### D4: Critical Locus and Interpolation Fiber\nDefine V_A = {w : grad L_A(w) = 0} (critical locus of model A), V_B analogously. The interpolation path gamma(alpha) = alpha * theta_A + (1-alpha) * theta_B is a line segment in R^d. The interpolation fiber is:\n  F_gamma = gamma([0,1]) intersect (V_A union V_B)\ni.e., points where the interpolation path crosses a parent singularity. The merged model singular fiber at parameter alpha is:\n  V_merge(alpha) = {w in gamma([0,1]) : grad L_merge(w) = 0} intersect {near W_alpha}\n\n### D5: TIES Sign-Resolution Stratification\nTIES merging resolves sign conflicts: for each parameter index i, if sign(delta_A[i]) != sign(delta_B[i]), set the merged value to 0 (or to the majority sign). This defines a partition of indices into:\n  S_agree = {i : sign(delta_A[i]) = sign(delta_B[i])},  S_conflict = {i : sign(delta_A[i]) != sign(delta_B[i])}\nThe merged weight is:\n  W_TIES = theta_base + tau * (delta_A dot 1_{S_agree} + delta_B dot 1_{S_agree} + 0 * 1_{S_conflict})\nThis is a piecewise-linear map (semialgebraic selection on sign conditions), hence R_an,exp-definable. The sign-disjunction creates 2^|S_conflict| discrete strata (one per sign-conflict resolution pattern).\n\n### D6: Stratum Selector and RLCT\nFor linear interpolation, alpha in [0,1] is a continuous stratum selector. The RLCT of the merged model lambda(alpha) is:\n  lambda(alpha) = RLCT(L_merge, W_alpha)\nwhich varies as alpha moves W_alpha along the interpolation path through the singular landscape. For TIES, the pair (alpha, s) where s in {0,1}^|S_conflict| is a mixed continuous-discrete stratum selector.\n\n### D7: Generalization Bound\nBy the SLT generalization theorem, for the merged model at interpolation ratio alpha:\n  G(alpha) <= lambda(alpha) * log(n)/(2n) + U(alpha)/sqrt(n) + B(alpha)\nwhere lambda(alpha) is the RLCT at W_alpha, U(alpha) captures the fluctuation from the interpolation fiber geometry, and B(alpha) is a bias term from the distance of W_alpha to the nearest true minimizer.\n\n### Claims Summary\nC1 PROVEN: R_an,exp definability — linear interpolation and sign-disjunction preserve definable structure.\nC2 CONJECTURAL: The merged singular fiber is the intersection of the interpolation line with parent critical loci.
