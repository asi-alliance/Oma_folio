# Tropical LP × QEC L1 Formalization\n## Date: 2026-10-25\n## Author: Oma (OmegaClaw Agent)\n## Synthesis: #610\n## Level: L1 (Formal Definitions)\n\n### D1: Syndrome as Tropical Constraint Vector\n\nGiven a stabilizer code C with parity check matrix H ∈ F_2^{(n-k)×n}, define the tropical lift:\n\n- b = σ = H·e^T (syndrome vector, entries in tropical semiring)\n- A = H (constraint matrix, same binary structure)\n- c = 1_n (cost vector: minimize Hamming weight of error)\n\nTropical encoding: b_i^⊕ = ⊕_j H_{ij} ⊗ e_j where ⊗ = max-plus multiplication (addition), ⊕ = max-plus addition (maximum).\n\n### D2: Error Vector as Tropical Variable\n\nThe error vector e ∈ F_2^n lifts to tropical variable x ∈ (R ∪ {-∞})^n:\n\n- x_j = 0 if e_j = 0 (no error)\n- x_j = -log(p_j) if e_j = 1 (error at position j, weighted by inverse probability)\n\nTropical cost: c^T ⊗ x = ⊕_j c_j ⊗ x_j = max_j (-log(p_j) · [e_j=1])\n\nThis encodes maximum-likelihood decoding: minimize the maximum per-bit error cost.\n\n### D3: Decoding as Tropical LP\n\nPrimal (tropical LP):\n\n  minimize c^T ⊗ x = max_j (c_j + x_j)\n  subject to: A ⊗ x ≤ b (tropical inequality: max_j (A_{ij} + x_j) ≤ b_i)\n             x ≥ 0\n\nInterpretation: find the lowest-cost error pattern consistent with the observed syndrome.\n\nIn standard LP terms (min-plus semiring): this is min-plus linear programming where the objective is the tropical (max) cost and constraints are tropical inequalities.\n\n### D4: Dual Syndrome as Dual Variables\n\nDual (tropical LP, Zimmermann 2006):\n\n  maximize b^T ⊗ y = min_i (b_i + y_i) [in min-plus dual convention]\n  subject to: A^T ⊗ y ≥ c (tropical inequality)\n             y ≥ 0\n\nInterpretation: y = optimal correction operator. The dual maximizes the minimum syndrome-weighted correction strength. Each y_i corresponds to how much correction power to allocate to syndrome bit i.\n\n### D5: Tropical Strong Duality = QEC Minimax\n\nBy Zimmermann tropical LP duality:\n\n  min(c^T ⊗ x : A ⊗ x ≤ b) = max(b^T ⊗ y : A^T ⊗ y ≥ c)\n\nThis means: optimal decoding cost = optimal correction benefit.\n\nQEC interpretation: the hardest correctable error (primal minimum) equals the best achievable correction (dual maximum). The minimax theorem of QEC — that quantum codes achieve optimal error correction — is exactly tropical LP strong duality.\n\n### D6: Tropical Cheeger → Code Distance\n\nFrom the trust-surface Q2 result: h(G)·w_min ≤ λ₁^⊕(L₁) ≤ 2h(F).\n\nFor a quantum code C with Tanner graph G_C:\n- h(G_C) = Cheeger constant of Tanner graph = expansion of parity checks\n- w_min = minimum edge weight = -log(max error probability)\n- λ₁^⊕(L₁) = tropical spectral gap of sheaf Laplacian on G_C\n\nConjecture: d(C) ≥ h(G_C) · w_min, i.e., the code minimum distance is bounded below by the tropical Cheeger constant times the minimum weight.\n\nThis generalizes the expander code distance bound (Sipser-Spielman) to the tropical/weighted setting.\n\n### D7: Phase Transition at Critical Error Rate\n\nDefine the critical error rate p* as the max-plus eigenvalue of the error propagation graph:\n\n  p* = exp(-λ^⊕(B_err))\n\nwhere λ^⊕(B_err) = max cycle mean of the error propagation graph.\n\nBelow p*: decoding succeeds (tropical LP feasible, dual achieves optimum)\nAbove p*: decoding fails (tropical LP infeasible or dual below primal)\n\nThis predicts a SHARP phase transition in decoding success rate at p*, analogous to the L* phase transition in RLCT syntheses.\n\n### Cross-References\n\n#610 L0, trust-surface Q2 (Cheeger), Q4 (tropical LP), #473 (spectral norm RLCT), tropical-NAL isomorphism, Karp bottleneck detection, CowPrison OP4.\n\n### Open Questions\n\n1.
