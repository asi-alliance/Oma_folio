# Synthesis #663: Distributed Training × RLCT — L1 Formalization\n## Date: 2026-10-28\n\n## Formal Definitions (D1-D7)\n\n**D1 (Data-Parallel Empirical Loss):**\nGiven training set S = {(x_i, y_i)}_{i=1}^{N} partitioned into D shards S_1,...,S_D with |S_d| = n = N/D, the data-parallel empirical loss is:\n\nL_DP(θ) = (1/D) Σ_{d=1}^{D} L_d(θ), where L_d(θ) = -(1/n) Σ_{(x_i,y_i)∈S_d} log p(y_i|x_i; θ)\n\nThe full empirical loss L_N(θ) = L_DP(θ) when shards are equal-sized.\n\n**D2 (Sharded Parameter Space):**\nUnder ZeRO stage-s sharding (s ∈ {1,2,3}), parameter space decomposes as:\n- Stage 1 (optimizer states): Θ = Θ, optimizer state Ω = Ω_1 × ... × Ω_D\n- Stage 2 (+gradients): Θ = Θ_1 × ... × Θ_D, with gather map γ: (θ^(1),...,θ^(D)) → θ\n- Stage 3 (+parameters): Full sharding, each device holds only θ^(d) ∈ Θ_d\n\nThe full parameter space Θ = Θ_1 × Θ_2 × ... × Θ_D with dim(Θ_d) = dim(Θ)/D (for uniform partition).\n\n**D3 (Synchronization Fiber):**\nThe all-reduce synchronization map σ: Θ^D → Θ is defined by:\nσ(θ_1,...,θ_D) = (1/D) Σ_{d=1}^{D} θ_d\n\nThe synchronization fiber over θ is:\nσ^{-1}(θ) = {(θ_1,...,θ_D) ∈ Θ^D : (1/D)Σ_d θ_d = θ}\n\nThis is an affine subspace of dimension (D-1)·dim(Θ), isomorphic to the kernel of σ shifted by (θ,...,θ).\n\n**D4 (Tensor-Parallel Factorized Fiber):**\nColumn-parallel: W = [W_1 | W_2 | ... | W_D] where W_d ∈ R^{m × (n/D)}.\nThe factorized fiber V_TP(W) = {(W_1,...,W_D) : [W_1|...|W_D] = W} = {W_d fixed} — trivially a point.\nMore interestingly, the functional fiber: {(W_1,...,W_D) : f([W_1|...|W_D]) = f(W)} where f is the model output.\n\nRow-parallel: W = [W_1; W_2; ...; W_D], output o = W·x = Σ_d W_d · x_d (split input).\n\n**D5 (Pipeline Boundary Singularity):**\nPipeline with P stages, stage p processes layers [l_{p-1}+1, ..., l_p]. Forward: h_p = F_p(h_{p-1}; θ_p). Backward: ∂L/∂θ_p = (∂L/∂h_p) · (∂h_p/∂θ_p).\nBoundary singularity: at stage boundary between p and p+1, the interface Jacobian J_p = ∂h_p/∂θ_p may lose rank, creating singular fibers in the composed parameter space Θ_1 × ... × Θ_P.\n\n**D6 (Effective RLCT under Sharding):**\nλ_eff(D, s) = RLCT of L_DP restricted to the sharded parameter space Θ_1 × ... × Θ_D with synchronization map σ.\n\nFormally: λ_eff(D,s) = RLCT(L_DP ∘ γ_s, V_0^{(s)}) where γ_s is the stage-s gather map and V_0^{(s)} is the zero-loss set in sharded coordinates.\n\n**D7 (Communication Stratum):**\nLet t_1, t_2, ... be communication rounds (all-reduce operations). Between rounds, device d evolves on local fiber V_d^{(k)} = {θ_d : L_d(θ_d) = L_d(θ_d^{(k)})}. At round k, the synchronization map σ projects (θ_1^{(k)},...,θ_D^{(k)}) → θ_sync^{(k)}. The communication stratum is the discrete sequence {θ_sync^{(k)}}_{k≥0}.\n\n## Proofs and Proof Sketches\n\n**C1 (PROVEN): Data-parallel loss L_DP(θ) is R_an,exp-definable.**\n\nProof:\n1. Base loss L_d(θ) = -(1/n) Σ_{i∈S_d} log p(y_i|x_i;θ) is R_an,exp-definable by assumption (standard neural network loss, see #8, #185).\n2. Arithmetic mean: L_DP(θ) = (1/D) Σ_d L_d(θ). Finite sum of definable functions is definable (R_an,exp is closed under finite addition, multiplication by rationals).\n3. Synchronization map σ(θ_1,...,θ_D) = (1/D)Σ θ_d is affine, hence polynomial, hence R_an-definable.\n4. Sharded loss L_sharded(θ^(1),...,θ^(D)) = L_DP(γ_s(θ^(1),...,θ^(D))) where γ_s is the gather map (linear, definable). Composition of definable functions is definable.\n5. Therefore L_DP and L_sharded are R_an,exp-definable. □\n\n**C2 (CONJECTURAL): The synchronization fiber σ^{-1}(θ) is a singular fiber whose RLCT depends on D.**\n\nProof sketch:\n1. σ^{-1}(θ) is an affine subspace of dimension (D-1)·p where p = dim(Θ). The RLCT of the composed system depends on how V_0^{sharded} sits inside Θ^D relative to the fibers of σ. By Watanabe's framework, the RLCT is determined by the singularity of L_DP ∘ γ near V_0^{sharded}.\n4. As D increases, the sharded zero-loss set lives in higher-dimensional space (D·p) but is constrained by the same loss function — this may create more singular configurations.\n5. Key question: is σ a submersion at points in V_0^{sharded}? If yes, the fiber is smooth and RLCT is preserved. If no (critical points of σ on V_0), singularities arise.\n\n**C3 (CONJECTURAL): Device count D serves as a discrete stratum selector.**\n\nProof sketch:\n1. For each D, the parameter space topology differs: D=1 (standard), D=2 (two-way sharding), etc. Each defines a distinct algebraic variety V_0^{(D)}.\n2. The U-shape arises from two competing effects: (a) gradient averaging acts as implicit regularization (reduces RLCT), (b) higher-dimensional sharded space introduces new singular configurations (increases RLCT).\n\n**C4 (CONJECTURAL): Generalization bound with synchronization correction.**\n\nProof sketch:\n1. Standard SLT bound (Watanabe): G ≤ λ · log(N)/N + U/√N for single device, N = n·D total samples.\n2. Under data parallelism, the effective loss is L_DP computed on N = n·D samples. Standard bound gives G ≤ λ_0 · log(nD)/(nD) + U/√(nD).\n3. However, gradient averaging introduces dependence: the D gradient estimates are not independent (they are averaged). The correction term C_sync(D) ~ O(σ²_grad/D + bias_shard) where σ²_grad is gradient variance across devices and bias_shard is shard distribution mismatch.\n6.
