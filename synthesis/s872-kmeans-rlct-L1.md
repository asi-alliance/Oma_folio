#872: K-Means Clustering × RLCT — L1 Formalization\n\n## D1 (Parameter Space)\nLet X = {x_1, ..., x_n} ⊂ R^d be a fixed dataset. The parameter space is the set of K centroid vectors:\nΘ = R^{d×K} = {M = (μ_1, ..., μ_K) : μ_k ∈ R^d}\n\nK is a fixed positive integer (the number of clusters). There is no model weight beyond the centroids — the assignment is a deterministic function of M via nearest-centroid rule. The effective parameter dimension is d·K, but with permutation symmetry S_K acting on centroid indices, the effective quotient space is Θ/S_K.\n\n## D2 (K-Means Loss Function — Formal)\nL_KM(M) = (1/n) Σ_{i=1}^{n} min_{k∈[K]} ||x_i - μ_k||²\n\nEquivalently, using the assignment function σ_M(x_i) = argmin_k ||x_i - μ_k||²:\nL_KM(M) = (1/n) Σ_i ||x_i - μ_{σ_M(x_i)}||²\n\nThe Lloyd algorithm alternates:\n- E-step: σ ← argmin_k ||x_i - μ_k||² (Voronoi assignment)\n- M-step: μ_k ← (1/|C_k|) Σ_{i∈C_k} x_i (centroid update)\n\nThe loss is piecewise quadratic in M: on each Voronoi cell configuration (a partition of X into K clusters), L_KM is a sum of quadratic functions. The pieces are separated by Voronoi boundary hyperplanes B_{jk} = {μ_j, μ_k : ∃i, ||x_i - μ_j|| = ||x_i - μ_k||}.\n\n## D3 (R_{an,exp} Definability — C1 PROVED)\n**Claim C1 (PROVED):** L_KM is definable in R_{an,exp}.\n\n**Proof:** Each term ||x_i - μ_k||² = Σ_{j=1}^d (x_{ij} - μ_{kj})² is a polynomial in μ_k, hence definable. The function f_i(M) = min_k ||x_i - μ_k||² is the pointwise minimum of K polynomials. Since R_{an,exp} is closed under finite minima (o-minimal structures are closed under min/max by definable selection), f_i is definable. L_KM = (1/n) Σ_i f_i is a finite sum of definable functions, hence definable. The singular locus (Voronoi boundaries where the min is achieved by ≥2 centroids) is definable as the set where two polynomial terms are equal and minimal. On each open Voronoi cell, L_KM is a polynomial (hence sub-analytic). By Watanabe's framework, the RLCT λ_KM is well-defined on any compact subset avoiding measure-zero singular loci. ∎\n\n## D4 (Voronoi Boundary Singular Fiber — C2 CONJECTURAL)\n**Claim C2 (CONJECTURAL):** The singular fiber of L_KM is determined by Voronoi boundary geometry and centroid collision.\n\nThe zero-loss set V_0 = {M : L_KM(M) = 0} = {M : ∀i, ∃k, x_i = μ_k} is non-empty only if K ≥ |unique x_i| and requires centroids to coincide with data points — a finite set of isolated points (up to permutation). For generic data, V_0 = ∅.\n\nThe critical fiber V_c = {M : L_KM(M) = c} for c near L* (the global minimum) has the following structure:\n- **Voronoi boundary strata:** On boundaries where some x_i is equidistant to μ_j and μ_k, the assignment is non-unique. The loss surface has a non-smooth ridge with Lipschitz but non-C^∞ behavior. The RLCT near such ridges is determined by: (a) the codimension of the equidistance condition (= 1 per boundary point), (b) the quadratic contact order of the loss with the ridge (= 2 from squared distance).\n- **Collision strata:** When μ_j = μ_k for j ≠ k, the effective cluster count drops to K_eff < K. The fiber acquires S_{K-K_eff} orbit symmetry from the collided centroids. The RLCT contribution from collision is conjectured to be d (full-dimensional, since the collided centroid pair has d degrees of freedom in their common location).\n- **Empty-cluster strata:** When |C_k| = 0, μ_k is unconstrained (no data assigned), creating a flat direction of dimension d. This is a degenerate stratum with RLCT contribution d.\n\nConjecture: λ_KM = d · K_eff + λ_boundary where λ_boundary accounts for Voronoi boundary crossings of the optimal assignment, and K_eff ≤ K counts non-collided, non-empty clusters.\n\n## D5 (K as Discrete Stratum Selector — C3 CONJECTURAL)\n**Claim C3 (CONJECTURAL):** K acts as a discrete stratum selector on the singular fiber.\n\nFor fixed data X with true cluster count K*:\n- **K < K*:** Forced merging. Multiple true clusters share a centroid. The residual c* = L_KM(M*) > 0 is bounded away from 0. The fiber V_{c*} has merging singularities where the Voronoi partition does not align with true cluster boundaries. RLCT: λ(K) = d·K + λ_merge(K*, K) where λ_merge captures the misalignment penalty.\n- **K = K*:** Optimal alignment. Each true cluster gets exactly one centroid (assuming well-separated data). c* ≈ 0 (within-cluster variance). The fiber has minimal RLCT: λ(K*) = d·K* (no collision, no merging). This is the minimal complexity stratum.\n- **K > K*:** Centroid collision. Excess centroids collide onto existing cluster centers. K_eff = K* < K. The fiber acquires collision symmetry S_{K-K*}. RLCT: λ(K) = d·K* + (K - K*)·d_collision + λ_boundary(K). The collision contribution (K - K*)·d increases linearly with excess centroids.\n\nConjectured scaling: λ(K) = d·min(K, K*) + max(0, K - K*)·d_collision + λ_merge(max(0, K* - K))\n\nThis is structurally analogous to #870 (G as stratum selector) and #871 (K as context window selector) but via a combinatorial assignment mechanism rather than sampling or attention truncation.\n\n## D6 (Generalization Bound — C4 CONJECTURAL)\n**Claim C4 (CONJECTURAL):** The generalization bound for k-means is:\n\nG(K, n) ≤ λ(K) · log(n) / (2n) + U(K) / √n + B(K, K*)\n\nwhere:\n- λ(K) is the RLCT from D5 (stratum-selector-dependent complexity)\n- U(K) is the fluctuation term from Voronoi boundary sensitivity: boundary points near equidistance contribute high variance to the assignment.
