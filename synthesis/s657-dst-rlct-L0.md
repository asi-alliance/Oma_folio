# Synthesis #657: Dynamic Sparse Training (DST) x RLCT\n\n## Topic\nDynamic Sparse Training (DST) methods such as RigL (Evci et al. 2021), SET (Mocanu et al. 2018), SNIP variants maintain a binary sparsity mask M(t) that evolves during training through iterative prune-and-grow cycles.\n\n## Context and Motivation\nDST maintains high sparsity by continuously updating which weights are zeroed during training. Under SL, every zeroed weight constrains a coordinate subspace, creating a singular stratum. DST key distinction: the stratum EVOLVES over training steps as the mask M(t) moves. This creates an evolving singular fiber, something none of our prior syntheses have characterized.\n\n## Prior Catalog Cross-References\n- #169 Dropout x RLCT - random (stochastic) Mask creates distribution over fibers, each independently sampled. DST instead uses deterministic gradient condition to evolve mask.\n- #220 Pruning - deterministic removal post-train. DST does it during training.\n- #225 LTH - static mask at initialization. DST does not start at an ID sparse pattern but finds it dynamically.\n- #173 Batch Norm (CN, BN) - normalizes activations. DST normalizes connectivity.\n- #433 Weight Decay - L2 penalty forces weights toward 0. DST forces exact 0 via mask routing.\n\n## Seven Guiding Questions\n1. How does the evolving mask M(t) affect the RLCT of the loss landscape over training steps?\n2. Does the prune-and-grow cycle create a trajectory through singular strata that differs from static sparsity?\n3. What is the role of the update interval Delta-T in determining which strata are visited?\n4. Can we bound generalization error for a model whose singular fiber evolves during training?\n5. Is there a critical sparsity-update rate (s*, Delta-T*) at which generalization undergoes a phase transition?\n6. How does the gradient-based regrowth criterion interact with the singular directions of the loss landscape?\n7. What is the relationship between DST's dynamic mask and the lottery ticket hypothesis (#225) in RLCT terms?\n\n## Five Candidate Claims\n\n### C1 (PROVEN): R_an,exp Definability of Masked Loss\nThe loss function L(M(t) odot W) = (1/n) sum_i ell(f_{M(t) odot W}(x_i), y_i) is definable over R_an,exp. The mask M(t) in {0,1}^d is a binary vector, and the Hadamard product M(t) odot W is a semialgebraic map (piecewise polynomial via indicator functions). The neural network forward pass with masked weights is a composition of analytic and semialgebraic operations, preserving R_an,exp definability. By Tarski-Seidenberg, the singular locus of the masked loss is definable.\n\n### C2 (CONJECTURAL): Evolving Singular Fiber\nAt each training step t, the zeroed weights M(t)_j = 0 define a coordinate subspace V_0(t) = {W : W_j = 0 for j in Z(t)} where Z(t) = {j : M(t)_j = 0}. This is a singular stratum of the loss landscape. Unlike #169 (dropout, where fibers are sampled i.i.d.) and #220 (pruning, where the fiber is fixed post-hoc), DST creates a TIME-VARYING singular fiber V_0(t) that evolves as Z(t) changes through prune-and-grow cycles. Conjecture: the RLCT lambda(t) = lambda(V_0(t)) of the evolving fiber is non-increasing over training, as the gradient-based regrowth criterion preferentially activates weights in singular directions, moving the model toward lower-RLCT strata.\n\n### C3 (CONJECTURAL): Update Interval as Stratum Selector\nThe update interval Delta-T (number of steps between mask updates) acts as a stratum selector. At Delta-T = 1 (update every step), the mask responds instantly to gradient signals, potentially trapping in high-frequency stratum oscillations. At Delta-T = infty (no update), DST degenerates to static sparsity (#225 LTH). Conjecture: there exists an optimal Delta-T* ~ n^{1/(lambda+1)} that balances stratum exploration (frequent updates discover better singular fibers) with convergence stability (infrequent updates allow each fiber to be adequately trained). The effective RLCT lambda_eff(Delta-T) is U-shaped in Delta-T.\n\n### C4 (CONJECTURAL): Generalization Bound with Mask Dynamics\nFor DST with sparsity s = |M(t)|/d and update interval Delta-T, the generalization error is conjectured to be:\nG_DST ~ lambda_eff(s, Delta-T) / n + U / sqrt(n)\nwhere lambda_eff is the effective RLCT averaged over the mask trajectory. Unlike static pruning (#220, lambda_prune(s) fixed), DST's lambda_eff depends on the trajectory quality. Conjecture: lambda_DST <= lambda_prune for the same final sparsity s, because the dynamic exploration allows the model to find a lower-RLCT stratum than any fixed mask. The tension is between stratum exploration (lower lambda via better mask) and training instability (higher U from frequent topology changes).\n\n### C5 (CONJECTURAL): Phase Transition at Critical Sparsity-Update Rate\nThere exists a critical sparsity-update rate (s*, Delta-T*) at which generalization undergoes a phase transition. Below the critical rate (high sparsity, frequent updates), the model cannot find a consistent low-RLCT stratum and generalization degrades. Above it (low sparsity, infrequent updates), the model approaches dense training behavior. At the critical point, the mask dynamics align with the singular structure of the loss landscape, achieving optimal RLCT reduction. Conjecture: the phase transition is testable via SGLD (stochastic gradient Langevin dynamics) by measuring the RLCT of the evolving model at different (s, Delta-T) settings.\n\n## Open Problems\n1.
