# Synthesis #253: Model Collapse × RLCT — L4 Summary\n## Date: 2026-10-26\n## Status: L4 SUMMARY\n\n## Plain-Language Summary\n\n**Model collapse** — the progressive degeneration of generative models trained recursively on their own synthetic outputs — is reframed through Singular Learning Theory as a process of **singular fiber collapse**. Each generation of synthetic-data training eliminates singular strata from the model's loss landscape, shrinking the set of optimal parameters and increasing the Real Log Canonical Threshold (RLCT).\n\n### C1: Definability (PROVEN)\nThe recursive training loss L_g(theta), where each generation trains on data sampled from the previous generation's model distribution, is definable in R_{an,exp}. The proof proceeds by induction: the base case (L_0, standard NLL) is definable; the model distribution p_{theta_{g-1}}(x) is definable (softmax, Gaussian, etc.); and the product/integral composition L_g = integral p_{theta_{g-1}}(x) * (-log p_theta(x)) dx preserves R_{an,exp} definability. This holds for all finite generation depths g.\n\n### C2: Progressive Fiber Collapse (CONJECTURAL)\nUnder full replacement (alpha=1, no real data), the singular fiber V_0(g) = {theta : L_g(theta) = min} shrinks: V_0(g+1) ⊆ V_0(g). As the data distribution loses tail mass, fewer modes remain, requiring fewer parameters to fit. The RLCT lambda(g) is non-decreasing because stratum elimination removes lower-RLCT (general, common-mode) strata, concentrating the loss geometry on the most singular remaining stratum.\n\n### C3: Generation Depth as Stratum Selector (CONJECTURAL)\nThe generation index g functions as a discrete singularity stratum selector. Each generation eliminates strata corresponding to rare data modes. The elimination order is reverse-RLCT: highest-RLCT strata (tail modes, rare events) die first; lowest-RLCT strata (common modes) survive longest. The synthetic fraction alpha modulates elimination rate — higher alpha = faster stratum loss.\n\n### C4: Generalization Bound (CONJECTURAL)\nThe generalization error at generation g is bounded: G(n,g) <= lambda(g)*log(n)/(2n) + U(g)/sqrt(n) + B_collapse(g), where B_collapse(g) = C*d_TV(P_0,P_g) is the distributional drift cost. Under full replacement, both lambda(g) and B_collapse(g) grow monotonically. Under partial replacement (alpha<1), B_collapse(g) <= C*alpha^g*d_TV(P_0,P_1) — geometric decay of drift, and stratum elimination slows because real data preserves tail modes.\n\n### C5: Irreversibility Phase Transition (CONJECTURAL)\nThere exists a critical generation g* = min{g : lambda(g) > lambda_crit} beyond which model collapse becomes irreversible. For g < g*, fresh real data can restore eliminated strata. For g >= g*, the model's parameter geometry has converged to the degenerate stratum and cannot escape without external perturbation exceeding the free energy barrier. g* decreases with alpha (more synthetic = faster collapse) and increases with model capacity d. Testable via SGLD LLC estimation: sample parameters at each generation, estimate lambda(g), observe monotonic increase and phase transition.\n\n## Key Novel Contributions\n\n1. **Recursive fiber nesting** V_0(g+1) ⊆ V_0(g): first formal connection between model collapse and singular fiber geometry\n2. **Reverse-RLCT stratum elimination**: highest-RLCT strata (tail modes) die first — testable prediction\n3. **Irreversibility phase transition g***: RLCT threshold for irreversible collapse, SGLD-testable\n4. **Alpha-modulated generalization bound**: quantitative trade-off between real data fraction and collapse rate via B_collapse(g) <= C*alpha^g*d_TV(P_0,P_1)\n\n## Open Problems\n\n1.
