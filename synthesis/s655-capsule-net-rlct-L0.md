Capsule squash has TWO nonlinearities: the scale ||s||^2/(1+||s||^2) AND the direction s/||s||.\n\n2. Dynamic routing by agreement: coupling c_ij = softmax(b_ij) where b_ij = sum over iterations of u_hat_i_j * v_j. The iterative update creates a FIXED POINT map b -> b + Delta(b). The boundary c_ij = c_kl between routing decisions is a semi-algebraic surface.\n\n4. Prediction tensor u_hat = W_ij * u_i: the affine transformation W_ij maps child capsule to parent. W_ij = 0 (identity-free) is a degenerate fiber where routing has no signal. Multiple W_ij producing same routing = non-identifiability fiber.\n\n5. Instantiation parameters as fiber structure: each capsule's pose vector encodes instantiation parameters. The manifold of valid pose configurations forms a fiber over the true distribution.
