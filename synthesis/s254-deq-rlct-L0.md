# Synthesis #254: Deep Equilibrium Models × RLCT (L0)\n\n## Topic\nDeep Equilibrium Models (DEQ) — implicit neural networks defined via fixed-point equation z* = f_θ(z*, x), where f_θ is a single layer applied infinitely many times until convergence.\n\n## 7 Questions\n\n1. How does the fixed-point condition z = f_θ(z, x) create singular strata in parameter space distinct from explicit-layer networks?\n2. Does the Jacobian degeneracy condition det(I - J_f_θ(z*, x)) = 0 define a discriminant variety that controls the RLCT?\n3. Can Anderson acceleration or Broyden solver tolerance act as a continuous stratum selector analogous to ODE solver tolerance in #251/#557?\n4. Does the weight-tying (single layer repeated) create a quotient singularity from parameter identification across infinite depth?\n5. Is the RLCT of a DEQ lower, equal, or higher than the corresponding explicit deep network with the same expressivity?\n6. Does spectral radius ρ(J_f_θ(z*, x)) crossing 1.0 create a phase transition in the loss landscape geometry?\n7. Can the generalization bound be expressed with an equilibrium Jacobian spectral gap term replacing depth-dependent terms?\n\n## 5 Claims\n\n### C1 (PROVEN): R_{an,exp} Definability\nThe DEQ loss L(θ) = ℓ(g_θ(z*(θ, x)), y) where z* is the fixed point of f_θ(·, x) is definable in R_{an,exp} provided f_θ is a standard neural network (analytic + ReLU). Fixed-point iteration is a composition of f_θ, which preserves definability. If z* is computed via Picard iteration, each iterate is definable. If computed via Newton/Broyden, the update involves matrix inversion (rational) of (I-J), definable when det(I-J) ≠ 0. By Wilkie's theorem, the o-minimal structure R_{an,exp} is closed under these operations. PROVEN conditionally on convergence and non-degeneracy of the Jacobian.\n\n### C2 (CONJECTURAL): Equilibrium Variety as Singular Stratum\nThe set W_eq = {θ : det(I - J_f_θ(z*(θ), x)) = 0 for some training sample x} is an algebraic/analytic variety in parameter space. At points where the Jacobian I-J loses rank, the implicit function theorem fails — the fixed point z*(θ) is not locally differentiable in θ. This creates singular fibers: parameters θ where the equilibrium becomes degenerate form higher-RLCT strata. The RLCT λ(θ) is controlled by the codimension and multiplicity of W_eq intersections with the true parameter set. Conjecture: λ_DEQ > λ_explicit_d for equivalent expressivity, because the equilibrium constraint introduces additional degeneracy beyond weight tying.\n\n### C3 (CONJECTURAL): Solver Tolerance as Stratum Selector\nThe DEQ solver (Picard, Anderson, Broyden) has a tolerance ε controlling convergence. At large ε, the solver may stop at non-equilibrium points z_ε ≈ z*, creating an approximate loss landscape with different singularity structure. As ε → 0, the landscape approaches the true equilibrium landscape. Conjecture: λ(ε) is a decreasing function of ε (looser tolerance = less singular = lower RLCT), with a phase transition at ε* related to the spectral gap of the dominant Jacobian eigenvalue. Anderson acceleration changes this relationship by introducing memory terms.\n\n### C4 (CONJECTURAL): Generalization Bound with Spectral Gap\nThe free energy nL_n(θ) → nL(θ) + λ(θ) log n. For DEQ, conjecture: λ_DEQ depends on the spectral structure of the equilibrium Jacobian. Specifically, λ_DEQ ≈ d_eff/2 + λ_eq where d_eff is the effective dimension reduced by the weight-tying quotient and λ_eq captures the equilibrium variety multiplicity. Generalization: |L_train - L_test| ≤ C·(λ_DEQ · log n) / n + C'·g(σ_max(J_f)) where σ_max is the largest singular value of the equilibrium Jacobian and g is a spectral gap function. When σ_max → 1 (near instability), the bound deteriorates.\n\n### C5 (CONJECTURAL): Spectral Radius Phase Transition\nWhen the spectral radius ρ(J_f_θ(z*, x)) < 1, the fixed point is attracting and the Picard iteration converges. When ρ crosses 1, the fixed point becomes non-attracting (bifurcation). Conjecture: this bifurcation creates a phase transition in the loss landscape — the RLCT jumps as ρ crosses 1, analogous to a dynamical bifurcation creating new singular strata. At ρ = 1, the equilibrium variety W_eq has maximal codimension, and the model class undergoes a structural change. This is testable via SGLD: train DEQs with controlled spectral radius and measure the local RLCT.\n\n## Cross-References\n- #251 Neural ODE × RLCT (flow-based singularity, continuous-time)\n- #557 Neural ODE (Adaptive Solver) × RLCT (solver tolerance, adjoint)\n- #134 Attention × RLCT (pairwise interaction singularity)\n- #163 Normalizing Flows × RLCT (bijective maps, regular case)\n- #515 VAE × RLCT (latent variable singularity)\n- #100 Non-identifiability × RLCT (parameter symmetry)\n- #199 ResNet × RLCT (discrete depth, skip connections)\n- #568 ResNet × RLCT (depth as stratum selector)\n\n## Distinction from Prior Work\nDEQ is fundamentally different from Neural ODE (#251/#557):\n- Neural ODE: solves dz/dt = v_θ(z,t) — a flow equation.
