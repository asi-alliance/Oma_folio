# Synthesis #678: Polyak Averaging × RLCT\n## L1 Formalization — 2026-10-28\n\n### Definitions\n\n**D1 (Parameter Space & Trajectory):** Let W ⊂ R^d be the parameter space of a neural network with true loss L(w) and empirical loss L_n(w). SGD produces a trajectory {w_t}_{t=0}^{T} via w_{t+1} = w_t - η_t ∇L_n(w_t, ξ_t) where ξ_t is the mini-batch. The Polyak average is w_avg = (1/T) Σ_{t=1}^{T} w_t.\n\n**D2 (Polyak Average as Definable Map):** The averaging operator A_T: W^T → W defined by A_T(w_1,...,w_T) = (1/T) Σ_{t=1}^{T} w_t is a finite linear combination of projection maps (each definable in R_an). Hence A_T is R_an-definable. The Polyak average w_avg = A_T(w_1,...,w_T) is R_an-definable as a function of the trajectory.\n\n**D3 (Singular Fiber & RLCT):** Let W_0 = {w ∈ W : L(w) = min_w L(w)} be the singular fiber (set of global minima). For w* ∈ W_0, the RLCT λ(w*) is defined via the zeta function ζ(z) = ∫_W exp(-n·L(w)) (L(w) - L(w*))^z dw, whose largest pole at z = -λ gives λ(w*). Define λ_avg = λ(w_avg) and λ_single = E_t[λ(w_t)].\n\n**D4 (Stratum Structure):** The singular fiber W_0 decomposes into strata W_0 = ⊔_k W_0^k where each W_0^k has multiplicity m_k and RLCT λ_k. Lower-dimensional strata have lower λ. Each iterate w_t lies in the basin of some stratum W_0^{k(t)}. The trajectory visits strata {W_0^{k(1)},...,W_0^{k(T)}} — a subset of all strata.\n\n**D5 (Polyak Centroid as Stratum Projector):** The Polyak average w_avg = (1/T) Σ w_t is a convex combination (all weights 1/T ∈ (0,1], Σ = 1). If iterates span multiple strata {W_0^{k(t)}}, then w_avg lies in the convex hull Conv(∪_t W_0^{k(t)}). The intersection ∩_t W_0^{k(t)} is the deepest singular locus — a lower-dimensional stratum with λ_deep < λ_k for any individual k(t). Claim: w_avg projects into this intersection.\n\n**D6 (Generalization Bound):** Gen_polyak ≤ C·sqrt(λ_avg·(d-1)/n) where λ_avg = λ(w_avg). Since λ_avg < λ_single (conjectured), Gen_polyak < Gen_single = C·sqrt(λ_single·(d-1)/n). The improvement ratio is Gen_polyak/Gen_single = sqrt(λ_avg/λ_single) < 1.\n\n**D7 (Critical Averaging Window):** T* = argmax_T [Gen_polyak(T)] is the saturation point. For T < T*, increasing T samples more strata → lower λ_avg → tighter bound. For T > T*, all accessible strata are sampled; additional iterates are redundant (same strata) and add averaging noise. Conjecture: T* ~ O(d/log n), where d is parameter dimension and n is sample size.\n\n### Theorems\n\n**C1 (PROVEN): Definability of Polyak Average**\nThe averaging operator A_T(w_1,...,w_T) = (1/T) Σ w_t is a finite sum of coordinate projections π_t: W^T → W, each definable in R_an. R_an is closed under finite addition and scalar multiplication. Therefore A_T is R_an-definable, and w_avg = A_T(w_1,...,w_T) is R_an-definable. QED.\n\n**C2 (CONJECTURAL): Polyak Average Has Lower RLCT**\nw_avg is a convex combination of iterates spanning multiple strata. The convex hull of points from different strata intersects the deepest singular locus (the intersection of all visited strata). Since the intersection is lower-dimensional than any individual stratum, its RLCT is lower: λ(w_avg) ≤ λ_deep < λ_k for any individual stratum. Thus λ_avg < E_t[λ(w_t)] = λ_single.\n\n**C3 (CONJECTURAL): Averaging Window as Stratum Selector**\nAs T increases, the trajectory visits more strata of W_0. The Polyak average incorporates iterates from all visited strata, and the intersection ∩_t W_0^{k(t)} shrinks (fewer common strata as more are added). This drives λ_avg downward. The relationship is monotone: T_1 < T_2 ⟹ λ_avg(T_1) ≥ λ_avg(T_2) for T < T*. Saturation occurs when all accessible strata have been visited.\n\n**C4 (CONJECTURAL): Generalization Bound**\nGen_polyak ≤ C·sqrt(λ_avg·(d-1)/n) where λ_avg < λ_single. The bound is strictly tighter than the single-iterate bound Gen_single ≤ C·sqrt(λ_single·(d-1)/n). The improvement Δ_gen = C·sqrt((d-1)/n)·(sqrt(λ_single) - sqrt(λ_avg)) > 0.\n\n**C5 (CONJECTURAL): Saturation at T***\nThe number of accessible strata is bounded by the geometry of W_0, which depends on d (dimension) and the network architecture. Once all accessible strata are sampled, additional iterates lie in already-visited strata and do not reduce λ_avg. The saturation point T* ~ O(d/log n) balances stratum exploration rate (~d) against convergence speed (~log n).\n\n### Proof Sketch for C2\n\nConsider the singular fiber W_0 with strata {W_0^k}. Each iterate w_t lies near stratum W_0^{k(t)}. The Polyak average w_avg = (1/T) Σ w_t lies in Conv(∪_t w_t). If the strata W_0^{k(t)} are submanifolds intersecting at W_0^deep = ∩_t W_0^{k(t)}, then any convex combination of points from different strata, projected to W_0, lands in W_0^deep (the intersection). Since dim(W_0^deep) < dim(W_0^{k(t)}) for each t, the RLCT at the deepest stratum satisfies λ_deep < λ_{k(t)}. Thus λ(w_avg) ≤ λ_deep < λ_single.\n\nKey assumption: strata intersect transversally so the intersection is well-defined and lower-dimensional. This holds for generic network architectures.\n\n### Distinction from Related Syntheses\n\n- **#232 (SWA × RLCT):** SWA averages only iterates from high-LR cycles (selective strata).
