# Synthesis #880: N-gram Language Model x RLCT --- L0\n\n**Date:** 2026-11-09 | **Status:** L0 (preliminary)\n**Distinct from:** #873 (HMM -- hidden states, temporal coupling), #193 (BPE -- tokenization, not modeling), #520 (neural MLM -- continuous representation)\n\n---\n\n## Motivation\n\nN-gram models estimate P(w_t | w_{t-n+1},...,w_{t-1}) by counting occurrences. Despite their simplicity, they exhibit rich singular structure:\n\n1. **Zero-count fibers**: When a context never appears in training, the conditional probability is undefined (0/0). This creates a singular fiber in the probability simplex.\n2. **Markov order n as discrete stratum selector**: The order n determines model dimension V^n x V (exponential in n). Different n values define different model classes with distinct RLCT values.\n3. **MLE counting as polynomial fractional map**: The MLE estimate p(w|context) = count(context,w)/count(context) is a ratio of counting polynomials. The denominator creates a singularity when it vanishes.\n4. **Smoothing as singularity regularization**: Add-k smoothing, Good-Turing, and Kneser-Ney modify the counting map to remove or soften the zero-count singularity. Analogous to randomized smoothing (#570) or weight decay (#220).\n\n## Key RLCT Bridges\n\n### Bridge 1: Zero-Count Fiber Singularity\n\nThe n-gram MLE is: p_MLE(w | c) = N(c, w) / N(c)\nwhere c = (w_{t-n+1},...,w_{t-1}) is the context and N(c) = sum_w N(c,w).\n\nThe parameter space is the product simplex W = (Delta_V)^{V^{n-1}} where V = |vocab| and each context c has a conditional distribution p(.|c) in Delta_V.\n\nThe **zero-count fiber** is:\nV_0 = {p in W : exists c, N(c) = 0}\n\nWhen N(c) = 0, p(.|c) is unconstrained by data -- any point in Delta_V is equally valid. This creates a **fiber of free parameters** with dimension V-1 per unobserved context. Unlike neural network singularities (parameter symmetries), this singularity arises from **data-dependent rank deficiency** in the counting operator.\n\n### Bridge 2: Markov Order n as Discrete Stratum Selector\n\nThe n-gram model with order n has parameter dimension d_n = V^{n-1} x (V-1). As n increases:\n- d_n grows exponentially (V^{n-1} contexts)\n- Each context has its own conditional distribution\n- The RLCT depends on n through the number of free fibers (contexts with zero or sparse counts)\n\nThe **effective order** n* satisfies: V^{n*-1} x (V-1) ~ n_samples. Below n*, most contexts are well-observed (regular model). Above n*, most contexts are unobserved (singular fiber dominates). This is a **phase transition in sparsity**, analogous to #873 HMM K* but driven by combinatorial explosion of contexts.\n\n**C3 CONJECTURAL:** lambda_n ~ (V-1)/2 x (# unobserved contexts) / V^{n-1}. As n increases past n*, lambda_n approaches (V-1)/2. Below n*, lambda_n -> 0.\n\n### Bridge 3: MLE Counting as Polynomial Fractional Map\n\nThe MLE map from counts to probabilities is:\nPhi: (N(c,w))_{c,w} -> (N(c,w)/N(c))_{c,w}\n\nThis is a **rational map** -- ratio of polynomials in the count variables. The denominator N(c) = sum_w N(c,w) vanishes on V_0 (zero-count fiber). By resolution of singularities (Hironaka), the rational map can be resolved into a proper morphism, and the RLCT is determined by the **multiplicity of the denominator** along the zero-count fiber.\n\n**C1 PROVEN:** The n-gram likelihood is R_an-definable. The MLE is a rational function (polynomial numerator / polynomial denominator). The log-likelihood log(N(c,w)/N(c)) is subanalytic (log of a rational function on the simplex, bounded below). No exp terms needed for discrete n-gram models (R_an suffices).\n\n### Bridge 4: Smoothing as Singularity Regularization\n\nSmoothing techniques modify the counting map to remove the zero-count singularity:\n\n1. **Add-k (Laplace) smoothing:** p(w|c) = (N(c,w) + k) / (N(c) + kV). The denominator N(c) + kV never vanishes for k > 0. This is a **desingularization** -- the map is smooth on the entire simplex. Analogous to #570 randomized smoothing.\n\n2. **Good-Turing smoothing:** Reassign probability mass from observed-once events to unseen events. p_GT(w|c) = N*(r)/N where N*(r) = (r+1)N(r+1)/N(r). This creates a **non-polynomial** adjustment (ratio of counting functions), still in R_an.\n\n3. **Kneser-Ney smoothing:** p_KN(w|c) = max(N(c,w) - D, 0) / N(c) + lambda(c) p_KN(w|c'). The absolute discount D creates a **piecewise-linear** map with a kink at N(c,w) = D, analogous to ReLU singularity (#220). The recursion to lower-order models creates a **hierarchical desingularization**.\n\n**C4 CONJECTURAL:** The RLCT of the smoothed model lambda_smooth <= lambda_MLE, with equality only when smoothing is trivial (k=0, D=0).\n\n### Bridge 5: Sparsity-Driven Phase Transition at n*\n\nThe critical Markov order n* satisfies:\nV^{n*-1} x (V-1) ~ n_samples / log(n_samples)\n\n**C5 CONJECTURAL:** Below n*, the model is effectively regular. At n*, the LLC profile shows a kink. Above n*, the singular fiber dominates (lambda_n -> (V-1)/2). This is distinct from:\n- #873 HMM: K* driven by hidden state count, not context sparsity\n- #480 muP: width* driven by parameter count vs sample count, continuous\n- #877 Decision Tree: D* ~ log2(n), depth-driven\n\nThe n-gram n* is **combinatorial** -- it depends on V^{n-1} growing exponentially while n_samples grows polynomially.\n\n## Claims\n\n| Claim | Description | Status | Key Evidence |\n|-------|-------------|--------|--------------|\n| C1 | R_{an,exp}-definability of n-gram likelihood | PROVEN | Counting polynomials + rational MLE + subanalytic log |\n| C2 | Zero-count fiber RLCT (V-1)/2 per unobserved context | CONJECTURAL | Free simplex fiber with standard RLCT (Watanabe 2009) |\n| C3 | Markov order n as discrete stratum selector | CONJECTURAL | Exponential context growth, sparsity threshold |\n| C4 | Smoothing as desingularization, lambda_smooth <= lambda_MLE | CONJECTURAL | Add-k removes zero-count singularity, KN hierarchical |\n| C5 | Phase transition at n* ~ log_V(n/log(n)) | CONJECTURAL | Combinatorial capacity matching |\n\n## Key Novelty\n\n**Data-dependent singular fibers from zero counts.** Unlike neural network singularities (parameter symmetries, #220) or HMM label-switching (#873, #268), n-gram singularities arise from the **data itself** -- unobserved contexts create free parameter fibers. The RLCT is data-dependent through the counting operator, not just model-dependent.\n\n**Smoothing as explicit desingularization.** Each smoothing method (add-k, Good-Turing, Kneser-Ney) corresponds to a specific algebraic desingularization of the zero-count fiber. This bridges the NLP smoothing literature directly to SLT desingularization theory.\n\n## Open Problems\n\n1.
