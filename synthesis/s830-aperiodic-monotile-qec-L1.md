# Synthesis #830 L1: Aperiodic Monotile QEC — Formal Definitions\n\n## D1: Tiling Space\nLet T be a tiling of R^2 by a single prototile tau (either Hat or Spectre). The tiling space X_T is the set of all tilings obtained from T by translations and rotations (Hat) or translations and rotations only (Spectre, no reflections). X_T is a compact topological space under the local topology.\n\n## D2: QEC Code Construction\nGiven tiling T in X_T, define the Hilbert space H_T = tensor over tiles t in T of C^2 (qubit per tile). The QEC code C_T is the subspace of H_T spanned by ground states of the aperiodicity Hamiltonian H_ap = sum over local patterns P of |P><P| - |P*><P*| where P* ranges over forbidden local configurations. The code C_T is the kernel of H_ap restricted to the physical subspace.\n\n## D3: R_an,exp Definability (C1 — PROVEN)\nThe tiling space X_T is definable in R_an,exp: tile positions are semialgebraic (polygon vertices), rotations use exp(i*theta) (exponential function), and the matching rules are finite Boolean combinations of semialgebraic conditions. The Hamiltonian H_ap is a finite sum of semialgebraic operators. Thus C_T is R_an,exp-definable as the kernel of an R_an,exp-definable operator. C1 PROVEN.\n\n## D4: Aperiodic Singular Fiber\nDefine V_ap = {theta in parameter space : H_ap(theta) has degenerate ground state}. For periodic tilings, V_ap has positive codimension singular strata from translational symmetry degeneracy. For aperiodic monotile tilings, the breaking of translational symmetry lifts this degeneracy. Conjecture (C2): V_ap for aperiodic monotile tilings has strictly lower RLCT lambda_ap than periodic codes of equivalent density.\n\n## D5: Tile Type as Stratum Selector\nFor the Hat tiling, the single prototile appears in multiple orientations (reflected + unreflected). Define s = number of distinct orientation classes. For the Spectre, s = 1 (chiral, no reflections). Conjecture (C3): lambda(C_T) is monotone decreasing in s, with the Spectre (s=1) achieving minimal RLCT among single-tile aperiodic QEC codes.\n\n## D6: Generalization Bound\nConjecture (C4): The generalization error of learning on aperiodic monotile QEC codes satisfies:\n  G_ap <= lambda_ap / n + U / sqrt(n)\nwhere lambda_ap < lambda_per (periodic counterpart) under the aperiodic advantage hypothesis. The chiral structure of the Spectre provides an additional correction term C_chiral from the non-classical symmetry group.\n\n## D7: Phase Transition\nConjecture (C5): There exists a critical tiling density rho* at which the QEC code transitions from aperiodic-advantaged to aperiodic-disadvantaged. For rho < rho*, the aperiodic monotile code outperforms periodic codes; for rho > rho*, translational-type degeneracies re-emerge from near-periodic configurations.\n\n## Claims Summary\n- C1 (R_an,exp definability): PROVEN via semialgebraic + exponential closure\n- C2 (lower RLCT for aperiodic): CONJECTURAL\n- C3 (Spectre s=1 minimizes RLCT): CONJECTURAL\n- C4 (generalization bound with aperiodic advantage): CONJECTURAL\n- C5 (density phase transition rho*): CONJECTURAL\n\n## Open Problems (7)\n1.
