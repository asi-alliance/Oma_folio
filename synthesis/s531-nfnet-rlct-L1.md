# S531: Normalizer-Free Networks (NFNet) × RLCT — Level L1\n## Level L1: Formal Definitions\n\n**Date:** 2026-10-23\n**Author:** Oma (OmegaClaw agent)\n**Status:** L1 formalization\n**Depends on:** #531 L0, SLT framework (Watanabe), NFNet (Brock et al. 2021)\n\n---\n\n## Formal Definitions\n\n### D1: Network Architecture\n\nLet a deep CNN with L layers. Each layer l in 1..L comprises:\n- A convolution or linear layer with weights W_l, bias b_l\n- An activation function sigma(.) (scalable gain gamma_l)\n- Residual blocks with scaled skip connections\n\n### D2: Scaled Unit Weight Standardization (SUW)\n\nFor a convolution layer l with weights W_l, define:\n\nW'_l = gamma_l * (W_l - mean(W_l)) / sqrt(Var(W_l) + eps)\n\nwhere gamma_l is a learnable per-block scalar, mean(W_l) and Var(W_l) are computed over fan-in dimensions, eps > 0 is a small constant.\n\nThis is an analytic map (rational polynomial composition) of W_l — sqrt is a square root of a polynomial in W_l, thus definable in R_{an,exp} by closure under division (assuming W_l ≠ 0 and Var(W_l) > 0).\n\n- **Singularity:** If W_l = 0 or Var(W_l) = 0, the SUW map is undefined. The point W_l = 0 forms a degenerate singularity in layer l.\n- **Fiber object:** The nullset S_{W_l=0} = {theta : W_l = 0} forms a stratification S^1_l of the parameter space — the subtractive structure of the loss landscape around W_l = 0 changes radically.\n\n### D3: Adaptive Gradient Clipping (AGC)\n\nFor each unit r responsible for layer l with parameters theta_{h,l}, learning rate eta, and clip threshold tau. For gradient g_l of loss with respect to theta_{h,l}:\n\nDefine partial gradient norm rho_{l,r} = ||g_{l,r}|| / ||theta_{l,r}||.\n\nThe AGC-corrected gradient is:\n\ng'_{l,r} = g_{l,r} * min(1, tau / rho_{l,r})\n\nThis is a piecewise semi-algebraic map:\n- If rho_{l,r} <= tau: g'_{l,r} = g_{l,r} (no clip)\n- If rho_{l,r} > tau: g'_{l,r} = g_{l,r} * tau / rho_{l,r} = g_{l,r} * tau * ||theta_{l,r}|| / ||g_{l,r}|| (clipped)\n\nThe boundary hypersurface is B_{l,r} = {theta : ||g_{l,r}|| / ||theta_{l,r}|| = tau}, which is semi-algebraic (defined by polynomial equation ||g||^2 = tau^2 ||theta||^2).\n\n### D4: Residual Branch Scaling\n\nFor a residual block at depth d (block index within total N blocks), the skip connection is scaled by:\n\nalpha_d = 1 / sqrt(2 * (N - d + 1))\n\nor more precisely, the expected variance contribution of each residual block is alpha = 1/sqrt(2N) where N is the total number of residual blocks. This ensures that the signal variance at the output is preserved (bounded growth).\n\nThis is a constant (for fixed N) or algebraic (if N varies) scaling — definable in R_{an,exp}.\n\n### D5: NFNet Loss Function\n\nThe NFNet loss is the standard cross-entropy (or KL divergence) composed with the forward pass:\n\nL_NFNet(theta) = (1/n) * sum_i KL(p_i || f_NFNet(x_i; theta))\n\nwhere f_NFNet is the forward map: composition of SUW-scaled convolutions, ReLU activations (subanalytic), residual scaling (linear), and softmax (exp-definable).\n\nBy closure under composition in R_{an,exp}:\n- SUW: analytic (rational polynomial)\n- ReLU: subanalytic (semi-algebraic)\n- Residual scaling: linear (polynomial)\n- Softmax + CE: exp-definable\n- AGC affects the optimizer, not the loss function directly — but the effective loss landscape includes the clipping boundary structure\n\n### D6: Effective Loss with AGC\n\nThe AGC-modified training dynamics trace a trajectory on the parameter space constrained by the clipping boundaries. Define the effective loss:\n\nL_eff(theta, tau) = L_NFNet(theta) + I_{tau}(theta)\n\nwhere I_{tau}(theta) is an indicator-like term capturing the clipping boundary structure. More precisely, the AGC boundary B_{l,r}(tau) partitions the parameter space into regions:\n- R^0: no clipping active (rho < tau)\n- R^1: clipping active (rho > tau)\n\nThe effective loss is piecewise-smooth with C^0-not-C^1 transitions at B_{l,r}.\n\n### D7: RLCT Definition\n\nThe RLCT lambda_NFNet(tau) is defined as the RLCT of L_eff(theta, tau) at a non-degenerate local minimum theta*. Formally:\n\nlambda_NFNet(tau) = lim_{epsilon->0} log(V(epsilon)) / log(epsilon)\n\nwhere V(epsilon) = {theta : L_eff(theta, tau) - L_eff(theta*, tau) < epsilon} is the volume of the near-minimum set.\n\n---\n\n## Claim Formalization\n\n### C1 (PROVEN): R_{an,exp} Definability\n\n**Proof:** The NFNet loss L_NFNet(theta) is a composition of:\n1. SUW maps: gamma_l * (W_l - mean(W_l)) / sqrt(Var(W_l) + eps) — rational polynomial, definable in R_{an,exp}\n2. Convolution: polynomial (bilinear in weights and inputs)\n3. ReLU: subanalytic (semi-algebraic: max(0,x) = (x+|x|)/2, |x| = sqrt(x^2))\n4. Residual scaling: alpha * (x + f(x)) — linear composition, polynomial\n5. Softmax: exp(x_i) / sum_j exp(x_j) — exp-definable\n6. Cross-entropy: -sum y_i log(softmax_i) — log of exp-definable, definable in R_{an,exp}\n\nBy closure under composition in R_{an,exp}, L_NFNet is exp-definable. The AGC boundary surfaces B_{l,r} are semi-algebraic (defined by polynomial equations in theta), so the effective loss L_eff is piecewise R_{an,exp}-definable.\n\nQED.\n\n### C2 (CONJECTURAL): RLCT Reduction vs Batch Normalization\n\n**Claim:** lambda_NFNet <= lambda_BN\n\n**Reasoning:** BN creates an affine rescaling manifold (scale and shift parameters per channel) that adds a smooth group action to the parameter space. This group action creates additional singular fiber directions (the BN scale invariance orbits from #234). Removing BN eliminates these orbits, reducing the effective dimension of the singular set.\n\nHowever, SUW introduces its own singularity at W_l = 0 (the normalization denominator vanishes). The net effect depends on the relative dimension change:\n- BN removes: d_channels scale parameters + d_channels shift parameters = 2*d_channels fiber dimensions\n- SUW adds: 1 degenerate singularity per layer (codimension fan_in*fan_out)\n\nIf 2*d_channels > codim(SUW singularity), then lambda_NFNet < lambda_BN. This is expected for large fan_in*fan_out (the SUW singularity is high-codimension, thus low-RLCT contribution).\n\n**Gaps:**\n1. The comparison assumes BN fiber dimensions are all singular — some may be regular\n2. SUW singularity RLCT contribution not precisely computed\n3. Interaction between SUW singularity and ReLU kinks not analyzed\n\n### C3 (CONJECTURAL): AGC Threshold as Stratum Selector\n\n**Claim:** lambda_eff(tau) is monotonically non-decreasing in tau, with phase transition at tau*.\n\n**Formalization:** For fixed theta*, define the clipping boundary B_{l,r}(tau) = {theta : ||g_{l,r}(theta)|| = tau * ||theta_{l,r}||}. As tau varies:\n- tau -> infinity: B_{l,r} recedes to infinity, no clipping, lambda_eff -> lambda_NFNet (full RLCT)\n- tau -> 0: B_{l,r} contracts to theta_{l,r} = 0, all gradients clipped to zero, effective dynamics frozen, lambda_eff -> 0 (degenerate)\n- tau* : critical value where B_{l,r}(tau*) is tangent to the dominant singular fiber S* of L_NFNet\n\nThe phase transition at tau* corresponds to the AGC boundary crossing from the regular region into the singular fiber. For tau < tau*, clipping constrains the optimizer to remain within the regular region (reduced effective dimension). For tau > tau*, clipping is inactive near the minimum (full singular fiber accessible).\n\n**Gaps:**\n1. Monotonicity of lambda_eff(tau) not proven — may be non-monotonic due to multi-unit interactions\n2. Exact form of tau* depends on data distribution and network architecture\n3. Multi-unit boundary interaction (per-unit clipping creates L*dimensional boundary product structure)\n4. The tangent condition B_{l,r}(tau*) tangent to S* is heuristic — rigorous derivation needed\n\n### C4 (CONJECTURAL): Generalization Bound\n\n**Claim:** G_NFNet <= lambda_NFNet * log(n) / (2n) + U(tau, sigma) / sqrt(n)\n\nwhere U(tau, sigma) captures the bias-variance tradeoff of AGC clipping and signal propagation stability.\n\n**Reasoning:** By Watanabe's theorem, the generalization gap is bounded by lambda * log(n) / (2n) + O(1/sqrt(n)). For NFNet:\n- lambda = lambda_NFNet (reduced from lambda_BN by C2)\n- U(tau, sigma) captures the additional variance from AGC boundary crossings and the signal propagation residual scaling\n\nThe residual scaling alpha = 1/sqrt(2N) ensures variance preservation, which constrains the loss landscape to be well-conditioned (bounded Hessian eigenvalues), reducing the O(1/sqrt(n)) term.\n\n**Gaps:**\n1. Precise form of U(tau, sigma) not derived\n2. The bound assumes AGC boundary crossings are rare near the minimum — if frequent, the effective loss is non-smooth and standard SLT does not directly apply\n3. Interaction between SUW spherical constraint and the generalization bound not quantified\n\n### C5 (CONJECTURAL): SUW Spherical Constraint and RLCT\n\n**Claim:** SUW constrains the effective parameter space to a product of spheres (one per layer), and the RLCT on this constrained manifold differs from flat-space RLCT by a codimension correction.\n\n**Formalization:** SUW maps W_l to W'_l = gamma_l * (W_l - mean) / sqrt(Var + eps). The image of this map lies on a sphere of radius |gamma_l| in the space of W'_l (after centering). The constraint manifold is:\n\nM_SUW = {theta : ||W'_l - mean(W'_l)||^2 = gamma_l^2 * fan_in for all l}\n\nThis is a product of spheres S^{fan_in*fan_out - 1} (one per layer), intersected with the loss function's singular set.\n\nThe RLCT on a constrained manifold M is related to the flat-space RLCT by:\n\nlambda_SUW = lambda_flat - codim(M_SUW) / 2\n\nwhere codim(M_SUW) = L (one constraint per layer, assuming the sphere constraint reduces dimension by 1 per layer).\n\n**Gaps:**\n1. The codimension correction formula lambda_SUW = lambda_flat - codim/2 is heuristic — derived from Gaussian integral on constrained manifold, not rigorous SLT\n2. The sphere constraint is not exact (eps > 0 softens it)\n3. gamma_l is learnable — the sphere radius changes during training, creating a dynamical constraint manifold\n4. Interaction between SUW sphere constraint and ReLU kink singularity not analyzed\n\n---\n\n## Open Problems\n\n1. **Exact lambda_NFNet vs lambda_BN comparison:** Precise computation of the fiber dimension difference\n2. **tau* analytical form:** Derivation of the phase transition threshold from network and data properties\n3. **SUW spherical RLCT correction:** Rigorous derivation of the codimension correction\n4. **AGC multi-unit boundary interaction:** How per-unit clipping boundaries compose into a global boundary structure\n5. **gamma_l dynamics:** Does the learnable SUW gain converge to a fiber-preserving value or traverse strata?\n6. **Signal propagation and fiber width:** Does 1/sqrt(2N) residual scaling affect dominant singular fiber width?\n7. **NFNet vs other normalizer-free methods:** Comparison to Weight Normalization (#505) and Fixup (#424) RLCT\n\n## Cross-References\n\n#8 (ReLU definability), #16 (semi-algebraic sets), #99 (SGD dynamics), #169 (dropout), #173 (SAM), #213 (LR scheduling), #234 (BN), #424 (Fixup), #466 (RMSNorm), #480 (muP), #485 (RLT), #505 (Weight Norm), #526 (schedule-free), #530 (MAML)\n\n## Next Steps\n- L2: Novelty verification via websearch (NFNet × RLCT, normalization-free × singular learning theory)\n- L3: MeTTa encoding of C1 proof and C2-C5 conjectures\n- L4: Summary\n- L5: Catalog append
