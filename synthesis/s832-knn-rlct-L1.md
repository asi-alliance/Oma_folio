#832 kNN × RLCT - L1 Formalization\n\n## Setup\nNo trained parameters: the parameter space is the training set itself, Theta = (X_train, Y_train) in R^{n*d} x Y^n, drawn iid from a data distribution q(x,y). The kNN predictor f_hat(x; Theta) = majority vote (or average) over labels of the k nearest training points under metric d_M. Expected risk R(Theta) = E_x,y[L(y, f_hat(x; Theta))]. This inverts the usual SLT setup: the "model" is the identity map from data to predictor, and all singularity resides in the data configuration.\n\n## Formal Claims\n- C1 (PROVEN-ish): For fixed test x, the set of Theta-configurations in which the k-nearest-neighbor set of x changes is the tie arrangement T(x) = {Theta : exists distinct i,j <= k, ||x-x_i||_M = ||x-x_j||_M, plus boundary ties at rank k vs k+1}. Each tie surface {(x_i,x_j) : ||x-x_i||^2_M = ||x-x_j||^2_M} is a hyperplane in the (x_i,x_j) coordinates when M is fixed (both sides are quadratic but their difference in the pair-coordinates is linear after expansion of the quadratic terms in the test point x). Hence T(x) is a hyperplane arrangement, semialgebraic, definable in R_an; the risk R(Theta) is a finite sum of definable functions over regions of this arrangement (finitely many regions a.s. via general position), so R is definable. Caveat: R is piecewise-smooth, definable but not analytic; C1 requires definable-loss SLT extensions, same burden as #831 C1.\n- C2 (CONJECTURAL): The tie strata T = union over x of T(x) have positive codim-1 part under generic data; degenerate configurations (duplicates: x_i = x_j, codim d; on-cell-boundary: lower-dim faces) form deeper strata. Claim: the free-energy n*e_n(Theta)-concentration argument transfers: the posterior over Theta (as parameter) concentrates near maximal-degeneracy strata, giving RLCT lambda_kNN > nd/2, with equality only for non-degenerate (general-position) training sets.\n- C3 (CONJECTURAL): k as discrete stratum selector: for k=1 every rank-1 tie surface is active (maximal arrangement); as k grows, rank-j ties for j <= k become label-invariant (vote unchanged if labels agree), removing effective strata. Predicted phase transition at k* where the effective tie stratum drops in dimension, matching the classical optimal k ~ n^{2/(d+2)} rate crossover as an RLCT phase transition rather than a bias-variance heuristic.\n- C4 (CONJECTURAL): 1-NN interpolating limit is maximally singular: every point is a support atom, RLCT(1-NN) strictly maximal in k for fixed n. Monotonicity claim: lambda(1-NN) > lambda(3-NN) > ... > lambda(k-NN), testable by counting active tie surfaces.\n- C5 (CONJECTURAL): Metric M as arrangement-reshaper: the tie surfaces are M-weighted hyperplanes; degenerate M (det M = 0) collapses the arrangement, creating fiber degeneracy V_0 = {Theta : f_hat identical across M-collapse}, analogous to #831 kernel collapse and #103 GP kernel degeneracy. Learned-metric kNN (#581) moves along this fiber family.\n\n## Key Definitions\n- Tie locus T(x): hyperplane arrangement where the kNN set of x is non-unique or boundary-ambiguous.\n- Data-as-parameter: Theta = training set itself; posterior concentration on Theta-configuration strata.\n- Support atom: training point on the boundary of some cell whose removal changes the predictor (analog of SVM support vector).\n- Vote-invariant tie: a tie that does not change the kNN vote outcome; inactive stratum.\n\n## Notes on scope\n- 0-1 loss for classification is itself non-definable-friendly (indicator); use surrogate definable loss or average over labels; regression kNN with squared loss is cleanly definable. Flag as proof burden for C1.\n- The expected risk E_x is an integral over definable functions; definability of R(Theta) needs o-minimal integration results (Comte-Lion-Rolin type) — marked as open tooling.\n\n## Next\nL2 novelty verification.
