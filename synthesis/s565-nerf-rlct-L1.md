# Synthesis #565: NeRF (Neural Radiance Fields) × RLCT\n## Date: 2026-10-23\n## Status: L1 (Formalization)\n## Prior: L0 at s565-nerf-rlct-L0.md\n\n### D1: Data Space and NeRF Architecture\n\nLet the dataset D = {(I_k, P_k)}_{k=1}^n where I_k ∈ R^{H×W×3} is an image and P_k ∈ SE(3) is a camera pose. Each pixel (i,j) defines a camera ray r_{ij}(t) = o + t·d where o is the camera origin and d the ray direction.\n\nThe NeRF network is an MLP f_θ: R^{2L+3} × R^{2L+3} → R^4 where:\n- Input: γ(x) ∈ R^{2L+3} (position encoding of 3D point x ∈ R^3) concatenated with γ(d) ∈ R^{2L+3} (encoding of viewing direction d ∈ S^2)\n- Output: (σ, c) ∈ R × R^3 where σ ≥ 0 is volume density and c ∈ [0,1]^3 is RGB color\n- γ(x) = [x, sin(2^0 πx), cos(2^0 πx), ..., sin(2^{L-1} πx), cos(2^{L-1} πx)] (Fourier positional encoding with L frequencies)\n- Architecture: 8-layer MLP with ReLU activations for σ, additional layer for c with sigmoid output\n\n### D2: NeRF Loss Function\n\nThe rendered color for ray r is computed via discrete volume rendering over N sample points {t_i}_{i=1}^N along the ray:\n\n  T_i = exp(-Σ_{j=1}^{i-1} σ_j δ_j),  α_i = 1 - exp(-σ_i δ_i),  Ĉ(r) = Σ_{i=1}^N T_i α_i c_i\n\nwhere δ_i = t_{i+1} - t_i is the inter-sample distance.\n\nThe loss is the photometric MSE over all rays:\n\n  L(θ) = (1/|R|) Σ_{r∈R} ||Ĉ_θ(r) - I(r)||²_2\n\nwhere R is the set of all rays from all training images.\n\nThe true loss is L_true(θ) = E_{r~P(ray)} [||Ĉ_θ(r) - I(r)||²].\n\n### D3: Zero-Loss Set\n\nThe zero-loss set is:\n\n  W_0 = {θ ∈ R^d : L_true(θ) = 0} = {θ : Ĉ_θ(r) = I(r) ∀ r}\n\nThis is the set of all parameter configurations producing pixel-perfect rendering. Due to the rendering operator's null space, W_0 is not a single point but a variety of positive dimension: different radiance fields (σ, c) can produce identical rendered images.\n\n### D4: Singular Fiber Structure\n\nThe singular fiber contains parameters where the loss landscape has non-generic (degenerate) geometry. Four sources:\n\n(a) **Rendering Operator Null Space**: The map R: (σ, c) → Ĉ is many-to-one. The fiber V_null = {θ : Ĉ_θ = Ĉ_{θ*}, θ ≠ θ*} is a positive-dimensional variety. Its dimension depends on scene geometry — empty space (σ=0) contributes free parameters that do not affect rendering.\n\n(b) **Positional Encoding Degeneracy**: At L=0 (no Fourier features), γ(x) = x is injective but low-bandwidth. The fiber V_PE(L) = {θ : f_θ ∘ γ_L produces same rendered output as f_θ* ∘ γ_{L'}} for L < L' has higher dimension — high-frequency scene detail is invisible, creating degenerate minima.\n\n(c) **Opacity Saturation Discriminant**: The set V_sat = {θ : ∃ i, r with σ_i δ_i → ∞} where T_{i+1} → 0. Points beyond saturation are invisible, creating a discriminant variety where gradients w.r.t. downstream parameters vanish.\n\n(d) **View-Dependent Angular Symmetry**: The set V_ang = {θ : ∃ d₁ ≠ d₂ with c(x,d₁) = c(x,d₂)} where specular reflections create angular non-identifiability.\n\nThe total singular fiber is the union V = V_null ∪ V_PE ∪ V_sat ∪ V_ang.\n\n### D5: RLCT of NeRF Singular Fiber\n\nThe RLCT λ of the NeRF loss landscape at a singularity θ* ∈ W_0 is:\n\n  λ = lim_{ε→0} log(Vol{θ : L(θ) - L(θ*) ≤ ε}) / log(ε)\n\nThe dominant contribution comes from the largest-dimensional singular stratum. Hypothesis:\n\n  λ(L, N) ≈ λ_MLP + dim(V_null(L)) / 2\n\nwhere λ_MLP is the intrinsic RLCT of the MLP and dim(V_null(L)) is the dimension of the rendering operator null space, which decreases with L (more frequencies → less ambiguity) and increases with scene void space.\n\n### D6: Stratum Selectors\n\nTwo stratum selectors:\n\n1. **Positional encoding frequency L**: Low L → large V_null (coarse field, many degeneracies) → high λ. High L → small V_null (full frequency representation) → low λ but higher d (more parameters). Predicted U-shape: λ(L) first decreases then the capacity penalty dominates. Optimal L* where generalization bound is minimized.\n\n2. **Ray sample count N**: Low N → aliasing artifacts create additional singular strata V_alias. High N → continuous integral limit, aliasing strata merge. N acts as a secondary selector modifying the fiber structure.\n\nFormally, the strata are indexed by (L, N) and the RLCT is a function λ(L, N).\n\n### D7: Generalization Bound\n\nBy Watanabe's theorem, the generalization error satisfies:\n\n  G(L, N, n) ≤ λ(L, N) · log(n) / (2n) + O(1/√n)\n\nwhere λ(L, N) is the RLCT at the singular point. The bound predicts:\n- Generalization improves with L up to L* (reducing rendering ambiguity)\n- Beyond L*, the parameter count d grows and the λ decrease is offset by increased variance\n- For fixed L, increasing N beyond N* does not improve the bound (aliasing strata already resolved)\n\n### C1 (PROVEN): R_{an,exp} Definability\n\nThe NeRF rendering loss is definable in the o-minimal structure R_{an,exp}.\n\nProof sketch:\n- The MLP f_θ with ReLU is subanalytic (definable in R_{an})\n- Sigmoid output σ(x) = 1/(1+e^{-x}) is definable in R_{an,exp}\n- Positional encoding γ(x) = [sin(2^k πx), cos(2^k πx)] uses sin/cos of exponential arguments — definable in R_{an,exp} via the restricted sine/cosine (Wilkie's theorem: R_{an,exp} is o-minimal and contains restricted sin/cos)\n- Volume rendering: T_i = exp(-Σ σ_j δ_j) is exp of a polynomial in θ (through MLP outputs) — definable in R_{an,exp}\n- α_i = 1 - exp(-σ_i δ_i) — definable by composition\n- Ĉ(r) = Σ T_i α_i c_i — polynomial in definable functions — definable\n- Loss L(θ) = (1/|R|) Σ ||Ĉ_θ(r) - I(r)||² — polynomial in definable functions — definable\n\nBy closure of R_{an,exp} under composition, summation, and polynomial operations, the full NeRF loss is definable. □\n\n### C2 (CONJECTURAL): Singular Fiber Decomposition\n\nThe singular fiber V = V_null ∪ V_PE ∪ V_sat ∪ V_ang has four distinct strata. The rendering null space V_null dominates the RLCT (largest dimension). V_sat is a discriminant variety of codimension ≥ 1 (saturation requires σ → ∞, a boundary condition). V_ang has positive codimension (angular symmetry is non-generic). V_PE degeneracy is parameterized by L.\n\nGap: Exact dimension of V_null as function of scene geometry and L is unknown. The interaction between strata (whether they intersect transversally) is unproven.\n\n### C3 (CONJECTURAL): U-Shaped RLCT in L\n\nλ(L) has a U-shape: λ(0) is large (no Fourier features → maximal degeneracy), λ(L) decreases for moderate L (resolving ambiguity), then λ(L) stabilizes or the effective complexity d(L) = (2L+3)·(hidden layers) grows. The optimal L* minimizes the generalization bound G(L) = λ(L)·log(n)/(2n).\n\nGap: Monotonicity of λ(L) in the decreasing regime is unproven. The exact form of the U-shape (sharpness, location of L*) is scene-dependent.\n\n### C4 (CONJECTURAL): Generalization Bound with Rendering Null Space\n\nG(L, N, n) ≤ [λ_MLP + dim(V_null(L))/2] · log(n) / (2n) + U(L, N)/√n\n\nwhere U(L, N) captures the variance from finite ray sampling and finite frequency encoding. The rendering null space inflates λ beyond the intrinsic MLP complexity.\n\nGap: The additive decomposition λ = λ_MLP + dim(V_null)/2 is heuristic — interaction between MLP singularities and rendering null space may be multiplicative rather than additive.\n\n### C5 (CONJECTURAL): Ray-Marching Phase Transition at N*\n\nThere exists a critical N* such that:\n- For N < N*: aliasing creates additional singular strata V_alias(N) with λ(N) > λ(∞)\n- For N ≥ N*: aliasing strata merge into the continuous-integral structure, λ(N) = λ(∞)\n\nN* depends on scene geometry (highest frequency present) and L (encoding bandwidth). Predicted: N* ~ C · 2^L (exponential in frequency count).\n\nGap: The exponential scaling N* ~ C·2^L is heuristic from Nyquist-type arguments. The phase transition sharpness is unproven.\n\n### Open Problems\n\n1. Formal computation of dim(V_null) as function of scene geometry and L\n2.
