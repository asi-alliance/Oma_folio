# Synthesis #852: Mamba (Selective State Space Model) x RLCT\n## L0: Outline & Architecture Overview\n## Date: 2026-11-06\n\n### Architecture: Mamba (Gu & Dao, 2023)\nMamba is a selective state space model (SSM) that replaces attention with input-dependent gating. Core mechanism:\n\n- Continuous SSM: h'(t) = A*h(t) + B*x(t), y(t) = C*h(t) + D*x(t)\n- Discretization (ZOH): A_bar = exp(A*dt), B_bar = (A_bar - I)*A^{-1}*B\n- Selective gating: dt, B, C are input-dependent (functions of x), making the model selectively compress or expand information\n- Parallel scan for efficient training, recurrent for inference\n\nKey parameter groups:\n- A in R^(d x N): state transition matrix (learned, structured: Diag + low-rank or HiPPO init)\n- B, C in R^(d x N): input/output projection matrices (input-dependent in Mamba)\n- D: skip connection (scalar per channel)\n- dt = softplus(s_delta(x)): input-dependent step size, the SELECTIVE mechanism\n- Linear projections: W_in, W_out in R^(d x d) (like attention QKV/O projections)\n\n### Parameter Space\ntheta_mamba = (W_in, W_out, A, B(x), C(x), D, dt(x))\n\nKey distinction from non-selective SSMs (#385 LoRA-adjacent, #490 RoPE-adjacent): dt, B, C are FUNCTIONS of input, not fixed parameters. This input-dependence creates a novel singularity structure.\n\n### Claim Preview\n- C1 (PROVEN): Mamba loss is R_an,exp-definable. ZOH discretization (matrix exp, matrix inverse), softplus (analytic), linear projections (polynomial) all in R_an,exp. Closure under composition preserves definability.\n- C2 (CONJECTURAL): Selective gating singular fiber V_sel = {theta : dt(x) -> 0 or dt(x) -> infty for some x}. dt->0 collapses A_bar -> I (state frozen, information loss). dt->infty makes A_bar -> 0 (full reset, memoryless). This fiber is INPUT-DEPENDENT — different from architectural fibers in prior syntheses.\n- C3 (CONJECTURAL): Selectivity (variance of dt across inputs) acts as stratum selector. Low selectivity: dt ~ constant, reduces to linear RNN (connects to structured SSM). High selectivity: rich singular strata from input-dependent degeneracy.\n- C4 (CONJECTURAL): Generalization bound G_mamba ~ lambda_mamba/(2n)*log(n) + U/sqrt(n). Selective compression reduces effective hypothesis space (lower U) but input-dependent singularity increases lambda. Trade-off phase transition at critical selectivity s*.\n- C5 (CONJECTURAL): Selectivity phase transition at training iteration t*. As model learns selective gating, LLC shows kink when dt transitions from uniform to input-dependent. SGLD-detectable.\n\n### Key Novelty\nINPUT-DEPENDENT singular fiber. All prior syntheses (#134 attention, #653 conv, #851 conformer) have FIXED architectural singularities. Mamba's dt(x) means the singular fiber V_sel VARIES with input x — the singularity locus is a function of the data point. This is fundamentally new in the RLCT framework.\n\n### Cross-References\n#134 (attention Plucker toric fiber), #490 (RoPE positional), #385 (LoRA low-rank), #498 (mixture-of-depths), #586 (model merging), #466 (RMSNorm), #8 (RLCT basics), #16 (definability), #851 (conformer product stratum)\n\n### Open Problems\n1.
