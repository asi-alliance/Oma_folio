## Synthesis #900: DBSCAN × RLCT -- L0 Exploration\n\nDate: 2026-11-12\n\n## Topic\nDBSCAN (Density-Based Spatial Clustering of Applications with Noise) × Real Log Canonical Threshold (RLCT)\n\n## Background\nDBSCAN clusters points by density reachability. Given parameters (epsilon, minPts):\n- A point p is a **core point** if |N_epsilon(p)| >= minPts, where N_epsilon(p) = {q : d(p,q) <= epsilon}\n- A point q is **directly density-reachable** from p if p is core and q in N_epsilon(p)\n- **Density-reachable**: chain of direct reachability links\n- **Density-connected**: p and q both reachable from some core point o\n- **Border point**: in N_epsilon of a core point but not itself core\n- **Noise**: neither core nor border\n\nClusters = maximal sets of density-connected points. No explicit loss function — clustering is defined by graph connectivity on the epsilon-neighborhood graph.\n\n## RLCT Bridge: Why DBSCAN is Singular\n\n### Singularity Source 1: epsilon-Neighborhood Graph Topology Discontinuity\nThe epsilon-neighborhood graph G(epsilon) has edges {i,j : d(x_i,x_j) <= epsilon}. As epsilon varies continuously, edges appear/disappear at critical values epsilon* = d(x_i,x_j) for pairs (i,j). At these critical values, the graph topology changes (connected components merge or split). This is a **stratum crossing**: the clustering output changes discontinuously while epsilon changes continuously. The set of critical epsilon values forms a discrete set of stratum boundaries.\n\n### Singularity Source 2: Core/Border/Noise Partition as Singular Fiber\nFor fixed epsilon, the partition into core/border/noise is determined by |N_epsilon(p)| >= minPts. The boundary |N_epsilon(p)| = minPts - 1 vs minPts is a **discrete threshold crossing** — a point transitions from noise/border to core. The core set C = {p : |N_epsilon(p)| >= minPts} changes as minPts varies. Points at the threshold |N_epsilon(p)| = minPts are on the singular stratum: small perturbations of data can flip their status.\n\n### Singularity Source 3: Border Point Ambiguous Assignment\nBorder points reachable from core points in multiple clusters have ambiguous assignment — the assignment function is multi-valued. This creates a **discrete fiber** over border points: the set of valid cluster labels for a border point forms a fiber of size equal to the number of clusters it borders. This is analogous to permutation symmetry S_k in k-means (#872) but data-dependent and per-point.\n\n### Singularity Source 4: No Explicit Loss — Definability Challenge\nDBSCAN has no differentiable loss function. The clustering is defined by a combinatorial algorithm (graph connectivity). For RLCT analysis, we need a **surrogate loss** whose zero-loss set coincides with the DBSCAN partition. Candidate: a piecewise-constant loss L(partition) = 0 if partition is a valid DBSCAN output, >0 otherwise. This is R_an-definable (semialgebraic indicator on distance comparisons). The singular fiber = set of all valid DBSCAN partitions for given (epsilon, minPts, data).\n\n### Singularity Source 5: epsilon as Continuous Stratum Selector\nVarying epsilon continuously sweeps through stratum boundaries. Each critical epsilon* where graph topology changes is a phase transition. The RLCT lambda(epsilon) is piecewise constant (within a stratum) with jumps at critical values. This creates a **staircase** lambda(epsilon) profile — analogous to #888 eigenvalue gap crossings but in graph-topology space rather than eigenspace.\n\n## C1-C5 Claims\n\n### C1 (Definability): CONJECTURED PROVABLE\nThe DBSCAN surrogate loss can be formulated as a semialgebraic condition: L(partition, epsilon, minPts) = sum_i [indicator(x_i is misclassified given partition, epsilon, minPts)]. Each indicator is a Boolean combination of polynomial inequalities (distance comparisons d(x_i,x_j) <= epsilon, cardinality comparisons |{j : d(x_i,x_j) <= epsilon}| >= minPts). Boolean combinations of polynomial inequalities define semialgebraic sets, which are R_an-definable. The surrogate loss is piecewise-constant (R_an-definable). Thus RLCT exists for the surrogate.\n\nKey challenge: cardinality counting |{j : d(x_i,x_j) <= epsilon}| >= minPts involves a sum of indicator functions, which are semialgebraic. The composition is definable. Similar to #880 n-gram zero-count contexts and #882 Naive Bayes probability collapse.\n\n### C2 (Singular Fiber): CONJECTURAL\nThe singular fiber V_0(epsilon, minPts) = {partitions P : P is a valid DBSCAN output for (epsilon, minPts, data)}. The fiber structure:\n(a) Core points: uniquely assigned (fiber = singleton) — regular part\n(b) Border points with single cluster reachability: uniquely assigned (fiber = singleton) — regular part\n(c) Border points with multi-cluster reachability: fiber = set of valid cluster labels (size = number of bordering clusters) — singular stratum\n(d) Noise points: fiber = {noise label} (singleton but different from cluster labels) — boundary stratum\n\nThe singular locus is the set of partitions where at least one border point has multi-cluster reachability. The fiber dimension = sum over ambiguous border points of (log2 of number of reachable clusters - 1).\n\n### C3 (Stratum Selector): CONJECTURAL\nepsilon as continuous stratum selector:\n- epsilon small: graph disconnected, all points noise, trivial fiber (all-noise partition)\n- epsilon increasing: components merge at critical epsilon* values, core points appear, clusters form\n- epsilon large: fully connected graph, single cluster containing all points (if all become core), minimal fiber\n\nminPts as discrete stratum selector:\n- minPts = 1: all points core, single cluster (trivial)\n- minPts increasing: fewer core points, more noise, finer clustering\n- minPts too large: all noise (trivial fiber)\n\nThe (epsilon, minPts) parameter space is tiled by strata where the DBSCAN partition is constant. Stratum boundaries are at critical epsilon* = pairwise distances and minPts thresholds.\n\n### C4 (Generalization Bound): CONJECTURAL\nFor a surrogate loss formulation, the generalization bound takes the form:\nG(epsilon, minPts) <= lambda(epsilon, minPts) * log(n) / (2n) + U(epsilon, minPts) / sqrt(n)\n\nwhere lambda(epsilon, minPts) is the RLCT of the surrogate loss at the selected stratum, and U accounts for the combinatorial complexity of the partition space (number of valid DBSCAN partitions for given parameters).\n\nKey insight: lambda is piecewise constant in epsilon with jumps at critical values. The optimal epsilon* minimizes the tradeoff: small epsilon gives low U (few valid partitions) but high lambda (degenerate all-noise fiber), large epsilon gives high U (many valid partitions) but lower lambda (simpler fiber). There should be an optimal epsilon* at a stratum boundary.\n\n### C5 (Phase Transition): CONJECTURAL\nAt each critical epsilon* = d(x_i,x_j) where the graph topology changes, the RLCT lambda(epsilon) jumps. This is a phase transition detectable via SGLD on the surrogate loss:\n- Within a stratum: LLC constant\n- At stratum boundary epsilon*: LLC jumps (kink in LLC vs epsilon curve)\n\nThe staircase structure of lambda(epsilon) creates multiple phase transitions. The most significant is the transition from all-noise (epsilon < epsilon_min) to first-cluster formation (epsilon > epsilon_min), where the fiber jumps from trivial to non-trivial.\n\nminPts transitions: at minPts = |N_epsilon(p)| + 1 for some point p, that point flips from core to border/noise, creating a discrete phase transition.\n\n## Open Problems\n1.
