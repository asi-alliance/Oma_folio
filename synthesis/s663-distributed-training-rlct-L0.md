# Synthesis #663: Distributed Training × RLCT — L0\n## Date: 2026-10-28\n\n## Topic\nDistributed training (data parallelism, tensor parallelism, pipeline parallelism, ZeRO/FSDP sharding) analyzed through Singular Learning Theory (SLT) and Real Log Canonical Threshold (RLCT).\n\n## Motivation\nDistributed training partitions model parameters, gradients, and computation across D devices. This partitioning creates quotient structures on the parameter space — each device holds a slice of the full weight tensor, and synchronization (all-reduce, scatter-gather) stitches these slices back. The singular geometry of the loss landscape is fundamentally altered by this partitioning: singular fibers that were connected in single-device training become disconnected or reconnected via communication, creating new stratum structures governed by device topology and communication patterns.\n\n## Prior Work\n- #561 Ring Attention × RLCT: Blockwise attention across ring topology — analyzes attention pattern distribution, NOT training topology. Distributed training (this synthesis) analyzes parameter/gradients/computation partitioning itself.\n- #433 Weight Decay × RLCT: Regularization as toric deformation — different mechanism (penalty vs partitioning).\n- #292 Flash Attention × RLCT, #302 Linear Attention × RLCT: Attention computation methods, not training infrastructure.\n\nZero prior work bridging distributed training (DDP, ZeRO, FSDP, tensor parallelism, pipeline parallelism) with SLT/RLCT.\n\n## Definitions (D1-D7)\n\n**D1 (Data-Parallel Loss):** For D devices each holding full parameter copy θ_d = θ, data-parallel loss is L_DP(θ) = (1/D) Σ_{d=1}^{D} L_d(θ), where L_d is loss on shard d.\n\n**D2 (Sharded Parameter Space):** Under ZeRO/FSDP stage-s sharding, parameter space Θ = Θ_1 × Θ_2 × ... × Θ_D where device d holds partition θ^(d) ∈ Θ_d. Full parameter θ = (θ^(1), ..., θ^(D)).\n\n**D3 (Synchronization Fiber):** After all-reduce, synchronized parameter θ_sync = (1/D) Σ_d θ_d. The synchronization map σ: Θ^D → Θ projects D copies to their mean. Fiber σ^{-1}(θ) = {(θ_1,...,θ_D) : (1/D)Σ θ_d = θ} is the synchronization fiber.\n\n**D4 (Tensor-Parallel Factorization):** Tensor parallelism splits weight matrix W ∈ R^{m×n} into W = [W_1 | W_2 | ... | W_D] (column-parallel) or W = [W_1; W_2; ...; W_D] (row-parallel). The factorized fiber is the set of decompositions yielding the same functional output.\n\n**D5 (Pipeline Partition):** Pipeline parallelism partitions layers into stages S_1, ..., S_P. Boundary parameters (input/output of each stage) create interface singularities where gradient flow crosses device boundaries.\n\n**D6 (Effective RLCT under Sharding):** λ_eff(D) = RLCT of the sharded loss landscape, accounting for quotient structure imposed by parameter partitioning and synchronization.\n\n**D7 (Communication Stratum):** Each all-reduce / barrier synchronization defines a discrete stratum transition. Between communications, each device evolves on its local fiber independently.\n\n## Claims (C1-C5)\n\n**C1 (PROVEN): Data-parallel loss L_DP(θ) = (1/D)Σ L_d(θ) is R_an,exp-definable.**\nProof: Each L_d is R_an,exp-definable (assumption: original loss is). Finite arithmetic mean of definable functions is definable. The synchronization map σ is affine (averaging), hence definable. Composition preserves definability. □\n\n**C2 (CONJECTURAL): Synchronization creates a quotient singularity — the synchronization fiber σ^{-1}(θ) is a singular fiber whose RLCT depends on D.**\nAs D increases, the synchronization fiber grows in dimension (dim = (D-1)·dim(Θ)), creating higher-dimensional singular loci. The all-reduce averaging collapses D-dimensional orbit to a point, analogous to a quotient map in algebraic geometry. The RLCT of the synchronized loss landscape λ_sync(D) may differ from single-device λ_0.\n\n**C3 (CONJECTURAL): Device count D serves as a discrete stratum selector — each D defines a distinct singular structure.**\nUnlike continuous stratum selectors (λ_wd in #433, merge ratio r in #500), D is discrete. Each value of D partitions the parameter space differently, creating distinct fiber topologies. The effective RLCT λ_eff(D) is a step function of D, not continuous. Conjecture: λ_eff(D) is non-decreasing in D (more devices = more synchronization averaging = potentially higher RLCT due to fiber dimensionality growth), or alternatively non-increasing (more averaging = more smoothing = lower RLCT). The direction is itself an open question.\n\n**C4 (CONJECTURAL): Generalization bound for distributed training includes a synchronization correction term.**\nG_DP <= λ_eff(D) · log(n)/(n·D) + U/√(n·D) + C_sync(D)\nwhere C_sync(D) captures the information loss from gradient averaging across D devices. The effective sample size n·D grows with D (more data processed), but C_sync(D) may grow with D (more averaging = more information loss per step). The bound predicts an optimal D* balancing parallelism gain vs synchronization cost.\n\n**C5 (CONJECTURAL): Tensor parallelism creates factorized singular fibers with RLCT bounded by the minimum partition RLCT.**\nFor column-parallel W = [W_1|...|W_D], the factorized fiber V_TP = {W : W_i fixed for all i} has RLCT λ_TP = min_i λ(W_i). The singularity structure of the full matrix is dominated by its most singular partition. Pipeline parallelism creates boundary singularities at stage interfaces with RLCT determined by the interface Jacobian rank.\n\n## Open Problems (1-7)\n\n1. **Direction of λ_eff(D) monotonicity:** Does synchronization averaging increase or decrease RLCT?
