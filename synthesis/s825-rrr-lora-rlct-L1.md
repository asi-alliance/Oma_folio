# Synthesis #825 L1: RRR Aoyagi Validation -> LoRA RLCT Bridge\n\n## Definitions\n\nD1 (RRR Parameter Space): Let X in R^{n x d_in}, Y in R^{n x d_out}. RRR models Y = XAB + eps where A in R^{d_in x r}, B in R^{r x d_out}, rank(W)=r<=min(d_in,d_out). Parameter space Theta_RRR = {(A,B) in R^{d_in*r} x R^{r*d_out}}. Total d_params = r(d_in + d_out).\n\nD2 (LoRA Parameter Space): Given frozen W_0 in R^{d_in x d_out}, LoRA models W = W_0 + BA where A in R^{d_in x r}, B in R^{r x d_out}. Parameter space Theta_LoRA = {(A,B)} identical to D1. The shift by W_0 is a translation, preserving singular fiber structure.\n\nD3 (Determinantal Variety): D_r = {W in R^{d_in x d_out} : rank(W) <= r}. This is an algebraic variety defined by vanishing of all (r+1)-minors of W. Codim(D_r) = (d_in - r)(d_out - r). The singular locus of D_r is D_{r-1} (matrices of rank < r).\n\nD4 (GL(r) Gauge Fiber): The map pi: (A,B) -> AB is invariant under (A,B) -> (AC, C^{-1}B) for C in GL(r). Fiber dimension = r^2 - r (dimension of GL(r) minus identity component). This gauge redundancy creates the singular fiber structure.\n\nD5 (Aoyagi RLCT Formula): For RRR with rank r, the RLCT at the true parameter is:\n  lambda_RRR = r(d_in + d_out - r) / 2\nThis is strictly less than d_params/2 = r(d_in + d_out)/2, with gap r^2/2 = (gauge fiber dim)/2.\n\nD6 (RWMH LLC Estimator): Given ERM solution theta_hat, run Random Walk Metropolis-Hastings with proposal sigma = sqrt(2T/n), temperature T. LLC = (E[L(theta)] - min L(theta)) / T, where expectation is over the posterior sample after burnin.\n\nD7 (Generalization Bound): For singular model with RLCT lambda, the generalization error scales as G ~ lambda/n + U/sqrt(n), where U is the fluctuation term.
