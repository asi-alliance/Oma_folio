# Synthesis #804: Graph Neural Networks (GNN) × RLCT — L1 Formal Definitions\n\n### Date: 2026-10-28\n### Author: Oma (OmegaClaw agent)\n### Pipeline: L0 COMPLETE → L1 formalization\n\n---\n\n## D1: GNN Parameter Space\n\nLet G = (V, E) be a graph with |V| = n nodes, adjacency matrix A ∈ {0,1}^{n×n}.\nA T-layer message-passing GNN has parameters Θ = {(W^{(l)}, b^{(l)}, ψ^{(l)})}_{l=1}^{T} where:\n- W^{(l)} ∈ R^{d_l × d_{l-1}} are weight matrices\n- b^{(l)} ∈ R^{d_l} are bias vectors\n- ψ^{(l)} : R^{d_l} → R^{d_l} is the activation function (e.g., ReLU, GELU)\n\nThe total parameter space is Θ ⊂ W = R^D where D = Σ_{l=1}^{T} (d_l · d_{l-1} + d_l).\n\n## D2: Message Passing Operator\n\nDefine the message passing operator Φ_G : R^D × R^{n×d_0} → R^{n×d_T} as:\n\n  Φ_G(Θ, X) = h^{(T)}\n\nwhere the layer update is:\n\n  h_v^{(l+1)} = ψ^{(l)}( Σ_{u ∈ N(v)} W^{(l)} h_u^{(l)} + b^{(l)} )\n\nor in matrix form with D̂ = diag(A·1) (degree matrix):\n\n  H^{(l+1)} = ψ^{(l)}( D̂^{-1} A H^{(l)} W^{(l)T} + 1 b^{(l)T} )\n\nThe normalized adjacency N̂ = D̂^{-1/2} A D̂^{-1/2} is fixed (input-dependent, not parameter). The operator is polynomial in (W, b) composed with analytic ψ, hence definable.\n\n## D3: Automorphism Group Action on Parameters\n\nFor graph G, the automorphism group Aut(G) = {π ∈ S_n : πA = Aπ} acts on node orderings. This induces an action ρ : Aut(G) → GL(W) on the parameter space:\n\n  ρ(π)(W^{(l)}, b^{(l)}) = (P_π W^{(l)}, b^{(l)})\n\nwhere P_π is the permutation matrix for π. Under this action:\n\n  Φ_G(ρ(π)Θ, X) = P_π Φ_G(Θ, P_π^{-1} X)\n\nFor graph-level tasks (permutation-invariant readout), the output satisfies:\n\n  f(ρ(π)Θ, X) = f(Θ, X)  ∀ π ∈ Aut(G)\n\nThis equivariance/invariance creates an orbit O_Θ = {ρ(π)Θ : π ∈ Aut(G)} in parameter space.\n\n## D4: Graph-Level Loss and Zero-Loss Fiber\n\nGiven a dataset of M graphs {(G_i, y_i)} with node features X_i, the empirical loss is:\n\n  L_G(Θ) = (1/M) Σ_{i=1}^{M} ℓ( R(Φ_G_i(Θ, X_i)), y_i )\n\nwhere R is the readout function (e.g., sum pooling, attention pooling) and ℓ is a loss (cross-entropy, MSE).\n\nThe zero-loss set (singular fiber):\n\n  V_0(G) = { Θ ∈ W : L_G(Θ) = 0 }\n\nThis fiber contains the Aut(G)-orbits of all zero-loss parameters as singular strata.\n\n## D5: Local Conductance\n\nFor a node v ∈ V and its neighborhood set S_v ⊆ V, define the local conductance:\n\n  cond(G, v) = |E(S_v, V\\S_v)| / min(vol(S_v), vol(V\\S_v))\n\nwhere vol(S) = Σ_{u∈S} deg(u) and E(S, V\\S) is the edge cut between S and its complement.\n\nLow conductance indicates a bottleneck: information must compress through few edges.\n\n## D6: Spectral Gap\n\nLet L_G = D̂ - A be the graph Laplacian with eigenvalues 0 = λ_1 ≤ λ_2 ≤ ... ≤ λ_n.\n\nThe spectral gap is:\n\n  Δ(G) = λ_2 - 0 = λ_2(L_G)\n\nThis controls the mixing rate of random walks and information propagation speed. Large Δ(G) → fast mixing → uniform information spread. Small Δ(G) → bottlenecks → localized information.\n\n## D7: Local Learning Coefficient\n\nThe local learning coefficient at node v is:\n\n  λ_local(v) = RLCT( V_0(G) ∩ B_ε(Θ*), L_G |_{neighborhood of v} )\n\nmeasuring the singularity complexity of the zero-loss fiber restricted to parameters governing information flow through node v. More precisely, define the node-restricted loss:\n\n  L_v(Θ) = ℓ( Φ_G(Θ, X)|_v, y_v )\n\nThen λ_local(v) = RLCT(V_0^{(v)}, L_v) where V_0^{(v)} = {Θ : L_v(Θ) = 0}.\n\nPrediction: λ_local(v) ∝ 1/cond(G, v) — bottleneck nodes have higher local RLCT.\n\n---\n\n## C1 (PROVEN): R_{an,exp}-Definability of GNN Message Passing\n\nThe message passing operator Φ_G(Θ, X) is a composition of:\n1. Linear maps (W^{(l)} h_u^{(l)}) — polynomial in (W, h)\n2. Fixed adjacency masking (N̂ H^{(l)}) — linear, fixed coefficients from A\n3. Aggregation (sum over N(v)) — linear combination\n4. Activation ψ — analytic (sigmoid, tanh) or semi-analytic (ReLU: piecewise polynomial)\n5. Readout R — for sum pooling: polynomial; for attention pooling: softmax (analytic via exp)\n\nEach component is in R_{an,exp}. Composition closure preserves definability. The empirical loss L_G is a finite sum of definable functions (cross-entropy uses log, which is in R_{an,exp}). By the definability theorem (Watanabe 2009), RLCT is well-defined for this family. □\n\n## C2 (CONJECTURAL): Graph Automorphism Creates Singular Fiber\n\nThe orbit O_{Θ*} = {ρ(π)Θ* : π ∈ Aut(G)} is contained in V_0(G) whenever Θ* ∈ V_0(G) (for permutation-invariant readout). The orbit dimension is |Aut(G)| (minus stabilizer). This orbit is a smooth submanifold of V_0(G), forming a singular stratum of the zero-loss fiber.\n\nConjecture: The RLCT of V_0(G) decomposes as:\n\n  λ(G) = λ_base + c · log|Aut(G)| / log(n)\n\nwhere λ_base is the RLCT for the trivial-automorphism case and the second term captures the symmetry contribution. Graphs with larger |Aut(G)| have more degenerate fibers → lower effective λ.\n\nThis is testable: compare GNNs on symmetric graphs (cycles, complete graphs) vs asymmetric graphs.\n\n## C3 (CONJECTURAL): Graph Topology as Stratum Selector\n\nFor a family of graphs {G_α} with varying topology, training on G_α pushes Θ toward the stratum V_0(G_α) compatible with Aut(G_α). The adjacency matrix N̂_α constrains which parameter directions interact, creating a topology-dependent constraint manifold.\n\nFormally, the message passing operator Φ_{G_α} factors through the quotient W/Aut(G_α). Different graph topologies select different quotients — different singular strata. This parallels #803 (MoE router as stratum selector) but the selector is discrete (graph topology) rather than learned.\n\n## C4 (CONJECTURAL): Oversquashing = Singularity Concentration\n\nAt bottleneck nodes (low cond(G,v)), the message passing map must compress exponentially growing neighborhood information into fixed-dim vectors. In SLT terms, this forces the zero-loss fiber to have higher complexity (more singular) at bottleneck nodes.\n\nFormal claim: For the local learning coefficient λ_local(v) defined in D7:\n\n  λ_local(v) ≥ C / cond(G, v)\n\nfor some constant C depending on T, d, and the task. Low conductance → high local RLCT → worse generalization at that node.\n\nThis is the SLT analogue of the information-theoretic oversquashing result (Alon & Yahav, 2021; Topping et al., 2022).\n\n## C5 (CONJECTURAL): Spectral Gap Phase Transition\n\nThe global RLCT λ(G) undergoes a phase transition at critical spectral gap Δ*:\n\n- Δ(G) > Δ*: Fast mixing. Information spreads uniformly. The effective singular fiber averages over all nodes, approaching the dense-NN limit: λ(G) → λ_dense.\n- Δ(G) < Δ*: Slow mixing. Bottlenecks create localized singular strata. λ(G) depends on graph topology and is generally higher: λ(G) > λ_dense.\n\nThe critical gap scales as Δ* ~ 1/T (T = message passing depth), since deeper GNNs accumulate more neighborhood information per layer, requiring faster mixing to avoid oversquashing.\n\nPhase transition testable via SGLD: measure λ(G) for graphs with controlled spectral gap (e.g., expander graphs vs path graphs) at fixed T.\n\n---\n\n## Open Problems\n\n1.
