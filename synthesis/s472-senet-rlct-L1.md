## Synthesis #472: SE-Net × RLCT — L1 Formalization\n\n### Formal Definitions\n\n**D1 (SE Block).** Given input X∈R^{C×H×W}, the SE block f_SE: R^{C×H×W}→R^{C×H×W} is:\n- Squeeze: z = GAP(X) = (1/HW)·Σ_{i,j} X[:,i,j] ∈ R^C\n- Excitation: s = σ(W₂·ReLU(W₁·z + b₁) + b₂) ∈ (0,1)^C, where W₁∈R^{C/r×C}, W₂∈R^{C×C/r}\n- Scale: Y = s ⊙ X (channel-wise multiplication)\n\n**D2 (GAP Quotient Map).** The squeeze operator π_GAP: R^{C×H×W}→R^C defined by z_c = (1/HW)Σ_{i=1}^H Σ_{j=1}^W X_{c,i,j}. For each z∈R^C, the fiber π_GAP^{-1}(z) = {X ∈ R^{C×H×W} : GAP(X)=z} is an affine subspace of dimension C·(HW−1).\n\n**D3 (Excitation MLP).** The map g_exc: R^C→(0,1)^C defined by g_exc(z) = σ(W₂·ReLU(W₁·z + b₁) + b₂). This is a two-layer MLP with bottleneck dimension C/r.\n\n**D4 (Sigmoid Saturation Locus).** For the excitation output s = g_exc(z), the saturation loci are: S_0 = {θ : s_c(θ) → 0} and S_1 = {θ : s_c(θ) → 1} for some channel c. These are defined by σ(·)≈0 (pre-activation → −∞) and σ(·)≈1 (pre-activation → +∞). At finite precision, approximate loci S_0^ε = {θ : s_c(θ) < ε} and S_1^ε = {θ : s_c(θ) > 1−ε} are semi-algebraic.\n\n**D5 (Reduction Ratio Stratum Selector).** The reduction ratio r∈N_{>0} determines bottleneck dimension d_b = ⌊C/r⌋. Each r defines a stratum Σ_r of the parameter space partitioned by excitation capacity. Larger d_b (smaller r) → finer excitation → more channels independently rescaled.\n\n**D6 (RLCT).** λ = RLCT(W,L) = the real log canonical threshold of the loss function L(θ) at its minimum set, computed via resolution of singularities. λ governs the asymptotic generalization gap G ≈ λ·log(n)/n (Watanabe).\n\n**D7 (Generalization Bound).** G_SE(r,n) ≈ λ_SE(r)·log(n)/n, where λ_SE(r) is the RLCT of the SE-Net loss landscape as a function of reduction ratio r.\n\n### Claims\n\n**C1 (Proven):** The SE block f_SE is definable in R_{an,exp}.\n*Proof:* GAP is a polynomial map (arithmetic mean over spatial indices) — polynomial maps are R_an-definable. ReLU(x) = max(x,0) is subanalytic (piecewise-linear), hence R_an-definable. σ(x) = 1/(1+e^{−x}) uses exp, hence R_{an,exp}-definable. Matrix multiplication W₁·z and W₂·h are polynomial (bilinear) maps. Elementwise multiplication s⊙X is polynomial. Composition of R_{an,exp}-definable maps is R_{an,exp}-definable (closure under composition). Therefore f_SE ∈ R_{an,exp}. □\n\n**C2 (Conjectural):** The GAP quotient map π_GAP creates a singular fiber structure. The fiber π_GAP^{-1}(z) has dimension C·(HW−1), collapsing spatial information. The loss function L(θ) restricted to this fiber is constant in the GAP-output direction, creating a degenerate Fisher information matrix. The singularity arises where the excitation map g_exc transitions between active and saturated channels — the fiber dimension jumps as channels enter/exit saturation. The RLCT satisfies λ_SE ≥ C·(HW−1)/2 from the GAP fiber degeneracy alone.\n\n**C3 (Conjectural):** The reduction ratio r acts as a continuous stratum selector. As r decreases (bottleneck d_b=C/r increases), the excitation MLP has more capacity to produce diverse channel rescaling vectors s. This creates finer strata in parameter space — more distinct saturation patterns are realizable. The RLCT λ_SE(r) is conjectured to be monotonically non-increasing in d_b (decreasing in r), with λ_SE(r₁) ≤ λ_SE(r₂) for r₁ < r₂, because finer excitation resolves more of the GAP quotient singularity. This parallels the group-count selector in GroupNorm (#369) and bit-width in QAT (#470).\n\n**C4 (Conjectural):** Sigmoid saturation creates multiplicative rescaling fibers. When s_c → 0 (channel c saturated off), the output Y_c = s_c·X_c → 0 regardless of X_c — channel c is effectively pruned, reducing effective parameter dimension by the number of saturated channels. When s_c → 1, the channel passes through unmodified. The saturation loci S_0^ε ∪ S_1^ε partition parameter space into strata by saturation count k. Each stratum has effective dimension d_eff = d − k·(H·W+1), and RLCT λ_k ≈ d_eff/2 + λ_base. The transition between strata (channel entering/leaving saturation) creates a branch-switch singularity analogous to #468 PPO clip boundary and #470 QAT grid boundary.\n\n**C5 (Conjectural):** The optimal reduction ratio r* corresponds to an RLCT phase transition. The generalization bound G_SE(r,n) = λ_SE(r)·log(n)/n is minimized at some r* where RLCT reduction (decreasing in 1/r) balances capacity increase (increasing parameter count in W₁,W₂ as 1/r grows). At r*, the marginal RLCT reduction per unit of capacity equals the marginal complexity penalty. This r* is an RLCT phase transition: for r > r*, the SE block under-resolves the GAP quotient (high λ, poor generalization); for r < r*, excess excitation capacity adds parameters without proportional RLCT reduction (overfitting). The phase transition is testable via SGLD: measure λ_SE(r) at multiple r values and observe the kink.\n\n### Open Problems\n1.
