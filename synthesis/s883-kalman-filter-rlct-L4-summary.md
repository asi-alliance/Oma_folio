# Synthesis #883: Kalman Filter x RLCT — L4 Executive Summary\n## Date: 2026-11-09\n\n## Plain-Language Summary\n\nThis synthesis bridges the Kalman Filter (KF) — the optimal recursive estimator for linear-Gaussian state-space models — with Watanabe's Real Log Canonical Threshold (RLCT) from Singular Learning Theory. The key insight: when a KF has unobservable states (observability rank deficiency), the loss landscape develops a continuous-dimensional singular fiber whose geometry is invisible to standard Fisher information but governs generalization through the RLCT.\n\n### C1 PROVEN: The KF loss is R_an,exp-definable\nThe negative log-likelihood of a Kalman filter involves matrix products (polynomial), Riccati recursion with matrix inverses (rational), log-determinants, and quadratic forms. These compose into an R_an,exp-definable function, satisfying Watanabe's definability requirement. This is the entry ticket — the RLCT machinery applies.\n\n### C2 CONJECTURAL: Unobservable subspace contributes (n-r)/2 to RLCT\nWhen the observability matrix has rank r < n, a continuous subspace of dimension n-r leaves the output distribution unchanged. Parameters in this subspace are invisible to the data. Each free direction contributes 1/2 to the RLCT, giving lambda_KF = (n-r)/2 + lambda_obs. This is a continuous fiber — distinct from the discrete permutation fibers seen in HMMs (#873) or mixture models (#268).\n\n### C3 CONJECTURAL: Riccati convergence creates an RLCT phase transition\nDuring the transient phase (T < t*), initial covariance P_0 contributes n(n+1)/2 extra effective parameters. After Riccati convergence (T > t*), P_0 is forgotten and the RLCT drops. SGLD local learning coefficient should show a kink at t* — a testable prediction.\n\n### C4 CONJECTURAL: Measurement noise R is a continuous stratum selector\nIncreasing R makes more states unobservable (higher lambda, worse generalization). Decreasing R reveals more structure (lower lambda). The generalization bound G(R,T) = lambda(R)log(T)/(2T) + U(R)/sqrt(T) has an optimal R* — a U-shaped curve paralleling classifier-free guidance (#362) and nucleus sampling (#359), but in estimation rather than generation.\n\n### C5 CONJECTURAL: Multiple Riccati fixed points increase RLCT\nThe algebraic Riccati equation can have multiple positive-definite solutions under non-generic conditions. Each additional solution corresponds to a desingularization blow-up that increases the RLCT above the regular value d_obs/2.\n\n### Standout Insight\nThe continuous-dimensional unobservable fiber (C2) is a new singularity type in the catalog: not discrete multiplicity (HMMs, GMMs) but a genuine continuous subspace of free directions. This connects classical control theory (observability) directly to SLT generalization bounds.\n\n### Open Problems (7)\n1. Does system matrix A modify the (n-r)/2 fiber contribution?\n2.
