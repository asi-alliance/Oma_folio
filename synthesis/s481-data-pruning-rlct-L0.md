#481 Data Pruning × RLCT — L0 EXPLORATION\nDate: 2026-10-21\nStatus: EXPLORATION\n\n## Topic\nData Pruning / Coreset Selection × Singular Learning Theory (RLCT)\n\n## Data Pruning Summary\n- Removing training samples deemed "easy" or "redundant" to create smaller, more efficient training sets\n- Sorsorce et al. (2022): prune based on memorization difficulty (forgetting scores)\n- Paul et al. (2021): prune via data influence / sensitivity estimation\n- Key methods: difficulty-based pruning, redundancy-based pruning, influence-based pruning, coreset selection\n- Modern context: critical for efficient LLM pretraining (e.g., FineWeb-Edu filtering)\n\n## Candidate RLCT Bridge (C1-C5)\n\n- C1: DEFINABILITY — Pruned empirical loss is a sum over subset S ⊂ {1,...,n} of per-sample losses\n  - L_S(θ) = (1/|S|) Σ_{i∈S} ℓ_i(θ) where ℓ_i is per-sample loss\n  - Each ℓ_i is analytic → L_S is analytic → RLCT exists\n  - Key: pruning changes the SET of true parameters W_S = {θ : L_S(θ) = 0} (or minimizers)\n  - Different subsets S give different W_S → different singularity structures\n\n- C2: FIBER STRATIFICATION BY DATA SUBSET\n  - Each pruning mask m ∈ {0,1}^n defines an empirical loss L_m(θ)\n  - The true parameter set W_m depends on which samples are retained\n  - Pruning "easy" samples (low loss at optimum) may not change W → same RLCT\n  - Pruning "hard" samples (high loss / near-boundary) may change W → different RLCT\n  - Data-dependent fiber: K_m(θ) = {φ : L_m(φ) = L_m(θ)} depends on subset\n  - Novel mechanism: RLCT is a FUNCTION of the pruning mask m — λ(m)\n\n- C3: PHASE TRANSITION AT CRITICAL PRUNING RATIO\n  - As pruning fraction α = |S|/n increases from 0 to 1:\n    - Low α: too few samples → W_S is LARGER (underdetermined) → higher RLCT (more singular)\n    - High α: more samples → W_S shrinks → lower RLCT (more regular)\n    - But: redundant samples don't change W_S → RLCT flat in redundant region\n  - Prediction: λ(α) has a PHASE TRANSITION at α* where removing more samples\n    starts removing "informative" (W_S-changing) samples\n  - α* separates redundant-pruning regime (λ flat) from informative-pruning regime (λ rising)\n\n- C4: GENERALIZATION BOUND\n  - Standard: G ~ λ/n + U/sqrt(n) (Watanabe)\n  - Pruned: G_S ~ λ(S)/|S| + U(S)/sqrt(|S|)\n  - Tradeoff: smaller |S| increases both terms, but λ(S) may DECREASE if pruning\n    removes samples that create singularities (hard-to-fit samples)\n  - Optimal pruning: minimize λ(S)/|S| — remove samples contributing most to singularity\n  - Connection: "prunable" samples = those whose removal reduces λ without changing W\n\n- C5: MEMORIZATION SCORE AS RLCT PROXY\n  - Forgetting score (Sorsorce) measures how often a sample transitions from\n    learned-to-forgotten during training — proxy for sample's contribution to singularity\n  - Hypothesis: high-forgetting samples contribute MORE to RLCT (create local singularities)\n  - Removing them reduces λ but may increase bias (changes W_S)\n  - RLCT-optimal pruning ≠ accuracy-optimal pruning in general\n\n## Distinction from Related Syntheses\n- #220 (Pruning × RLCT): parameter-space pruning — removes weights, changes model class\n  Data pruning: data-space pruning — removes samples, changes empirical measure\n  KEY DIFFERENCE: parameter pruning changes H (hypothesis class), data pruning changes D (data)\n- #178 (Unlearning × RLCT): removing specific samples for privacy — targeted removal\n  Data pruning: bulk removal for efficiency — not targeted, optimization-driven\n- #95 (Curriculum × RLCT): ordering of samples, not removal\n  Data pruning: subset selection, not ordering\n\n## Cross-references: #220 (parameter pruning), #178 (unlearning), #95 (curriculum), #169 (dropout), #222 (weight decay)\n## Open problems: 8 (RLCT as function of pruning mask, phase transition α*, memorization-RLCT correlation, optimal pruning criterion, redundancy vs informativeness boundary, data pruning + parameter pruning interaction, scale-dependent pruning ratio, theoretical lower bound on |S|, connection to data quality filtering)
