## Synthesis #672: Hyena Operator × RLCT\n## L0: Initial Exploration\n\n**Date:** 2026-10-28\n**Status:** L0 DRAFT\n\n---\n\n### Background\n\nHyena is a subquadratic replacement for attention that composes:\n1. **Implicitly parametrized long convolutions** — kernel h[t] is not learned directly but generated by a small MLP from positional embeddings\n2. **Data-controlled multiplicative gating** — layers alternate convolution with elementwise gating: y = H_1 * (H_2 * (H_3 * x))\n3. **FFT-based computation** — convolution via FFT: h * x = IFFT(FFT(h) · FFT(x))\n\n### Questions\n\nQ1: How does the implicit kernel parameterization (MLP generating filter from positional embedding) affect the loss landscape geometry? The kernel lives in function space but is parametrized by finite weights.\n\nQ2: The multiplicative gating composition y = h_1 ⊙ (h_2 ⊙ (h_3 ⊙ x)) creates a product structure. Does this create product singularities in the loss, where singular loci from each gate compose?\n\nQ3: FFT transforms the convolution to elementwise multiplication in frequency domain. Does this create a unitary transformation of the singular fiber (preserving RLCT), or does the frequency-domain representation change the singularity structure?\n\nQ4: The long convolution kernel has length T (sequence length). As T grows, does the RLCT scale with T? This connects to #233 Mamba's λ(T) ~ log(T) conjecture.\n\nQ5: Hyena gating is data-controlled — gate values depend on input. Does this create input-conditioned singular strata like Mamba's selective scan, or is the structure fundamentally different because the gating is multiplicative rather than selective?\n\nQ6: What is the relationship between Hyena's implicit parametrization and hypernetwork architectures? Both generate weights via auxiliary networks. Is the singularity structure analogous?\n\nQ7: The composition order (right-to-left gating) creates a recursive structure. Does this recursive composition create hierarchical singular fibers?\n\n### Claims\n\n**C1 (PROVEN):** The Hyena operator is definable in R_{an,exp}. Each component is analytic: MLP kernel generator (polynomial/analytic activation), FFT (unitary linear map = analytic), elementwise multiplication (polynomial), composition of analytic maps is analytic. The loss is therefore in the definable class.\n\n**C2 (CONJECTURAL):** The multiplicative gating composition creates product singularities. If each gate H_i has singular locus S_i, the composition H_1 ⊙ (H_2 ⊙ (H_3 ⊙ x)) has singular locus contained in the union of S_i and their preimages through subsequent gates. The RLCT of the composition may decompose as a sum over gate-level RLCTs weighted by composition depth.\n\n**C3 (CONJECTURAL):** The implicit kernel parameterization via MLP creates a fiber structure where the true kernel space (infinite-dimensional, length T) is projected onto a finite-dimensional parameter space. This projection creates a singular fiber map: many weight configurations map to equivalent kernels. The RLCT of the implicit parametrization is lower-bounded by the RLCT of direct kernel learning, with the gap determined by the MLP's expressivity.\n\n**C4 (CONJECTURAL):** FFT is a unitary (orthogonal) transformation on R^T. Unitary maps preserve RLCT (they are diffeomorphisms). Therefore the frequency-domain singular fiber is isomorphic to the time-domain singular fiber, and RLCT_FFT = RLCT_time. The FFT does not fundamentally change the singularity structure but may reveal it in a more interpretable form (frequency-stratified singularities).\n\n**C5 (CONJECTURAL):** As sequence length T increases, the implicit kernel MLP must generate longer filters from the same parameter budget. This creates a capacity-compression tension: the singular fiber dimension grows with T but the parameter space stays fixed. The RLCT is predicted to scale as λ(T) ~ λ_base + α·log(T)·λ_gate, similar to #233 Mamba, driven by the growing gap between kernel space dimension and parameter space dimension.\n\n### Predictions\n\n1. SGLD on Hyena models will show LLC transitions correlated with gate specialization (each gate learning distinct frequency bands).\n2. Models with explicit kernel parameters (no implicit MLP) will have higher RLCT than implicit-parameterized ones of the same effective kernel length.\n3. FFT-domain analysis will show singularities concentrated in specific frequency bands, with low-frequency components having higher RLCT (slower convergence) than high-frequency.\n4. Increasing composition depth (more gates) increases RLCT sublinearly — each gate adds diminishing singular contribution.\n5. Data-controlled gating creates input-dependent singular strata, but the multiplicative structure (vs Mamba's selective structure) produces smoother transitions — no piecewise branch-switching singularity.\n\n### Open Problems\n\n1. Proof that unitary transforms (FFT) preserve RLCT — should follow from diffeomorphism invariance.\n4. Comparison with Mamba #233: multiplicative gating vs selective scan — fundamentally different singularity structures?\n6. Comparison with attention #134: Hyena as attention replacement — does the RLCT relationship to attention reveal why Hyena generalizes differently?\n7. Recursive composition depth vs RLCT scaling law: linear? Sublinear? Logarithmic?\n\n### Cross-References\n#233 (Mamba/SSM), #134 (Attention), #317 (RetNet/Retention), #396 (GLA), #557 (Mamba candidate dup), #151 (SSM toric fan), #215 (SSM standard SLT), #506 (Hypernetwork), #490 (RoPE), #229 (KV Cache)\n\n### Distinctions from Prior Work\n- **vs #233 Mamba:** Mamba uses selective state space (input-dependent gating on recurrence); Hyena uses multiplicative gating on long convolutions. Mamba's singularity is piecewise (branch-switch at selection threshold); Hyena's is multiplicative (product of gates). Fundamentally different singularity class.\n- **vs #134 Attention:** Attention uses softmax pairwise mixing (quadratic); Hyena uses subquadratic convolution. Attention singularity is in the softmax saturation (#169); Hyena singularity is in the kernel-gate composition.\n- **vs #317 RetNet:** Retention uses recurrent decay with exponential weighting; Hyena uses fixed-length convolution. Different temporal structure, different fiber geometry.\n- **vs #506 Hypernetwork:** Both use auxiliary networks to generate parameters, but Hyena generates a convolution kernel (structured, Toeplitz) vs general weight matrices. The structure constraint changes the fiber.
