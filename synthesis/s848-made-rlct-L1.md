# Synthesis #848: MADE × RLCT — L1 Formalization\n\n## Date: 2026-11-06\n## Status: L1 (formal definitions + proofs). C1 PROVEN, C2-C5 CONJECTURAL.\n\n## Formal Definitions\n\n- **D1** (MADE Architecture): An autoencoder with L hidden layers. Each layer l has weight W^l ∈ R^{d_l × d_{l-1}} and bias b^l ∈ R^{d_l}. Binary mask M^l ∈ {0,1}^{d_l × d_{l-1}} is applied elementwise: h^l = sigmoid((W^l ⊙ M^l) h^{l-1} + b^l). The mask M^l_{ij} = 1 iff m^l(i) >= m^{l-1}(j), where m^l is a random permutation of hidden unit indices ensuring output unit i receives input only from units with lower index.\n\n- **D2** (Autoregressive Factorization): For data x ∈ R^D, the network computes p(x) = Π_{i=1}^D p(x_i | x_{1:i-1}) via a single forward pass. Each conditional p(x_i | x_{<i}) = sigmoid(W̃^L_{i,:} h^{L-1} + b^L_i) is determined by the masked connectivity.\n\n- **D3** (Zero-Weight Stratum): For a fixed mask assignment m = (m^1,...,m^L), the zero-weight set Z_m = {θ ∈ Θ : W^l_{ij} = 0 whenever M^l_{ij} = 0, ∀l} is a coordinate subspace of parameter space Θ. The effective parameter space under mask m is Θ_m = Θ ∩ Z_m^⊥, a linear subspace of dimension dim(Θ_m) = Σ_l |{(i,j) : M^l_{ij} = 1}|.\n\n- **D4** (Combinatorial Non-Identifiability): Let S_{d_l} be the symmetric group on d_l elements. A permutation σ_l ∈ S_{d_l} acting on hidden units of layer l that preserves the mask ordering (i.e., m^l(σ(i)) = m^l(i)) yields an equivalent network f_θ = f_{σ(θ)}. The equivalence class [θ]_σ defines a quotient singularity Θ_m / Γ_m where Γ_m = Π_l Stab(m^l) is the product of mask-preserving permutation groups.\n\n- **D5** (Empirical Loss): L_n(θ) = -(1/n) Σ_{k=1}^n log Π_{i=1}^D p(x_i^{(k)} | x_{<i}^{(k)}; θ). Within each mask stratum Θ_m, L_n is a composition of affine maps (masked linear layers), sigmoid functions, and log-likelihood terms — hence piecewise analytic (semi-algebraic after Tarski-Seidenberg).\n\n- **D6** (Singular Fiber): For mask m, V_m = {θ ∈ Θ_m : L_n(θ) = L*} where L* is the true loss minimum. The full fiber is V = ∪_m V_m, a finite union of strata (one per valid mask pattern). Each V_m inherits the quotient structure V_m / Γ_m.\n\n- **D7** (Real Code): The real code ℓ_f is defined as the local ideal generator near θ_0 ∈ V_m, restricted to non-zero-weight coordinates. Within each stratum, ℓ_f ~ Π_i p(x_i|p) composed of analytic functions (sigmoid, affine), so ℓ_f is in R_{an,exp}. At mask boundary crossings (where m changes), ℓ_f is piecewise-defined and singular.\n\n## Claims\n\n- **C1** (Definability [PROVEN]): Within each mask stratum Θ_m, L_n(θ) is a finite composition of: (a) affine maps (masked linear layers W̃^l h^{l-1}), (b) sigmoid activations (analytic, definable in R_{an}), (c) logarithm of sigmoid (analytic on (0,1)), and (d) finite sums over data. Each operation preserves R_{an,exp}-definability. By Tarski-Seidenberg, the zero set V_m is semi-algebraic. The real code ℓ_f restricted to non-zero coordinates is R_{an,exp}-definable. SLT conditions (properness, analyticity, compact support) are satisfied. QED.\n\n- **C2** (Mask-Induced Quotient Singularity [CONJECTURAL]): The quotient Θ_m / Γ_m creates orbifold-type singularities at fixed points of non-trivial permutations. For σ ∈ Γ_m with σ ≠ id, the fixed-point locus Fix(σ) = {θ : σ(θ) = θ} is a proper subvariety of V_m. The RLCT of the quotient λ(V_m/Γ_m) >= λ(V_m) because quotient singularities introduce additional local complexity (the local ring of the quotient has higher embedding dimension). This parallels #134 attention permutation equivariance but with fixed (not learned) ordering.\n\n- **C3** (Combinatorial Stratum Complexity [CONJECTURAL]): The number of valid mask patterns |M| grows as Π_l (d_l choose ⌊d_l/2⌋) for typical architectures. Each pattern defines a distinct stratum V_m. The union V = ∪_m V_m has RLCT λ_total >= max_m λ(V_m) because the most complex stratum dominates the local geometry near the global singularity. For deep MADE, strata interact: λ_total may exceed the maximum due to transverse intersection of strata at boundary crossings.\n\n- **C4** (Generalization Bound [CONJECTURAL]): By the SLT generalization theorem, G(n) ≈ λ/n · log n + U·√(log n / n) where λ is the RLCT of the active stratum. For MADE, the active mask m selects a specific λ_m. Simpler autoregressive orderings (fewer conditionals per output) produce lower λ_m → tighter gen bound. This suggests a bias-variance-RLCT tradeoff: richer masks increase expressivity (lower bias) but increase λ_m (worse generalization).\n\n- **C5** (Mask Width vs RLCT Trade-off [CONJECTURAL]): Wider hidden layers (larger d_l) increase |M| combinatorially, creating more strata. However, each stratum Θ_m has higher dimension, potentially lower λ_m (more parameters to fit data). The net effect is conjectured to follow a U-shaped curve in d_l: too narrow → high λ (underfitting singularity), optimal → balanced λ, too wide → high λ_total (stratum complexity dominates). This mirrors #169 dropout rate tradeoff but with deterministic rather than stochastic strata.\n\n## Open Problems\n\n1.
