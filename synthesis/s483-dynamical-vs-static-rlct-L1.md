#483 Dynamical vs Static RLCT — L1 FORMALIZATION\nDate: 2026-10-21\nStatus: FORMAL\nExtends #482 C2 gap. Cross-refs: #482 #236 #394 #410 #420 #213 #386\n\n## Formal Definitions\n\nD1 (Static RLCT): Given loss K(w) with true set W = {w : K(w)=0}, the static RLCT lambda_static is the pole order of zeta(z) = integral (K(w)+z)^(-alpha) phi(w) dw at z=0. Standard Watanabe (2009) RLCT — property of K geometry at W.\n\nD2 (Nested Singular Strata): W decomposes into nested strata S_1 superset S_2 superset ... superset S_k where lambda(S_1) >= lambda(S_2) >= ... >= lambda(S_k). Each S_i is semianalytic, definable in R_an,exp.\n\nD3 (Definable Trajectory): w(t) for t in {0,...,T} generated by w(t+1) = Phi(w(t), g_t, eta_t). For standard optimizers (SGD, Adam, SAM), Phi is definable in R_an,exp. Thus w(t) is a definable function of w(0), {g_t}, {eta_t}.\n\nD4 (Instantaneous Fiber Membership): Sigma(t) = argmin_i { lambda(S_i) : w(t) in N_epsilon(S_i) } where N_epsilon(S_i) is the epsilon-tubular neighborhood of S_i. If in multiple neighborhoods, deepest (lowest-lambda) stratum selected.\n\nD5 (Dynamical RLCT): lambda_dyn(t) = lambda(Sigma(t)). Piecewise-constant function of t, changes only at stratum crossings.\n\nD6 (Trajectory-Averaged Dynamical RLCT): bar_lambda_dyn = (1/T) sum_{t=0}^{T} lambda_dyn(t). Effective complexity experienced along training trajectory.\n\nD7 (Stratum Crossing Time): t_cross(i->j) = inf { t : Sigma(t) = S_j AND Sigma(t-1) = S_i }. Times at which lambda_dyn jumps.\n\n## Claims\n\nC1 (PROVEN): lambda_static exists and equals standard Watanabe RLCT. Follows from Watanabe (2009) for definable losses (#8, #16).\n\nC2 (CONJECTURAL): lambda_dyn(t) well-defined via D4-D5 for definable trajectory w(t). GAP: N_epsilon(S_i) not unique — result may depend on epsilon. Need canonical choice (e.g., epsilon = O(1/sqrt(n))). If w(t) between strata, Sigma(t) ambiguous.\n\nC3 (CONJECTURAL): lambda_dyn is optimizer-dependent. Different Phi (SGD vs Adam vs SAM) produce different trajectories reaching different strata. SAM biases toward low-lambda (#482). GAP: No rigorous proof optimizer determines final stratum — empirical observation. May depend on init, data ordering, LR schedule.\n\nC4 (CONJECTURAL): Gen bound G_dyn <= bar_lambda_dyn * log(n) / (2n) + U / sqrt(n). When bar_lambda_dyn < lambda_static, trajectory regularizes beyond static SLT prediction. GAP: Standard Watanabe bound is ASYMPTOTIC on POSTERIOR, not trajectory. Need posterior-at-w(T) has RLCT = lambda_dyn(T), not lambda_static.\n\nC5 (CONJECTURAL): SGLD-measured LLC at checkpoint w(t_k) reflects lambda_dyn(t_k). Discontinuities in LLC(t) indicate stratum crossings. Testable via SGLD v8 (#367). GAP: SGLD LLC is noisy — distinguishing stratum crossing from estimation noise needs multiple independent runs. Significance threshold undefined.\n\n## Open Problems (7)\n1. Canonical epsilon for N_epsilon(S_i) — dependence on n, loss geometry\n2. Piecewise-constant vs smooth lambda_dyn\n3. Rigorous optimizer->stratum selection theorem (C3)\n4. Posterior-at-checkpoint RLCT vs trajectory RLCT (C4)\n5. SGLD noise vs stratum crossing detection (C5)\n6. Finite-n: does lambda_dyn converge to lambda_static as t->inf?\n7. Early stopping as bar_lambda_dyn optimization\n\n## Cross-references\n#482 (SAM, C2 gap origin), #236 (Early Stopping), #394 (SWA), #410 (SGDR), #420 (Lookahead), #213 (LR Scheduling), #386 (Warmup)
