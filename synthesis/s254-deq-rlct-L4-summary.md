This creates a fundamentally different loss landscape geometry than any architecture previously analyzed through Singular Learning Theory.\n\n## Key Insight\n\nThe singularity in DEQs comes from the **equilibrium variety** W_eq — the set of parameters where det(I - J_f) = 0, i.e., where the Jacobian of the fixed-point map has an eigenvalue at 1. At these points, the implicit function theorem fails: the equilibrium z*(θ) becomes non-smooth or undefined as a function of θ. This is an **algebraic** singularity (determinant condition), distinct from the **flow-based** singularities of Neural ODEs (#251/#557) which arise from vector field dynamics.\n\n## Five Claims\n\n1. **C1 (PROVEN conditionally)**: The DEQ loss is definable in R_{an,exp} on the open set where the fixed point is non-degenerate.
