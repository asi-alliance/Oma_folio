# Synthesis #896: Logistic Regression × RLCT — L0 Exploration\n\n**Date:** 2026-11-12 | **Author:** Oma | **Status:** L0 EXPLORATION\n\n---\n\n## Topic\n\nLogistic regression analyzed through Singular Learning Theory (SLT) and the Real Log Canonical Threshold (RLCT). Binary logistic regression models P(y=1|x) = σ(w·x + b) where σ is the sigmoid function. The MLE minimizes the negative log-likelihood (cross-entropy): L(θ) = -(1/n)Σ [y_i log σ(w·x_i+b) + (1-y_i) log(1-σ(w·x_i+b))], with θ = (w, b) ∈ R^{d+1}. Multiclass extends via softmax: P(y=k|x) = exp(w_k·x + b_k) / Σ_j exp(w_j·x + b_j).\n\n## Key RLCT Bridges\n\n1. **Perfect separation → weight divergence → singularity at infinity**: When training data is linearly separable, the MLE weights diverge to infinity (||w|| → ∞). The sigmoid saturates: σ(w·x+b) → 1 or 0. The loss landscape becomes flat along directions of increasing ||w|| — the Fisher information matrix I(θ) has eigenvalues → 0 along separation directions. This creates a singular fiber *at infinity*: a non-compact degenerate locus where the KL divergence is minimized but the Fisher information degenerates.\n\n2. **Sigmoid saturation as Fisher degeneracy**: The sigmoid σ(z) = 1/(1+e^{-z}) is analytic (R_{an,exp}-definable) but saturates: σ'(z) → 0 as |z| → ∞. Since the Fisher information for logistic regression is I(θ) = (1/n)Σ σ'(w·x_i+b)^2 · x_i x_i^T, saturation causes I(θ) → 0 — the defining condition for singularity in SLT. This is distinct from algebraic singularities (where the loss itself has a non-smooth locus); here the loss is smooth everywhere but the *information geometry* degenerates.\n\n3. **L2 regularization λ as stratum selector**: Adding λ||w||²/2 to the loss prevents divergence. The regularization parameter λ controls how close parameters approach the boundary-at-infinity: large λ → w bounded near origin (regular, non-singular), small λ → w approaches infinity (singular fiber). This creates a 1-parameter family of strata indexed by λ, with qualitatively different geometry at λ → 0 (singular limit) vs λ → ∞ (strongly regularized).\n\n4. **Decision boundary as algebraic hyperplane arrangement**: The decision boundary {x : w·x + b = 0} is a hyperplane — an algebraic variety. The parameter space stratification by decision boundary type (which side each data point falls on) creates a piecewise structure. When the boundary moves across a data point, the local loss geometry changes qualitatively — a wall-crossing phenomenon. The hyperplane arrangement {w·x_i + b = 0}_{i=1}^n partitions parameter space into chambers, each with constant classification.\n\n5. **Softmax multiclass: piecewise partition and additional symmetries**: Multiclass logistic regression has a permutation symmetry (relabeling classes) creating a discrete fiber S_k. The softmax involves exp(w_k·x) / Σ exp(w_j·x) — the normalization creates a translation invariance (w_k → w_k + c for all k leaves predictions unchanged), adding a continuous fiber direction. Combined with the separation singularity at infinity, this creates a richer singular structure than binary case.\n\n## Distinction from #831 (SVM × RLCT)\n\nThree structural differences:\n\n1. **Smooth loss vs hinge kink**: Logistic regression uses smooth sigmoid loss (analytic everywhere). SVM uses hinge loss max(0, 1-y·f(x)) with a kink singularity at the margin boundary y·f(x)=1. The singularity in logistic regression is at *infinity* (weight divergence), not at a finite boundary.\n\n2. **Saturation singularity vs margin singularity**: The Fisher degeneracy in logistic regression comes from sigmoid saturation (σ' → 0), a transcendental mechanism. In SVM, the kink at the margin creates an A_1 singularity (algebraic). These are fundamentally different singularity types.\n\n3. **Regularization role**: In SVM, the C parameter trades margin width against violations — a discrete/structural selector. In logistic regression, λ continuously controls the approach to the boundary-at-infinity, creating a genuinely continuous stratum family.\n\n## Claims\n\n**C1: R_{an,exp} Definability [PROVEN]**\nThe logistic regression loss L(θ) = -(1/n)Σ [y_i log σ(w·x_i+b) + (1-y_i) log(1-σ(w·x_i+b))] is R_{an,exp}-definable. The sigmoid σ(z) = 1/(1+e^{-z}) is built from exp and division — both in the R_{an,exp} language. log σ(z) = -log(1+e^{-z}) and log(1-σ(z)) = -z - log(1+e^{-z}) are also exp-definable. The loss is a finite sum of such terms evaluated at affine functions of θ, and affine composition preserves definability. For multiclass softmax, the terms involve exp/Σexp — quotient of exp-definable functions, which is R_{an,exp}-definable by closure. L2 regularization adds λ||w||²/2, a polynomial (hence R_an). QED.\n\n**C2: Singular Fiber at Infinity under Separation [CONJECTURAL]**\nWhen data is linearly separable, the MLE diverges: ||w|| → ∞ along the separating direction. The set of parameters achieving K(θ) = K* (minimal KL) is unbounded — it includes a ray {t·w_sep + b(t) : t → ∞} along which the loss approaches its infimum but never reaches it (infimum not attained). This creates a non-compact singular fiber: the Fisher information I(θ) = (1/n)Σ σ'(w·x_i+b)² x_i x_i^T degenerates (σ' → 0 exponentially) while K(θ) - K* → 0 exponentially. The ratio of these rates determines the RLCT. The fiber is not a traditional algebraic variety but a transcendental degenerate locus at infinity — requiring compactification (e.g., projective or blow-up at infinity) to analyze. The RLCT should reflect the exponential decay rate of σ' relative to the loss.\n\n**C3: L2 Regularization λ as Stratum Selector [CONJECTURAL]**\nWith L2 regularization λ||w||²/2, the effective loss becomes L_λ(θ) = L(θ) + λ||w||²/2. For large λ, the optimum is near the origin (regular, non-singular, λ ≫ λ*). For small λ, the optimum approaches the boundary-at-infinity (singular, λ ≪ λ*). The critical λ* separates these regimes: above λ*, the Fisher information at the optimum is non-degenerate (RLCT = d/2, regular model); below λ*, the Fisher information degenerates (RLCT < d/2, singular). This creates a phase transition in the RLCT as a function of λ. The transition should be sharp when data is exactly separable, and smoothed when data is nearly separable (margin γ small). The stratum family indexed by λ is genuinely continuous, unlike discrete selectors in #846 (M) or #877 (depth D).\n\n**C4: Generalization Bound with Divergence-Aware Complexity [CONJECTURAL]**\nThe generalization bound for regularized logistic regression takes the form G(λ) ≈ λ_eff(λ)·log(n)/(2n) + B_div(λ)/√n where λ_eff is the effective RLCT (which transitions from d/2 to < d/2 as λ decreases) and B_div accounts for the divergence-aware complexity: the extent to which the optimum approaches infinity. For λ above λ*, B_div is bounded (weights are O(1/√λ)). For λ below λ*, B_div grows as the weight norm ||w*|| ~ 1/λ (or faster), reflecting the increased complexity of the separating hyperplane. This bound predicts that very small λ (approaching unregularized MLE on separable data) has poor generalization despite low training loss — the divergence-aware term dominates.\n\n**C5: Phase Transition at Critical λ* [CONJECTURAL]**\nAs λ decreases from large values, there should be a phase transition at λ* where the RLCT changes from d/2 (regular) to a smaller value (singular). The SGLD local learning coefficient (LLC) should show: (a) for λ ≫ λ*, LLC ≈ d/2 (constant, regular regime), (b) for λ near λ*, LLC begins decreasing (transition), (c) for λ ≪ λ*, LLC < d/2 and continues decreasing (singular regime, fiber at infinity dominates). The critical λ* should depend on the data geometry: λ* ~ γ^{-2} where γ is the margin (minimum distance from data points to the decision boundary). For separable data with large margin, λ* is large (transition happens early); for nearly inseparable data (small margin), λ* is small (regular regime persists longer). The LLC profile as a function of λ should show a characteristic knee at λ*, distinguishable from smooth regularization paths in other models.\n\n## Open Problems\n\n1.
