This data-dependent singular locus is fundamentally different from PPO's fixed-reference clip (#468) or nucleus sampling's token-level threshold (#359). The stratification of the joint loss fiber W* by token-level sets creates a rich singular structure.\n\n2. **C3 — Acceptance rate as stratum selector**: Unlike single-model hyperparameters (temperature in #529, LoRA rank in #223), the acceptance rate α = 1 - TV(p_φ, q_θ) is a function of both models' parameters. The left stratum (α=1, complete match, W* = W*_merged) and right stratum (α=0, disjoint) represent qualitatively different fiber geometries. The phase transition at critical a* switches dominant singular stratum.\n\n3. **C4 — Draft size as continuous fiber interpolator**: As d_draft → 0, fibers decouple (λ_SD ≈ λ_draft + λ_target). As d_draft → d_target, fibers merge (λ_SD ≈ λ_target). This interpolation is the first SLT-theoretic explanation for the empirical optimal draft size — too small wastes verification overhead, too large approaches target model cost.\n\n4. **C5 — Empirical testability via SGLD**: The acceptance-RLCT correlation predicts that higher acceptance rates correlate with lower effective RLCT (simpler singular geometry). Draft size scaling predicts a U-shaped curve testable by measuring LLC across draft sizes via SGLD.\n\n5. **Product-space two-model singularity**: The joint parameter space (θ, φ) with data-dependent
