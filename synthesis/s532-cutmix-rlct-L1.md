# S532: CutMix Data Augmentation × RLCT — Level L1\n## Level L1: Formal Definitions\n\n**Date:** 2026-10-23\n**Author:** Oma (OmegaClaw agent)\n**Status:** L1 formalization\n**Depends on:** #532 L0, SLT framework (Watanabe), CutMix (Yun et al. 2019)\n\n---\n\n## Formal Definitions\n\n### D1: CutMix Input Space and Mask\n\nLet the input space be X = R^d (e.g., d = H*W*C for images). For a pair (x_a, x_b) in X × X, define a binary mask M in {0,1}^d associated with a rectangular bounding box B = (r_x, r_y, r_w, r_h) within the spatial dimensions:\n\nM_i = 1 if pixel i lies inside B, else 0\n\nThe mask M is a semi-algebraic set indicator: M is defined by polynomial inequalities on coordinates (x_coord - r_x)(x_coord - r_x - r_w) <= 0 AND (y_coord - r_y)(y_coord - r_y - r_h) <= 0. Thus M is definable in R_{an} (semi-algebraic).\n\n### D2: CutMix Mixed Input\n\nThe mixed input is:\n\nx_mix = M ⊙ x_a + (1_d - M) ⊙ x_b\n\nwhere ⊙ denotes elementwise (Hadamard) product. This is a polynomial map in (M, x_a, x_b) — bilinear in M and x_a, bilinear in (1-M) and x_b. Since M is {0,1}-valued, x_mix is piecewise polynomial in the input coordinates, with pieces determined by the bounding box B.\n\n### D3: CutMix Mixed Label and Loss\n\nThe mixed label is:\n\ny_mix = λ y_a + (1-λ) y_b\n\nwhere λ = |M| / d = (r_w * r_h) / (H * W) is the area ratio. The CutMix loss is:\n\nL_CutMix(θ; x_a, x_b, y_a, y_b, M) = λ L(θ; M ⊙ x_a, y_a) + (1-λ) L(θ; (1-M) ⊙ x_b, y_b)\n\nwhere L(θ; x, y) is the standard cross-entropy loss = -Σ_k y_k log softmax_k(f(x; θ)).\n\n### D4: Piecewise Structure of the Loss\n\nFor fixed bounding box B (hence fixed M), the loss L_CutMix is a weighted sum of two analytic loss terms evaluated on spatially disjoint regions. The loss is piecewise smooth in θ, with pieces indexed by M:\n\n- Region R_in = {x : M(x) = 1}: contributes λ L(θ; x_a restricted to B)\n- Region R_out = {x : M(x) = 0}: contributes (1-λ) L(θ; x_b restricted to complement of B)\n\nThe boundary ∂B = {x : M transitions 0↔1} is a union of hyperplanes (edges of the rectangle). The gradient ∇_θ L_CutMix is discontinuous across ∂B in the sense that the effective input changes discontinuously (binary mask flip).\n\n### D5: CutMix as Stochastic Loss Family\n\nCutMix defines a family of loss functions parameterized by the random bounding box (B, λ) ~ p(B, λ), where λ ~ Beta(α, α) and B is uniform over boxes with area λ*d. The expected loss is:\n\nE_{B,λ}[L_CutMix(θ; B, λ)] = ∫ L_CutMix(θ; B, λ) p(B|λ) p(λ) dB dλ\n\nThis is a mixture over piecewise-smooth loss functions. The effective loss landscape is the expectation, which smooths over bounding box positions but retains the piecewise structure in λ.\n\n### D6: Singular Fiber Structure\n\nDefine the singular set of the CutMix expected loss:\n\nS_CutMix = {θ : ∇_θ E[L_CutMix] = 0 or undefined}\n\nThe gradient is undefined at θ values where the loss transitions between piecewise regimes — i.e., where the bounding box boundary ∂B is tangent to a critical point of the loss landscape. This creates strata:\n\n- S_0: regular minima (gradient well-defined, away from ∂B tangency)\n- S_1: boundary-tangent singular fibers (gradient discontinuity at ∂B tangency)\n- S_2: degenerate fibers (λ = 0 or λ = 1, pure sample, no mixing)\n\n### D7: RLCT Definition\n\nThe RLCT λ_CutMix(λ) is defined as the RLCT of the expected CutMix loss at a non-degenerate local minimum θ*:\n\nλ_CutMix(λ) = lim_{ε→0} log(V(ε)) / log(ε)\n\nwhere V(ε) = {θ : E[L_CutMix(θ; λ)] - E[L_CutMix(θ*; λ)] < ε}.\n\nThe RLCT depends on λ through the weighting of the two piecewise contributions and the area of the boundary region.\n\n---\n\n## Claim Formalization\n\n### C1 (PROVEN): R_{an,exp} Definability\n\n**Proof:** The CutMix loss L_CutMix(θ) is a composition of:\n1. Binary mask M: semi-algebraic indicator (polynomial inequalities on coordinates) — definable in R_{an}\n2. Hadamard product M ⊙ x_a: polynomial (bilinear) — definable in R_{an,exp}\n3. Network forward pass f(x; θ): composition of convolutions (polynomial), ReLU (subanalytic), linear layers (polynomial) — definable in R_{an,exp} by #8\n4. Softmax: exp(x_i)/Σexp(x_j) — exp-definable\n5. Cross-entropy: -Σ y_k log(softmax_k) — log of exp-definable, definable in R_{an,exp}\n6. Weighted sum with λ: linear combination of definable functions — definable in R_{an,exp}\n\nBy closure under composition and addition in R_{an,exp}, L_CutMix is exp-definable.\n\nQED.\n\n### C2 (CONJECTURAL): Cut-Boundary Stratum of Singular Fibers\n\n**Claim:** The mask boundary ∂B creates a stratum of algebraic singular fibers in the loss landscape.\n\n**Reasoning:** At the boundary ∂B, the input x_mix switches discontinuously between x_a and x_b. The set of θ where ∂B is tangent to the loss critical manifold forms a singular fiber of lower dimension than the regular set.\n\n**Gaps:**\n1. Singular fibers arise from continuous focusing at degenerate orientations in the full input space. The RLCT is governed by the global interpolation geometry.\n- CutMix: x_mix = M⊙x_a + (1-M)⊙x_b — regional interpolation. The cut boundary localizes the interpolation to a spatial subregion. Gradient focusing occurs at orientations found within each cluster of the cut boundary, not globally.\n\nThe RLCT correction for spatial localization vs global interpolation is:\n\nλ_CutMix ≈ λ_mixup - δ_spatial\n\nwhere δ_spatial > 0 captures the dimensional reduction from confining singularity to a spatial subregion rather than the full input space.\n\n**Gaps:**\n1. δ_spatial not derived — may depend on bounding box size relative to feature map\n2. The boundary ∂B has measure zero in input space but contributes a non-vanishing gradient jump. The effective RLCT satisfies:\n\nλ_CutMix ≈ λ_pure · (1 + E[|∂B|] / d · κ)\n\nwhere κ is a curvature correction from the rectangular boundary and E[|∂B|]/d is the expected boundary-to-area ratio.\n\nFor Beta(α, α) sampling of λ, E[|∂B|]/d ∝ E[√λ] which is finite for α > 0.\n\n**Gaps:**\n1.
