# Synthesis #856: Mixture of Experts (MoE) × RLCT\n## L1: Formalization\n## Date: 2026-11-06\n\n### Formal Definitions\n\n**D1: MoE Layer Forward Pass**\nGiven input x ∈ R^d, expert networks E_1,...,E_m each E_i: R^d → R^d_out, and gating network g: R^d → R^m:\n\ng(x;θ_g) = softmax(W_g x + b_g), where W_g ∈ R^{m×d}, b_g ∈ R^m\n\nTop-k selection: S(x) = argtop_k(g(x;θ_g)) = {i : g_i(x) ranks in top k}\n\nMoE output: y(x;θ) = Σ_{i∈S(x)} g_i(x;θ_g) · E_i(x;θ_i)\n\n**D2: Gating Boundary Variety**\nFor expert pair (i,j), the gating boundary is:\nB_{ij} = {(x,θ) : g_i(x;θ_g) = g_j(x;θ_g), i ∈ S(x), j ∉ S(x) or j ∈ S(x), i ∉ S(x)}\n\nThis is a semi-algebraic hypersurface in (x,θ) space where the top-k selection is ambiguous. The full boundary variety is:\nB = ∪_{i<j} B_{ij}, with |B| = C(m,k)·(m-k) boundary pairs.\n\n**D3: Piecewise Loss Function**\nThe total loss is piecewise-defined:\nL(θ) = L_task(θ) + α·L_balance(θ)\n\nOn region R_S (where active set S is fixed):\nL_S(θ) = (1/n)Σ_ℓ [ℓ(y(x_ℓ;θ), t_ℓ)] + α·m·Σ_i f_i·P_i\n\nwhere f_i = (1/n)Σ_ℓ 1[i∈S(x_ℓ)], P_i = (1/n)Σ_ℓ g_i(x_ℓ;θ_g)\n\nL is analytic on each R_S (composition of analytic functions), but non-analytic across B_{ij}.\n\n**D4: Capacity Constraint**\nExpert i has capacity C_i = ⌊C·n/m⌋. Tokens exceeding capacity are dropped:\nẼ_i = {tokens routed to i, first C_i by arrival order}\n\nEffective output: y_i(x;θ) = E_i(x;θ_i) if token ∈ Ẽ_i, else 0\n\nCapacity boundary: ∂C_i = {state where expert i exactly at capacity}. This is a discrete (token-count) boundary, creating a piecewise discontinuity in the effective loss.\n\n**D5: Expert Collapse Order Parameter**\nUtilization entropy: H_util(θ) = -Σ_i f_i(θ) log f_i(θ)\n\n- Balanced: H_util ≈ log(m) (uniform routing)\n- Collapsed: H_util ≪ log(m) (few experts dominate)\n\nPhase transition: at step t*, H_util drops discontinuously or with discontinuous derivative.\n\n**D6: Expert Permutation Symmetry**\nThe symmetric group S_m acts on expert parameters: σ·(θ_1,...,θ_m) = (θ_{σ(1)},...,θ_{σ(m)}). The loss is invariant: L(σ·θ) = L(θ). This creates an S_m-orbifold structure in parameter space, analogous to #847 group equivariant but with DISCRETE (not continuous) symmetry.\n\n**D7: Piecewise RLCT**\nOn each region R_S, the zero-loss set V_0 ∩ R_S is an analytic variety. The RLCT λ_S is computed per-region. The global RLCT is:\nλ_MoE = max_S λ_S + λ_boundary + λ_capacity + λ_balance\n\nwhere λ_boundary arises from gating boundary varieties B_{ij}, λ_capacity from capacity boundaries ∂C_i, and λ_balance from load-balancing constraint fibers.\n\n### Claim Formalization\n\n**C1 (PROVEN): Piecewise R_{an,exp} Definability**\n- On each R_S: L_S is a composition of softmax (analytic), linear maps (analytic), and expert networks (analytic if E_i uses analytic activations). L_balance is polynomial in f_i, P_i. Thus L_S ∈ R_{an,exp}.\n- Top-k selection is piecewise constant (indicator functions), making L piecewise R_{an,exp}.\n- RLCT applies per piece via Watanabe's theorem on each R_S.\n- Capacity boundary (hard token limit) introduces a non-analytic discontinuity. If modeled as a step function, this is subanalytic but not R_{an,exp}. The global loss is piecewise R_{an,exp} with subanalytic capacity boundaries.\n- **Verdict**: C1 PROVEN with caveat (subanalytic capacity boundary).\n\n**C2 (CONJECTURAL): Gating Boundary Singular Fiber**\nAt (x,θ) ∈ B_{ij}: g_i = g_j and the pair straddles the k/k+1 threshold. Since L_balance is polynomial, λ_balance = (m-1) (heuristic: codim/2).\n\nCompound generalization bound:\nG_MoE(n) ≤ [λ_task + λ_balance]·log(n)/(2n) + V(k,m)/√n\n\nwhere V(k,m) captures the complexity of the top-k selection combinatorics. Trade-off: increasing α increases λ_balance (higher RLCT) but prevents expert collapse (lower λ_task by maintaining expert diversity).\n\n**C4 (CONJECTURAL): Capacity-Limited Singular Fiber**\nWhen expert i is at capacity C_i, the effective loss has a discontinuity: tokens beyond C_i contribute zero.
