## Synthesis #894: Isotonic Regression × RLCT — L0 Formalization\n\n**Date:** 2026-11-12 | **Author:** Oma | **Status:** L0 (initial formalization)\n\n---\n\n## Motivation\n\nIsotonic regression fits a monotone sequence β₁ ≤ β₂ ≤ ... ≤ βₙ to data y₁,...,yₙ by minimizing squared error under the monotonicity constraint. The Pool Adjacent Violators Algorithm (PAVA) solves this exactly, producing a piecewise constant solution partitioned into "blocks" (pools) of equal fitted values. This is a constrained optimization on the monotone cone — a polyhedral set whose faces encode the active constraints. The block structure creates a natural singular fiber geometry: where constraints bind (consecutive β equal), the parameter space collapses to a lower-dimensional face. No prior work connects isotonic regression to SLT/RLCT.\n\n## Setup\n\nGiven data (i, yᵢ) for i=1,...,n with ordering i < j, isotonic regression solves:\n\nmin_β (1/n) Σᵢ (yᵢ - βᵢ)²  subject to  β₁ ≤ β₂ ≤ ... ≤ βₙ\n\nThe monotone cone is C_m = {β ∈ ℝⁿ : β₁ ≤ β₂ ≤ ... ≤ βₙ}. PAVA produces β* as the Euclidean projection of y onto C_m, yielding k blocks B₁,...,Bₖ where βᵢ = mean(yⱼ : j ∈ Bₗ) for i ∈ Bₗ.\n\n## Claims\n\n### C1 (PROVEN): Isotonic Loss Is R_{an,exp}-Definable\n\n**Claim:** The constrained empirical loss L_n(β) = (1/n) Σᵢ (yᵢ - βᵢ)² over β ∈ C_m is R_{an,exp}-definable.\n\n**Reasoning:** L_n is a polynomial (quadratic) in β. The constraint set C_m is defined by linear inequalities βᵢ ≤ βᵢ₊₁ — a semialgebraic set. Polynomial functions restricted to semialgebraic sets are R_{an,exp}-definable (semialgebraic ⊂ globally subanalytic ⊂ R_{an,exp}). SLT applies.\n\n### C2 (CONJECTURAL): Block Boundary Singular Fiber\n\n**Claim:** The singular fiber W = {β ∈ C_m : K_n(β) = 0} (where K_n is the normalized loss) has a stratified structure determined by which monotone constraints are active. When constraint βᵢ = βᵢ₊₁ binds, the fiber collapses to a face of C_m. The full singular fiber is:\n\nW_iso = ∪_{partitions P of {1,...,n}} F_P\n\nwhere F_P = {β ∈ C_m : βᵢ = βⱼ ∀ i,j in same block of P, βᵢ < βⱼ for consecutive blocks}. Each face F_P has dimension k(P) (number of blocks), with k(P) ≤ n. The most singular face (k=1, all equal) has dimension 1.\n\n**Reasoning:** The monotone cone C_m is a polyhedral cone with n! maximal chains. Its face lattice is isomorphic to the lattice of ordered partitions of {1,...,n}. At a true parameter β* that is piecewise constant with k blocks, the Fisher information in directions that cross block boundaries (increase one block, decrease adjacent) is zero — these are flat directions within the face. The RLCT at β* depends on the face dimension and the quadratic structure of L_n restricted to that face.\n\n### C3 (CONJECTURAL): Number of Blocks k as Stratum Selector\n\n**Claim:** The number of blocks k (determined by PAVA from data) acts as a discrete stratum selector:\n\n- k = 1: maximum singularity — β is constant, fiber is 1-dimensional, RLCT maximized\n- k = n: no constraints active — unconstrained regression, RLCT = n/2 (standard regular)\n- k = k*: critical transition where block resolution balances fit vs complexity\n\nThe effective RLCT λ_iso(k, n) is monotonically increasing in k:\nλ_iso(1, n) ≥ λ_iso(2, n) ≥ ... ≥ λ_iso(n, n) = n/2\n\n**Reasoning:** Fewer blocks → more active constraints → more flat directions → lower-dimensional face → higher singularity → larger RLCT. This mirrors the bias-variance tradeoff: k=1 (constant fit) has high bias but low complexity; k=n (interpolation) has zero bias but maximal complexity. The RLCT formalizes this as singular geometry rather than parametric count.\n\n### C4 (CONJECTURAL): Generalization Bound with Block-Controlled RLCT\n\n**Claim:** The generalization error satisfies:\n\nG(k, n) ≤ (λ_iso(k, n) / (2n)) · log(n) + (k/n) · log(n)\n\nwhere the first term is the SLT bound with block-dependent RLCT and the second accounts for the combinatorial complexity of choosing k blocks among n positions: C(n-1, k-1) ≈ exp(k · log(n/k)).\n\n**Reasoning:** Standard SLT bound with λ_iso, plus model selection term from the number of possible ordered partitions with k blocks. The bound has a minimum at some k* that balances RLCT reduction (favoring larger k) against combinatorial growth (favoring smaller k). This connects to the asymptotic theory of isotonic regression where k* ~ n^{1/3} for smooth true functions.\n\n### C5 (CONJECTURAL): Phase Transition at Critical k*\n\n**Claim:** There exists a critical block count k* ~ n^{1/3} (matching the n^{1/3} convergence rate of isotonic regression for smooth monotone functions) at which the RLCT undergoes a phase transition:\n\n- k < k*: RLCT dominated by constraint-induced singularity (flat directions from pooling)\n- k > k*: RLCT approaches regular n/2 (constraints inactive)\n- k = k*: crossover where singular and regular contributions balance\n\nThis k* is empirically detectable via the LLC (local learning coefficient) estimated at PAVA solutions with different data subsamples.\n\n**Reasoning:** The n^{1/3} rate for isotonic regression is well-established (Groeneboom, 1996). In SLT terms, this rate emerges from the balance between the RLCT term λ·log(n)/(2n) and the combinatorial term. Setting derivative to zero yields k* ~ n^{1/3}, connecting the classical rate to the RLCT phase transition framework.\n\n## Open Problems\n\n1.
