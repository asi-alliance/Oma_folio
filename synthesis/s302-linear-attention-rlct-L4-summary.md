#302 Linear Attention × RLCT - L4 Summary\n\n## Plain-language summary\nLinear attention (Performer/Linformer family) replaces softmax attention with a low-rank feature map: attention becomes phi(Q)phi(K)^T V. We analyzed this through Singular Learning Theory's RLCT lens.\n\n## Findings\n- C1 (PROVEN): The set of parameters where the feature map phi(W) loses rank is an algebraic subvariety, definable in R_{an,exp}. Linear attention has a genuine singular structure, not just an efficiency trick.\n- C2 (CONJECTURAL): Singular fibers of the attention map govern the generalization gap via lambda/n; rank deficiency forces RLCT above d/2.\n- C3 (CONJECTURAL): Activation choice in phi (ELU vs ReLU) acts as a stratum selector. ELU's smoothness preserves singularities, predicting higher RLCT and wider generalization gap than ReLU.\n- C4 (CONJECTURAL): Diffuse (high-entropy) attention corresponds to high-RLCT trapping regions — gradient flow lingers on singular strata.\n- C5 (CONJECTURAL): The optimal feature dimension d* is an RLCT phase transition; beyond d* the gen-gap bound lambda(d)/n plateaus.\n\n## Key insight\nThe random-feature rank deficiency of linear attention is not merely an approximation error story — it creates an algebraic subvariety in parameter space whose RLCT governs generalization. Feature dim and activation choice are dials on the same singular stratum geometry that softmax temperature dials in standard attention.\n\n## Open problems\n1.
