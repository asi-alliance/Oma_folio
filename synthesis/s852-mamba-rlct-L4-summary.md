# Synthesis #852: Mamba (Selective State Space Model) × RLCT\n## L4: Executive Summary\n## Date: 2026-11-06\n\n### Overview\nThis synthesis bridges Mamba (Gu & Dao, 2023), a selective state space model that replaces attention with input-dependent gating, with Watanabe's Real Log Canonical Threshold (RLCT) from Singular Learning Theory. The key innovation is identifying that Mamba's selective mechanism — the input-dependent step size dt(x) = softplus(W_dt · x) — creates a singular fiber that VARIES WITH INPUT, breaking the standard RLCT assumption of a fixed singular locus V(θ).\n\n### Claims Summary\n\n**C1 (PROVEN): R_an,exp Definability**\nMamba's loss function is definable in the restricted analytic/exponential class. ZOH discretization uses matrix exponential (analytic), matrix inverse (rational on dense open set), softplus (analytic), and linear projections (polynomial). All closed under composition. This is standard but establishes the formal foundation.\n\n**C2 (CONJECTURAL): Input-Dependent Singular Fiber V_sel(x)**\nThe star contribution. V_sel(x) = {θ : dt(x_t) → 0 or dt(x_t) → ∞ for some t}. When dt→0, the state transition matrix Ā→I (state freezes, information accumulates without compression). When dt→∞, Ā→0 (memoryless reset). Crucially, this fiber DEPENDS ON INPUT x — different data points activate different singular strata. This requires extending the RLCT framework from V(θ) to V(θ,x).\n\n**C3 (CONJECTURAL): Selectivity as Stratum Selector**\nSelectivity metric s = Var[dt(x)]/E[dt(x)] governs the singular structure. At s→0, Mamba reduces to a non-selective SSM with fixed GL(d) gauge degeneracy. At s>0, the input-dependent fiber family emerges, breaking the gauge symmetry (since exp(dt·P⁻¹AP) ≠ P⁻¹exp(dt·A)P for varying dt). A phase transition at critical s* shifts from fixed-fiber to input-dependent-family geometry.\n\n**C4 (CONJECTURAL): Selectivity-Dependent Generalization Bound**\nG_mamba(s) ~ λ_mamba(s)/(2n)·log(n) + U_mamba(s)/√n. As selectivity increases: λ increases (richer singular family) while U decreases (selective compression reduces effective hypothesis space). Optimal s* minimizes the bound — a trade-off between singular complexity and compression benefit.\n\n**C5 (CONJECTURAL): Selectivity Phase Transition**\nAt training iteration t* ~ log(n), the model transitions from uniform dt to input-dependent dt. SGLD should detect this via an LLC kink and Fisher information rank increase as dt(x) develops input dependence.\n\n### Star Contribution\n**Input-dependent singular fiber V_sel(x)** — the singular locus itself is a function of the data point. This is the first formalization in the synthesis folio of a singular fiber that varies across the data distribution, requiring extension of Watanabe's framework from V(θ) to V(θ,x). This conceptually advances beyond #233 (parameter-space fixed fibers) and #580 (piecewise branch singularity).\n\n### Distinction from Prior Mamba Syntheses\n- #233: Parameter-space claims about fixed fibers (gating saturation, GL(d) gauge). #852 introduces V(θ,x) — data-dependent singular structure.\n- #580: Piecewise-definable branch-switch singularity. #852's fiber varies per-input, not per-branch-threshold.\n- #825b (Titans): Path-dependent fiber (temporal sequence). #852 is pointwise per-input (varies across data distribution).\n\n### Open Problems\n1.
