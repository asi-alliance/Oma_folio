The monotone cone is the polyhedral set:\n\nC_m = {β ∈ ℝⁿ : β₁ ≤ β₂ ≤ ... ≤ βₙ} = {β : Aβ ≥ 0}\n\nwhere A ∈ ℝ^{(n-1)×n} is the difference matrix A_{i,i} = -1, A_{i,i+1} = 1, A_{ij} = 0 otherwise. C_m is a pointed polyhedral cone with n extreme rays (the unit vectors e_i accumulated: r_k = Σ_{j≥k} e_j).\n\n### D2: Empirical Loss and True Distribution\n\nThe empirical loss is:\n\nL_n(β) = (1/n) Σᵢ (yᵢ - βᵢ)²\n\nThe true distribution assumes y = f* + ε where f* ∈ C_m is monotone and ε ~ N(0, σ²I). The PAVA solution β* = Π_{C_m}(y) (Euclidean projection onto C_m) minimizes L_n over C_m.\n\nThe normalized loss (KL divergence from truth) is:\n\nK_n(β) = (1/2n) Σᵢ (βᵢ - f*ᵢ)²  for β ∈ C_m\n\nThe singular fiber is W = {β ∈ C_m : K_n(β) = 0} = {f*} when f* is strictly monotone, but degenerates when f* has flat blocks.\n\n### D3: R_{an,exp}-Definability (C1 PROVEN)\n\n**Claim C1:** L_n restricted to C_m is R_{an,exp}-definable.\n\n**Proof:** L_n is a polynomial in β. The constraint set C_m = {β : β₁ ≤ β₂ ≤ ... ≤ βₙ} is defined by finitely many linear inequalities, hence semialgebraic. By the van den Dries theorem, semialgebraic sets are globally subanalytic, and globally subanalytic sets are R_{an,exp}-definable. The restriction of a polynomial to an R_{an,exp}-definable set is R_{an,exp}-definable. SLT applies. ∎\n\n### D4: Face Lattice and Singular Fiber Structure\n\nThe face lattice L(C_m) of the monotone cone is isomorphic to the lattice of ordered partitions of {1,...,n}:\n\n- Each face F_P corresponds to an ordered partition P = (B₁, B₂, ..., B_k) where blocks are consecutive: B₁ = {1,...,b₁}, B₂ = {b₁+1,...,b₂}, ..., B_k = {b_{k-1}+1,...,n}\n- dim(F_P) = k (number of blocks)\n- F_P = {β ∈ C_m : βᵢ = βⱼ ∀ i,j ∈ B_l for each l, and β_{B_l} < β_{B_{l+1}} for each l}\n- The minimal face (k=1): F_{(n)} = {β : β₁ = β₂ = ... = βₙ}, dim = 1\n- The maximal face (k=n): F_{(1,...,1)} = int(C_m), dim = n\n\n**Singular fiber when f* has k* blocks:**\n\nW_iso = {β ∈ C_m : K_n(β) = 0} = F_{P*}\n\nwhere P* is the ordered partition induced by f*. At β* = f*, the Fisher information matrix I(β*) has rank k* (only block-level directions have nonzero curvature). The n - k* within-block directions are flat (zero eigenvalues).\n\n**RLCT computation for k=1:**\n\nWhen f* is constant (k=1), W = {β : β₁ = ... = βₙ = c} is 1-dimensional.
