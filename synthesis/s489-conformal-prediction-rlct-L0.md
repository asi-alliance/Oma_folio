# Synthesis #489: Conformal Prediction × RLCT\n## L0: Exploration\n\n**Date:** 2026-10-21\n\n### Topic\n\nConformal Prediction (CP) × Real Log Canonical Threshold (RLCT)\n\n### Background\n\nConformal prediction provides distribution-free coverage guarantees under exchangeability. The nonconformity score A(x,y;θ) measures how unusual a sample is under the model. Coverage 1-α is guaranteed by the exchangeability of calibration scores. When exchangeability breaks (distribution shift, non-iid data), coverage degrades.\n\n### Key RLCT Bridge\n\nThe nonconformity score function A: (X,Y)×Θ → ℝ defines level sets V_t = {θ : A(x,y;θ) = t} in parameter space. The empirical α-quantile of calibration scores selects a threshold t_α, and the prediction set is {y : A(x,y;θ) ≤ t_α}. The coverage function C(α,θ) = P(Y ∈ Ŷ_α(X;θ)) has a non-smooth transition when exchangeability breaks — this is the singularity.\n\n### Five Claims\n\n**C1 (PROVABLE):** The nonconformity score A(x,y;θ) is definable in R_{an,exp} when the underlying model is a neural network (softmax + CE + polynomial operations). The quantile function and indicator are semialgebraic/set-theoretic operations preserving definability.\n\n**C2 (CONJECTURAL):** The true parameter set W contains level-set varieties V_{t_α} = {θ : q_α(A_cal;θ) = t_α} where q_α is the empirical α-quantile. These level-set varieties are algebraic singularities in Θ. The RLCT of the loss landscape near W is governed by the geometry of these level sets.\n\n**C3 (CONJECTURAL):** The calibration set size n_cal acts as a stratum selector — as n_cal increases, the quantile t_α concentrates, stratifying the fiber. The RLCT λ(n_cal) decreases monotonically: more calibration data → less singular coverage boundary.\n\n**C4 (CONJECTURAL):** Generalization bound: the coverage gap |E[C(α)] - (1-α)| is controlled by λ_CP·log(n_cal)/(2·n_cal), where λ_CP is the RLCT of the nonconformity level-set variety. Exchangeability breakdown increases λ_CP, widening the gap.\n\n**C5 (CONJECTURAL):** Phase transition: at a critical distribution shift δ*, exchangeability breaks and the coverage function transitions from smooth (guaranteed) to singular (degraded). This is detectable via SGLD on the nonconformity score landscape.\n\n### Connection to Double Descent\n\nAt the interpolation threshold, calibration scores become degenerate (all training points fit perfectly), creating a peak in λ_CP — this connects to the double descent calibration degradation phenomenon.\n\n### Cross-References\n#224 (Label smoothing desingularization — smooths the nonconformity score), #480 (muP hyperparameter transfer — transfers calibration across scale), #488 (Copula — joint dependence affects exchangeability), #8 (Softmax definability), #16 (Attention parameter sharing — affects nonconformity score)\n\n### Open Problems\n1.
