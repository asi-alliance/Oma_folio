#582: Curriculum Learning x RLCT - L1 Formalization\nDate: 2026-10-24\nStatus: L1 (formal definitions)\n\n## Formal Definitions\n\nD1 (Pace Function): p: [0,inf) -> [0,1] monotone non-decreasing, p(0)=0, p(inf)=1. At time t, model trains on D_{p(t)} = {x in D : difficulty(x) <= F^{-1}(p(t))} where F = CDF of difficulty distribution.\n\nD2 (Curriculum Loss): L_n(w,t) = (1/|D_{p(t)}|) sum_{x in D_{p(t)}} l(w,x). As t->inf, L_n(w,t) -> L_n(w) full empirical loss. At finite t, restricted to easier examples.\n\nD3 (R_an,exp Definability): L_n(w,t) = (1/n_t) sum_{i: d_i <= theta(t)} l(w,x_i), theta(t) = F^{-1}(p(t)). If l(w,x) is R_an,exp-definable in w and indicator {d_i <= theta(t)} is fixed per t, then L_n(w,t) is finite sum of R_an,exp-definable functions, hence R_an,exp-definable in w for each fixed t. (C1 PROVEN)\n\nD4 (Difficulty-Stratified Singular Fiber): S_d = {w in W : KL(q(w)||p(w)) has local RLCT lambda_d} where lambda_d is RLCT restricted to data of difficulty <= d. lambda_d non-decreasing in d. Stratum chain S_{d1} subset S_{d2} for nested curricula.\n\nD5 (Pace-Stratified Loss Family): {L_n(w,t)}_{t>=0} is 1-parameter family. RLCT lambda(t) = lambda_{theta(t)} is non-decreasing since theta(t) monotone. Model encounters progressively higher-RLCT strata.\n\nD6 (Generalization Bound): G(t) ~ lambda(t)/(n*p(t)) + U(t)/sqrt(n*p(t)) by SLT free energy. Compared to random G ~ lambda_full/n + U_full/sqrt(n), curriculum gives transient G(t) <= G_full when lambda(t) < lambda_full and n*p(t) large enough.\n\nD7 (Critical Pace Phase Transition): Critical pace p*(t) = fastest monotone function s.t. model settles in S_{theta(t)} before advancing: tau_settle(lambda(t)) <= 1/p_dot(t) * Delta_theta. When p_dot(t) > p*_dot(t), curriculum collapse - skips strata without settling. Phase transition at p* separates beneficial (p < p*) from ineffective (p >= p*).\n\n## Claims Summary\nC1 PROVEN: R_an,exp definability via finite sum with fixed data selection (D3).\nC2 CONJECTURAL: Ordered RLCT descent - easy-to-hard induces lambda(t) non-decreasing trajectory (D4, D5).\nC3 CONJECTURAL: Curriculum collapse when pace exceeds p* (D7).\nC4 CONJECTURAL: Anti-curriculum enters high-lambda strata first, suboptimal for nested singularities (D4).\nC5 CONJECTURAL: Optimal curriculum minimizes total RLCT descent integral (D6, D7).\n\n## Open Problems\n1.
