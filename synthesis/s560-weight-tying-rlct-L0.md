#560 Weight Tying × RLCT — L0 Hypothesis (2026-10-23)\n\n## Topic\nWeight tying (tied embeddings): sharing input embedding matrix W_emb and output projection matrix W_out = W_emb^T (or W_out = W_emb) in language models. The same parameter matrix appears in two distinct functional roles.\n\n## Key Insight\nWeight tying creates a non-injective identification map: a single parameter point (W_emb) maps to two distinct locations in the model's forward pass (input lookup + output projection). This constrains the parameter space to a quotient-like submanifold where the input and output representations are forced to coincide. The singular set of the tied model is the intersection of the singular sets of the untied input and output embeddings — a stricter condition that may either increase or decrease the RLCT depending on the alignment of the two singular structures.\n\n## Claims\n\n**C1 (PROVEN):** The tied model's loss function K(w) = L(f_w(x), y) where f_w uses w in two positions is R_an-definable. The tying map phi: w -> (w, w) is a polynomial (linear) map, and composition of analytic maps with polynomial maps preserves R_an-definability. The KL divergence of the tied model is thus definable in the o-minimal structure R_an,exp. \n\n**C2 (CONJECTURAL):** Weight tying restricts the parameter space to a diagonal submanifold Delta = {(W_in, W_out) : W_in = W_out} inside the full parameter space. The singular set of the tied model is the intersection of the untied singular set with this diagonal. When the input and output singular structures are transversal, the intersection has higher codimension → higher RLCT (harder to learn, less compression). When they align, the intersection preserves the singularity → RLCT unchanged or lower. The expected case is transverse intersection → tying INCREASES RLCT slightly.\n\n**C3 (CONJECTURAL):** There exists a critical embedding dimension d* at which the benefit of parameter reduction (fewer parameters → lower complexity) exactly balances the RLCT increase from diagonal constraint. Below d*, tying helps generalization (parameter savings dominate). Above d*, tying hurts (RLCT penalty dominates). This predicts an optimal tying dimension d* ~ O(vocabulary_size^{1/2}).\n\n**C4 (CONJECTURAL):** The generalization bound for the tied model takes the form: G_tied <= lambda_tied * log(n) / (2n) + b_tied / sqrt(n), where lambda_tied >= lambda_untied (RLCT increases) but the effective parameter count d_tied < d_untied (fewer free parameters). The net effect depends on the ratio lambda_tied / d_tied vs lambda_untied / d_untied. For typical LLMs, parameter savings (~50% of embedding params) dominate the modest RLCT increase, explaining the empirical success of weight tying.\n\n**C5 (CONJECTURAL):** Phase transition: as the model trains and descends to lower-RLCT strata, the diagonal constraint from tying may prevent descent into the deepest singular stratum if that stratum requires W_in != W_out. The tied model gets stuck at a higher-RLCT stratum that admits W_in = W_out. This predicts that very large models may benefit from untying late in training to access deeper singular strata — consistent with practice of untying embeddings in large-scale LLMs.\n\n## Distinction from Prior Syntheses\n- #223 LoRA: Low-rank constraint on weight matrices (rank restriction), not parameter sharing across positions\n- #222 BatchNorm: Normalization creates reparameterization orbits, not diagonal constraints\n- #505 Weight Normalization: Scale-direction decomposition with ||v||=0 singularity, not parameter sharing\n- #169 Dropout: Stochastic masking creates mixture strata, not deterministic parameter sharing\n- #433 Weight Decay: L2 penalty shifts singular locus, not quotient constraint\n- #240: Checked — no weight tying coverage found\n\n## Open Problems\n1.
