#669: Persistent Homology x RLCT\n\n## L1: Formalization\n\n### Definitions\n\n**D1 (Sublevel Set Filtration)**\nLet L_n: Theta -> R_{\geq 0} be the empirical KL loss on parameter space Theta \subset R^d. Define the sublevel set filtration {F_t}_{t \geq 0} by:\n  F_t = { w \in Theta : L_n(w) \leq t }\nThis is a nested family F_{t1} \subseteq F_{t2} for t1 \leq t2, giving a filtration of Theta by loss level sets.\n\n**D2 (Persistence Diagram)**\nFor each homology dimension p \geq 0, the persistent homology of the filtration {F_t} yields a persistence diagram Dgm_p(L_n) \subset R^2, where each point (b, d) represents a p-dimensional topological feature born at filtration value b and dying at filtration value d. Points with d - b large are persistent; points near the diagonal d = b are ephemeral. Dgm_p is a multiset (features can have identical birth-death pairs).\n\n**D3 (Bottleneck Distance)**\nFor two persistence diagrams Dgm, Dgm', the bottleneck distance is:\n  d_B(Dgm, Dgm') = inf { \epsilon \geq 0 : exists matching \mu: Dgm -> Dgm' s.t. max over all matched pairs of ||(b,d) - (b',d')||_\infty \leq \epsilon, and all unmatched points are within \epsilon of the diagonal }\nThis is the standard metric on persistence diagrams.\n\n**D4 (Persistence Stability)**\nThe persistence stability theorem (Cohen-Steiner, Edelsbrunner, Harer 2007) states that for tame functions f, g: X -> R on a topological space X:\n  d_B(Dgm_p(f), Dgm_p(g)) \leq ||f - g||_\infty\nThis means small perturbations of the loss function yield small perturbations of the persistence diagram.\n\n**D5 (Singular Stratum Fiber)**\nFollowing Watanabe, define the singular fiber V(epsilon) = { w \in Theta : L_n(w) - L_n^* \leq epsilon } where L_n^* = min_w L_n(w). The RLCT lambda governs:\n  Vol(V(epsilon)) ~ C * epsilon^lambda as epsilon -> 0\nThe singular strata are the subsets of V(0) where the Fisher information matrix degenerates (rank drops). These are the loci where standard asymptotic theory fails.\n\n**D6 (Birth-Death Pair as Stratum Signature)**\nA birth-death pair (b_i, d_i) in Dgm_p(L_n) is said to correspond to a singular stratum S_k if:\n- b_i approximates the loss threshold at which S_k first enters the sublevel set F_t\n- d_i approximates the loss threshold at which S_k becomes topologically trivial (filled in by higher-dimensional features)\nThe persistence p_i = d_i - b_i measures the topological stability of stratum S_k across the filtration.\n\n**D7 (Filtration Parameter as Stratum Selector)**\nThe filtration parameter t serves as a stratum selector: as t decreases from L_n^max toward L_n^*, the sublevel set F_t intersects progressively lower-dimensional and more singular strata. For t near L_n^*, F_t is dominated by the most singular strata. The function t -> dim(H_p(F_t)) tracks how each homology dimension responds to stratum selection by loss level.\n\n### Claims\n\n**C1 (PROVEN, stv 1.0 0.95): Persistence Diagrams are Well-Defined**\nFor standard neural network losses (analytic activation functions, polynomial/cross-entropy loss), L_n is R_an-definable. By Morse theory for generic (Morse-generic) perturbations of L_n, the sublevel set filtration has finitely many critical values, guaranteeing that Dgm_p(L_n) is a finite multiset for each p. The persistence diagram is a well-defined topological invariant of the sublevel set filtration.\n\n**C2 (CONJECTURAL, stv 0.5 0.9): Singular Strata Create Persistent Features**\nSingular strata of V(0) (where Fisher information degenerates) create persistent homology features in Dgm_p(L_n). The birth time of each feature corresponds to the stratum's activation threshold (the loss value at which the stratum enters the sublevel set), and the death time corresponds to the loss value at which the stratum is topologically filled by the surrounding sublevel set. Long-persisting features indicate stable singular strata that resist topological trivialization.\n\n**C3 (CONJECTURAL, stv 0.5 0.9): Filtration Parameter as Stratum Selector**\nThe filtration parameter t acts as a continuous stratum selector. As t decreases toward L_n^*, F_t intersects progressively lower-dimensional strata. Each dimension drop creates a characteristic birth-death pattern: a stratum of codimension k contributes features primarily in homology dimensions p \leq k. The sequence of birth-death events as t decreases encodes the singular stratification of the loss landscape.\n\n**C4 (CONJECTURAL, stv 0.5 0.9): Persistence-Aware Generalization Bound**\nThe Watanabe generalization bound G ~ lambda/n + U/sqrt(n) can be refined using persistence stability. Under the empirical-to-true loss perturbation L_n -> L (population loss), persistence stability gives:\n  d_B(Dgm_p(L_n), Dgm_p(L)) \leq ||L_n - L||_\infty\nThis bounds the topological perturbation of the loss landscape. The refined bound takes the form:\n  G_persist ~ lambda/n + U/sqrt(n) + f(d_B(Dgm_p(L_n), Dgm_p(L)))\nwhere f captures the topological contribution. For stable landscapes (small bottleneck distance), f is small and the standard bound dominates. For topologically unstable landscapes, f adds a correction term.\n\n**C5 (CONJECTURAL, stv 0.5 0.9): Phase Transition at Critical Filtration Value**\nThere exists a critical filtration value t* such that crossing t* changes the topological type of the sublevel set F_t (e.g., connected to disconnected, or loop creation/destruction). This t* corresponds to an RLCT stratum transition: the point at which the dominant singular stratum changes. Near t*, the Betti number function t -> beta_p(F_t) has a discontinuity, and the persistence diagram has a birth or death event. The phase transition t* is predicted to scale as t* ~ L_n^* + C/n^alpha for some alpha related to lambda.\n\n### Open Problems\n1. **Computability of Dgm_p for high-dimensional Theta**: Persistent homology is computationally expensive in high dimensions. Can dimensionality reduction (PCA, random projection) preserve the relevant topological features of the loss landscape filtration?\n2. **Relationship between lambda and birth distribution**: Is there a closed-form expression relating RLCT lambda to the distribution of birth times in Dgm_0 near L_n^*?\n3. **Morse function genericity**: Standard NN losses are not Morse-generic. How does the persistence diagram change under Morse-generic perturbation, and does this lose information about the singular strata?\n4. **Empirical estimation of bottleneck distance**: Can d_B(Dgm_p(L_n), Dgm_p(L)) be estimated from finite samples without computing the population loss landscape?\n5. **Higher-dimensional features**: Do H_p features for p \geq 2 carry RLCT-relevant information, or is H_0 (and possibly H_1) sufficient?\n6. **Connection to #666 ECC**: Is the ECC curve a sufficient statistic for RLCT estimation, or do individual persistence features carry additional information? Can this be tested empirically?\n7. **Activation function dependence**: Prior TDA work showed tanh and ReLU have identical H1 topology but different RLCT volume slopes. Does persistence diagram structure differ between activation functions even when Betti numbers match?\n\n### Cross-References\n- #666 ECC x RLCT (Euler characteristic curve as global topological invariant vs individual persistence features)\n- #8 Foundational RLCT framework\n- #16 Watanabe RLCT generalization bound\n- tda_loss_h1.py (empirical H1 persistence on 80-point ReLU loss landscape, 82160 pairs, max persistence 0.7614)\n- tda_singularity_tool.py (union-find H0 detection on loss landscape point clouds)\n- Four-eye TDA v0.2 (Betti0 + H1 + RLCT volume slope + spectral gap)\n- TDA-on-real-MLP (sublevel-set RLCT lambda=0.0309 on tanh MLP)\n- Cohen-Steiner, Edelsbrunner, Harer (2007): Persistence stability theorem\n- Edelsbrunner, Harer (2010): Computational Topology textbook (persistence diagrams, bottleneck distance)\n- Watanabe (2009): Algebraic Geometry and Statistical Learning Theory (RLCT, singular fibers)\n- Carlsson (2009): Topology and data (persistent homology overview)
