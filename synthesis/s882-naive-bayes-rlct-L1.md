# Synthesis #882: Naive Bayes × RLCT — L1 Formalization\n\n**Date:** 2026-11-09 | **Status:** L1 (formalization)\n\n---\n\n## Definitions\n\n### D1: Feature Space and Class Labels\nK classes Y = {1, ..., K}.\nFor discrete NB: d features, each with domain V_j = {v_{j,1}, ..., v_{j,m_j}}.\nFeature vector x = (x_1, ..., x_d), x_j in V_j.\nFor Gaussian NB: x_j in R, parameters (mu_{j,y}, sigma^2_{j,y}).\n\n### D2: Naive Bayes Model Distribution\nUnder conditional independence:\np_w(x, y) = pi_y * prod_{j=1}^d P(x_j | y)\n\nDiscrete NB parameters: w = {(pi_y, P(.|y))_{y=1}^K} where pi in Delta_K and P(.|y) in Delta_{m_j} for each (j,y).\nParameter space: W_NB = Delta_K x prod_{y=1}^K prod_{j=1}^d Delta_{m_j}\nDimension: d_NB = (K-1) + K * sum_j (m_j - 1)\n\nGaussian NB parameters: w = {(pi_y, mu_{j,y}, sigma^2_{j,y})}_{y,j}\nDimension: d_NB^G = (K-1) + K * d * 2 (mean + variance per feature-class pair)\n\n### D3: Factorized KL Divergence\nKL(q || p_w) = E_q[log q(x,y) / p_w(x,y)]\n= E_q[log(q(y)/pi_y)] + sum_{j=1}^d E_q[log(q(x_j|y) / P(x_j|y))]\n= KL(q(y) || pi) + sum_{j=1}^d KL(q(x_j|y) || P(x_j|y))\n\nThe zero-loss variety is the intersection:\nV_0 = {w in W_NB : KL(q(y)||pi) = 0} cap cap_{j=1}^d {w : KL(q(x_j|y)||P(x_j|y)) = 0}\n\n### D4: Zero-Count Feature Fiber\nFor discrete NB with MLE:\nP_MLE(x_j=v | y) = N(x_j=v, y) / N(y)\n\nZero-count set: Z_0 = {(v, j, y) : N(x_j=v, y) = 0}\nFor (v, j, y) in Z_0, the parameter P(v | j, y) is unconstrained by data.\nFree fiber dimension per zero-count: 1 (one simplex coordinate).\n\nV_0^{free} = {w : for all (v,j,y) in Z_0, P(v|j,y) arbitrary in [0,1]}\ndim(V_0^{free}) = |Z_0|\n\n### D5: Laplace Smoothing as Desingularization\nAdd-alpha smoothing:\nP_alpha(v | j, y) = (N(v,j,y) + alpha) / (N(y) + alpha * m_j), alpha > 0\n\nDenominator N(y) + alpha*m_j > 0 for all y, j. Map S_alpha: W_NB -> W_NB is smooth.\nSmoothed KL: K_alpha(w) = KL(q || S_alpha(w)) has no zero-count fibers.\nThe smoothed model is regular with RLCT = d_NB/2 (all parameters constrained).\n\n### D6: RLCT Definition\nThe partition function:\nZ_NB = int_{W_NB} exp(-n * K_n(w)) dw\n\nAs n -> infinity: Z_NB ~ C * n^{-(d_NB - lambda_NB)/2}\n\nFor MLE (singular): lambda_NB = |Z_0|/2 + lambda_reg where lambda_reg is the RLCT of well-observed parameters.\nFor well-observed discrete NB (all counts > 0): lambda_reg = 0 (regular model, Fisher information positive definite).\n\nConjecture: lambda_NB = |Z_0| / 2.\n\n### D7: Class Prior Stratum Selector\nClass prior pi = (pi_1, ..., pi_K) in Delta_K.\nGhost class set: G_0 = {y : N(y) = 0} (no training samples for class y).\nFor y in G_0: all conditional params P(.|y) are free fibers, contributing d_y = sum_j (m_j - 1) free dimensions.\n\nThe empirical class frequency n_y/n acts as a data-driven threshold. As n_y crosses 0 (ghost) to n_y > 0 (observed), the conditional parameters for class y transition from free to data-constrained. This is a continuous stratum selector on the simplex.\n\n---\n\n## Formal Claims\n\n### C1: Definability [PROVEN]\n**Statement:** The NB log-likelihood K_n(w) is R_an,exp-definable.\n**Proof sketch:**\n- Discrete NB: counting functions N(v,j,y) = sum_i 1[x_{i,j}=v, y_i=y] are polynomial in indicators (semialgebraic). MLE P_MLE = N(v,j,y)/N(y) is rational (R_an). Log-likelihood is sum of log(rational) on simplex = subanalytic. No exponential terms needed.\n- Gaussian NB: P(x_j|y) = (2*pi*sigma^2)^{-1/2} exp(-(x_j-mu)^2/(2*sigma^2)). Log-likelihood involves exp and rational functions of (mu, sigma^2). This is R_an,exp-definable.\n- Factorized KL is a finite sum of definable terms. Sum closure preserves definability.\n- R_an suffices for discrete NB; R_an,exp needed for Gaussian NB.\n\n### C2: Zero-Count Feature Fiber RLCT [CONJECTURAL]\n**Statement:** Each zero-count (v,j,y) in Z_0 contributes RLCT = 1/2. Total: lambda_NB = |Z_0|/2.\n**Argument:**\n- For (v,j,y) in Z_0, parameter P(v|j,y) lives in [0,1] with flat KL (no data constraint).\n- Free 1-dimensional fiber with K = 0 everywhere on the fiber.\n- By Watanabe (2009, Theorem 3.1), RLCT of free 1D fiber = 1/2.\n- For well-observed params: Fisher information positive definite, lambda_reg = 0.\n- Total: lambda_NB = |Z_0| * (1/2) + 0 = |Z_0|/2.\n- Analogous to #880 zero-count contexts, but in feature x class space instead of context space.\n\n### C3: Intersection Singularity from Conditional Independence [CONJECTURAL]\n**Statement:** The zero-loss variety V_0 = cap_{j=0}^d V_0^{(j)} has RLCT lambda_NB <= min_j lambda_j, where lambda_j is the per-feature RLCT.\n**Argument:**\n- V_0 is the intersection of d+1 varieties (d per-feature + 1 class prior).\n- Intersection reduces dimension: dim(V_0) <= min_j dim(V_0^{(j)}).\n- For regular (non-singular) per-feature models, dim(V_0^{(j)}) = d_NB - (K-1) - sum_{k!=j} (m_k - 1)*K.\n- The intersection V_0 has codimension sum of individual codimensions when transversality holds.\n- RLCT of intersection: by Watanabe's resolution theorem, lambda <= dim(V_0)/2 <= min_j dim(V_0^{(j)})/2.\n- This makes NB MORE singular than individual feature models — conditional independence is a strong constraint that reduces the true set.\n- Distinct from #652 ensemble (additive) where models are combined, increasing dimension.\n\n### C4: Laplace Smoothing as Desingularization [CONJECTURAL]\n**Statement:** For alpha > 0, lambda_smooth = d_NB/2 (regular model). For alpha = 0 (MLE), lambda_MLE = |Z_0|/2. Thus lambda_MLE <= lambda_smooth.\n**Argument:**\n- Add-alpha smoothing S_alpha makes all probabilities positive, removing zero-count fibers.\n- Smoothed model has positive definite Fisher information everywhere: regular model, lambda = d_NB/2.\n- MLE model has lambda_MLE = |Z_0|/2 < d_NB/2 when |Z_0| < d_NB.\n- This means the SINGULAR (MLE) model has LOWER RLCT than the smoothed (regular) model — better generalization from singular structure.\n- Consistent with #880 insight: smoothing can hurt generalization by removing beneficial singular fibers.\n- Trade-off: smoothing reduces variance (better point estimates) but increases RLCT (worse generalization bound).\n\n### C5: Gaussian NB Variance Collapse Phase Transition [CONJECTURAL]\n**Statement:** For Gaussian NB, sigma^2_{j,y} -> 0 creates a pole singularity. The LLC shows a phase transition at optimal sigma*^2.\n**Argument:**\n- As sigma^2 -> 0: log P(x_j|y) = -(x_j - mu)^2/(2*sigma^2) - (1/2)log(2*pi*sigma^2).\n- For x_j != mu: log P -> -infinity (likelihood -> 0).\n- The KL divergence K(sigma^2) = (1/2)log(sigma^2) + (1/(2*sigma^2)) * E[(x_j - mu)^2] + const.\n- As sigma^2 -> 0: K -> infinity (non-integrable pole).\n- The z-function integral Z = int exp(-n*K(sigma^2)) dsigma^2 has RLCT determined by the pole structure.\n- Pole singularity: K ~ 1/sigma^2 near sigma^2 = 0. Resolution: blow-up sigma^2 = 1/t, dK ~ t^2 dt. RLCT contribution = 1/2 (one blow-up).\n- For each (j,y) with variance collapse: lambda_pole = 1/2 per collapsing parameter.\n- Phase transition: at sigma*^2 = Var_q(x_j|y) (true variance), the model transitions from singular (sigma^2 < sigma*^2, overfitting) to regular (sigma^2 > sigma*^2, underfitting).\n- MAP with inverse-Wishart prior: sigma^2 ~ Inv-Wishart(nu, S) regularizes the pole, analogous to Laplace alpha for discrete NB.\n\n---\n\n## Cross-References\n\n- #880 (n-gram: zero-count contexts -> zero-count features, add-k = Laplace alpha)\n- #872 (k-means: empty clusters -> ghost classes, K as stratum selector)\n- #870 (LASSO: L1 shrinkage -> Gaussian NB variance shrinkage)\n- #866 (shrinkage: sigma^2->0 is extreme shrinkage)\n- #873 (HMM: temporal factorization -> NB spatial feature factorization)\n- #268 (GMM/EM: label switching -> NB class prior degeneracy)\n- #570 (randomized smoothing: Gaussian desingularization -> Laplace desingularization)\n- #652 (ensemble: additive combination -> NB multiplicative/intersection)\n\n---\n\n## Open Problems\n\n1.
