# Synthesis #252: TTT × RLCT — L1 Formalization\n## Date: 2026-10-26\n## Status: L1 FORMALIZATION\n\n## Definitions\n\n**D1 (Fast Weight Space)**: Let W in R^{d_w} be the fast-weight parameters (inner model of TTT layer). The main model parameters theta in R^{d_theta} are frozen at test time. The fast-weight space is the manifold M_w = R^{d_w} with the SSL loss landscape.\n\n**D2 (Self-Supervised Loss)**: L_ssl: R^{d_w} × X -> R_{>=0} is a twice-differentiable loss function (e.g., reconstruction loss for TTT-Linear, or MSE for TTT-MLP). L_ssl(W, x) measures how well inner model f(W; x) reconstructs or predicts from input x.\n\n**D3 (Inner-Loop Update Operator)**: The k-step inner-loop update is:\nW_k = Phi_k(W_0) where Phi_k = (id - eta * grad_W L_ssl) o ... o (id - eta * grad_W L_ssl)  [k compositions]\nEach step: W_{t+1} = W_t - eta * nabla_W L_ssl(W_t, x_t). Phi_k is a k-fold composition of gradient descent steps.\n\n**D4 (ReLU Stratification)**: For a network with ReLU activations, the parameter space decomposes into strata S_1 subset S_2 subset ... where each stratum S_j corresponds to a fixed activation pattern (sign pattern of pre-activations). Stratum boundaries occur where some pre-activation z_i = 0. The codimension of boundary divisors varies.\n\n**D5 (RLCT Functional)**: lambda: M_w -> R_{>0} maps each point W in the fast-weight space to its local RLCT. Near a true parameter W*, lambda(W*) = dim(W*) / (multiplicity of singularity). For the adapted model, lambda(W_k) is the RLCT of the loss landscape at the point reached after k inner steps.\n\n**D6 (TTT-Adapted Loss)**: L_TTT(theta, W_k) = L_main(theta, W_k) + alpha * L_ssl(W_0, x) where W_k = Phi_k(W_0). The total loss is a function of (theta, W_0, x, k, eta).\n\n**D7 (Generalization Bound Decomposition)**: G_TTT(n) = lambda(W_k) * log(n) / (2n) + U(W_k) / sqrt(n) + B_ssl(k) where B_ssl(k) = ||E[L_ssl(W_k, x)] - E[L_main(theta, W_k, x')]|| is the SSL-main objective mismatch, growing with k.\n\n## Claims\n\n**C1 (Definability) — PROVABLE**: L_TTT is definable in R_{an,exp}. Proof sketch: (1) L_ssl is analytic (standard for reconstruction losses). (2) grad_W L_ssl is analytic (gradient of analytic is analytic). (3) Each step W_{t+1} = W_t - eta * grad_W L_ssl(W_t) is analytic composition. (4) Phi_k is k-fold analytic composition, hence definable in R_{an,exp} by closure under composition. (5) L_main is piecewise-analytic for ReLU networks. (6) Sum of definable functions is definable. QED.\n\n**C2 (Stratum Crossing) — CONJECTURAL**: For ReLU networks, the fast-weight trajectory {W_0, W_1, ..., W_k} crosses stratum boundary S_j -> S_{j+1} iff some pre-activation changes sign during inner loop. Crossing probability P_cross(k, eta, lambda(W_0)) increases with k (more steps = more movement) and decreases with lambda(W_0) (higher RLCT = farther from singularity = fewer nearby boundaries). Formal: P_cross >= 1 - (1 - p_0)^k where p_0 is per-step crossing probability depending on eta and local geometry.\n\n**C3 (RLCT Delta) — CONJECTURAL**: Delta_lambda(k) = lambda(W_0) - lambda(W_k). If trajectory crosses to MORE singular stratum: Delta_lambda > 0 (improvement). If LESS singular: Delta_lambda < 0 (degradation). Expected delta: E[Delta_lambda(k)] = integral over strata S_j of [lambda(W_0) - lambda(S_j)] * P(W_k in S_j | W_0). k acts as stratum selector — larger k reaches more distant strata.\n\n**C4 (Generalization Bound) — CONJECTURAL**: G_TTT(n) <= lambda(W_k) * log(n)/(2n) + U(W_k)/sqrt(n) + B_ssl(k). Optimal k* minimizes this. For k < k*: lambda term dominates (model under-adapted). For k > k*: B_ssl dominates (SSL overfitting). U-shaped curve in k. B_ssl(k) ~ C * k * sigma^2_ssl where sigma^2_ssl is SSL noise variance.\n\n**C5 (Phase Transition) — CONJECTURAL**: Critical shift delta* exists where E[Delta_lambda] changes sign. For distribution shift d(P_test, P_train) < delta*: TTT helps (Delta_lambda > 0). For d > delta*: TTT hurts (Delta_lambda < 0). At delta*: trajectory crosses from beneficial to harmful stratum. Testable via SGLD LLC estimation.\n\n## Open Problems\n1. Formal closure proof for k-fold gradient composition in R_{an,exp} (induction on k).\n2.
