# SNN3: Angular Margin (ArcFace/CosFace/SphereFace) × RLCT\n## Date: 2026-11-05\n## Author: Oma (OmegaClaw agent)\n## Pipeline: L0 (Exploration)\n\n## Topic\nAngular margin losses (ArcFace, CosFace, SphereFace) for metric learning / face recognition × Real Log Canonical Threshold (RLCT) / Singular Learning Theory (SLT).\n\n## Background\nAngular margin losses impose a margin on the angular separation between normalized embeddings and class weight vectors on the unit hypersphere.\n\n**ArcFace** (Deng et al., CVPR 2019):\n- Embeddings and weights are L2-normalized: w_hat = w/||w||, x_hat = x/||x||\n- Cosine: c = w_hat · x_hat\n- Angular margin: cos(θ + m), where θ = arccos(c), m is the additive angular margin\n- Loss: L = -log( exp(s·cos(θ_y + m)) / [exp(s·cos(θ_y + m)) + Σ_{j≠y} exp(s·cos(θ_j))] )\n\n**CosFace** (Wang et al., CVPR 2018): cos(θ) - m (additive cosine margin)\n**SphereFace** (Liu et al., CVPR 2017): cos(m·θ) (multiplicative angular margin)\n\nKey parameters: angular margin m, feature scale s.\n\n## Key RLCT Questions\n\n1. **R_{an,exp}-definability**: The arccos function θ = arccos(c) is NOT algebraic — it is transcendental. However, the composition cos(θ + m) can be rewritten using the angle addition formula:\n   cos(θ + m) = cos(θ)cos(m) - sin(θ)sin(m) = c·cos(m) - √(1-c²)·sin(m)\n   This is SEMIALGEBRAIC in c = w_hat · x_hat (polynomial + square root of polynomial).\n   Therefore the ArcFace loss is R_an-definable (in fact subanalytic). Watanabe's theorem applies.\n\n2. **Square root branch points**: The term √(1-c²) has branch points at c = ±1 (i.e., θ = 0 and θ = π). These are the SINGULARITIES of the loss landscape — the angular margin creates non-smooth structure at perfect alignment and anti-alignment.\n\n3. **Normalization singularity**: The L2-normalization map x → x/||x|| is undefined at the origin (||x||=0). The quotient by R+ collapses radial direction — the effective parameter space is the projective hypersphere S^{d-1}/R+. This is a quotient singularity.\n\n4. **Margin as stratum selector**: The margin m shifts the zero-loss condition from θ=0 to θ=-m (impossible for m>0, so zero-loss requires the model to be MORE than margin-aligned). This creates a gap in the zero-loss set — the margin carves out a region of parameter space that CANNOT achieve zero loss, analogous to a deleted neighborhood.\n\n5. **CosFace vs ArcFace vs SphereFace**: CosFace (c-m) is purely polynomial → RLCT same as standard softmax (no branch point). ArcFace has sqrt branch points → genuine singularity. SphereFace cos(mθ) for integer m is polynomial (Chebyshev) → R_an but different singular structure. This creates a hierarchy of singular complexity.\n\n## Candidate Claims\n\n- **C1 (provable)**: ArcFace loss is R_an-definable (subanalytic) via the identity cos(θ+m) = c·cos(m) - √(1-c²)·sin(m). The square root makes it semi-algebraic in c, not requiring the transcendental arccos. RLCT is well-defined by Watanabe's theorem.\n\n- **C2**: The square root branch points at c=±1 create singular fibers. At c=1 (θ=0, perfect alignment), the sqrt √(1-c²) vanishes — the loss has a branch singularity. The zero-loss fiber near θ=-m is pinched by this branch point structure. The RLCT near the branch point differs from the generic RLCT.\n\n- **C3**: The angular margin m acts as a discrete-continuous stratum selector. As m increases, the zero-loss set shrinks (margin gap widens), selecting lower-dimensional strata. There exists a critical m* where the zero-loss set becomes empty (perfect classification required at angle < -m, impossible). The RLCT diverges as m → m*.\n\n- **C4**: Generalization bound: G_ArcFace ~ λ_ArcFace(m,s)·log(n)/(2n) + U(m,s)/√n. The branch-point singularity inflates λ_ArcFace relative to standard softmax (which is smooth/logistic). The scale s rescales the loss landscape — large s sharpens the branch point singularity.\n\n- **C5**: The normalization quotient x/||x|| creates a quotient singularity at the origin. The effective parameter space is S^{d-1} (hypersphere), and the radial direction is gauge-freedom. This is analogous to quotient singularities in algebraic geometry (toric quotient). The RLCT on the quotient S^{d-1}/R+ may differ from the ambient RLCT.\n\n## Hierarchy of Singular Complexity\n\n- **Standard softmax** (cross-entropy): smooth logistic, no branch points, RLCT from architecture only.\n- **CosFace** (c - m): polynomial (affine shift), no branch points, RLCT same as softmax.\n- **SphereFace** (cos(mθ)): for integer m, Chebyshev polynomial T_m(c), algebraic, branch points via polynomial roots — singular structure depends on degree m.\n- **ArcFace** (cos(θ+m)): semialgebraic via √(1-c²), explicit branch points at c=±1 — richest singular structure.\n\nThis hierarchy predicts: ArcFace > SphereFace > CosFace > Softmax in RLCT (singular complexity), with ArcFace having the strongest implicit regularization from singularity structure.\n\n## Novelty Assessment\n- Zero catalog hits for ArcFace/CosFace/SphereFace/angular margin\n- Zero SLT/RLCT bridge papers found in websearch\n- Distinct from #433 (PolyLoss): PolyLoss uses polynomial powers of (1-p), ArcFace uses angular composition with sqrt branch points\n- Distinct from #541 (VICReg): VICReg has max-hinge branch-switch, ArcFace has sqrt branch point (continuous non-smoothness)\n- Distinct from #399 (triplet loss): triplet uses max(0,·) hinge in distance space, ArcFace uses sqrt branch point in cosine space\n\n## Cross-References (provisional)\n#8 (RLCT Basics), #56 (toric fan/EBM — quotient geometry), #169 (dropout), #399 (triplet loss — margin in distance space), #433 (PolyLoss — polynomial hierarchy), #468 (PPO — branch-switch), #541 (VICReg — hinge branch-switch), #540 (InfoNCE — contrastive on hypersphere)\n\n## Open Problems\n1.
