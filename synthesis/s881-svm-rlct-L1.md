# Synthesis #881: SVM × RLCT — L1 Formalization\n## Date: 2026-11-09\n\n## Definitions\n\n### D1: Hinge Loss\nFor training set {(x_i, y_i)}_{i=1}^n with y_i ∈ {-1,+1}, model f_w(x) = w·φ(x) + b:\nL_hinge(w,b) = (1/n) Σ_{i=1}^n max(0, 1 - y_i·f_w(x_i))\n\nPiecewise linear: active region (y_i·f_w(x_i) < 1) and inactive region (y_i·f_w(x_i) ≥ 1). Kink locus: S_i = {(w,b) : y_i·(w·φ(x_i)+b) = 1} is a hyperplane in parameter space.\n\n### D2: Soft-Margin Primal\nmin_{w,b,ξ} (1/2)||w||² + C Σ_{i=1}^n ξ_i\nsubject to y_i·(w·φ(x_i)+b) ≥ 1 - ξ_i, ξ_i ≥ 0\n\nObjective is polynomial + linear. Constraint set is semialgebraic (linear inequalities). Feasible region is a polyhedron.\n\n### D3: Dual Formulation\nmax_α Σ_{i=1}^n α_i - (1/2) Σ_{i,j} α_i α_j y_i y_j K(x_i,x_j)\nsubject to 0 ≤ α_i ≤ C, Σ_i α_i y_i = 0\n\nwhere K(x_i,x_j) = φ(x_i)·φ(x_j). Dual objective is quadratic in α. Constraint set: box [0,C]^n ∩ hyperplane Σ α_i y_i = 0.\n\n### D4: KKT Strata\nAt optimum, three strata:\n- **S_0** (non-support): α_i = 0. Point satisfies y_i·f(x_i) > 1. No constraint on w from this point.\n- **S_m** (margin support): 0 < α_i < C. Point satisfies y_i·f(x_i) = 1. Actively constrains w.\n- **S_C** (margin violator): α_i = C. Point satisfies y_i·f(x_i) < 1. Maximally constrained.\n\n### D5: Kernel Map\nK(x,x') = φ(x)·φ(x'). For RBF: K(x,x') = exp(-γ||x-x'||²). Feature map φ: X → H (RKHS). Non-identifiability: φ and φ∘Q for any orthogonal Q give same K. Singular fiber = O(dim(H)) orbit.\n\n### D6: RLCT Setup\nParameter space Θ = {(w,b,ξ) ∈ R^d × R × R^n}. True distribution q(x,y). Model p(y|x;w,b) ∝ exp(-L_hinge). KL divergence K_n(w,b) = (1/n)Σ L_hinge(w,b;x_i,y_i) - empirical.\n\nSingular fiber V_0 = {(w,b) : K_n(w,b) = 0} (zero empirical hinge loss). For hard margin separable data: V_0 = {w : y_i·f_w(x_i) ≥ 1 ∀i}, a cone in w-space.\n\n### D7: Stratum Selector C\nFor fixed data, define |SV(C)| = number of support vectors (0 < α_i ≤ C). Free parameters = n - |SV(C)| (non-support α_i = 0 are unconstrained beyond sign). The map C ↦ |SV(C)| is piecewise constant, right-continuous, decreasing. C partitions the positive reals into intervals where |SV(C)| is constant.\n\n## Formal Claims\n\n**C1 (PROVEN):** The soft-margin SVM objective (1/2)||w||² + CΣξ_i with constraints y_i(w·φ(x_i)+b) ≥ 1-ξ_i, ξ_i≥0 is semialgebraic (polynomial objective + linear inequality constraints).
