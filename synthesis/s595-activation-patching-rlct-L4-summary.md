# Synthesis #595: Activation Patching × RLCT — L4 Integration & Critique\n\n**Date:** 2026-10-25\n**Status:** L4 COMPLETE\n\n## Plain-Language Summary\n\nActivation patching (causal tracing) is a mechanistic interpretability tool: run a model on clean and corrupted inputs, then swap a clean activation into the corrupted run at layer l, position p. The patched output reveals which components causally drive the model's behavior.\n\nThis synthesis connects activation patching to Singular Learning Theory (SLT) via the Real Log Canonical Threshold (RLCT). The key insight: patching creates a *hybrid* loss landscape — corrupted below layer l, clean at (l,p), then propagated forward. This hybrid defines a new singular fiber V_{l,p} that is neither the clean nor the corrupted fiber, but a gluing of both at the intervention point.\n\n## Claims Digest\n\n- **C1 (PROVEN):** The patched loss L_patch(θ,l,p) is definable in R_{an,exp}. Patching is affine coordinate substitution; forward passes are analytic; cross-entropy uses exp/log. Composition preserves definability.\n\n- **C2 (CONJECTURAL):** V_{l,p} is a hybrid singular fiber distinct from V_clean and V_corr. The intervention glues two loss varieties at (l,p), creating a non-generic fiber with RLCT λ(l,p) ≠ λ_clean, λ_corr.\n\n- **C3 (CONJECTURAL):** λ(l,p) is non-monotone in l, peaking at a critical layer l*. Early patches propagate through more layers → conflicting gradient signals → higher RLCT. Late patches barely change output → λ ≈ λ_corr.\n\n- **C4 (CONJECTURAL):** Generalization bound G(l,p) ≤ C·√(λ(l,p)·d_eff(l)/n) with d_eff(l) = d(L-l)/L. Most informative patching at l* (high λ, moderate d_eff).\n\n- **C5 (CONJECTURAL):** Phase transition at l* where effect size Δ(l,p) jumps from ≈0 to >0. Below l*: same stratum as corrupted. At l*: fiber splits. Above l*: transitions toward clean fiber.\n\n## Key Novelty\n\nThe standout contribution is **intervention as singularity probe**: activation patching doesn't just measure causal influence statistically — it experimentally queries the singular fiber structure by creating hybrid loss landscapes. The intervention location (l,p) acts as a stratum selector, and the patching effect Δ(l,p) measures stratum distance between clean and corrupted fibers. This is a new direction connecting mechanistic interpretability to SLT: not just observing singularities, but *creating* them via controlled intervention.\n\nDistinction from #340 (Logit Lens): both layer-index singularities, but #340 uses projection (unprojecting hidden states) while #595 uses intervention (patching). Different stratum selectors, different singularity types.\n\n## Critique\n\n- The d_eff(l) = d(L-l)/L formula is a heuristic; actual effective dimensionality likely depends on architecture specifics, not just layer depth ratio.\n- The non-monotonicity of λ(l) assumes conflicting gradient signals at early layers increase degeneracy — plausible but unproven for specific architectures.\n- The phase transition sharpness claim (first-order for trained models, smooth for undertrained) is an interesting conjecture but lacks even simple-model verification.\n- C2's fiber gluing V_{l,p} = V_clean ∩_{patch} V_corr needs precise transversality conditions to be well-defined.\n\n## Cross-References\n\n#8 #16 #57 #86 #94 #134 #139 #162 #170 #302 #335 #340 #503 #510 #545\n\n## Open Problems\n\n1.
