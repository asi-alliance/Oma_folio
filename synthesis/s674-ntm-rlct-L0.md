## Synthesis #674: Neural Turing Machine (NTM) × RLCT — L0 Exploration\n**Date:** 2026-10-28\n**Status:** L0 DRAFT\n**Candidate Selection:** Zero catalog hits confirmed. NTM has no prior SLT/RLCT bridge.\n---\n### Architecture Summary\nNTM (Graves et al. 2014) couples a neural controller to an external memory matrix M_t (N × W) via differentiable read/write heads. Addressing uses content lookup (softmax over cosine similarity) plus interpolation and convolutional shifting.\n\n### Key Singularity Bridges\n1. **Address-collision fiber:** When two memory locations i,j receive identical attention weights w_i = w_j, the write operation becomes non-injective — swapping contents of i,j produces identical output. This creates a singular fiber V_{coll} where the parameter-to-loss map has degenerate Jacobian.\n2. **Memory size M as stratum selector:** N (number of memory slots) discretizes the output space. Small N forces collisions (high singularity), large N spreads addressing (low singularity). N acts as a discrete stratum selector analogous to expert count in MoE (#434).\n3. **Content addressing fold singularity:** softmax(cosine_sim(k_t, M_t[i])) creates fold singularities at decision boundaries where argmax shifts. The softmax temperature beta creates a continuous family of approximations to the argmax fold.\n4. **Write erase/add non-injectivity:** The erase vector e_t and add vector a_t modify memory via M_t' = M_t ∘ (1 - w_t e_t^T) + w_t a_t^T. When w_t is sparse (one-hot), this is a clean write. When w_t is diffuse, multiple locations are modified identically, creating a degenerate fiber.\n5. **Controller-memory quotient:** The controller parameters θ_c and memory contents are jointly optimized. Memory contents act as additional "parameters" with their own singularity structure, creating a product singularity space.\n\n### Seven Questions\nQ1: Is the NTM loss L(θ) definable in R_{an,exp}?\nQ2: What is the codimension of the address-collision fiber V_{coll}?\nQ3: Does N (memory slots) act as a stratum selector with U-shaped λ(N)?\nQ4: Can we derive a generalization bound G_NTM with memory-capacity correction term?\nQ5: Is there a critical N* phase transition between collision-dominated and spread-dominated regimes?\nQ6: How does interpolation gate g_t (between content and location addressing) affect the singular structure?\nQ7: Does the shift convolution create additional singular strata from circular boundary effects?\n\n### Five Claims\n**C1 (PROVEN):** R_{an,exp}(θ) = L(θ) + β||θ||² is definable. L is analytic: cosine similarity is polynomial ratio (analytic where ||M_t[i]|| > 0), softmax is analytic, sigmoid interpolation is analytic, erase/add are polynomial. Closure under composition preserves analyticity. **R_{an,exp} is real-analytic on open dense subset.**\n\n**C2 (CONJECTURAL):** The address-collision fiber V_{coll} = {θ : ∃ i≠j, w_i(θ) = w_j(θ)} is a singular stratum. At collision points, the Jacobian of the loss map drops rank because the write operation becomes permutation-symmetric in locations i,j. The codimension depends on attention dimension.\n\n**C3 (CONJECTURAL):** Memory size N acts as a discrete stratum selector. Small N → high collision probability → higher RLCT λ. Large N → lower collision → lower λ but higher approximation error. λ(N) is conjectured U-shaped with optimal N*.\n\n**C4 (CONJECTURAL):** Generalization bound G_NTM ~ λ_NTM/n + U_NTM/√n where λ_NTM depends on N and collision structure. At N*, generalization is optimal.\n\n### Open Problems\n1. Formal codimension calculation for V_{coll}\n2. Interaction between content addressing beta and collision structure\n3.
