# Synthesis #881: SVM (Support Vector Machine) × RLCT — L0 Exploration\n## Date: 2026-11-09\n\n## Topic\nSupport Vector Machine classification viewed through Singular Learning Theory. SVM hinge loss creates a piecewise-linear, non-smooth objective whose singularity structure has not been analyzed via RLCT.\n\n## Key RLCT Bridges\n\n### Bridge 1: Hinge Loss Kink Singularity\nThe hinge loss L(y,f(x)) = max(0, 1 - y·f(x)) is piecewise linear with a kink at y·f(x) = 1 (the margin boundary). This kink is a non-smooth point — analogous to L1/|x| kink in #870 LASSO but in a different geometric context. The loss landscape has a subanalytic singularity along the manifold where y·f(x) = 1 for all training points simultaneously (the "all points on margin" fiber).\n\n### Bridge 2: Support Vector Selection as Data-Dependent Singular Fiber\nOnly support vectors (points with y·f(x) ≤ 1) constrain the solution. Non-support vectors (y·f(x) > 1) have zero gradient contribution — their parameters are free. This creates a data-dependent singular fiber: if a point moves from support to non-support, a degree of freedom is released. This is analogous to #880's zero-count contexts creating free parameters, but here the mechanism is geometric (margin) rather than combinatorial (counting).\n\n### Bridge 3: C Regularization as Stratum Selector\nThe soft-margin SVM: min (1/2)||w||² + C Σ ξ_i. The regularization parameter C controls how many points violate the margin. At C→∞ (hard margin): all points must be correctly classified — singular fiber is empty if data is non-separable. At C→0: all points are non-support vectors — maximum free-parameter fiber. C selects a stratum indexed by the number of support vectors |SV|.\n\n### Bridge 4: Kernel Feature Map Singularity\nThe kernel trick K(x,x') = φ(x)·φ(x') implicitly maps to RKHS. The feature map φ is typically not explicit (infinite-dimensional for RBF kernel). The non-identifiability of φ (any orthogonal transformation of RKHS gives same kernel) creates a continuous singular fiber (orthogonal group orbit), analogous to #266 spectral clustering eigenspace degeneracy.\n\n### Bridge 5: Dual KKT Singular Points\nThe dual optimization: max Σ α_i - (1/2) Σ α_i α_j y_i y_j K(x_i,x_j) subject to 0 ≤ α_i ≤ C, Σ α_i y_i = 0. KKT conditions define singular points: α_i = 0 (non-support), 0 < α_i < C (margin support), α_i = C (margin violator). These three strata create a stratified singular fiber structure.\n\n## Claims\n- **C1 (PROVEN):** Hinge loss is R_an-definable. max(0, 1-yf) is semialgebraic (piecewise polynomial), ||w||² is polynomial. Soft-margin objective is semialgebraic. Kernel matrix entries are definable (polynomial for linear, exponential for RBF → R_an,exp).\n- **C2 (CONJECTURAL):** The singular fiber for SVM consists of free parameters for non-support vectors. Each non-support vector releases 1 DOF (its α_i becomes unconstrained). Fiber dimension = d - |SV| where d = n_samples. RLCT contribution per non-support vector: 1/2 (standard regular fiber for 1 free parameter).\n- **C3 (CONJECTURAL):** C acts as continuous stratum selector. λ(C) ≈ (n - |SV(C)|)/2 + λ_kernel. As C decreases, |SV| increases, free parameters decrease, RLCT decreases. Hard margin (C→∞) has maximum RLCT (all parameters constrained except the margin-normal direction).\n- **C4 (CONJECTURAL):** Generalization bound: G(C) ≤ λ(C)·log(n)/(2n) + U(C)/√n where U(C) captures the margin-violation bias. Trade-off: lower C → lower RLCT but higher U (more violations). This differs from classical SVM generalization (margin-based VC dimension) by replacing margin with RLCT.\n- **C5 (CONJECTURAL):** Phase transition at C* where |SV| changes rapidly (data-dependent). SGLD LLC estimation shows kink at C* analogous to #870 LASSO λ* and #872 k-means K*.\n\n## Distinction from Prior Syntheses\n- #870 (LASSO): L1 kink at coordinate zeros (parameter-space). SVM kink at margin boundary (data-space × parameter-space interaction).\n- #880 (n-gram): Free parameters from unobserved contexts (combinatorial). SVM free parameters from non-support vectors (geometric).\n- #872 (k-means): Hard cluster assignment creates Voronoi boundary singularity. SVM hard margin creates hyperplane boundary singularity — but SVM has explicit dual optimization and regularization.\n- #266 (spectral clustering): Eigenspace degeneracy. SVM kernel degeneracy is in the dual coefficient space, not eigenvalue space.\n\n## Open Problems\n1. Formal proof of C2: is the free-parameter RLCT exactly 1/2 per non-support vector?\n2.
