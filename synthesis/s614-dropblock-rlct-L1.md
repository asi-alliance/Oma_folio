Let k_h×k_w be the convolutional kernel size.\n\n**D2 (DropBlock Mask Generator):** A binary mask M ∈ {0,1}^{H×W} generated by: (i) sample seed S ∈ {0,1}^{H×W} with P(S_{ij}=0)=γ, (ii) block dilation D_b: for each (i,j) with S_{ij}=0, set M_{i',j'}=0 for all (i',j') in the b×b block B_b(i,j) = {(i',j') : |i'-i|<b/2, |j'-j|<b/2, valid}. Formally M = 1 - D_b(1-S) where D_b is the block-dilation operator. The masked feature map is M⊙X (broadcast over channels).\n\n**D3 (Block-Dilation Operator):** D_b : {0,1}^{H×W} → {0,1}^{H×W} defined by D_b(S)_{ij} = max_{(i',j')∈B_b(i,j)} S_{i'j'}. This is a morphological dilation with a b×b square structuring element. D_b is a finite composition of max operations over b² elements — definable in R_{an,exp}.\n\n**D4 (Effective Drop Rate):** γ_eff(b,γ) = 1 - E[M_{ij}] = 1 - (1-γ)^{⌈b² / area_overlap⌉} accounting for block overlap. For non-overlapping seeds, γ_eff ≈ 1-(1-γ)^{b²}. The effective mask density is a polynomial-analytic function of (b,γ) in the non-overlapping regime.\n\n**D5 (Block-Covering Zero-Loss Fiber):** V_DB(b,γ) = {θ : E_M[L(θ; M⊙X)] = 0} where expectation is over mask sampling. Equivalently, V_DB(b,γ) = ∩_M {θ : L(θ; M⊙X) = 0}^{interior} — the set of parameters achieving zero loss across all block mask configurations. For fixed mask M, the fiber V_M = {θ : L(θ; M⊙X)=0} has a singular structure determined by which spatial regions are zeroed.\n\n**D6 (DropBlock RLCT):** λ_DB(b,γ) = RLCT of E_M[L(θ; M⊙X)] at the true parameter θ*. The RLCT depends on the singularity structure of the block-averaged loss landscape. For b=1, λ_DB(1,γ) = λ_dropout(γ) (#169).\n\n**D7 (LLC Percolation Signature):** The SGLD local learning coefficient LLC_DB(b,γ) = empirical estimate of λ_DB via Langevin sampling. The percolation threshold γ_c(b) is defined as the γ value where connected block clusters first span the H×W lattice.
