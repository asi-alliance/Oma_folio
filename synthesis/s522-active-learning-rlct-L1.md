# 522 | Active Learning × RLCT | L1 Formalization\n\n## Formal Definitions\n\n**D1 (Labeled set and unlabeled pool).** Let $\mathcal{L}_n = \{(x_i, y_i)\}_{i=1}^{n}$ be the labeled set with $|\mathcal{L}_n| = n$ and $\mathcal{U} = \{x_j\}_{j=1}^{M}$ the unlabeled pool with $M \gg n$. The labeled set grows iteratively: $\mathcal{L}_{n+1} = \mathcal{L}_n \cup \{(x^*, y^*)\}$ where $x^* = \arg\max_{x \in \mathcal{U}} a(x; w_n)$ and $y^*$ is the oracle label.\n\n**D2 (Acquisition function).** For model $f_w: \mathbb{R}^d \to \mathbb{R}^K$ (ReLU network, $w \in \mathbb{R}^D$), the uncertainty-sampling acquisition function is:\n$$a(x; w) = H(\text{softmax}(f_w(x))) = -\sum_{k=1}^{K} p_k(x;w) \log p_k(x;w)$$\nwhere $p_k(x;w) = \text{softmax}(f_w(x))_k$. The diversity-based acquisition (query-by-committee) is:\n$$a_{\text{QBC}}(x) = \text{Var}_{m \in \mathcal{M}}\left[\text{softmax}(f_{w_m}(x))\right]$$\nwhere $\mathcal{M}$ is a committee of $M_c$ models.\n\n**D3 (Iterative empirical loss).** At labeled-set size $n$:\n$$L_n(w) = \frac{1}{n} \sum_{(x_i,y_i) \in \mathcal{L}_n} \ell(f_w(x_i), y_i)$$\nwhere $\ell$ is cross-entropy: $\ell(p, y) = -\log p_y$. The minimizer is $w_n^* = \arg\min_w L_n(w)$.\n\n**D4 (RLCT at labeled-set size $n$).** The local learning coefficient (RLCT) of the trained model at size $n$ is:\n$$\lambda(n) = \text{RLCT}(W_n, L_n) = \lim_{\epsilon \to 0} \frac{\log V_n(\epsilon)}{\log \epsilon}$$\nwhere $W_n = \{w : L_n(w) - L_n(w_n^*) < \epsilon\}$ and $V_n(\epsilon) = \text{Vol}(\{w \in W_n : L_n(w) - L_n(w_n^*) < \epsilon\})$.\n\n**D5 (Singularity set at size $n$).** $\text{Sing}_n = \{w \in \mathbb{R}^D : \nabla L_n(w) = 0, \det(\text{Hess}\, L_n(w)) = 0\}$. Points in $\text{Sing}_n$ are singular local minima where the Fisher information degenerates — these define the RLCT $\lambda(n)$.\n\n**D6 (Acquisition stratum).** The high-uncertainty acquisition region:\n$$\mathcal{A}_\epsilon = \{x \in \mathcal{U} : a(x; w_n^*) \geq \epsilon\}$$\nThis is the set of unlabeled points where the model posterior is maximally ambiguous. Conjecturally, $\mathcal{A}_\epsilon$ concentrates near the projection of $\text{Sing}_n$ onto input space.\n\n**D7 (Definability class).** The active learning pipeline is definable over $R_{\text{an,exp}}$ if each component — $f_w$ (ReLU = piecewise-linear, definable), softmax ($\exp$ restricted to bounded domain, definable), entropy ($p \log p$ with $p = \text{softmax}$, definable via $\log$), argmax selection (semi-algebraic), committee variance (arithmetic + softmax), and $L_n$ (sum of CE, definable) — lies in $R_{\text{an,exp}}$ by closure under composition.\n\n## Claims\n\n**C1 (PROVEN): $R_{\text{an,exp}}$-definability of the active learning pipeline.**\n\n*Proof sketch.* ReLU networks $f_w(x) = \max(0, Wx + b)$ are piecewise-linear hence subanalytic (definable in $R_{\text{an}}$). The softmax $\sigma(z)_k = e^{z_k} / \sum_j e^{z_j}$ is definable in $R_{\text{an,exp}}$ (exponential restricted to compact codomain). Entropy $H(p) = -\sum p_k \log p_k$ is definable since $p_k \in (0,1)$ and $\log$ is restricted-analytic. The acquisition function $a(x;w) = H(\text{softmax}(f_w(x)))$ is a composition of definable maps, hence definable. The QBC variance is a finite sum of definable terms. Cross-entropy $\ell = -\log p_y$ is definable. The empirical loss $L_n$ is a finite sum of definable functions. The argmax selection $\arg\max_x a(x;w)$ defines a semi-algebraic set (graph of argmax is definable by Tarski-Seidenberg). Therefore the full pipeline $(f_w, a, \sigma, L_n, \text{selection})$ is definable in $R_{\text{an,exp}}$. By Watanabe's theorem, the RLCT $\lambda(n)$ is well-defined for each $n$. $\square$\n\n**C2 (CONJECTURAL): Acquisition function as RLCT gradient probe.**\n\nThe acquisition function $a(x; w_n^*)$ implicitly measures the local rate of change $d\lambda/dn$ at $x$. High-uncertainty regions (large $a$) correspond to input-space neighborhoods near singular fibers of $L_n$ — where acquiring a new label maximally resolves the RLCT. Formally: $\mathbb{E}[a(x; w_n^*) | x \in \text{proj}(\text{Sing}_n)] \geq \mathbb{E}[a(x; w_n^*) | x \notin \text{proj}(\text{Sing}_n)]$. Testable via SGLD-based LLC estimation before and after acquiring points from $\mathcal{A}_\epsilon$ vs random points.\n\n**C3 (CONJECTURAL): Committee disagreement as multi-stratum RLCT indicator.**\n\nIn QBC, if committee members $\{w_m\}$ occupy different singular strata of $L_n^{-1}(0)$, their disagreement variance $\text{Var}_m[\text{softmax}(f_{w_m}(x))]$ is high at points $x$ that distinguish strata. The number of disagreement modes $K_{\text{disagree}}(x)$ approximates the local stratum multiplicity: $K_{\text{disagree}}(x) \sim \dim(\text{strata of } L_n^{-1}(0) \text{ distinguishable at } x)$. High-disagreement queries select points that resolve the most singular strata, reducing $\lambda(n)$ fastest.\n\n**C4 (CONJECTURAL): RLCT generalization bound for active learning.**\n\n$$G(w_n^*) \leq \frac{C \cdot \lambda(n) \cdot \log n}{2n} + \frac{U(a, n)}{\sqrt{n}}$$\n\nwhere $U(a, n)$ is an acquisition-dependent tension term accounting for selection bias (analogous to #213 LR scheduling tension, #388 Mirostat feedback tension). Under the conjecture that active learning reduces $\lambda(n)$ faster than random:\n$$\lambda_{\text{active}}(n) \leq \lambda_{\text{random}}(n) \quad \forall n \geq n_0$$\nThe selection bias term $U(a, n)$ captures the distributional shift between acquired and i.i.d. samples. Under transversality (acquired labels don't create adversarial singularities), $U(a,n) = O(1)$.\n\n**C5 (CONJECTURAL): Phase transition at $n^*$ where RLCT stabilizes.**\n\nThere exists a critical labeled-set size $n^* = n^*(a, \mathcal{U})$ such that $\lambda(n)$ is strictly decreasing for $n < n^*$ and approximately constant for $n \geq n^*$. At $n^*$, the singular strata of $L_n$ are fully resolved — the model has acquired enough labels to distinguish all degenerate directions. The phase transition is sharp (analogous to grokking #492, double descent #491):\n$$\lambda(n) \approx \begin{cases} \lambda_0 - c \cdot n / n^* & n < n^* \\ \lambda_\infty & n \geq n^* \end{cases}$$\nwhere $\lambda_0$ is the cold-start RLCT (highly singular, small $n$) and $\lambda_\infty$ is the saturated RLCT. The acquisition strategy affects $n^*$: $n^*_{\text{uncertainty}} < n^*_{\text{random}} < n^*_{\text{worst-case}}$.\n\n## Open Problems\n\n1. **Entropy–RLCT gradient formal link:** Is $a(x;w) = H(\text{softmax}(f_w(x)))$ a valid proxy for $|d\lambda/dn|$ at $x$?
