# Synthesis #595: Activation Patching × RLCT — L1 Formalization\n\n**Date:** 2026-10-25\n**Status:** L1 Formalization\n**Prereq:** L0 (s595-activation-patching-rlct-L0.md) VERIFIED\n\n## Formal Definitions\n\n### D1: Clean and Corrupted Model\n- Parameter space: θ ∈ W ⊂ R^d (neural network parameters)\n- Clean input: x_clean, corrupted input: x_corr (e.g., x_corr = x_clean + noise, or ablated tokens)\n- Model forward pass: f_θ(x) decomposed as f_θ(x) = h_L ∘ h_{L-1} ∘ ... ∘ h_1(x)\n  where h_l is the layer-l transformation (analytic in θ for fixed input)\n- Clean activations: a^clean_l = h_l(a^clean_{l-1}), a^clean_0 = x_clean\n- Corrupted activations: a^corr_l = h_l(a^corr_{l-1}), a^corr_0 = x_corr\n- Output: y_clean = f_θ(x_clean), y_corr = f_θ(x_corr)\n\n### D2: Patching Operator\n- Patching at (layer l, position p): substitute a^clean_{l,p} into the corrupted forward pass\n- Patched activation: a^patch_l = a^corr_l with position p replaced by a^clean_{l,p}\n  Formally: a^patch_l = a^corr_l + (a^clean_{l,p} - a^corr_{l,p}) · e_p\n  where e_p is the standard basis vector at position p\n- Patched forward pass: a^patch_{l+k} = h_{l+k}(a^patch_{l+k-1}) for k ≥ 1\n  (layers 1..l-1 use corrupted path, layer l gets patched, layers l+1..L use patched path)\n- Patched output: y_patch(l,p) = f_θ^{patch(l,p)}(x_corr)\n- This is a piecewise construction: corrupted path up to layer l-1, clean substitution at (l,p), then corrupted path continues from patched activation\n\n### D3: Patched Loss Function\n- Task loss: L(y, y*) where y* is the clean label (target)\n- Patched loss: L_patch(θ, l, p) = L(y_patch(l,p), y_clean)\n  = L(f_θ^{patch(l,p)}(x_corr), f_θ(x_clean))\n- For cross-entropy: L_patch = -Σ_y y_clean[y] · log softmax(y_patch(l,p))[y]\n- The patched loss measures how well the patched corrupted run recovers the clean output\n- Effect size: Δ(θ, l, p) = L_corr(θ) - L_patch(θ, l, p)\n  where L_corr(θ) = L(f_θ(x_corr), f_θ(x_clean))\n  Δ > 0 means patching helped recover clean output\n\n### D4: R_an,exp Structure (C1 Formal)\nThe patched loss L_patch is definable in R_{an,exp}:\n- Each layer h_l is a neural network layer: linear map + activation (ReLU/tanh/GELU = subanalytic or analytic) → in R_an\n- Clean forward pass f_θ(x_clean): composition of analytic maps → R_an\n- Corrupted forward pass f_θ(x_corr): same architecture → R_an\n- Patching substitution a^patch_l = a^corr_l + (a^clean_{l,p} - a^corr_{l,p}) · e_p:\n  This is an affine (linear + constant) operation in the activations → preserves R_an\n- Patched forward pass from layer l onward: composition of analytic maps starting from patched activation → R_an\n- Cross-entropy loss: log softmax involves exp and log → R_{an,exp}\n- L_patch = L(y_patch, y_clean): composition of R_{an,exp} functions → R_{an,exp}\n- The patching operator is piecewise-linear (coordinate selection/substitution), and piecewise composition preserves R_{an,exp} definability\n- ∎\n\n### D5: Intervention-Stratified Singular Fibers (C2 Formal)\n- For fixed (l, p), the fiber of the patched loss:\n  V_{l,p} = {θ ∈ W : ∇_θ L_patch(θ, l, p) = 0}\n- This is a hybrid fiber: the patched model uses corrupted activations up to layer l-1 and clean activation at (l,p), then propagates through layers l+1..L\n- The fiber V_{l,p} is the intersection structure of two loss landscapes:\n  (a) The corrupted loss landscape (layers 1..l-1 corrupted)\n  (b) The clean loss landscape (layer l position p patched to clean)\n- Geometrically: V_{l,p} = V_clean ∩_{patch(l,p)} V_corr, a fiber obtained by "gluing" clean and corrupted fibers at the intervention point\n- The RLCT λ(l,p) of V_{l,p} is generically different from both λ_clean and λ_corr because the intervention creates a non-generic hybrid: the parameter space sees both clean and corrupted gradients simultaneously\n- Key structural observation: V_{l,p} is NOT a subvariety of V_clean or V_corr — it is a new variety defined by the patched forward pass, which is a different function of θ than either f_θ(x_clean) or f_θ(x_corr)\n\n### D6: (l,p) as Stratum Selector and Generalization Bound (C3, C4 Formal)\n- The intervention location (l, p) indexes a family of loss functions {L_patch(θ, l, p) : (l,p) ∈ [L] × [N]}\n- Each (l,p) defines a different effective loss landscape with RLCT λ(l,p)\n- Conjecture (C3): λ(l,p) is non-monotone in l. For early layers (l small), patching has maximal effect because the clean activation propagates through more layers — but also maximal degeneracy because the hybrid (clean at l, corrupted elsewhere) creates conflicting gradient signals → higher RLCT (more singular). For late layers (l large), patching barely affects the output → λ(l,p) ≈ λ_corr. Peak λ at l* = critical causal layer.\n- Generalization bound (C4):\n  G(l,p) ≤ C · √(λ(l,p) · d_eff(l) / n)\n  where d_eff(l) = d · (L - l) / L is the effective dimensionality (patching at layer l affects layers l+1..L, so d_eff decreases with l — later patches affect fewer layers)\n  - At l* (critical layer): G is maximized (high λ, moderate d_eff) — patching here is most informative\n  - At l = L (output layer): G ≈ G_corr (λ ≈ λ_corr, d_eff ≈ 0)\n  - At l = 1 (input layer): G is large but dominated by d_eff ≈ d (full model affected)\n\n### D7: Phase Transition at Critical Layer l* (C5 Formal)\n- Effect size: Δ(θ, l, p) = L_corr(θ) - L_patch(θ, l, p)\n- Phase transition: there exists l* such that:\n  - For l < l*: Δ(l,p) ≈ 0 (patching irrelevant, patched loss ≈ corrupted loss — same stratum)\n  - For l ≥ l*: Δ(l,p) > 0 (patching effective, crossed into new stratum)\n- The transition boundary l* is the intervention singularity surface:\n  Σ_int = {(l, p, θ) : Δ(θ, l, p) = ε_threshold} for small ε_threshold\n- Below l*: the patched and corrupted losses define the same singular fiber (V_{l,p} ≈ V_corr)\n- At l*: the patched fiber splits from V_corr — new singular structure emerges\n- Above l*: V_{l,p} transitions toward V_clean as l increases (more of the clean path is restored)\n- Conjecture: l* depends on the architecture and the nature of corruption. For token-level corruptions in transformers, l* is typically in the mid-to-early layers (empirically observed in causal tracing experiments)\n- The phase transition is conjectured to be sharp (first-order) for well-trained models where the singular fibers are well-separated, and smooth for undertrained models where fibers overlap\n\n## Claims Summary\n\n**C1 (PROVEN):** L_patch is definable in R_{an,exp} — patching is affine substitution, forward passes are analytic, loss is R_{an,exp}-definable. See D4.\n\n**C2 (CONJECTURAL):** V_{l,p} is a hybrid singular fiber distinct from both V_clean and V_corr. The RLCT λ(l,p) ≠ λ_clean, λ_corr generically. The intervention creates a non-generic fiber by gluing clean and corrupted loss varieties. Gaps: (1) exact fiber structure for specific architectures, (2) transversality conditions for V_{l,p}, (3) whether V_{l,p} is connected or has multiple components.\n\n**C3 (CONJECTURAL):** λ(l,p) is non-monotone in l, peaking at critical layer l*. Early patching creates conflicting gradient signals → higher RLCT. Late patching barely changes the loss → λ ≈ λ_corr. Gaps: (1) exact form of λ(l), (2) whether the peak is unique or multi-modal, (3) interaction with model depth L.\n\n**C4 (CONJECTURAL):** G(l,p) ≤ C·√(λ(l,p)·d_eff(l)/n) with d_eff(l) = d·(L-l)/L. Gaps: (1) constant C, (2) whether d_eff is exactly linear in l or depends on architecture, (3) empirical verification.\n\n**C5 (CONJECTURAL):** Sharp phase transition at l* where Δ(l,p) jumps from ≈0 to >0. The transition boundary is the intervention singularity surface Σ_int. Gaps: (1) whether transition is first-order or continuous, (2) dependence on corruption type, (3) multi-site patching and stratum intersection.\n\n## Cross-References\n\n#8 #16 #57 #86 #94 #134 #139 #162 #170 #302 #335 #340 #503 #510 #545\n\n## Open Problems\n\n1.
