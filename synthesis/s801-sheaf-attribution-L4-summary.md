G801: Sheaf-Theoretic Semantics of Feature Attribution — L4 Summary\nDate: 2026-10-25\nStatus: C1 PROVEN, C2-C5 CONJECTURAL\n\nCore Idea: Feature attribution methods (SHAP, LIME, Integrated Gradients) assign importance scores to input features. This synthesis constructs a sheaf over the feature space X where:\n- Stalks A_x encode local attribution values at each feature\n- Restriction maps r_{VU}: A(V) -> A(U) correspond to marginalization over excluded features\n- The gluing axiom checks whether local attributions agree on overlaps and assemble into a consistent global attribution\n- H^1(X, A) measures obstruction to global attribution consistency\n- Sheafification converts pre-attribution functors (e.g., raw gradient signals) into proper attribution sheaves\n\nKey Results:\n1. C1 PROVEN: The sheaf construction over a feature space is well-defined — feature spaces carry natural topological structure (discrete or product topology), and attribution functions define presheaves satisfying locality.\n2. C2 CONJECTURAL: Restriction maps equal feature marginalization. This holds for additive attributions (SHAP) but may fail for interaction-aware methods.\n3. C3 CONJECTURAL: Gluing axiom for attribution consistency — local attributions agreeing on feature overlaps should glue to global attribution. SHAP satisfies this by construction; LIME does not.\n4. C4 CONJECTURAL: First cohomology H^1 measures attribution inconsistency. Non-trivial H^1 indicates no consistent global attribution exists from local pieces — a topological obstruction.\n5. C5 CONJECTURAL: Sheafification of pre-attribution functors (gradients, attention weights) yields proper attribution sheaves satisfying gluing.\n\nNovelty: NOVEL (5/5). No prior bridge between sheaf theory and feature attribution methods exists in literature. Distinct from #70 (persistent sheaf × information bottleneck) which targets IB, not attribution.\n\nTestable Predictions:\n- Methods satisfying gluing (SHAP) should have H^1 = 0 on tree-structured feature spaces\n- Methods violating gluing (LIME, raw gradients) should have non-trivial H^1 on overlapping feature subsets\n- Sheafification should improve attribution consistency measurably\n\nOpen Problems:\n1. Optimal topology on feature space for sheaf construction\n2. Interaction effects and restriction map generalization beyond additive case\n3. Computational complexity of H^1 for high-dimensional features\n4. Connection to RLCT — does attribution sheaf singular structure relate to loss landscape geometry?\n5. Sheaf-theoretic unification of SHAP/LIME/IG as different sheafifications\n\nCross-refs: #70 (persistent sheaf IB), #82 (sheaf cohomology × RLCT), #86 (attention nonidentifiability), #139 (dev interp), #167 (normalization × RLCT)\n\nFiles: s801-sheaf-attribution-L0.md, L1.md, L2-novelty.md, L3.metta, L4-summary.mdpin Cycle 2/5: G801 L4 summary written.
