# Synthesis #896: Logistic Regression × RLCT — L1 Formalization\n\n**Date:** 2026-11-12 | **Author:** Oma | **Status:** L1 (formal definitions, pre-proof)\n\n---\n\n## Definitions\n\n### D1: Parameter Space\n\n**Binary case:** θ = (w, b) ∈ W = R^d × R = R^{d+1}. The model computes:\n\np_θ(x) = σ(w·x + b) = 1/(1 + exp(-(w·x + b)))\n\n**Multiclass case (K classes):** θ = (W, b) where W ∈ R^{K×d}, b ∈ R^K. Full parameter space W_K = R^{K(d+1)}, with translation invariance fiber: θ ~ θ + (c·1_K, c_0) for any c ∈ R^d, c_0 ∈ R (softmax normalization invariance). Effective dimension after quotient: K(d+1) - (d+1) = (K-1)(d+1).\n\n**Regularized parameter space:** With L2 regularization λ > 0, the effective parameter space is W_λ = R^{d+1} but the loss landscape is modified by λ||w||²/2, creating a λ-dependent geometry.\n\n### D2: Regularized Cross-Entropy Loss\n\nThe L2-regularized logistic regression loss over n samples {(x_i, y_i)} with y_i ∈ {0,1}:\n\nL_λ(θ) = -(1/n) Σ_{i=1}^n [y_i log σ(w·x_i + b) + (1-y_i) log(1-σ(w·x_i+b))] + (λ/2)||w||²\n\nEquivalently, using the identity log σ(z) = -log(1+e^{-z}) and log(1-σ(z)) = -z - log(1+e^{-z}):\n\nL_λ(θ) = (1/n) Σ_{i=1}^n [log(1 + exp(-ỹ_i(w·x_i+b)))] + (λ/2)||w||²\n\nwhere ỹ_i = 2y_i - 1 ∈ {-1,+1} is the signed label. The unregularized loss is L_0(θ) = L(θ).\n\n**KL divergence proxy:** K_λ(θ) = L_λ(θ) - L_λ(θ*) where θ* is the minimizer. For unregularized separable data, K_0(θ) has infimum 0 but no minimizer (||w|| → ∞).\n\n**Fisher information matrix:**\n\nI(θ) = (1/n) Σ_{i=1}^n σ'(w·x_i+b)² · x_i x_i^T\n\nwhere σ'(z) = σ(z)(1-σ(z)) = e^{-z}/(1+e^{-z})². Note: σ'(z) → 0 exponentially as |z| → ∞.\n\n### D3: R_{an,exp}-Definability (C1)\n\nL_λ(θ) is R_{an,exp}-definable.\n\n**Proof:** The sigmoid σ(z) = 1/(1+e^{-z}) is definable in R_{an,exp}: e^{-z} is in the language (restricted exponential), 1+e^{-z} is definable (addition closure), and 1/(1+e^{-z}) is definable (division closure for nonzero denominator — 1+e^{-z} > 0 always). The log-sigmoid terms log σ(z) = -log(1+e^{-z}) and log(1-σ(z)) = -z - log(1+e^{-z}) involve log of a positive definable function, which is R_{an,exp}-definable by closure under restricted log. The argument z_i = w·x_i + b is affine in θ (hence R_an-definable). Composition of definable functions is definable. The sum (1/n)Σ is a finite sum of definable functions, preserving definability. The regularizer (λ/2)||w||² is a polynomial, hence R_an-definable. Addition preserves definability. For multiclass softmax, exp(w_k·x)/Σ_j exp(w_j·x) is a quotient of exp-definable functions (denominator strictly positive), hence definable. QED.\n\n### D4: Singular Fiber at Infinity\n\n**Definition:** For unregularized logistic regression on separable data, the singular fiber is:\n\nV_∞ = {θ ∈ R^{d+1} : inf_θ' K_0(θ') = 0, K_0(θ) → 0 as ||θ|| → ∞ along separation direction}\n\nMore precisely, let w_sep be a separating direction (ỹ_i(w_sep·x_i) > 0 for all i). Define the ray:\n\nR(t) = (t·w_sep, t·b_sep), t ∈ [0, ∞)\n\nThen K_0(R(t)) → 0 exponentially as t → ∞ (since σ(t·w_sep·x_i + t·b_sep) → 1 for ỹ_i=+1, → 0 for ỹ_i=-1). Along this ray:\n\n- Loss: K_0(R(t)) ~ Σ_i exp(-t·|w_sep·x_i + b_sep|) → 0 exponentially\n- Fisher: I(R(t)) ~ Σ_i σ'(t·w_sep·x_i)² · x_i x_i^T → 0 doubly-exponentially (σ'(z)² ~ e^{-2|z|})\n\nThe RLCT is determined by the ratio of decay rates: if K ~ e^{-αt} and det(I) ~ e^{-βt}, then the RLCT involves the interplay of α and β. The fiber V_∞ is non-compact — a *singularity at infinity* requiring compactification.\n\n**Compactification:** Using projective compactification P^{d+1}, the ray R(t) converges to a point [w_sep : b_sep : 0] on the hyperplane at infinity. The loss function extends (after appropriate desingularization) to a function on the compactified space, and the RLCT is computed at this boundary point.\n\n**Margin dependence:** Let γ = min_i ỹ_i(w_sep·x_i + b_sep) > 0 be the separation margin. The loss decay rate α = γ (each term exp(-t·γ) at worst). The Fisher decay involves the closest points: σ'(t·γ)² dominates.\n\n### D5: λ-Stratified Loss Family\n\nDefine the λ-stratified loss family:\n\n{L_λ(θ)}_{λ ∈ (0,∞)}\n\nFor fixed data, this is a 1-parameter family. The singular fiber V_λ = {θ : K_λ(θ) = 0} (where K_λ(θ) = L_λ(θ) - L_λ(θ*_λ) and θ*_λ is the λ-dependent minimizer) varies with λ:\n\n- **λ → ∞ (strong regularization):** θ*_λ → 0 (origin). The loss is dominated by λ||w||²/2, which is strongly convex. Fisher I(θ*_λ) is non-degenerate. V_λ is a point (regular model). RLCT = (d+1)/2.\n\n- **λ → 0 (weak regularization):** θ*_λ → ∞ (approaches boundary-at-infinity if separable). The loss approaches the unregularized singular regime. V_λ becomes the non-compact fiber V_∞. Fisher degenerates. RLCT < (d+1)/2.\n\n- **Critical λ*:** The transition point where the minimizer θ*_λ shifts from O(1) (bounded) to O(1/λ) (diverging). For separable data, λ* ~ γ²/n (margin-dependent heuristic: the regularization must overcome the exponential loss gradient).\n\nThe stratum selector λ is genuinely continuous, unlike #846 AdaBoost (discrete M) or #877 Decision Tree (discrete depth D). This enables smooth phase transitions detectable via SGLD.\n\n### D6: Generalization Bound with Divergence-Aware Complexity\n\nThe generalization bound for L2-regularized logistic regression:\n\nG(λ) ≤ λ_eff(λ)·log(n)/(2n) + B_div(λ)/√n\n\nwhere:\n- λ_eff(λ) = RLCT(K_λ, V_λ) is the effective RLCT, transitioning from (d+1)/2 (large λ) to < (d+1)/2 (small λ)\n- B_div(λ) accounts for divergence-aware complexity\n\n**Divergence-aware term:**\n\nB_div(λ) = ||w*_λ|| · √(tr(I(θ*_λ)^{-1}))\n\nFor λ ≫ λ*: ||w*_λ|| = O(1/√λ), I non-degenerate, B_div = O(1/√λ) — bounded.\nFor λ ≪ λ*: ||w*_λ|| ~ 1/λ (or faster), I has eigenvalues → 0, B_div grows — the divergence term dominates.\n\nThis predicts that very small λ on separable data yields poor generalization despite zero training loss — the B_div term captures the complexity of a near-infinite separating hyperplane.\n\n**Comparison to #433 Weight Decay:** In #433, weight decay on neural networks controls the norm of an already-regular model. Here, λ controls the approach to a genuine singularity at infinity. The mechanisms differ: #433 compresses the singular fiber inward; here λ prevents escape to infinity. The B_div term is specific to the divergence-at-infinity mechanism and has no analog in #433.\n\n### D7: Phase Transition at Critical λ*\n\n**Definition:** The critical regularization λ* is defined as:\n\nλ* = sup{λ > 0 : ||w*_λ|| > C·√(d/λ) for some constant C}\n\ni.e., the largest λ at which the weight norm exceeds the regular-model scaling √(d/λ), signaling departure from the regular regime.\n\n**Predicted LLC profile:**\n\nFor data with margin γ > 0 (separable):\n- λ ≫ λ*: LLC ≈ (d+1)/2 (regular, constant)\n- λ ≈ λ*: LLC begins decreasing (transition begins)\n- λ ≪ λ*: LLC < (d+1)/2, decreasing further (singular-at-infinity regime)\n\n**Margin scaling:** λ* ~ γ²/n. For large margin γ: λ* large, transition happens early. For small margin γ → 0: λ* → 0, regular regime persists longer. For non-separable data (γ < 0 effectively): no divergence, λ* → 0, model is regular for all λ > 0.\n\n**High-dimensional regime (d ≫ n):** All data becomes linearly separable (Cover's theorem). The singular-at-infinity regime dominates for all practical λ. The RLCT is always < (d+1)/2. This connects to the double descent phenomenon: the transition through the interpolation threshold corresponds to the onset of the singular-at-infinity regime.\n\n**SGLD detection:** The LLC as a function of λ should show a characteristic knee at λ*, distinguishable from: (a) #831 SVM (hinge kink causes different singularity type), (b) #433 Weight Decay on NNs (no boundary-at-infinity mechanism), (c) #870 L1/Lasso (kink at coordinate zero, not infinity).\n\n## Claims (refined from L0)\n\n### C1 (PROVEN): R_{an,exp}-Definability\nSee D3 above. The logistic regression loss with L2 regularization is R_{an,exp}-definable by closure properties of restricted analytic functions with exponentials.\n\n### C2 (CONJECTURAL): Singular Fiber at Infinity\nUnder linear separability, the unregularized loss has a non-compact singular fiber V_∞ — a ray to infinity along which K → 0 and I → 0. The RLCT is determined by the ratio of exponential decay rates of K vs det(I). This is a transcendental singularity (arising from sigmoid saturation), fundamentally different from algebraic singularities (SVM hinge kink #831, tree split #877) or polynomial singularities (NMF boundary #895, PCA rank deficiency #833). Compactification converts it to a standard singularity analyzable via resolution of singularities.\n\n### C3 (CONJECTURAL): λ as Continuous Stratum Selector\nL2 regularization λ creates a genuinely continuous 1-parameter family of strata {V_λ}. The transition from regular (λ large) to singular-at-infinity (λ small) is smooth in λ. Unlike discrete selectors (#846 M, #877 D), this enables a continuous LLC profile and smooth phase transition. The critical λ* ~ γ²/n depends on the data margin.\n\n### C4 (CONJECTURAL): Generalization Bound with Divergence-Aware Complexity\nThe bound G(λ) ≤ λ_eff·log(n)/(2n) + B_div/√n with the divergence-aware term B_div = ||w*||·√(tr(I^{-1})) is novel. It predicts poor generalization for small λ on separable data despite zero training loss. This is distinct from #433 (norm control without divergence) and #870 (sparsity without infinity).\n\n### C5 (CONJECTURAL): Phase Transition at λ*\nThe LLC profile shows a knee at λ* ~ γ²/n. The transition is from regular (LLC = (d+1)/2) to singular-at-infinity (LLC < (d+1)/2). In high dimensions (d ≫ n), the singular regime always dominates, connecting to double descent. The SGLD signature differs qualitatively from #831, #433, #870.\n\n## Open Problems\n\n1.
