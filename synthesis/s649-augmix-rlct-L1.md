#649 | AugMix × RLCT | L1: Formalization\n\n## Setup\nLet W ⊂ R^d be the parameter space, K(w) = L_CE(y, p_w(·|x)) + λ · L_JS(w) the AugMix loss. True distribution q(x,y), empirical distribution q_n, sample size n.\n\n## D1: Augmentation Chain Map\nFor input x ∈ R^C, define the base augmentation operation set O = {translate, shear, rotate, posterize, sharpen, blur, ...} (14 operations). Each o ∈ O is a semi-algebraic or analytic map R^C → R^C. A chain of depth d is the composition o_{i_d} ∘ ... ∘ o_{i_1}(x) where each o_{i_j} is sampled uniformly from O with random intensity. The k-th augmented sample is:\n  x_k = o_{k,d_k} ∘ ... ∘ o_{k,1}(x), k = 1,...,K (K=3)\nThe AugMix input is the Dirichlet mixture:\n  x_aug = Σ_{k=0}^K w_k · x_k, where x_0 = x, (w_0,...,w_K) ~ Dir(α)\n\n## D2: AugMix Loss Functional\nThe Jensen-Shannon divergence between K+1 distributions:\n  L_JS(w) = JS(p_w(·|x), p_w(·|x_aug_1), ..., p_w(·|x_aug_K))\n         = H(Σ_{k=0}^K w_k p_w(·|x_k)) - Σ_{k=0}^K w_k H(p_w(·|x_k))\nwhere H(p) = -Σ_i p_i log(p_i) is Shannon entropy.\nTotal loss: K(w) = L_CE(y, p_w(·|x)) + λ · L_JS(w)\n\n## D3: λ-Indexed Zero-Loss Sets\nDefine the zero-loss set family parameterized by λ:\n  V_λ = {w ∈ W : K(w) = 0} = {w : L_CE(w) = 0} ∩ {w : λ · L_JS(w) = 0}\nFor λ > 0: V_λ = V_CE ∩ V_cons where V_CE = {w : L_CE(w) = 0}, V_cons = {w : L_JS(w) = 0}.\nFor λ = 0: V_0 = V_CE.\n\n## D4: Singular Fiber Structure\nThe consistency fiber: V_cons = {w ∈ W : JS(p_w(·|x), p_w(·|x_1), ..., p_w(·|x_K)) = 0}.\nV_cons = 0 means all augmented predictions agree: p_w(·|x_k) = p_w(·|x) for all k.\nThe composite singular fiber: V_λ = V_CE ∩ V_cons.\nKey: V_cons is a quotient-like constraint collapsing augmentation-orbit predictions to a single distribution. Unlike group-orbit quotients (#143), AugMix operations are non-invertible and the mixture is stochastic — this is a non-group quotient singularity.\n\n## D5: Generalization Bound\nG(λ, α) = λ_augmix(λ, α) · log(n)/(2n) + B(λ, α)/√n\nwhere:\n- λ_augmix(λ, α) = RLCT of K(w) at the true singularity under (λ, α) parameters\n- B(λ, α) = E_x[KL(p*_{λ,α}(·|x) || p*(·|x))] measures the bias from consistency constraint\nClaim: λ_augmix(λ, α) ≤ λ_CE for moderate λ (consistency desingularization).\n\n## D6: Dual Stratum Selector (λ, α)\n- λ (consistency weight): controls V_cons dimensionality. λ → 0: V_cons = W (no constraint). λ → ∞: V_cons shrinks to thin consistency manifold.\n- α (Dirichlet concentration): controls augmentation diversity. α → 0: one chain dominates (degenerate). α → ∞: uniform mixing (max diversity).\nJoint stratum selector (λ, α) ∈ R_+ × R_+. Optimal (λ*, α*) is interior.\n\n## D7: Phase Transition\nAt (λ*, α*): SGLD-detectable kink in LLC trajectory.\nFor λ < λ*: LLC constant at λ_CE level (consistency too weak).\nFor λ > λ*: LLC decreases (desingularization active).\nFor α < α*: weak desingularization (homogeneous augmentations).\nFor α > α*: strong desingularization (diverse augmentations).\n\n## T1 (C1 formal): R_{an,exp}-definability of AugMix loss\nThe map (w, x, {x_k}, {w_k}) ↦ K(w) = L_CE + λ·L_JS is R_{an,exp}-definable.\nProof: (i) Augmentation ops o ∈ O are semi-algebraic or analytic → R_{an,exp}. (ii) Composition of R_{an,exp} maps is R_{an,exp}. (iii) Dirichlet mixture Σ w_k x_k is polynomial in w_k → semi-algebraic. (iv) p_w(·|x) = softmax(W·φ(x) + b) involves exp (analytic) → R_{an,exp}. (v) H(p) = -Σ p_i log(p_i), log globally subanalytic → R_{an,exp}. (vi) L_JS = H(Σ w_k p_k) - Σ w_k H(p_k): sums and differences of R_{an,exp} → R_{an,exp}. (vii) L_CE = -log p_w(y|x) → R_{an,exp}. (viii) K = L_CE + λ·L_JS: sum → R_{an,exp}. □\n\n## T2 (C2 formal): Consistency fiber singularity\nClaim: V_λ = V_CE ∩ V_cons has codim(V_λ) ≥ codim(V_CE), and for λ > 0 the intersection creates a higher-codimension singularity with λ_RLCT(V_λ) potentially < λ_RLCT(V_CE).\nKey mechanism: V_cons constrains predictions to agree across augmentations, collapsing augmentation-orbit prediction variance. This is a desingularization via consistency constraint — the consistency term removes singular directions corresponding to augmentation-sensitive parameter perturbations.\n\n## T3 (C3 formal): λ as stratum selector\nλ controls which singular strata are reachable:\n- λ → 0: V_λ = V_CE, full stratum access, λ_RLCT → λ_CE\n- λ → ∞: V_λ → V_cons, trajectory trapped in consistency manifold, λ_RLCT → λ_cons\n- λ* optimal: balance between CE singularity and consistency desingularization\n\n## T4 (C4 formal): Generalization bound\nG(λ, α) = λ_augmix(λ, α)·log(n)/(2n) + B(λ, α)/√n\nB(λ, α) → 0 as λ → 0 (no consistency constraint). B(λ, α) increases with λ (stronger constraint = more bias).\nOptimal λ* = argmin G satisfies: ∂λ_augmix/∂λ · log(n)/(2n) + ∂B/∂λ · 1/√n = 0.\n\n## T5 (C5 formal): Phase transition at (λ*, α*)\n∃ (λ*, α*) such that LLC(λ, α) has a kink at λ* for fixed α, and α* for fixed λ.\nBelow λ*: LLC = λ_CE (constant, consistency inactive).\nAbove λ*: LLC < λ_CE (decreasing, desingularization).\nAt λ*: cusp — ∂LLC/∂λ discontinuous.\nFalsifiable: SGLD sweep over (λ, α) grid should reveal 2D phase diagram.\n\n## Open Problems\n1.
