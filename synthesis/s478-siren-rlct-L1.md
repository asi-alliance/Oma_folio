## Synthesis #478: SIREN × RLCT — L1 Formalization\n\n### Definitions\n\n**D1 (SIREN Forward Pass).** Let φ_0(x) = x ∈ R^d. For layer l = 1,...,L:\n  φ_l(x) = sin(ω_l · (W_l · φ_{l-1}(x) + b_l))\nwhere W_l ∈ R^{d_l × d_{l-1}}, b_l ∈ R^{d_l}, ω_l > 0. Parameters θ = {(W_l, b_l, ω_l)}_{l=1}^L. The SIREN network is f_θ(x) = W_{L+1} · φ_L(x) + b_{L+1} (linear readout).\n\n**D2 (Periodic Zero Locus).** For a single SIREN neuron with output g(x) = sin(ω(w·x + b)), the zero locus is:\n  Z(g) = {x ∈ R^d : w·x + b = kπ/ω, k ∈ Z}\nThis is a countable union of affine hyperplanes H_k = {x : w·x + b - kπ/ω = 0}, each of codimension 1, spaced at period π/|ω·w| along the direction w/||w||.\n\n**D3 (Z-Symmetry Action on Parameter Space).** Define the group action σ_k : θ → θ_k where (W_l, b_l) → (W_l, b_l + 2πk/ω_l · e) for standard basis vector e, k ∈ Z. Since sin(ω_l(y + 2πk/ω_l)) = sin(ω_l y), we have f_{θ_k}(x) = f_θ(x) for all x. This defines a free Z-action on parameter space (modulo the readout layer). The quotient parameter space is Θ/Z ≅ [0, 2π/ω) × R^{dim-1}.\n\n**D4 (Effective Period Count).** For input domain [-R, R]^d and frequency ω, the effective number of periods in the domain is:\n  N_eff(ω, R) = ⌊2Rω/(π·||w||)⌋\nFor the network, the total effective period count across all neurons is N_eff(θ) = Σ_l Σ_j ⌊2Rω_l/(π·||w_{l,j}||)⌋ where j indexes neurons in layer l.\n\n**D5 (RLCT Mod Period).** The RLCT λ_SIREN is computed on the quotient space Θ/Z. By periodicity, all critical points in a single period have identical local singularity type λ_local. The global RLCT satisfies:\n  λ_SIREN = λ_local + c · (N_eff - 1)\nwhere c is the per-period RLCT increment from the additional degenerate fibers. For N_eff >> 1, λ_SIREN ≈ λ_0 + (2Rc/π) · ω (linear in ω).\n\n**D6 (Generalization Bound).** G_SIREN(ω, n) = λ_SIREN(ω) · log(n) / n + U_SIREN(ω) / √n, where U_SIREN(ω) = Var_{θ~posterior}[L(θ)] captures variance across periodic minima. U is bounded by O(N_eff(ω)) since each period contributes an independent shallow minimum.\n\n**D7 (ω* Phase Transition).** Define ω* = argmin_ω G_SIREN(ω, n). For signal with intrinsic bandwidth B, ω* ~ O(B) when n is large, balancing capacity (need ω ≥ B to represent signal) against RLCT regularization (need ω small for low λ).\n\n### Claims and Proof Sketches\n\n**C1 (Proven): R_an,exp Definability.**\n*Theorem.* The SIREN loss L(θ) = (1/n)Σ_i (f_θ(x_i) - y_i)² is definable in R_an,exp.\n*Proof.* sin is entire analytic with convergent Taylor series sin(x) = Σ_{k=0}^∞ (-1)^k x^{2k+1}/(2k+1)!, hence definable in R_an (analytic functions restricted to compact domains are subanalytic).
