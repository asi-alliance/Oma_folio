# Synthesis #NN2: Zoneout × RLCT - L1 Formalization\nDate: 2026-11-05 | Status: L1 FORMAL DEFINITIONS\n\n## D1: Zoneout-Augmented Recurrent Loss\n\nLet theta = (W_h, W_x, b) in R^d be the RNN parameters. At each timestep t in {1,...,T} and hidden unit i in {1,...,d_h}, draw m_{t,i} ~ Bernoulli(1-p) independently. The hidden state evolves as:\n  h_t = m_t odot h_tilde + (1 - m_t) odot h_{t-1}\nwhere h_tilde = sigma(W_h h_{t-1} + W_x x_t + b), h_0 = 0.\n\nFor a fixed mask realization m in {0,1}^{T x d_h}, the per-mask loss:\n  L(theta, m) = (1/n) sum_{i=1}^n ell(f_theta(x_i; m), y_i)\nwhere f_theta(x; m) is the output of the zoneout-augmented RNN with mask m fixed.\n\nThe zoneout loss is the expectation over masks:\n  L_zoneout(theta) = E_m[L(theta, m)] = sum_{m in {0,1}^{T x d_h}} (1-p)^{|m|} p^{T*d_h - |m|} L(theta, m)\n\nThis is a finite sum of 2^{T*d_h} terms, each weighted by Bernoulli probabilities.\n\n## D2: R_{an,exp}-Definability (C1 PROVEN)\n\nClaim: L_zoneout(theta) is definable over R_{an,exp}.\n\nProof sketch: For analytic activation sigma (tanh, sigmoid), each L(theta, m) is analytic — the RNN recurrence composes analytic functions, and the zoneout carry h_t = m_t odot h_tilde + (1-m_t) odot h_{t-1} is a piecewise affine combination in the mask variable (for fixed m, it is simply a different analytic recurrence). For ReLU, each L(theta, m) is subanalytic (piecewise polynomial).\n\nThe Bernoulli weights w(m) = (1-p)^{|m|} p^{T*d_h - |m|} are in R_{an,exp}: writing |m| = k, w = (1-p)^k p^{T*d_h - k} = exp(k log(1-p) + (T*d_h - k) log(p)), which is exponential of a polynomial in log(1-p) and log(p), hence in R_{an,exp}.\n\nFinite sums of R_{an,exp}-definable functions are R_{an,exp}-definable. By Tarski-Seidenberg, the singular locus Sing(L_zoneout) is definable. By Watanabe's main theorem, the RLCT lambda_zoneout exists.\n\nDistinction from #169 (Dropout): Dropout loss is also a finite sum, but each term L(theta, m) involves INDEPENDENT activation masking per layer — no temporal coupling between timesteps. Zoneout's L(theta, m) has CONDITIONAL dependence: h_t depends on h_{t-1} via the carry term, creating a compositional tower.\n\n## D3: Tower of Conditional Singular Fibers (C2)\n\nFor each mask m, define the zero-loss fiber:\n  V_m = {theta in R^d : L(theta, m) = 0}\n\nThe total zero-loss fiber:\n  V_zoneout = intersection_m V_m  (if we require zero loss for ALL masks)\n  V_zoneout = union_m V_m  (if we require zero loss for SOME mask)\n\nIn practice, the relevant object is the EXPECTED loss fiber: {theta : L_zoneout(theta) = 0} = intersection_m V_m (zero expected loss requires zero loss for every mask realization, since all weights are positive).\n\nKey structure: The fiber at timestep t, V_t(m_{1:t}), depends on the fiber at timestep t-1, V_{t-1}(m_{1:t-1}), via the carry:\n  h_t(m_{1:t}) = m_t odot sigma(W_h h_{t-1}(m_{1:t-1}) + W_x x_t + b) + (1 - m_t) odot h_{t-1}(m_{1:t-1})\n\nThis creates a TOWER of conditional fibers:\n  V_1(m_1) -> V_2(m_1, m_2) -> ... -> V_T(m_1, ..., m_T)\nwhere each arrow is a conditional map: V_t depends on V_{t-1} through the carried state h_{t-1}.\n\nThe RLCT of the tower, lambda_tower, is NOT simply min_m lambda(V_m). The conditional structure creates JOINT singularities at each level of the tower. Specifically, if theta is singular for the fiber at level t, it constrains the fiber at level t+1 through the carry map.\n\nDefinition: The tower RLCT is:\n  lambda_tower = RLCT(V_zoneout, L_zoneout) = RLCT(intersection_m V_m, L_zoneout)\n\nConjecture: lambda_tower >= max_m lambda(V_m) > min_m lambda(V_m).\nThe conditional structure INFLATES the RLCT relative to independent fibers because the tower creates additional constraints at each level.\n\n## D4: Zoneout Rate p as Stratum Selector (C3)\n\nThe zoneout probability p in [0,1] parameterizes a family of loss functions:\n  F_zoneout = {L_zoneout(theta; p) : p in [0,1]}\n\nStratum analysis:\n- p = 0: No carry, h_t = h_tilde for all t. Standard RNN. Single fiber V_0. RLCT = lambda_standard.\n- p = 1: All states frozen, h_t = h_{t-1} = h_0 = 0. Trivial identity map. V = R^d (all theta give zero output if output depends only on h_T = 0). Degenerate, lambda -> 0.\n- 0 < p < 1: Tower of 2^{T*d_h} conditional fibers, weighted by p.\n\nThe effective recurrent depth:\n  E[T_eff(p)] = sum_{t=1}^T P(h_t is updated) = T * (1-p)\n\nLower p -> deeper effective recurrence -> richer singular structure -> potentially higher lambda. Higher p -> shallower effective recurrence -> simpler structure -> lower lambda but worse fit.\n\nPercolation analogy: Consider the temporal fiber graph G = (V, E) where nodes are timesteps and edges represent carry connections (h_t depends on h_{t-1}). The zoneout mask m determines which edges are "active" (updated) vs "frozen" (carried). The occupation probability is (1-p) for active edges. The RLCT lambda_tower(p) depends on the connectivity of this graph.\n\nBy directed percolation theory, there exists a critical occupation probability p_c (percolation threshold) below which the giant connected component spans the graph. Translating: there exists p* such that:\n- p < p*: Tower is "connected" — enough updates propagate through time to maintain rich singular structure. lambda_tower(p) approx lambda_standard.\n- p > p*: Tower is "disconnected" — too many frozen states, effective recurrence too shallow. lambda_tower(p) drops sharply.\n- p = p*: Phase transition, fiber connectivity changes topology.\n\n## D5: p-Stratified Loss Family\n\nDefine the parameterized family:\n  F_zoneout = {L_zoneout^{(p)} : p in [0,1]}\n\nFor each p, the singular fiber structure changes. The family F_zoneout is a continuous stratification of the loss landscape by zoneout rate.\n\nThe Fisher information matrix at the true parameter theta*:\n  I_zoneout(theta*; p) = E_m[ nabla_theta^2 L(theta, m) |_{theta*} ]\n\nThe effective rank of I_zoneout depends on p:\n  rank_eff(p) = rank(I_zoneout(theta*; p))\n\nFor p near 0: rank_eff approx rank_standard (full recurrence).\nFor p near 1: rank_eff -> 0 (frozen states, no gradient flow through time).\n\nThe RLCT in the generic (regular) case:\n  lambda_zoneout(p) = rank_eff(p) / 2\n\nIn the singular case (which is the interesting regime for RNNs):\n  lambda_zoneout(p) >= rank_eff(p) / 2\n\nwith equality iff the fiber is a regular submanifold.\n\n## D6: Tower Tension Generalization Bound (C4)\n\nFor zoneout-augmented RNNs with zoneout rate p, the generalization error:\n  G_zoneout(p) ~ lambda_tower(p) / n + U_tower(p) / sqrt(n)\n\nwhere:\n- lambda_tower(p) = RLCT of the conditional fiber tower at zoneout rate p\n- U_tower(p) = fluctuation functional, accounting for the variance across mask realizations\n\nThe "tower tension":\n  tau(p) = lambda_tower(p) - lambda_standard\n\nmeasures the REGULARIZATION cost of the conditional fiber structure.\n\n- tau(p) > 0: Tower structure INFLATES complexity relative to standard RNN. This happens when conditional dependencies create additional singular constraints.\n- tau(p) < 0: Tower structure REDUCES complexity (unlikely given the intersection structure, but possible if the tower resolves singularities via stochastic averaging).\n- tau(p) = 0: Tower collapses to standard RNN (p -> 0 limit).\n\nOptimal p* minimizes G_zoneout(p):\n  p* = argmin_p [ lambda_tower(p) / n + U_tower(p) / sqrt(n) ]\n\nThis balances tower complexity (lambda_tower) against fit quality (U_tower includes the bias from frozen states).\n\nComparison to #169 (Dropout): G_dropout ~ min_m lambda(V_m) / n + U_dropout / sqrt(n). Dropout's independent fibers give min over masks. Zoneout's conditional tower gives a JOINT lambda that accounts for temporal dependencies — fundamentally different geometry.\n\n## D7: Percolation Phase Transition at p* (C5)\n\nConjecture: There exists a critical zoneout rate p* in (0,1) where the RLCT undergoes a phase transition.\n\nMechanism: The temporal fiber graph undergoes a directed percolation transition at p*:\n- p < p*: The giant connected component of active (updated) edges spans the full sequence length T.
