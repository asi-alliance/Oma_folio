# Synthesis #856: Flow Matching x RLCT\n## L0: Claims and Definitions\n## Date: 2026-11-06\n\n### Topic\nFlow Matching (continuous-time generative modeling via ODE vector field regression) analyzed through Singular Learning Theory (RLCT).\n\n### Background\nFlow Matching learns a time-dependent vector field v_t(x;theta) that transports a base distribution p_0 (e.g. Gaussian) to a data distribution p_1 via ODE integration: dx/dt = v_t(x;theta). Training regresses v_t against a conditional vector field u_t(x|x_1) defining a probability path p_t(x|x_1). Conditional Flow Matching (CFM) loss: L_CFM = E_t E_{x_1~q, x_t~p_t(.|x_1)} ||v_t(x_t;theta) - u_t(x_t|x_1)||^2.\n\n### Key Definitions\n- D1: Conditional probability path p_t(x|x_1) = N(x; mu_t(x_1), sigma_t(x_1)^2 I), t in [0,1], interpolating noise (t=0) to data (t=1). Common choices: linear (mu_t = t*x_1, sigma_t = 1-t), OT (optimal transport), and variance-preserving (VP).\n- D2: Conditional vector field u_t(x|x_1) = (x - mu_t(x_1)) / sigma_t(x) * dsigma_t/dt + dmu_t/dt. This is the analytic target field.\n- D3: Flow Matching loss: L_FM(theta) = E_{t~U(0,1), x_1~q, x~p_t(.|x_1)} ||v_t(x;theta) - u_t(x|x_1)||^2. v_t is a neural network (the flow model).\n- D4: Marginal vector field: the marginal ODE dx/dt = v_t(x;theta*) where theta* minimizes L_FM. This generates samples by integrating from t=0 to t=1.\n- D5: Rectified flow: iterative straightening - retrain flow on pairs (x_0, x_1) where x_0 is a sample from the current flow. Each rectification step reduces curvature, approaching straight-line (constant vector field) trajectories. Distinct from the initial flow matching.\n\n### Claims\n- C1 (PROVEN): L_FM is definable in R_{an,exp}. The CFM loss is a squared L2 norm of (v_t - u_t), where v_t is a neural network (analytic composition if activations are analytic), u_t is an explicit analytic function of (x, x_1, t) for standard paths (Gaussian, linear, VP). The expectation over t (uniform) and x_t (Gaussian) preserves definability via finite-sample empirical sum. Thus L_FM in R_{an,exp}, finite RLCT via resolution of singularities.\n- C2 (CONJECTURAL): Transport map degeneracy singular fiber. The vector field v_t(x;theta) defines a flow map Phi_t: p_0 -> p_t. At theta where Phi_t is non-injective (multiple x_0 map to same x_t), the Fisher information loses rank in the direction of the collapsing flow. This occurs when v_t has a critical point (v_t = 0) creating a stationary solution, or when v_t has a saddle creating flow line merging. The singular fiber V_transport = {theta : Phi_t non-injective for some t} is a subvariety of the zero-loss set.\n- C3 (CONJECTURAL): Time-conditioned stratum structure. The vector field v_t depends on t, creating a family of singular fibers {V_t}_t in [0,1]. The global RLCT is lambda_FM = max_t lambda(V_t) or an integrated version. At t=0 (pure noise), the target u_t is smooth (Gaussian), low degeneracy. At t=1 (data manifold), the target concentrates on the data distribution, potentially high degeneracy. The time-parameterized stratum selector t selects which singular structure dominates.\n- C4 (CONJECTURAL): Compound generalization bound: G_FM(n) ~ [lambda_FM] * log(n)/(2n) + V(d_v)/sqrt(n), where lambda_FM is the RLCT of the flow matching loss and V(d_v) is the variance term from vector field dimension. Rectification (straightening) reduces lambda by simplifying the transport map: rectified flow has lower curvature -> fewer flow line crossings -> fewer non-injectivity -> lower lambda. Each rectification step monotonically decreases lambda (conjecture).\n- C5 (CONJECTURAL): Straightening phase transition. During rectification (iterative retraining), at step r*, the flow trajectories become effectively straight (vector field nearly constant along trajectories). Order parameter: trajectory curvature kappa = E[||d^2x/dt^2||]. At r*, kappa -> 0 sharply. SGLD-detectable: LLC decreases stepwise (each rectification reduces lambda), Fisher rank stabilizes (no more transport degeneracies), kappa drops. This is a training-procedure-driven phase transition, not a within-training phase transition.\n\n### Falsifiable Predictions\n1. Transport degeneracy: at theta where v_t(x)=0 for some (x,t), Fisher information loses rank in the spatial direction. Measurable via Hessian analysis at critical points of v_t.\n2. Time-stratified RLCT: lambda(V_t) should be lower at t=0 (Gaussian target) than at t=1 (data manifold target). Measurable by training separate models for fixed t and comparing LLC.\n3. Rectification RLCT reduction: each rectification step should show lower LLC than the previous. Measurable via SGLD.\n4. Straightening transition: curvature kappa should drop sharply at some rectification step r*, correlated with LLC stabilization.\n5. Path choice matters: OT path (straight mu_t = t*x_1) should have lower lambda than VP path (curved) because transport map is closer to injective.\n\n### Open Problems\n1.
