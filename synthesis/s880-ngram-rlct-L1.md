# Synthesis #880: N-gram Language Model x RLCT --- L1\n\n**Date:** 2026-11-09 | **Status:** L1 (formalization)\n\n---\n\n## Definitions\n\n### D1: Vocabulary and Token Sequence\nV = {v_1, ..., v_V} is a finite vocabulary of size V.\nA token sequence x = (x_1, ..., x_T) with x_t in V.\nIndicator function: 1[x_t = v] in {0, 1}.\n\n### D2: Context and Counts\nFor Markov order n, the context of position t is:\nc_t = (x_{t-n+1}, ..., x_{t-1}) in V^{n-1}\n\nContext-count function:\nN(c) = sum_{t=n}^{T} 1[c_t = c] (number of times context c appears)\nJoint count: N(c, w) = sum_{t=n}^{T} 1[c_t = c, x_t = w]\n\nNote: N(c) = sum_w N(c, w) (partition of counts).\n\n### D3: N-gram Likelihood\nThe n-gram model parameter space is the product simplex:\nW_n = (Delta_V)^{V^{n-1}} = {p = (p(.|c))_{c in V^{n-1}} : for each c, p(.|c) in Delta_V}\n\nDimension: d_n = V^{n-1} x (V - 1)\n\nThe n-gram likelihood for sequence x given parameter p is:\nL_n(p | x) = prod_{t=n}^{T} p(x_t | c_t)\n\nLog-likelihood:\nK_n(p | x) = - (1/T) sum_{t=n}^{T} log p(x_t | c_t)\n          = - (1/T) sum_{c, w} N(c, w) log p(w | c)\n\nThe MLE is: p_MLE(w | c) = N(c, w) / N(c) when N(c) > 0.\n\n### D4: Zero-Count Fiber\nThe zero-count set is:\nZ_0 = {c in V^{n-1} : N(c) = 0}\n\nThe zero-count fiber in parameter space is:\nV_0 = {p in W_n : for all c in Z_0, p(.|c) is unconstrained}\n\nEach c in Z_0 contributes a free (V-1)-dimensional simplex fiber. The fiber dimension is:\ndim(V_0) = |Z_0| x (V - 1)\n\nThe singular locus of the likelihood is determined by the zero-count contexts: where the data provides no constraint, the Fisher information vanishes.\n\n### D5: Smoothing Operators\n\n**Add-k (Laplace):**\nS_k(p)(w|c) = (N(c,w) + k) / (N(c) + kV), k > 0\nDenominator N(c) + kV > 0 for all c, so the map is smooth on W_n.\n\n**Good-Turing:**\nN_r = #{(c,w) : N(c,w) = r} (number of n-grams with count r)\nN*(r) = (r+1) x N_{r+1} / N_r (Turing estimate of adjusted count)\nS_GT(p)(w|c) = N*(N(c,w)) / N when N(c,w) > 0\nUnseen mass: P_0 = N_1 / N (total probability for unseen events)\n\n**Kneser-Ney:**\nS_KN(p)(w|c) = max(N(c,w) - D, 0) / N(c) + lambda(c) x p_KN(w|c')\nwhere c' = (c_2, ..., c_{n-1}) is the suffix context, D is the discount, and\nlambda(c) = (D / N(c)) x |{w' : N(c,w') > 0}|\n\nThe recursion S_KN^{(n)} -> S_KN^{(n-1)} creates a hierarchical desingularization.\n\n### D6: RLCT Definition\nFor the n-gram model with true distribution q and model P_p:\nThe KL divergence is:\nK(p) = sum_{c,w} q(c,w) log(q(w|c) / p(w|c))\n\nThe set of optimal parameters:\nW_0 = {p in W_n : K(p) = 0} = {p : p(w|c) = q(w|c) for all c with q(c) > 0}\n\nNote: For c in Z_0 (zero-count contexts), any p(.|c) in Delta_V is in W_0 (no constraint).\n\nThe RLCT lambda_n is defined via the z-function:\nZ_n = int_{W_n} exp(-T x K_n(p)) dp\n\nAs T -> infinity: Z_n ~ C x T^{-(d_n - lambda_n)/2}\n\nThe RLCT captures the effective dimensionality reduction from the singular fibers.\n\n### D7: Phase Transition Order n*\nThe critical Markov order n* is defined as:\nn* = max{n : V^{n-1} x (V-1) <= n_samples / log(n_samples)}\n\nEquivalently: n* ~ log_V(n_samples / log(n_samples))\n\nBelow n*: rho_n = |Z_0| / V^{n-1} approx 0 (most contexts observed)\nAt n*: rho_n crosses a critical threshold (combinatorial phase transition)\nAbove n*: rho_n -> 1 (most contexts unobserved)\n\n---\n\n## Formal Claims\n\n### C1: Definability [PROVEN]\n**Statement:** The n-gram log-likelihood K_n(p|x) is R_an-definable.\n**Proof sketch:**\n- The counting functions N(c,w) = sum_t 1[c_t=c, x_t=w] are polynomial in the indicator variables, hence semialgebraic (in R_an).\n- The MLE p_MLE(w|c) = N(c,w)/N(c) is a rational function (polynomial / polynomial), hence in R_an.\n- The log-likelihood K_n = -(1/T) sum_{c,w} N(c,w) log p(w|c) is the log of a positive rational function on the simplex, which is subanalytic (bounded below by 0, composition of log with rational function on a compact domain).\n- For smoothed variants: add-k is rational (R_an), Good-Turing uses counting functions (piecewise R_an), Kneser-Ney uses max(.,0) (semialgebraic, R_an).\n- No exponential terms needed for discrete n-gram models. R_an suffices.\n\n### C2: Zero-Count Fiber RLCT [CONJECTURAL]\n**Statement:** Each unobserved context c in Z_0 contributes RLCT contribution (V-1)/2 to the total RLCT.\n**Argument:**\n- For c in Z_0, the parameter p(.|c) lives in Delta_V, a (V-1)-dimensional simplex.\n- The KL divergence K(p) has no dependence on p(.|c) for c in Z_0 (data provides no constraint).\n- The fiber is a free (V-1)-dimensional simplex with flat KL divergence (K = 0 on the entire fiber).\n- By Watanabe (2009, Theorem 3.1 for multinomial models), the RLCT of a free d-dimensional simplex fiber is d/2 = (V-1)/2.\n- Total RLCT: lambda_n = (V-1)/2 x |Z_0| + lambda_reg, where lambda_reg is the regular-model RLCT for observed contexts.\n- For the regular part: lambda_reg = 0 (non-singular, Fisher information positive definite for well-observed contexts).\n- Conjecture: lambda_n = (V-1)/2 x |Z_0|.\n\n### C3: Markov Order as Discrete Stratum Selector [CONJECTURAL]\n**Statement:** The RLCT lambda_n is a function of the sparsity ratio rho_n = |Z_0|/V^{n-1}, with lambda_n approx (V-1)/2 x rho_n x V^{n-1}.\n**Argument:**\n- As n increases, V^{n-1} grows exponentially while |Z_0| also grows (more contexts unobserved).\n- Below n*: rho_n approx 0, so lambda_n approx 0 (regular model).\n- At n*: rho_n crosses a threshold, lambda_n begins to grow.\n- Above n*: rho_n -> 1, so lambda_n -> (V-1)/2 x V^{n-1} (all contexts are free fibers).\n- The order n acts as a discrete stratum selector, analogous to #877 decision tree depth D* and #480 muP width*.\n\n### C4: Smoothing as Desingularization [CONJECTURAL]\n**Statement:** For any smoothing operator S, the smoothed RLCT satisfies lambda_S <= lambda_MLE, with equality iff smoothing is trivial.\n**Argument:**\n- Add-k: S_k removes the zero-count singularity by ensuring the denominator N(c) + kV > 0. The map S_k is smooth on W_n. The smoothed KL divergence K_S_k(p) = K_n(S_k(p)) has no singular fibers (positive definite Fisher information everywhere). Thus lambda_{add-k} = d_n/2 (regular model, all parameters contribute). But wait -- this means lambda_{add-k} = d_n/2 > lambda_MLE for large n (since d_n grows exponentially). \n- Correction: The RLCT compares the singular model to the regular model. The MLE singular model has lambda_n = (V-1)/2 x |Z_0| (reduced from d_n/2 by the singular fibers). Smoothing removes the singular fibers, making the model regular with lambda = d_n/2. So lambda_smooth = d_n/2 >= lambda_MLE. The singular model has LOWER RLCT than the smoothed (regularized) model. This is consistent with Watanabe's theory: singular models generalize better because lambda < d/2.\n- Revised statement: lambda_MLE <= lambda_smooth = d_n/2, with strict inequality when |Z_0| > 0. The MLE singular model has lower RLCT (better generalization) than the smoothed regular model.\n- This explains why smoothing can HURT generalization when the singular structure is beneficial (contrary to standard NLP wisdom). But smoothing also reduces variance, so the trade-off is RLCT (bias) vs variance.\n\n### C5: Phase Transition at n* [CONJECTURAL]\n**Statement:** The LLC (local learning coefficient) profile shows a kink at n = n*, transitioning from regular (lambda approx 0) to singular (lambda -> (V-1)/2 x V^{n-1}).\n**Argument:**\n- n* ~ log_V(n/log(n)) is the combinatorial capacity threshold.\n- Below n*: V^{n-1}(V-1) << n, most contexts observed, lambda approx 0.\n- At n*: the fraction of zero-count contexts rho_n crosses a critical value, creating a phase transition in the LLC.\n- Above n*: rho_n -> 1, lambda -> (V-1)/2 x V^{n-1}, singular fiber dominates.\n- The transition is COMBINATORIAL (driven by exponential growth of V^{n-1} vs polynomial growth of n), distinct from algebraic transitions in neural networks (#480 muP, #570 randomized smoothing).\n- SGLD estimation of the LLC should show a sharp kink at n*.\n\n---\n\n## Cross-References\n\n- #873 (HMM x RLCT): Hidden state count K* as stratum selector; n-gram uses Markov order n (fully observable, no hidden states).\n- #268 (GMM/EM label switching): Discrete non-identifiability via permutation; n-gram has no label switching (contexts are observed).\n- #520 (Neural MLM): Continuous representation via softmax; n-gram is discrete counting (rational MLE).\n- #220 (Weight decay/pruning): Parameter regularization; n-gram smoothing is data regularization (removing data-driven singularities).\n- #570 (Randomized smoothing): Gaussian desingularization of parameter space; add-k is algebraic desingularization of count space.\n- #877 (Decision Tree depth D*): Discrete stratum selector via tree depth; n-gram order n is analogous.\n- #409 (Gumbel-Softmax): Temperature phase transition; n-gram smoothing parameter k is analogous desingularization parameter.\n\n---\n*Next: L2 (novelty assessment and gap analysis).*
