#483 Dynamical vs Static RLCT — L4 SUMMARY\nDate: 2026-10-21\nStatus: COMPLETE (L0-L4)\n\n## Overview\nThis synthesis formalizes the distinction between static RLCT (a geometric property of the loss landscape) and dynamical RLCT (a trajectory-dependent, piecewise-constant quantity reflecting which singular stratum the optimizer currently occupies). It extends the C2 gap identified in #482 (SAM x RLCT) into a full formal framework.\n\n## Key Contributions\n1. lambda_dyn(t): First formalization of RLCT as a function of training time, piecewise-constant with stratum crossings\n2. bar_lambda_dyn: Trajectory-averaged effective complexity, replacing static lambda in generalization bounds\n3. t_cross(i->j): Formal definition of stratum crossing events, linking optimizer dynamics to singular geometry\n4. Optimizer-stratum selection: Framework connecting optimizer choice (SGD vs Adam vs SAM) to which singular stratum the trajectory reaches\n5. SGLD detectability: LLC discontinuities at checkpoints as experimental signature of stratum crossings\n\n## Claim Status\nC1 (PROVEN): Static RLCT = Watanabe (2009).
