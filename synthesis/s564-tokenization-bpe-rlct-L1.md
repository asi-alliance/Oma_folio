# Synthesis #564: Tokenization / BPE × RLCT\n## Date: 2026-10-23\n## Status: L1 (Formalization)\n\n### Formal Definitions\n\n**D1 (BPE Tokenization Map)**: Let Σ be a byte alphabet. A BPE tokenizer with merge table M = (m_1, ..., m_K) defines a map T_M: Σ* → {1, ..., V}* where V = |Σ| + K is the vocabulary size. Each merge m_k = (a, b) → c replaces the leftmost occurrence of pair (a,b) with token c, applied in order. T_M is a deterministic, piecewise-constant function of the input string.\n\n**D2 (Embedding Lookup)**: The embedding matrix E ∈ R^{V×d} maps token IDs to vectors via E[i] = e_i. The composed map from input string s to embedding is φ_E∘T_M(s) = (E[T_M(s)_1], ..., E[T_M(s)_{|T_M(s)|}]). This is piecewise-linear in E (for fixed T_M) and piecewise-constant in s (for fixed E).\n\n**D3 (Tokenized Loss)**: For a model with parameters θ = (E, W) where W are non-embedding parameters, the loss is L(θ) = E_{s~D}[KL(p_θ(·|T_M(s)) || q(·|s))]. Since T_M is fixed (not learned during training), the parameter space is Θ = R^{V×d} × R^P where P = dim(W).\n\n**D4 (Token Fiber)**: For token ID i, the fiber is F_i = T_M^{-1}(i) = {s ∈ Σ* : i ∈ T_M(s)}. For a sequence of tokens (i_1,...,i_n), the fiber is F_{i_1,...,i_n} = T_M^{-1}((i_1,...,i_n)). These fibers partition Σ*.\n\n**D5 (Singular Locus)**: The singular locus in E-space is Σ_E = {E : ∃ i≠j, E_i = E_j} ∪ {E : rank(E_{S}) < min(|S|, d) for some token subset S}. The first component is the embedding collision set (permutation symmetry), the second is the rank-deficiency set (determinantal variety).\n\n**D6 (Vocabulary Size as Stratum Selector)**: For vocabulary size V, define the stratum S_V = {θ ∈ Θ : the effective partition granularity is determined by V}. As V increases, the partition refines and the fiber sizes |F_i| decrease. The RLCT λ(V) is a function of V through the fiber structure.\n\n**D7 (Generalization Bound)**: The generalization gap for a tokenized model satisfies G(V) ≤ C·λ(V)/n + U(V)/√n where λ(V) is the RLCT at vocabulary size V, n is the number of training samples, and U(V) captures the model complexity term (growing with V·d).\n\n### Claims\n\n**C1 (R_{an,exp}-definability) — PROVEN**: T_M is a composition of equality tests (semi-algebraic on discrete symbols). E[·] is piecewise-linear. The KL divergence is analytic in the model output. The composition is definable in R_{an,exp} by closure under composition and Tarski-Seidenberg projection of semi-algebraic sets.\n\n**C2 (Singular Fiber Structure) — CONJECTURAL**: The singular locus Σ_E has strata indexed by: (a) embedding collisions (E_i = E_j), creating S_V-symmetric permutation fibers, and (b) tokenization boundary crossings, where small input perturbations change T_M(s). The embedding collision stratum has RLCT = dim(E)/2 by the determinantal variety formula. The tokenization boundary stratum contributes an additional singular component proportional to the number of active merge boundaries.\n\n**C3 (RLCT Phase Transition with V) — CONJECTURAL**: There exists V* such that λ(V) is minimized at V*. For V < V*, coarse tokenization creates large degenerate fibers (high λ from embedding collisions). For V > V*, the parameter count V·d dominates and λ increases due to overfitting capacity. The phase transition at V* reflects the match between tokenization granularity and the data manifold's local structure.\n\n**C4 (Generalization Bound) — CONJECTURAL**: G(V) ≤ C·λ(V)/n + U(V)/√n with λ(V) U-shaped in V. The optimal vocabulary size V* minimizes this bound. Tokenization acts as a preconditioner: directions in input space along which T_M is constant are invisible to gradient descent, creating flat directions in the loss landscape.\n\n**C5 (Interactions) — CONJECTURAL**: (a) BPE merge order affects Σ_E structure → different λ for same V.
