# Synthesis #657: Dynamic Sparse Training (DST) x RLCT - L1 Formalization\n\n## Date: 2026-10-26\n## Status: L1 FORMAL DEFINITIONS\n\n## D1: Masked Loss and Mask Update Map\n\nLet W in R^d be the full parameter vector. A binary mask M(t) in {0,1}^d selects active weights. The masked forward pass is f_{M(t) odot W}(x), where odot denotes the Hadamard product.\n\nThe empirical loss at step t:\n  L_n(M(t) odot W) = (1/n) sum_{i=1}^n ell(f_{M(t) odot W}(x_i), y_i)\n\nMask update rule (RigL variant): every Delta-T steps, prune the lowest-magnitude active weights and regrow the highest-gradient-magnitude inactive weights:\n  For pruning: remove j where |W_j| is smallest among {j : M(t)_j = 1}\n  For regrowth: add k where |grad_k L_n| is largest among {k : M(t)_k = 0}\n  Maintain |M(t)| = s*d (fixed sparsity s).\n\nSET variant: prune by magnitude, regrow randomly. SNIP variant: single-shot at initialization. We focus on RigL as the canonical dynamic case.\n\n## D2: R_an,exp Definability\n\nThe masked loss L_n(M(t) odot W) is definable over R_an,exp.\n\nProof sketch: The mask M(t) is a binary vector. The Hadamard product M(t) odot W = (M_1 W_1, ..., M_d W_d) is semialgebraic: for each coordinate j, (M_j W_j) = W_j if M_j=1, 0 if M_j=0, expressible as M_j * W_j where M_j in {0,1} (a semialgebraic set). The neural network f_{M(t) odot W} is a composition of analytic functions (ReLU is definable in R_an,exp as max(x,0) = x * 1_{x>0}, semialgebraic). The loss ell is analytic (cross-entropy, MSE). The composition preserves R_an,exp definability. By Tarski-Seidenberg, the singular locus Sing(L_n(M(t) odot W)) is definable.\n\n## D3: Evolving Singular Fiber V_0(t)\n\nAt step t, define the zeroed set Z(t) = {j in [d] : M(t)_j = 0}. The coordinate subspace:\n  V_0(t) = {W in R^d : W_j = 0 for all j in Z(t)}\nis a singular stratum of the masked loss landscape.\n\nKey distinction from prior syntheses:\n- #169 Dropout: V_0 is random per minibatch (i.i.d. Bernoulli), no temporal evolution.\n- #220 Pruning: V_0 is fixed post-training, no evolution.\n- #225 LTH: V_0 is fixed from initialization.\n- #657 DST: V_0(t) EVOLVES deterministically via prune-grow cycles. The fiber trajectory {V_0(t)}_{t=0}^T traces a path through the stratum lattice.\n\nThe RLCT at step t: lambda(t) = lambda(V_0(t), L_n).\n\nConjecture: lambda(t) is non-increasing over training (gradient-based regrowth preferentially activates weights in singular directions, moving toward lower-RLCT strata).\n\n## D4: Update Interval Delta-T as Stratum Selector\n\nThe update interval Delta-T (steps between mask updates) parameterizes the stratum evolution rate.\n\n- Delta-T = 1: mask updates every step. Fast stratum switching, potentially high-frequency oscillation in lambda(t). The model may not converge within any single stratum.\n- Delta-T = infinity: no updates, degenerates to static sparsity (#225 LTH-like).\n- Delta-T finite > 1: periodic stratum transitions.\n\nThe effective number of strata visited: N_strata ~ T/Delta-T.\n\nThe effective RLCT is a trajectory average:\n  lambda_eff(Delta-T) = (1/T) sum_{t=1}^T lambda(V_0(t))\n\nConjecture: lambda_eff(Delta-T) is U-shaped, with optimal Delta-T* ~ n^{1/(lambda+1)} balancing exploration (lower lambda via better mask) and stability (lower U from fewer topology changes).\n\n## D5: Delta-T-Stratified Loss Family\n\nDefine the parameterized family:\n  F_DST = { L_n^{(Delta-T)} : Delta-T in {1, 2, ..., T} }\nwhere L_n^{(Delta-T)} is the loss trajectory with update interval Delta-T.\n\nFor each Delta-T, the singular fiber structure changes. The family F_DST is a discrete stratification of the loss landscape by update frequency.\n\nAt Delta-T = 1, the fiber V_0(t) changes every step, creating a dense trajectory through stratum space.\nAt Delta-T = T (single update), V_0 is fixed except one transition, approximating two-stage pruning.\n\nThe Fisher information matrix at the true parameter W* restricted to active coordinates has RLCT:\n  lambda_{active}(t) = dim(V_0(t)) / 2  (in the generic case)\nbut the singularity correction from the loss landscape structure gives the true lambda(t) >= lambda_{active}(t).\n\n## D6: Generalization Bound with Mask Dynamics\n\nFor DST with sparsity s and update interval Delta-T, the generalization error:\n  G_DST ~ lambda_eff(s, Delta-T) / n + U(Delta-T) / sqrt(n)\n\nwhere:\n- lambda_eff(s, Delta-T) = trajectory-averaged RLCT (lower with better mask exploration)\n- U(Delta-T) = complexity from topology changes (higher with more frequent updates)\n\nConjecture: lambda_DST <= lambda_prune(s) for the same final sparsity s, because dynamic exploration finds lower-RLCT strata than any fixed mask.\n\nTension: Lower Delta-T reduces lambda_eff (better exploration) but increases U (instability from frequent topology changes). The bound is minimized at Delta-T*.\n\nComparison to #220 (static pruning): G_prune ~ lambda_prune(s)/n + U_prune/sqrt(n), where lambda_prune(s) is fixed by the pruning criterion. DST trades a potentially lower lambda for a potentially higher U.\n\n## D7: Phase Transition at Critical Sparsity-Update Rate\n\nThere exists a critical sparsity-update rate (s*, Delta-T*) at which generalization undergoes a phase transition.\n\n- High sparsity + frequent updates (s >> s*, Delta-T << Delta-T*): the mask oscillates among high-RLCT strata without convergence. Generalization degrades. The model cannot find a stable low-RLCT fiber.\n- Low sparsity + infrequent updates (s << s*, Delta-T >> Delta-T*): DST approaches dense training. lambda_eff approaches lambda_dense. Generalization matches dense baseline.\n- At (s*, Delta-T*): the mask dynamics align with the singular structure. lambda_eff is minimized. The phase transition is testable via SGLD by measuring the RLCT of the evolving model at different (s, Delta-T) settings.\n\nConjecture: the phase transition is sharp (non-analytic in s and Delta-T) because the stratum topology changes discontinuously at the critical point.\n\n## Claims Summary\n- C1 (PROVEN): R_an,exp definability of masked loss (D2).\n- C2 (CONJECTURAL): Evolving singular fiber V_0(t) with non-increasing lambda(t) (D3).\n- C3 (CONJECTURAL): Update interval Delta-T as stratum selector, U-shaped lambda_eff (D4-D5).\n- C4 (CONJECTURAL): Generalization bound G_DST ~ lambda_eff/n + U/sqrt(n) with lambda_DST <= lambda_prune (D6).\n- C5 (CONJECTURAL): Phase transition at critical (s*, Delta-T*) (D7).\n\n## Open Problems\n1.
