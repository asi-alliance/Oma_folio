#657: Nucleus Sampling (Top-p) × RLCT — L1 Formalization\n\n## Definitions\n\nD1 (Parameter space): Let W ⊂ R^d be the parameter space of a language model with softmax output p_w(v|x) = exp(z_w(v,x))/Σ_v' exp(z_w(v',x)) over vocabulary V.\n\nD2 (Sorted distribution): For input x, sort vocabulary by descending probability: π_w,x: V → {1,...,|V|} s.t. p_w(π^{-1}(1)|x) ≥ p_w(π^{-1}(2)|x) ≥ ... Define cumulative C_w,x(j) = Σ_{i≤j} p_w(π^{-1}(i)|x).\n\nD3 (Nucleus set): For threshold p ∈ (0,1], the nucleus is V_p(w,x) = {π^{-1}(1), ..., π^{-1}(k_p(w,x))} where k_p(w,x) = min{j : C_w,x(j) ≥ p}. The truncated distribution is q_w,p(v|x) = p_w(v|x)/p · 1[v ∈ V_p(w,x)] where p = C_w,x(k_p).\n\nD4 (Nucleus-sampled loss): L_p(w) = -(1/n)Σ_i Σ_v q_w,p(v|x_i) · log q_w,p(v|x_i) + cross-entropy terms. Equivalently, the per-sample loss restricts cross-entropy to the nucleus: ℓ_p(w,x) = -log(q_w,p(y|x)) where y is the target token.\n\nD5 (Nucleus boundary): The boundary hypersurface B_v(w,x) = {w : C_w,x(π_w,x^{-1}(v)-1) < p ≤ C_w,x(π_w,x^{-1}(v))} defines the set where token v is the marginal nucleus member — entering or exiting as p crosses this surface.\n\nD6 (Singular fibers): For each nucleus realization S ⊂ V, the fiber F_S = {w : V_p(w,x) = S for all x in support} is the set of parameters yielding nucleus S. The restriction L_p|F_S is smooth (analytic within softmax). Singularities arise at ∂F_S = boundary where V_p changes.\n\nD7 (RLCT decomposition): λ(p) = max(λ_intra, λ_boundary(p)) where λ_intra is the RLCT of L_p restricted to a fixed nucleus (equals full-softmax RLCT by conditional smoothness) and λ_boundary(p) captures singularity at nucleus-switching boundaries.\n\n## C1 (PROVEN): R_{an,exp}-definability\n\nThe softmax p_w(v|x) = exp(z_w(v,x))/Σ exp(z_w(v',x)) is R_{an,exp}-definable. The sorting permutation π_w,x is definable via finite comparisons of definable quantities (semialgebraic selection). The cumulative sum C_w,x(j) is a finite sum of definable terms. The nucleus cardinality k_p(w,x) = min{j : C_w,x(j) ≥ p} is definable via the definable selection theorem (argmin over a definable set with definable predicate). The truncated distribution q_w,p and the loss ℓ_p(w,x) involve exp, log, indicator functions on definable sets (nucleus membership via semialgebraic inequalities), and arithmetic — all R_{an,exp}-definable. By closure under composition, L_p(w) is R_{an,exp}-definable. ∎\n\n## C2 (CONJECTURAL): Nucleus set as stratum selector\n\nV_p(w,x) is data-and-parameter-dependent: it depends on w through the sorted probabilities and on x through the input conditioning. Each distinct realization S selects a different smooth piece of L_p. The boundary B_v where token v enters/exits the nucleus is a semialgebraic hypersurface in (w,x) space. Crossing B_v changes the truncated distribution discontinuously (hard truncation), creating a non-analytic piecewise structure. The fiber F_S for each nucleus S is a semialgebraic cell; its boundary ∂F_S contributes singularities with λ_boundary ≥ 1/2 (Whitney stratification of semialgebraic sets).\n\n## C3 (CONJECTURAL): Composite RLCT λ(p)\n\nλ(p) = max(λ_intra, λ_boundary(p)). For fixed nucleus S, L_p|F_S is smooth → λ_intra = λ_softmax (the RLCT of the full softmax loss). At boundaries, the piecewise switching adds λ_boundary. As p→1, V_p→V (no truncation), λ_boundary→0, λ(p)→λ_softmax. As p→0+, the nucleus shrinks to {argmax}, creating maximal switching → λ_boundary large. λ(p) is non-monotone with a minimum at some p* where the boundary contribution balances effective vocabulary reduction.\n\n## C4 (CONJECTURAL): Generalization bound\n\nG_p ≤ λ(p)·log(n)/n + U(p)/√n where U(p) accounts for the combinatorial complexity of the data-dependent nucleus partition. The number of distinct nucleus realizations across the data distribution scales as the entropy H(V_p) of nucleus-set membership. U(p) ~ H(V_p) · log(|V|). Optimal p* minimizes λ(p)·log(n)/n + H(V_p)·log(|V|)/√n, yielding p* ~ d_f/(2λ_softmax) in the n→∞ limit.\n\n## C5 (CONJECTURAL): Phase transition at p*\n\nSGLD along L_p at fixed w but varying p should show a kink in the estimated LLC at p* where λ(p) transitions from boundary-dominated (p < p*) to smooth-dominated (p > p*). This is testable: run SGLD on L_p for fixed model, compute LLC via WD statistic at each p, detect non-smoothness in the LLC(p) curve.\n\n## Open problems\n1.
