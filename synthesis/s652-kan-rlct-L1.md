# Synthesis #652: Kolmogorov-Arnold Networks × RLCT — L1 Formalization\n\n## Date: 2026-10-26\n\n## Formal Definitions\n\n### D1: B-Spline Edge Function\nLet B_j(x; k, t) be the j-th B-spline basis function of order k with knot vector t = (t_0, ..., t_{G+k}). An edge function is:\n  φ(x) = Σ_{j=0}^{G+k-1} c_j B_j(x; k, t)\nwhere c_j ∈ R are learnable coefficients. For fixed knots t, each B_j is a piecewise polynomial of degree ≤ k on intervals [t_i, t_{i+1}). For free knots, t ∈ R^{G+k+1} with constraint t_0 ≤ t_1 ≤ ... ≤ t_{G+k}.\n\n### D2: KAN Layer\nA KAN layer L maps R^{d_in} → R^{d_out} via:\n  L_l(x)_i = Σ_{j=1}^{d_in} φ_{ij}^{(l)}(x_j)\nwhere each φ_{ij}^{(l)} is a B-spline edge function (D1). The full KAN with L layers computes:\n  f_θ(x) = Φ_L ∘ Φ_{L-1} ∘ ... ∘ Φ_1(x)\nwhere each Φ_l is a KAN layer. Parameters θ = {(c_{ij}^{(l)}, t_{ij}^{(l)}) : l, i, j} (coefficients and optional knot positions).\n\n### D3: KAN Loss Function\nL(θ) = (1/n) Σ_{m=1}^{n} ℓ(f_θ(x_m), y_m)\nwhere ℓ is a definable loss (e.g., cross-entropy, MSE). The true loss is:\n  L_true(θ) = E_{(x,y)~q}[ℓ(f_θ(x), y)]\nThe Kullback-Leibler divergence: K(θ) = L_true(θ) - S(θ) where S is the entropy term.\n\n### D4: Knot-Merging Variety W_knot\nFor free-knot KANs, define the knot-merging locus:\n  W_knot = {θ ∈ Θ : ∃ (l,i,j,m) such that t_m = t_{m+1} for some m in knot vector t_{ij}^{(l)}}\nThis is an analytic variety: the condition t_m = t_{m+1} is a polynomial equality constraint on the knot parameters. When two adjacent knots merge, the B-spline basis loses one degree of freedom (support collapses), creating a degeneracy.\n\n### D5: KA Representation Gauge Group\nThe Kolmogorov-Arnold representation f(x) = Σ_i Φ_i(Σ_j φ_{ij}(x_j)) is non-unique. Define the gauge group G_KA as the set of reparametrizations (φ, Φ) → (φ̃, Φ̃) preserving f. Elements include: (a) rescaling φ_{ij} → a·φ_{ij}, Φ_i → Φ_i/a; (b) adding constants φ_{ij} → φ_{ij} + b, Φ_i → Φ_i - Σ_j b; (c) linear recombination of inner functions within each sum. The quotient space Θ/G_KA parameterizes distinct functions, not distinct parameters.\n\n### D6: Grid Resolution Stratum Selector\nThe spline order k and grid resolution G (number of knot intervals) are discrete hyperparameters. For fixed (k, G), the parameter space Θ_{k,G} has dimension d_param = L · d_in · d_out · (G + k). Define the stratum family {Θ_{k,G} : k ∈ N, G ∈ N} ordered by (k, G) ≤ (k', G') iff k ≤ k' and G ≤ G'. The RLCT λ(k, G) is conjectured monotone in this partial order.\n\n### D7: Effective Knot Density\nDefine ρ_knot = G / d_in (knots per input dimension per edge). This measures the resolution of the spline approximation. The effective dimension of the parameter space after quotienting by G_KA is:\n  d_eff(k, G) = dim(Θ_{k,G}) - dim(G_KA)\nThe conjectured generalization bound involves both λ(k, G) and ρ_knot.\n\n## Five Claims\n\n### C1: R_{an,exp} Definability (PROVEN)\n\n**Proof**: We show each component is definable in R_{an,exp}:\n\n1. **B-spline basis functions**: For fixed knots, B_j(x; k, t) is a piecewise polynomial of degree ≤ k on intervals defined by the knots. Piecewise polynomial functions with definable partition boundaries are definable in R_{an,exp} (they are restrictions of polynomials to semialgebraic sets, and R_{an,exp} contains all semialgebraic functions by Tarski-Seidenberg).\n\n2. **Free-knot B-splines**: When knots are parameters, B_j(x; k, t) depends on (x, t) jointly. The Cox-de Boor recursion defines B-splines recursively via divisions by (t_{j+k} - t_j), which are definable on the open set where t_{j+k} ≠ t_j. On the knot-merging variety W_knot, the basis is defined by continuous extension (limit). The function (x, t) → B_j(x; k, t) is definable in R_{an,exp} on {t_{j+k} ≠ t_j} and extends continuously to W_knot. By o-minimality of R_{an,exp}, this extension is definable if it exists (van den Dries, Theorem 1.5). Thus B-splines with free knots are definable.\n\n3. **KAN layer**: Sum of definable functions is definable. Composition of definable functions is definable (R_{an,exp} is closed under composition). Thus f_θ(x) is definable in (x, θ).\n\n4. **Loss function**: ℓ (MSE or cross-entropy) is definable. L(θ) = (1/n) Σ ℓ(f_θ(x_m), y_m) is a finite sum of definable functions, hence definable.\n\n5. **KL divergence**: K(θ) involves an expectation over definable functions, which is definable under standard regularity conditions.\n\n**Conclusion**: L(θ) and K(θ) are definable in R_{an,exp}. The KAN loss landscape satisfies the conditions of Singular Learning Theory.\n\n### C2: Knot-Merging Singular Stratum (CONJECTURAL)\n\nOn W_knot, the B-spline basis degenerates: when t_m = t_{m+1}, the basis function B_m has zero-width support, reducing the effective number of basis functions by one. This creates a singular fiber: parameters on W_knot represent functions with fewer degrees of freedom than generic parameters.\n\nConjecture: W_knot is a singular stratum of the loss landscape. The RLCT on W_knot is lower than on the generic stratum (fewer effective parameters → simpler model → lower complexity). The knot-merging variety is analogous to the weight-degeneracy varieties in MLPs (#8, #100) but arises from basis function collapse rather than weight cancellation.\n\nThe analytic structure of W_knot (polynomial equality constraints on knot positions) suggests the RLCT can be computed via resolution of singularities for the knot-merging locus.\n\n### C3: Grid Resolution as Stratum Selector (CONJECTURAL)\n\nThe hyperparameters (k, G) discretely stratify the parameter space. Conjecture:\n- λ(k, G) is monotone increasing in both k and G (more basis functions → higher complexity → higher RLCT)\n- For a target function with regularity r (Sobolev s), there exists an optimal (k*, G*) where the spline basis matches the target regularity\n- Below (k*, G*): underfitting, high bias, RLCT determined by approximation error\n- Above (k*, G*): overfitting, the extra basis functions create degenerate fibers (coefficients → 0), RLCT increases\n- The phase transition at (k*, G*) is detectable via SGLD as a kink in the local learning coefficient\n\nThis parallels the width selector in MLPs (#8) and the expert count in MoE (#434), but operates on spline resolution rather than network width.\n\n### C4: Generalization Bound with Knot Density (CONJECTURAL)\n\nConjecture: The generalization gap satisfies:\n  |L_train - L_test| ≤ C · λ(k, G) · log(n) / n + C' · g(ρ_knot)\nwhere:\n- λ(k, G) is the RLCT of the KAN loss landscape\n- ρ_knot = G / d_in is the effective knot density\n- g(ρ_knot) captures the bias from knot density (over-dense knots → overfitting penalty, under-dense → approximation error)\n\nFor free-knot KANs, the bound additionally includes the adaptivity gain from knot relocation:\n  |L_train - L_test|_free ≤ |L_train - L_test|_fixed - Δ_adapt\nwhere Δ_adapt > 0 is the benefit of placing knots where the target function has high curvature.\n\nDistinct from MLP bounds (#100, #8) which depend on width and depth, this bound depends on spline resolution and knot density.\n\n### C5: KA Gauge Freedom Phase Transition (CONJECTURAL)\n\nThe KA representation gauge group G_KA creates non-identifiability: many parameter settings produce the same function. The quotient Θ/G_KA has orbifold-type singularities where the gauge group action has non-trivial isotropy (e.g., when some φ_{ij} is constant, the rescaling gauge collapses).\n\nConjecture: At critical data size n*, the KAN transitions from exploiting the full gauge freedom (low n, parameters lie on high-degeneracy strata with low RLCT) to a unique representation (high n, gauge is fixed, RLCT reflects true complexity).
