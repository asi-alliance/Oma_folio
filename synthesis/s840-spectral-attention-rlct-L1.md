# Synthesis #840: Spectral Attention × RLCT - L1 Formal Definitions\n# Date: 2026-11-03\n# Pipeline: L0 COMPLETE (s840-spectral-attention-rlct-L0.md) | L1 formalization\n\n## D1: Spectral Transform Operator\nLet X in R^{N×d} be the input sequence (N tokens, d channels).\nLet T be a fixed unitary spectral transform (DFT or DCT) acting on the sequence dimension.\nDFT: (TX)_{k,j} = sum_{n=0}^{N-1} X_{n,j} * exp(-2πi kn/N) for k=0,...,N-1, j=1,...,d.\nInverse: (T^{-1}Y)_{n,j} = (1/N) sum_{k=0}^{N-1} Y_{k,j} * exp(2πi kn/N).\nBoth T and T^{-1} are fixed linear operators with entries in C (or R for DCT).\nAs functions of X, they are linear (polynomial), hence R-an-definable.\nFor DCT: (CX)_{k,j} = sum_{n=0}^{N-1} X_{n,j} * cos(πk(2n+1)/(2N)), also definable (cos restricted to bounded domain is definable).\n\n## D2: Learnable Spectral Mask\nLet M(W) in R^{N×N} (or R^{N} diagonal) be a learnable spectral mask parameterized by W in R^p.\nM(W)_{k,k'} = delta_{k,k'} * sigma(sum_m W_{k,m} * phi_k(m)) for diagonal case,\nwhere sigma is sigmoid or softplus (both definable: sigmoid = 1/(1+exp(-z)), softplus = log(1+exp(z))).\nFull matrix case: M(W)_{k,k'} = sigma(W_{k,k'}), element-wise learnable weights.\nThe masked spectral representation: Z(W) = M(W) ⊙ (TX), i.e., Z_{k,j} = M(W)_{k,k} * (TX)_{k,j}.\nM(W) is R_{an,exp}-definable in W (polynomial + sigmoid/softplus = definable).\n\n## D3: Spectral Attention Output\nThe reconstructed output in spatial domain:\n  O(W) = T^{-1} Z(W) = T^{-1} (M(W) ⊙ (TX)).\nFor standard attention integration, the spectral features are used as:\n  Q_s = O(W) W_Q, K_s = O(W) W_K, V_s = O(W) W_V (standard projections).\nAttention weights: A(W) = softmax(Q_s K_s^T / sqrt(d_k)).\nOutput: H(W) = A(W) V_s.\nAll components are compositions of:\n  - Linear maps (polynomial in W, W_Q, W_K, W_V)\n  - Sigmoid/softplus (definable)\n  - exp (softmax numerator) and division (softmax normalization)\n  - Fixed T, T^{-1} (linear, definable)\nBy closure under composition, H(W) is R_{an,exp}-definable in the full parameter vector theta = (W, W_Q, W_K, W_V).\n\n## D4: Expected Loss Function\nFor training data {(X_n, t_n)} and parameters theta in R^d:\n  L(theta) = (1/N) sum_{n=1}^N l(H_theta(X_n), t_n)\nwhere l is cross-entropy or MSE. By D3, H_theta is definable, and:\n  - Cross-entropy: l(y,t) = -sum_k t_k log(y_k) — polynomial + log, definable\n  - MSE: l(y,t) = ||y - t||^2 — polynomial, definable\nFinite sum of definable functions is definable. L(theta) is R_{an,exp}-definable.\nBy resolution of singularities (Hironaka) applied to definable functions, L has finite RLCT.\n\n## D5: Spectral Mask as Stratum Selector\nThe mask M(W) controls which frequency bands contribute to the output:\n- M(W) ≈ I (identity): full-spectrum pass, all frequencies active (dense stratum)\n- M(W) ≈ diag(1,...,1,0,...,0) (low-pass): only low frequencies, truncated spectral basis (sparse stratum)\n- M(W) with learned band selection: intermediate strata\nDefine mask density: rho(W) = (1/N) sum_k M(W)_{k,k} (average mask activation).\nFamily of fibers parameterized by effective spectral rank:\n  V(r) = {theta : L(theta) = L* and rho(theta) = r}.\nConjecture: lambda(r) (RLCT of V(r)) is monotone non-decreasing as r increases from 0 to N:\n  More active frequency bands → richer function class → higher complexity → higher RLCT.\nCritical spectral rank r* where strata separate, conjectured r* ~ O(sqrt(N)).\n\n## D6: Generalization Bound with Spectral-Dependent RLCT\n  E[L_test] <= E[L_train] + C * sqrt( lambda(rho(theta*)) * log(n) / n ) + b(rho)\nwhere:\n- lambda(rho) is the RLCT of the fiber at mask density rho\n- b(rho) is the spectral truncation bias:\n  b(rho) = inf_{theta: rho(theta)=rho} L_0(theta) - L*\n  b(rho) → 0 as rho → N (full spectrum, no truncation)\n  b(rho) > 0 for rho < N (truncated basis loses high-frequency information)\n- Optimal rho_opt minimizes lambda(rho)*log(n)/(2n) + b(rho):\n  Too restrictive (rho small): low lambda but high bias from truncation\n  Too permissive (rho large): low bias but high lambda (overfitting via unused frequency bands)\n  Interior optimum exists when both terms are non-trivial.\n\n## D7: Spectral Band Annealing as Temporal Stratum Curriculum\nGiven training schedule rho(t) for t in [0,T] (e.g., progressive band unfreezing):\n  Early training: rho small (low-pass only, smooth low-complexity stratum, low lambda)\n  Late training: rho → N (full spectrum, high-complexity stratum)\nConjecture: optimal schedule satisfies rho(t) ~ N * (t/T)^{alpha}\n  where alpha = 1/(1 + lambda_full) from free energy balance at spectral phase transition.\nSGLD detectability: LLC shows step when rho(t) crosses r* (spectral rank phase transition).\nDistinct from #839 temperature annealing: spectral annealing expands frequency support rather than sharpening distribution.\n\n## Claim Status\n\nC1 PROVEN: L(theta) is R_{an,exp}-definable in theta.\n  -
