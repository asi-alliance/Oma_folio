#873: Hidden Markov Models × RLCT — L1 Formalization\n\n## D1 (Parameter Space)\nLet O = {o_1, ..., o_T} be an observation sequence of length T over alphabet V = {v_1, ..., v_M} (discrete emissions) or R^d (continuous emissions). The parameter space is:\nΘ = {θ = (A, B, π) : A ∈ [0,1]^{K×K}, B ∈ [0,1]^{K×M} (or emission params), π ∈ [0,1]^K}\nsubject to stochastic constraints: Σ_j A_{ij} = 1 ∀i (row-stochastic), Σ_k π_k = 1, Σ_m B_{km} = 1 ∀k.\n\nThe effective parameter dimension (before singularities) is K^2 + KM + K - K - K - 1 = K^2 + KM - 1 (after removing K+K+1 constraint dimensions). The permutation group S_K acts on Θ by simultaneous relabeling of states, creating a quotient Θ/S_K.\n\n## D2 (HMM Log-Likelihood — Formal)\nL_HMM(θ) = log p(O | θ) = log Σ_{z∈Z} π_{z_1} B_{z_1}(o_1) Π_{t=2}^{T} A_{z_{t-1},z_t} B_{z_t}(o_t)\n\nwhere Z = {1,...,K}^T is the set of all state sequences.\n\nForward recursion: α_t(i) = B_i(o_t) Σ_{j=1}^{K} α_{t-1}(j) A_{ji}, α_1(i) = π_i B_i(o_1)\nL_HMM(θ) = log Σ_{i=1}^{K} α_T(i)\n\nThis is equivalently the log-sum-exp of all path probabilities. For continuous emissions B_i(o) = N(o; μ_i, Σ_i), each term is an exponential of a quadratic form.\n\n## D3 (R_{an,exp} Definability — C1 PROVED)\n**Claim C1 (PROVED):** L_HMM is definable in R_{an,exp}.\n\n**Proof:** Each emission probability B_i(o_t) for Gaussian emissions is exp(-1/2 (o_t - μ_i)^T Σ_i^{-1} (o_t - μ_i)) / (2π)^{d/2} |Σ_i|^{1/2}, which is a composition of exp, polynomials, and division — all definable in R_{an,exp}. For discrete emissions, B_i(o_t) is a coordinate projection of a polynomial (definable). Transition A_{ij} and initial π_i are polynomial coordinates.\n\nThe forward recursion α_t(i) = B_i(o_t) Σ_j α_{t-1}(j) A_{ji} involves finite products and sums of definable functions, hence definable at each step. By induction on t, all α_t(i) are definable.\n\nL_HMM = log(Σ_i α_T(i)). Log is definable on (0,∞). Since Σ_i α_T(i) > 0 for θ in the interior of Θ (all probabilities strictly positive), L_HMM is definable on the interior. The boundary (where some A_{ij}=0 or B_i(v)=0) is a definable subset. By o-minimal extension, L_HMM is R_{an,exp}-definable on any compact subset of the parameter space with strictly positive probabilities. ∎\n\n## D4 (Three-Stratum Singular Fiber — C2 CONJECTURAL)\n**Claim C2 (CONJECTURAL):** The singular fiber of L_HMM has three stratum types.\n\n(a) **Permutation stratum V_perm:** S_K acts by relabeling states. For any σ∈S_K, L_HMM(σ·θ) = L_HMM(θ). This creates K! equivalent critical points. The quotient Θ/S_K has orbifold singularities at fixed points of σ (where states are partially identified). The RLCT contribution is λ_perm = 0 (discrete symmetry, same as #872 k-means).\n\n(b) **Transition degeneracy stratum V_trans:** Where A has rank < K or contains absorbing states (A_{ii}=1 for some i). An absorbing state i creates a trapping stratum: once z_t = i, all future z_{t'} = i. The likelihood factorizes: L = log p(O_{≤t}) + log p(O_{>t} | absorbing). The flat direction is the outgoing transition probabilities A_{ij} for j≠i (they do not affect likelihood once absorbed). This creates d_flat = K-1 flat directions per absorbing state. RLCT contribution: λ_absorb = (number of absorbing states) × (K-1).\n\nDisconnected components: If A decomposes into c communication classes, K_eff = max class size, and the likelihood depends only on the class containing z_1. Extra classes contribute flat directions.\n\n(c) **Emission collision stratum V_emit:** Where B_i = B_j for states i≠j. States i,j are observationally indistinguishable — any state sequence with i↔j substitution gives identical likelihood. This creates a continuous family of equivalent parameterizations (the transition probabilities between i and j are unconstrained up to sum). RLCT contribution: λ_collision = λ_emit × (K - K_eff) where λ_emit depends on emission family.\n\nConjecture: λ_HMM = λ_emit × K_eff + λ_trans(A) + λ_absorb where K_eff ≤ K counts non-collided, non-absorbed states and λ_trans(A) captures transition graph connectivity.\n\n## D5 (K as Temporal-Dynamic Stratum Selector — C3 CONJECTURAL)\n**Claim C3 (CONJECTURAL):** K (hidden state count) selects strata via transition graph topology.\n\nFor data generated by HMM with K* true states:\n\n- **K < K* (state merging):** Multiple true states forced into one hidden state. Transition matrix A is a coarse-graining of the true transition graph. Residual c* = L_HMM(θ*) > L*_{K*}. The fiber V_{c*} has merging singularities where the coarse-grained A cannot represent true temporal dynamics. λ(K) = λ_emit × K + λ_merge(K*, K) where λ_merge captures temporal misalignment.\n\n- **K = K* (optimal):** All true states represented. A matches true transition graph. λ(K*) = λ_emit × K* + λ_trans(A*). Minimal complexity.\n\n- **K > K* (state splitting):** Excess states collide (B_i = B_j). Transition matrix has spurious connections between identical states. K_eff = K* < K. λ(K) = λ_emit × K* + (K-K*) × λ_collision + λ_trans(K). Collision grows linearly with excess states.\n\nConjectured scaling: λ(K) = λ_emit × min(K, K*) + max(0, K-K*) × λ_collision + λ_merge(max(0, K*-K)) + λ_trans(A(K))\n\nStructurally analogous to #872 (K as combinatorial selector) but λ_trans(A(K)) adds temporal-graph topology term absent in k-means. Distinct from #870 (G as sampling selector), #871 (K as context window selector).\n\n## D6 (Generalization Bound — C4 CONJECTURAL)\n**Claim C4 (CONJECTURAL):** HMM generalization bound:\n\nG(K,n) ≤ λ(K) · log(n)/(2n) + U(K)/√n + B(K,K*)\n\nwhere:\n- λ(K) from D5 (state-count-dependent RLCT)\n- U(K) = transition boundary sensitivity (sequences near state boundaries contribute high variance to forward-backward posterior)\n- B(K,K*) = state-mismatch bias:\n  - K < K*: B = KL(p_true(O) || p_K(O)) > 0 (missed states cause systematic prediction error)\n  - K = K*: B ≈ 0\n  - K > K*: B ≈ 0 (redundant states don't add bias, only variance)\n\nPhase transition at K=K*: B(K,K*) has discontinuous derivative. The bias decreases smoothly for K→K* from below, then flattens. The variance term λ(K)·log(n)/(2n) increases for K>K*. Optimal K* is the transition point.\n\nDistinct from #872: B involves temporal sequence prediction error (perplexity), not spatial clustering error. The bias depends on transition graph structure, not just partition geometry.\n\n## D7 (Phase Transition at K* — C5 CONJECTURAL)\n**Claim C5 (CONJECTURAL):** Phase transition detectable via SGLD.\n\n- K < K*: λ̂(K) sub-linear (merging suppresses complexity, fewer effective states)\n- K = K*: λ̂(K*) = canonical value (minimal RLCT)\n- K > K*: λ̂(K) super-linear (collision redundancy adds flat directions)\n\nDetection: Run SGLD on L_HMM for each K, estimate LLC via learning coefficient.
