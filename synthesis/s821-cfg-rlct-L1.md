# Synthesis #821: Classifier-Free Guidance × RLCT — L1 Formalization\n\n## Date: 2026-10-29\n## Status: L1 Formalization\n\n## Formal Definitions\n\n**D1 (Parameter Space).** Let Θ ⊂ R^d be the parameter space of a conditional denoising network εθ(x_t, t, c) with parameters θ ∈ Θ, diffusion timestep t ∈ [0,T], noisy input x_t, and conditioning c ∈ C ∪ {∅} where C is the conditioning space and ∅ is the null token. The network is trained with conditioning dropout rate p: during training, c is replaced by ∅ with probability p.\n\n**D2 (CFG Loss Family).** Define the guided score:\n  ε_guided(θ; w) = (1+w)·εθ(x_t,t,c) - w·εθ(x_t,t,∅)\nfor guidance scale w ≥ 0. The CFG loss at scale w is:\n  L_CFG(θ, w) = E_{x_0,ε,t} [ ||ε_guided(θ; w) - ε||² ]\nThis is a polynomial in θ and w of degree 2 in w (cross terms between conditional and unconditional scores).\n\n**D3 (R_an,exp-Definability).** The network εθ is a feedforward neural network with analytic activations (ReLU, GELU, etc.), hence R_an,exp-definable in θ. The guided score ε_guided is a polynomial (degree 1) combination of R_an,exp-definable functions, hence R_an,exp-definable. The loss L_CFG is a polynomial (degree 2) in R_an,exp-definable functions, hence R_an,exp-definable by Tarski-Seidenberg projection closure. The parameter space Θ is semialgebraic.\n\n**D4 (Null-Token Singular Fiber).** Define the null-token fiber:\n  F_∅ = {θ ∈ Θ : εθ(x,t,∅) = εθ(x,t,c) for all c ∈ C, for all (x,t)}\nThis is the set where conditional and unconditional scores coincide — the most degenerate stratum where all class information collapses. For each c, define the conditional fiber:\n  F_c = {θ ∈ Θ : εθ(x,t,c) = ε*_c(x,t) for all (x,t)}\nwhere ε*_c is the true conditional score. The RLCT of F_∅ is λ_∅, and of F_c is λ_c. By information collapse, λ_∅ ≥ λ_c for all c. The training mixture (dropout rate p) creates a mixture stratum M_p = p·F_∅ + (1-p)·Σ_c F_c spanning null and conditional fibers.\n\n**D5 (Guidance Scale as Stratum Selector).** The guidance scale w parameterizes a continuous family of loss landscapes {L_CFG(·, w) : w ≥ 0}. At w=0, L_CFG(θ, 0) = L_cond(θ) + L_uncond(θ) - 2·cross, selecting the unconditional-dominated stratum (highest λ_∅). As w→∞, the extrapolation term dominates, selecting the extrapolated conditional stratum (approaching λ_cond). Define the effective RLCT:\n  λ_eff(w) = RLCT(L_CFG(·, w), W₀(w))\nwhere W₀(w) is the true parameter set at scale w. Conjecture: λ_eff(w) is monotone non-increasing in w.\n\n**D6 (RLCT-Governed Generalization Bound).** For CFG with guidance scale w and n training samples:\n  E[L_test(w)] ≤ E[L_train(w)] + C·sqrt(λ_eff(w)·log(n)/n)\nwhere λ_eff(w) replaces d/2 from regular theory. Lower w → higher λ_eff → larger complexity penalty but richer generative diversity. Higher w → lower λ_eff → tighter bound but risk of over-saturation. Optimal w* minimizes the RHS.\n\n**D7 (Phase Transition at Critical w*).** There exists critical w* where the dominant singular stratum transitions:\n  - w < w*: null-token singularity dominates, λ_eff ≈ λ_∅\n  - w > w*: extrapolated conditional singularity dominates, λ_eff ≈ λ_cond\nAt w*, the loss landscape undergoes a phase transition detectable via SGD LLC (Local Learning Coefficient) estimation. The critical scale satisfies:\n  w* ~ f(λ_∅, λ_cond, n)\nconjectured as w* ~ sqrt(n / (λ_∅ - λ_cond)) for large n.\n\n## Claims\n\n**C1 PROVEN: R_an,exp-definability.** By D3: ε_guided is polynomial combination of neural network outputs (R_an,exp-definable), and L_CFG is polynomial in ε_guided (degree 2).
