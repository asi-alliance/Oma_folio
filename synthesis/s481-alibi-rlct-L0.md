Unlike RoPE (#367) which rotates in embedding space, ALiBi shifts pre-softmax logits additively\n  - This is a LOGIT-SPACE deformation vs RoPE's REPRESENTATION-SPACE rotation\n  - Stratum change is smooth in m (linear) → no branch-switch singularity from slope itself\n  - BUT: softmax saturation at large distances creates effective piecewise behavior\n- C3: Extrapolation behavior — ALiBi's fixed slopes don't adapt to longer sequences\n  - At extrapolation lengths, attention scores for distant tokens → -inf (linear penalty dominates)\n  - This creates an EFFECTIVE TRUNCATION: distant positions get ~zero attention weight\n  - RLCT prediction: effective context length L_eff ~ 1/(m_h * max_softmax_input) creates a soft boundary\n  - Lambda at extrapolation: loss landscape changes character as effective attention pattern becomes sparse\n- C4: Generalization bound — ALiBi trades positional parameter count for bias structure\n  - Fewer parameters (no pos embeddings) but structured bias → RLCT may be LOWER\n  - Prediction: G_ALiBi ~ lambda_ALiBi/n where lambda_ALiBi < lambda_RoPE at extrapolation\n  - Because ALiBi's singularity is "softer" (linear vs rotational periodicity)\n- C5: Head slope schedule m_h = geometric sequence — multi-scale stratum\n  - Different heads attend at different distance scales\n  - Analogy: wavelet decomposition, each head = different resolution stratum\n  - Phase transition: if slopes too steep → all heads local-only (loss of global info)\n  - If slopes too flat → all heads uniform (no positional discrimination)\n\n## Distinction from #367 (RoPE × RLCT)\n- RoPE: rotational encoding in Q,K space — singularity from frequency periodicity (2π/omega)\n- ALiBi: additive bias on pre-softmax logits — singularity from softmax saturation boundaries\n- RoPE's RLCT bridge: frequency interpolation creates non-analyticity at Nyquist-like boundaries\n- ALiBi's RLCT bridge: linear penalty creates effective attention cutoff, no periodicity\n- Key novelty: ALiBi has NO positional parameters → RLCT is purely determined by content+structure interaction\n\n## Cross-references: #367 (RoPE), #229 (KV Cache), #480 (muP), #385 (LoRA), #244 (top-k/nucleus)\n## Open problems: 7 (slope schedule optimization, extrapolation RLCT, head specialization phase transition, comparison to RoPE RLCT, parameter-free singularity, softmax saturation singularity, multi-scale stratum interaction)
