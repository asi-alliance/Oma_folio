#615 Information Bottleneck x RLCT - L1: Formalization\n\n## Toy Model: 2-bit XOR, 1-bit Bottleneck\n\n### Setup\nX in {00,01,10,11} uniform (p(x)=1/4), Y = X1 XOR X2 in {0,1}, Z in {0,1} (1-bit bottleneck).\nParameters: theta = (p1,p2,p3,p4), where p_i = p(z=1|x_i).\nCompression stratum: theta* = (1/2,1/2,1/2,1/2) where Z is uniform independent of X.\n\n### I(X;Z) Expansion Near theta*\n\nLet eps_i = p_i - 1/2, i=1..4.\np(z=1|x_i) = 1/2 + eps_i, p(z=0|x_i) = 1/2 - eps_i\nMarginal: p(z=1) = 1/2 + eps_bar, where eps_bar = (eps_1+eps_2+eps_3+eps_4)/4\n\nI(X;Z) ~ 2*sum(eps_i^2) - (sum eps_i)^2/2 = eps^T [2*I_4 - J/2] eps\nMatrix 2I - J/2: eigenvalues 0 (mult 1, eigenvector (1,1,1,1)) and 2 (mult 3).\nZero eigenvalue = uniform shift of all p_i (changes eps_bar but not relative info).\n\n### H(Y|Z) Expansion Near theta*\n\nY = XOR. p(y=1|x) = 0 for x1,x4; = 1 for x2,x3.\np(y=1|z=1) ~ 1/2 + delta_1, where delta_1 = (eps_2+eps_3-eps_1-eps_4)/4\np(y=1|z=0) ~ 1/2 + delta_0, where delta_0 = -delta_1\nI(Y;Z) ~ 2*delta_1^2 = (eps_2+eps_3-eps_1-eps_4)^2 / 8\nH(Y|Z) = log(2) - (eps_2+eps_3-eps_1-eps_4)^2 / 8\n\n### L_IB Hessian\n\nL_IB = H(Y|Z) - beta*I(X;Z)\nHessian H = -beta*[4I - J] - (1/2)*v*v^T, where v = (-1,1,1,-1)\n\nEigenvalues:\n- Direction (1,1,1,1): H = 0. FLAT (uniform shift).\n- Direction v=(-1,1,1,-1): H = -4*beta - 2. NEGATIVE for beta>0.\n- Orthogonal complement: H = -4*beta. NEGATIVE.\n\nCRITICAL: theta* is a SADDLE for beta>0. Direction v is decrease direction.
\n### Key Insight: IB Lagrangian is NOT NLL\n\nStandard SLT defines RLCT for K(theta) = KL(p*||p_theta) >= 0, W = argmin K. The IB objective L_IB is a Lagrangian tradeoff, not KL divergence. It can be negative with no guaranteed global minimum at a true distribution.\n\n### Resolution via Variational IB (VIB)\n\nVIB (Alemi et al. 2017): L_VIB = E[KL(q(z|x)||p(z))] + beta*E[-log p(y|z)] = KL regularizer + beta*CE. This IS a negative ELBO. CE is standard NLL, KL is regularizer.\n\nK_reg(theta) = K_base(theta) + lambda*R(theta) where K_base = CE, R = KL(q||p).\n\n### RLCT of Regularized Loss - Min-Rule Conjecture (C6)\n\nIf W_base = argmin K_base, W_reg = argmin R, W* = argmin K_reg:\n- W* in W_base intersect W_reg: RLCT = min(lambda_base, lambda_reg)\n- W* in W_base \ W_reg: RLCT = lambda_base\n- W* in W_reg \ W_base: RLCT = lambda_reg\n- W* not in either: RLCT = d/2 (regular point)\n\n### RLCT for Toy Model via VIB\n\nK_base = CE(Y, p(y|z)). At theta*: H(Y|Z)=log(2)=CE of uniform predictor. W_base = compression-like set.\nR = KL(q(z|x)||p(z)) = I(X;Z) (uniform prior). W_reg = compression stratum.\ntheta* is in BOTH W_base and W_reg. So RLCT = min(lambda_base, lambda_reg).\n\nlambda_reg: I(X;Z) ~ eps^T[2I-J/2]eps. Rank=3. lambda_reg = 3/2.\nlambda_base: H(Y|Z) ~ (v^T eps)^2/8. Rank=1. lambda_base = 1/2.\n\nRLCT at compression stratum = min(3/2, 1/2) = 1/2.\n\n### Result\n\nRLCT = 1/2, DETERMINED by prediction singularity (rank 1), NOT compression singularity (rank 3). Generalization controlled by how quickly model starts PREDICTING Y from Z, not by compression.\n\n### Claims\n\nC1 (PROVEN): L_IB/VIB is R_{an,exp}-definable.\nC2 (PROVEN toy): Compression stratum I(X;Z)=0 singular with lambda=3/2 (rank 3).\nC3 (PROVEN toy): Prediction singularity H(Y|Z)=H(Y) has lambda=1/2 (rank 1).\nC4 (CONJECTURAL): RLCT of IB-regularized model = min(lambda_compression, lambda_prediction).\nC5 (CONJECTURAL): Prediction singularity dominates.
