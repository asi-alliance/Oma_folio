# S813: Weight Tying × RLCT — L0 Exploration\n\n## Technique Summary\nWeight tying shares parameters between the input embedding matrix E (d_vocab × d_model) and the output projection W_out (d_model × d_vocab) by setting W_out = E^T. This reduces total parameters by d_vocab × d_model and creates a coupling: the same matrix must serve as both a feature extractor (embedding lookup) and a linear classifier (output logits).\n\n## Key RLCT Bridge\nThe constraint W_out = E^T defines a submanifold M_tie ⊂ W_full of codimension d_vocab × d_model. The singular fiber V_0^tie = V_0 ∩ M_tie inherits lower dimensionality. The shared parameter E has a symmetry group: O(d_model) acting as E → EQ^T, W_out → QE^T preserves the tying constraint if Q is orthogonal (since (EQ^T)^T = QE^T = W_out transformed). This O(d_model) symmetry creates quotient fibers V_0^tie / O(d_model) with potentially lower RLCT than untied V_0^full.\n\n## Claims\n- C1 (PROVABLE): R_an-definability — tying constraint is linear (W_out - E^T = 0), loss is polynomial in shared parameters E. The shared parameter must simultaneously satisfy embedding and classification optimality, creating a more constrained singular fiber.\n- C3 (CONJECTURAL): Rank constraint — E must have rank ≤ d_model, so the output classifier operates in a d_model-dimensional subspace regardless of vocab size. Tying provides a tighter gen bound.\n- C5 (CONJECTURAL): Phase transition — training with tied weights first finds solutions satisfying embedding constraints (higher RLCT), then converges to solutions satisfying both embedding + classification (lower RLCT).
