Five key properties emerge:\n\n1. **NC1 (Within-class variability collapse)**: Last-layer features collapse to their class means — within-class covariance → 0\n2. **NC2 (Simplex ETF)**: Class means form a simplex Equiangular Tight Frame (ETF) — maximally separated configuration\n3. **NC3 (Classifier-feature alignment)**: Weight vectors align with class means\n4. **NC4 (Nearest Class Center)**: Decision rule simplifies to nearest class-center classification\n5. **NC5 (Scaling)**: Feature norms and weight norms satisfy specific scaling relations\n\nThe ETF for K classes is a set of K vectors in R^{K-1} (or R^K with constraint) forming a regular simplex — Gram matrix G = (K/(K-1))(I - (1/K)11^T), a rank-(K-1) projection matrix.\n\n### RLCT Bridge\nNeural Collapse has rich singular structure:\n\n(a) **Within-class collapse as rank drop**: NC1 means the feature covariance within each class drops rank — the per-class feature distribution collapses from rank-d to rank-0. This is a codimension-d singular stratum in feature space. The zero-loss set V_0 requires all features to lie exactly on their class means, creating a degenerate fiber.\n\n(b) **ETF constraint as algebraic variety**: NC2 requires the class means to satisfy the ETF Gram constraint G = (K/(K-1))(I - (1/K)11^T). This is a real algebraic variety — the intersection of the Stiefel-like manifold with the equiangularity constraints. The ETF condition is a system of polynomial equations (equal norms, equal inner products), defining a specific algebraic variety.\n\n(c) **Collapse as RLCT phase transition**: NC emerges gradually during training — the loss landscape transitions from a high-RLCT regime (features spread, many equivalent solutions) to a low-RLCT regime (features collapsed to ETF, minimal singularity). The terminal phase of training (approaching zero loss) corresponds to convergence to the minimal-RLCT stratum.\n\n(d) **K (number of classes) as stratum selector**: The ETF structure depends on K. For K=2, ETF is antipodal (1D). For K=3, equilateral triangle (2D). For general K, regular simplex in (K-1)D. Each K defines a different algebraic variety and RLCT.\n\n(e) **Temperature/margin as continuous stratum selector**: During training, the effective margin (controlled by softmax temperature or cross-entropy sharpness) acts as a continuous parameter interpolating between the uncollapsed (high entropy, high RLCT) and collapsed (low entropy, low RLCT) regimes.\n\n## Claims\n\n**C1 (PROVABLE): The NC-constrained loss L_NC(θ) = L_CE(θ) + constraints for NC1-NC5 is R_{an,exp}-definable.**\nProof: Cross-entropy loss is R_{an,exp}-definable.
