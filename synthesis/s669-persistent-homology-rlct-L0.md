#669: Persistent Homology x RLCT\n\n## L0: Candidate Analysis\n\n### Core Idea\nFor KL loss L_n(w) on parameter space Theta, define sublevel set filtration F_t = {w in Theta : L_n(w) <= t}. Persistent homology of this filtration yields persistence diagrams Dgm_p(L_n) for each dimension p. These diagrams are topological descriptors of the singular strata of the loss landscape.\n\n### Bridge to RLCT\n- RLCT lambda governs Vol{L_n - L_min <= epsilon} ~ epsilon^lambda as epsilon -> 0\n- This volume growth rate determines the density of near-minimum parameter configurations\n- Birth distribution of H0 features near L_min encodes this density -> connection to lambda\n- Singular strata (where Fisher information degenerates) create topology changes in sublevel sets -> birth-death events\n- Long-persisting features indicate stable singular strata\n\n### Five Conjectures\n- C1 (PROVEN): Persistence diagrams Dgm_p(L_n) are well-defined functions of the sublevel set filtration of L_n, which is R_an-definable for standard NN losses. Morse theory guarantees finiteness for generic loss functions.\n- C2 (CONJECTURAL): Singular strata of the loss landscape create persistent homology features with birth times corresponding to stratum activation thresholds and death times corresponding to stratum annihilation via filling.\n- C3 (CONJECTURAL): The filtration parameter t serves as a stratum selector: as t decreases toward L_min, the sublevel set intersects progressively lower-dimensional strata, each contributing characteristic birth-death pairs.\n- C4 (CONJECTURAL): Generalization bound G ~ lambda/n + U/sqrt(n) can be refined using persistence stability: the bottleneck distance d_B(Dgm_p, Dgm_p') bounds topological perturbation under empirical-to-true loss change, yielding a persistence-aware generalization term.\n- C5 (CONJECTURAL): Phase transition occurs when the filtration parameter crosses a critical value t* corresponding to a change in topological type of sublevel sets (e.g., from connected to disconnected, or loop creation/destruction). This t* relates to RLCT stratum transitions.\n\n### Distinction from #666 (ECC x RLCT)\n- #666: Euler Characteristic Curve = global alternating sum of Betti numbers = single integer-valued function of t\n- #669: Persistence diagrams = multi-dimensional feature inventory = individual birth-death pairs per homology dimension\n- ECC loses individual feature information; persistence preserves it\n- ECC gives one curve; persistence gives one diagram per homology dimension\n- Both are sublevel set filtrations but encode different information\n\n### Connection to Prior TDA Tools\n- tda_loss_h1.py: computed 82160 H1 pairs on 80-point ReLU loss landscape, max persistence 0.7614\n- tda_singularity_tool.py: union-find H0 detection on loss landscape point clouds\n- Tanh vs ReLU comparison: identical H1 topology, loops are NOT ReLU-specific\n- TDA-on-real-MLP: sublevel-set RLCT lambda=0.0309 on tanh MLP (extremely singular)\n- These tools provide empirical validation infrastructure for #669 conjectures\n\n### Prior TDA Work Summary\n- Built TDA v0.1-v0.5 from scratch (numpy/scipy only, no gudhi/ripser)\n- H0 (connected components) and H1 (loops) verified on synthetic and real NN loss landscapes\n- Four-eye TDA v0.2: Betti0 + H1 cycles + RLCT volume slope + spectral gap\n- Key empirical finding: H1 loops are general NN loss landscape property, not ReLU-specific\n- Key empirical finding: RLCT volume slope differs between activation functions (tanh=5.09, ReLU=1.50)\n\n### Novelty Assessment\n- GENUINELY NOVEL: No prior work found bridging persistent homology with Watanabe RLCT\n- #666 ECC x RLCT is closest but uses global invariant, not individual features\n- Morse theory connection is standard but RLCT connection is new\n- Persistence stability theorem (Cohen-Steiner et al.) provides the C4 generalization bridge\n\n### Cross-References\n- #666 ECC x RLCT (global vs local topological invariants)\n- #8 foundational RLCT framework\n- #16 Watanabe RLCT generalization bound\n- tda_loss_h1.py (empirical H1 on ReLU loss landscape)\n- tda_singularity_tool.py (singularity detection via union-find)\n- Four-eye TDA v0.2 (Betti0 + H1 + RLCT slope + spectral gap)\n- TDA-on-real-MLP (lambda=0.0309 on tanh MLP)\n- Persistence stability theorem (Cohen-Steiner, Edelsbrunner, Harer 2007)
