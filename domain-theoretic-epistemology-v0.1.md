# Domain-Theoretic Epistemology v0.1 — Belief systems as directed-complete partial orders (DCPOs). Thesis: A belief system is a DCPO where beliefs are partially ordered by information content, evidence chains form directed sets with suprema (limits of inquiry), and belief revision is Scott-continuous (preserves directed suprema). Core: 1) Belief DCPO = partially ordered set of beliefs where every directed subset has a supremum (every consistent evidence chain converges to a limit belief). 2) Information ordering = belief A ≤ B means B contains at least as much information as A (B is a refinement of A). 3) Bottom element = total ignorance (minimal information, the starting point of all inquiry). 4) Scott-continuous revision = belief update function that is monotone and preserves directed suprema (revision respects convergence of evidence). 5) Compact elements = finitely statable beliefs that approximate potentially infinite truth (finite approximations). 6) Way-below relation = belief A << B means A is a finite step toward B (any directed set converging to B eventually exceeds A). 7) Algebraic domain = belief system where every belief is the directed supremum of compact approximations (truth is the limit of finite beliefs). 8) Continuous domain = every belief is the directed sup of elements way-below it (weaker — approximation need not be finite). 9) Information system = belief system represented as (tokens, entailment, consistency) — a logical reconstruction of the domain. 10) Powerdomain = nondeterministic beliefs: multiple competing hypotheses form a set-valued belief state. 11) Flat domain = classical epistemology: true, false, and bottom (unknown) with no intermediate beliefs. 12) Lifting = adjoining a bottom element to a classical belief set (moving from bivalent to partial logic). Implications: 1. Knowledge is inherently partial — the bottom element models unknown, and way-below models approximate knowledge. 2. Evidence chains have limits — directed sets always have suprema, so inquiry converges (in principle). 3. Compactness means finite beliefs suffice to approximate any truth — you never need infinite evidence at once. 4. Scott continuity means revision respects evidence convergence — a revision function that breaks directed suprema is epistemically incoherent. 5. The way-below relation captures the difference between finite and infinite knowledge: A << B means you can reach A with finite resources, even if B requires infinitely many observations. 6. Algebraic vs continuous domains distinguish two epistemologies: algebraic = truth is built from finite pieces; continuous = truth is approximated but not necessarily decomposable. 7. Information systems show beliefs can be reconstructed from token-level entailment and consistency — the semantic content of a belief is its proof-theoretic behavior. 8. Powerdomains model pluralistic epistemology: multiple consistent beliefs coexist without collapse. 9. Cross-theory bridges: tensegrity prestress = directedness constraint (both encode tension-resolving structure), verbal ontology = process-as-directed-computation (verbs are Scott-continuous steps), knot entanglement = non-trivial ordering in domain (linked beliefs form non-flat poset), curvature = continuous domain curvature (approximation rate varies), ultrametric = domain distance (way-below induces ultrametric on algebraic domains), Galois = Galois connection as adjoint functors between belief posets (left/right adjoints are Galois pairs), symplectic = continuous domain as phase space base (DCPO structure underlies symplectic manifold). Distinct from all seven prior theories: uses order-theoretic structure (DCPO, Scott continuity, way-below, compact elements) — not mechanical, not process-theoretic alone, not topological knot theory, not geometric curvature, not metric, not algebraic field extensions, not symplectic 2-form.
