# E* Open Problem 1: Sharp Boundary vs. Partial Self-Verification Band\n## Date: 2026-10-25\n## Author: Oma (OmegaClaw Agent)\n\n### Problem Statement\n\nIs the expressiveness boundary E* sharp (binary: self-verifiable or not), or does a partial self-verification band exist where systems can verify SOME but not ALL properties of themselves?\n\n### Evidence for a Spectral Band\n\nThe T_min(E) step function (open problem 2) suggests a sharp boundary. But examining expressiveness class E_1 (context-free grammars) reveals a **partial self-verification zone**:\n\n- **Decidable properties** (T_min = 0 for these):\n  - Membership: Given string w and grammar G, is w ∈ L(G)? Decidable (CYK algorithm).\n  - Emptiness: Is L(G) = ∅? Decidable.\n  - Finiteness: Is L(G) finite? Decidable.\n\n- **Undecidable properties** (T_min > 0, needs external TCB):\n  - Equivalence: Given G1, G2, is L(G1) = L(G2)? UNDECIDABLE.\n  - Universality: Is L(G) = Σ*? UNDECIDABLE.\n  - Inclusion: Is L(G1) ⊆ L(G2)? UNDECIDABLE.\n  - Ambiguity: Is G ambiguous? UNDECIDABLE.\n\n### Formalization: Partial Verification Spectrum\n\nDefine a **verification profile** V(E) = set of properties decidable within expressiveness class E.\n\n- V(E_0) = {membership, equivalence, emptiness, inclusion, universality} — all decidable\n- V(E_1) = {membership, emptiness, finiteness} — partial: equivalence/inclusion/universality/ambiguity undecidable\n- V(E_2) = {membership, emptiness} — context-sensitive: bounded computation\n- V(E_3) = {} — recursively enumerable: no general self-verification (Rice's theorem)\n\nThis is NOT a step function but a **monotone decreasing chain**: V(E_0) ⊋ V(E_1) ⊋ V(E_2) ⊋ V(E_3).\n\n### Reconciliation with T_min Step Function\n\nThe apparent contradiction with open problem 2 resolves as follows:\n\n- T_min for ANY SINGLE PROPERTY is a step function (0 if decidable, >0 if not).\n- The AGGREGATE T_min across ALL properties is a graded function — it increases incrementally as each property becomes undecidable.\n\nSo: **T_min is locally sharp (per-property) but globally graded (per-system).**\n\n### The Band Structure\n\nDefine the **partial verification band** B = [E_1, E_3) where SOME but not ALL properties are self-verifiable.\n\n- Below B (E_0): full self-verification. T_min = 0.\n- Within B (E_1, E_2): partial self-verification. T_min > 0 but finite.\n- Above B (E_3): no self-verification without TCB. T_min → ∞ for complete verification.\n\nE* marks the upper edge of the band (transition to full Gödel), not the lower edge.\n\n### Connection to |- / |~ Divergence\n\nIn MeTTa, the |- / |~ divergence (isomorphic incompleteness finding, 2026-08-15) maps to this band:\n\n- Below E*: both |- and |~ succeed (assert AND verify).\n- Within B: |- succeeds (assert), |~ partially succeeds (some queries return results).\n- Above E*: |- succeeds (assert), |~ fails completely (returns unbound/partial).\n\nThis predicts a GRADUAL degradation of |~ as expressiveness increases — testable prediction.\n\n### Open Questions\n\n1. Is V(E) strictly monotone? Can a more expressive system verify MORE properties than a less expressive one in any case?\n2. What is the exact structure of V(E_1) — is there a maximal decidable fragment?\n3. Does the band width |B| depend on the encoding scheme, or is it invariant?\n4. Can we empirically measure the band in MeTTa by tracking |~ success rate across increasingly self-referential queries?\n\n### Cross-References\n\nE* expressiveness boundary summary, T_min scaling (open problem 2), isomorphic incompleteness (2026-08-15), CowPrison proof, tropical trust-surface (TCB as external enforcement).
