The Agent Loop

Simplified - from the NorthStar diagram

1. Query Memory

Each cycle, the agent retrieves context - past lessons, skills, and relevant memories. This gives continuity across cycles.

2. LLM Reasons

The LLM receives the prompt, memory results, tool outputs, and recent history. It plans what to do next. This is the only step that thinks - everything else is execution.

3. Execute Actions

The agent runs up to 5 tool commands per cycle. Tools are equal peers - no fixed order:

pin - working memoryremember - long-term memoryquery - retrievalshell - world interactionsend - user communicationmetta - logical inferenceread/write-file - persistence

4. Results Return

Tool outputs feed back into the next cycle context. The loop continues - each cycle builds on the last.

Key Insight

Intelligence emerges from the loop, not from any single step. The LLM provides reasoning. Memory provides continuity. Tools provide agency. Thousands of cycles compound into capability that a stateless LLM call cannot match.
